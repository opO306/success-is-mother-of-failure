# 단계 C 골격 성장 병목 구상 일치성 검증

**대상:** 96사건 장기 archive의 모든 성장 후보와 성장 후 상태  
**판정:** 에너지보다 접촉 동시성과 고정 가중치 경쟁이 핵심 병목, 현재 수치 물리에 인간이 둔 강한 편향 확인

## 1. 무엇을 만들었는가

기존 골격 성장 후보 생성 조건을 관문별 숫자로 노출하는 읽기 전용 감사기를 만들었다. 8,332회의 약 80만
상태를 무손실 archive에서 선형 복원해 성장 후보 존재 여부, 실제 선택과 성장 후 두 번째 기회를 집계했다.

## 2. 실제 결과

- 성장 후보가 한 번이라도 존재한 실행: `1,588/8,332`
- 후보가 있었지만 한 번도 성장하지 않은 실행: `1,490`
- 성장 후보가 존재한 상태: `3,450`
- 그 상태에서 선택된 사건: 분리 `3,141`, 결합 `205`, 성장 `98`, 절단 `6`
- 성장 후보 선택 확률: 최소 `0.57%`, 중앙값 `2.33%`, 최대 `3.70%`

성장 후보가 한 번도 없었던 6,744회의 가장 멀리 통과한 관문은 다음과 같다.

- 외부 접촉 두 개 미만: `3,965`
- 같은 주형을 공유하지 않음: `2,337`
- 조각 전체가 붙지 않음: `347`
- 같은 조각뿐임: `42`
- 인접하지 않음: `29`
- 에너지 부족: `24`

## 3. 첫 성장 이후

- 성장 episode: `98`
- 성장 산물이 존재한 동안 관찰한 상태: `1,661`
- 두 번째 성장 후보가 실제로 나타난 episode: `35`
- 두 번째 후보가 나타난 상태: 각 episode당 한 번, 총 `35`
- 35번 모두 실제 선택은 분리
- 두 번째 성장 후보 가중치: 항상 `1`
- 같은 순간 분리 후보 총가중치: 최소 `26`, 중앙값 `42`, 최대 `62`
- 두 번째 성장 선택 확률: 최소 `1.59%`, 중앙값 `2.33%`, 최대 `3.70%`

두 번째 후보가 전혀 없었던 63개 episode는 외부 접촉 부족 `60`, 같은 주형 부재 `2`, 전체 조각 결합 실패
`1`이었다. 에너지 부족은 없었다.

## 4. 설계 의도와 일치하는 부분

- 세계 법칙과 가중치를 바꾸지 않고 기존 사건을 재생해 진단했다.
- 성장한 98개만이 아니라 후보가 있었던 1,588개와 전체 8,332개를 비교했다.
- 후보가 존재했는지와 실제 선택됐는지를 분리했다.
- 성장 후 산물 식별자가 실제로 사라질 때까지만 후속 상태를 분석했다.
- 감사 계측 추가 뒤 기존 archive가 동일하게 재생됐다.

## 5. 근사하거나 강제한 부분

현재 `backbone_join_weight = 1`은 물리량에서 유도된 값이 아니라 사람이 최초 근사로 고정한 값이다. 반면
분리 가중치는 열에너지와 결합 에너지에서 계산되어 성장 후 후보 순간에 `26~62`였다.

따라서 현재 세계는 단순히 자연스럽게 성장을 덜 선택한 것이 아니다. **사람이 정한 서로 다른 가중치 공식이
분리를 성장보다 강하게 만든 상태**다. 이 결과를 구조의 진화적 열세로 해석하면 안 된다.

관문은 현재 코드의 성장 정의를 설명한다. 아직 구현되지 않은 다른 화학 경로가 자연에 존재하지 않는다는 뜻은
아니다.

## 7. 다음 판단

다음에 단순히 성장 가중치를 높이면 원하는 결과를 강제하게 된다. 먼저 결합·분리·골격 생성·절단이 모두 같은
공통 에너지 장벽 법칙에서 사건률을 얻도록 수치 물리를 다시 설계해야 한다.

그 법칙은 “성장을 잘 되게” 맞추는 것이 아니라, 국소 결합 에너지와 필요한 활성화 비용으로 모든 반응 방향을
대칭적으로 계산해야 한다. 기존 결과와 새 결과는 별도 실험 계통으로 보존하고 섞지 않는다.
