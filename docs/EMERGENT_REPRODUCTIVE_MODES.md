# 암수·생식 호환성·번식 경향의 창발 설계

**상태:** 장기 설계 명세. 현재 분자 세계에 암수 또는 번식 본능을 직접 추가하지 않음.

## 현재 사실

현재 `engine.sequence`에는 수컷, 암컷, 성별, 짝짓기, 자식을 남겨야 한다는 본능이 없다. 물질의 결합·절단·
재결합만 있으며 부모와 자손도 관찰자가 물질 전달을 확인한 뒤에만 붙일 수 있는 이름이다.

## 왜 지금 암수를 직접 넣지 않는가

지구 생명 전체가 암수 두 성으로 번식하지 않는다. 무성생식, 분열, 출아, 포자, 자가수정, 다수의 교배형,
환경에 따른 성 결정, 성전환 등 여러 방식이 있다. 엔진에 `male`, `female`, `mate_drive`를 기본값으로 넣으면
인간과 일부 동물의 방식을 세계 전체의 절대 규칙으로 강제한다.

## 물리 언어에 필요한 더 낮은 기능

- 서로 다른 물질 조각이 한 새 구획 또는 새 구조에 실제로 함께 전달될 수 있음
- 결합 가능한 표면과 결합 불가능한 표면이 구조에 따라 달라짐
- 같은 구조끼리도 결합할 수 있고, 다른 구조끼리만 결합할 수도 있음
- 물질 교환, 융합, 분리, 재조합에 실제 에너지·시간·위험 비용이 있음
- 상대를 찾고 접근하게 만드는 감각–상태–이동 연결이 진화할 수 있음
- 교환 뒤 생긴 구조가 유지·복제되지 못하면 자연스럽게 사라짐
- 생식 없이도 개체가 살 수 있으나 그 물질 계보는 끝날 수 있음

이 기반에서 두 종류의 상보적 생식 역할이 반복적으로 갈라지면 관찰자가 암수와 비슷한 체계로 해석할 수 있다.
세 종류 이상, 연속적인 역할 차이, 생애 중 역할 전환 또는 무성생식이 나타나도 허용한다.

## 번식 본능의 낮은 수준 표현

`자식을 남겨라`라는 목표를 주지 않는다. 내부 상태, 특정 신호에 대한 접근 경향, 접촉 뒤 몸 상태 변화,
상대별 경험 기억, 물질 방출과 결합 행동이 서로 이어질 수 있게 한다. 그 결과 짝 탐색과 유사한 행동이 비용을
감수하면서 반복되고 물질 계보를 실제로 연장한다면 관찰자가 번식 경향으로 분류한다.

개체가 번식하지 않아 계보가 끝나도 구조하지 않는다. 개체나 세계의 소멸은 유효한 결과이며, 장기 탐색 실행은
아무 물질도 남지 않은 세계만 새 초기조건으로 다시 시작한다.

## 관찰자 분석

- 물질 전달에 기여한 구조의 수와 종류
- 같은 구조끼리와 다른 구조끼리의 결합 성공 분포
- 역할이 고정되는지 환경·나이·상태에 따라 바뀌는지
- 짝 접근 행동의 에너지 비용과 실제 계보 연장 관계
- 무성 경로와 물질 교환 경로의 공존
- 교차 조합별 후속 유지·복제 가능성

분류 이름은 분석 결과이고 사건 가중치에 다시 들어가지 않는다.
