# 자기 해석형 서열 구조 문맥 수치 물리 v0

**상태:** 단계 C 기준 실행기 다섯 번째 조각  
**목적:** 접힌 구조가 고정 기능표 없이 기존 사건의 가능성을 촉진하거나 억제하게 함

## 1. 원칙

구조는 새로운 행동을 실행하지 않는다. 현재 접촉 형상이 기존 사건의 접근 가능성과 머무는 시간을 바꾼다.

```text
점유된 위치      → 다른 사건 접근 불가
접힘 안쪽 주머니 → 재료가 오래 머물러 결합 형성 기회 증가
```

엔진에는 `복제 효소`, `절단 효소`, `활성 부위` 문자열 표를 만들지 않는다.

## 2. 접힘 주머니

한 서열의 두 떨어진 구간이 접촉하면 그 두 접촉면 사이의 노출 구간을 접힘 주머니로 근사한다.

```text
왼쪽 접촉면 ── 노출된 안쪽 구간 ── 오른쪽 접촉면
```

접촉면 자체는 이미 점유되어 다른 사건을 억제한다. 안쪽 구간은 주머니 안에 머무는 공간으로 보고 결합 형성
사건의 체류 배율을 높인다.

## 3. 촉진 대상

현재 주머니 배율은 새로운 결합을 만드는 다음 사건에만 적용한다.

- 서로 다른 서열의 측면 결합
- 기존 접힘 안에서 생기는 추가 접힘
- 주형에 붙은 두 조각의 골격 결합

분리, 풀림과 절단에는 적용하지 않는다. v0의 주머니는 재료를 가까이 머물게 하는 효과만 근사하며 결합을 직접
약화시키거나 골격을 자르는 기능은 갖지 않는다.

## 4. 배율

후보 사건이 사용하는 위치 중 하나 이상이 현재 접힘 주머니 안에 있으면 그 접힘의 결합 에너지를 한 번 더한다.

```text
context_multiplier = min(64, 1 + 관련 접힘 bond_energy 합)
final_weight       = base_weight × context_multiplier
```

두 끝점이 같은 주머니에 있어도 같은 접힘 에너지는 한 번만 더한다. 여러 접힘 주머니가 겹치면 각 접힘의
에너지가 합쳐진다.

상한 64는 정수 가중치 폭발을 막는 실행 한계다. 자연법칙처럼 숨기지 않고 실행기 지문과 사건 기록에 남긴다.

## 5. 억제

억제는 별도 음수 명령이 아니다.

- 접힘 접촉면에 사용된 위치는 다른 결합·접힘·성장 후보가 될 수 없다.
- 외부 서열이 먼저 결합한 위치도 접힘 후보가 될 수 없다.
- 구조가 풀리면 위치는 다시 노출된다.

따라서 같은 서열도 먼저 일어난 사건에 따라 어떤 반응이 촉진되고 어떤 반응이 차단되는지가 달라진다.

## 6. 사건 기록

모든 선택 사건에 다음을 기록한다.

- `base_weight`: 구조 문맥 적용 전 가중치
- `context_multiplier`: 접힘 주머니가 만든 정수 배율

인간 번역기는 이 값으로 “특정 구조가 특정 사건의 발생 기회를 높였다”는 인과를 설명할 수 있지만 그 구조에
본질적인 기능 이름을 붙이지 않는다.

## 7. 현재 근사와 위험

- 실제 3차원 부피 대신 선형 서열에서 두 접촉면 사이를 주머니로 취급한다.
- 후보의 한 위치만 주머니 안에 있어도 전체 후보 가중치를 높인다.
- 주머니 크기와 입구 방향을 고려하지 않는다.
- 재료 농도를 직접 보존하지 않고 사건 가중치로 체류시간을 근사한다.
- 강한 접힘이 촉진도 강하게 한다는 선택은 절대적인 현실 법칙이 아니다.
- 중첩 접힘이 상한에 자주 도달하면 서로 다른 구조 차이가 사라질 수 있다.

## 8. 통과 조건

- 같은 결합 후보가 접힘 주머니 안에서는 더 큰 가중치를 가진다.
- 기본 결합 점수와 최종 가중치를 구분해 기록한다.
- 기호 문자열이나 계통 이름이 배율 계산에 사용되지 않는다.
- 접촉면의 위치 억제는 그대로 유지된다.
- 분리·풀림·절단 기본 가중치는 주머니 때문에 바뀌지 않는다.
- 기록된 최종 가중치로 같은 사건을 재생할 수 있다.
