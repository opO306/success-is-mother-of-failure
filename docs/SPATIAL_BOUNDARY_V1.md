# 2차원 위치와 물리 경계막 v1

## 목적

물질을 사람이 골라 특정 공간에 넣는 대신, 모든 물질에 위치를 주고 실제 이동으로 경계를 통과한 물질만 그
공간 안에 존재하게 한다. 공간의 이름과 용도는 외부 관찰자가 붙이며 세계는 `자손`, `생식세포`, `선택된
유전자`라는 말을 알지 못한다.

## 최소 물리

- 유한한 2차원 정수 격자
- 물질 단위마다 서로 겹치지 않는 한 위치
- 상하좌우 한 칸 이동
- 격자 밖 이동, 장벽 통과, 점유 칸 이동과 결합을 늘이는 이동은 실패
- 장벽이 놓이지 않은 경계 변은 물리적인 틈
- 실패한 이동도 시간을 소비하고 사건 기록에 남음
- 확률 실행은 모든 물질과 네 방향을 성공 여부와 무관하게 균등 표본

관찰자는 직사각형 안의 단위 ID를 읽을 수 있지만 이 질의는 세계 상태나 다음 이동 확률을 바꾸지 않는다.

## 계층 경계

```text
세계 내부: 위치, 이동, 장벽, 틈, 충돌 실패, 시간
세계 외부: 이 영역을 자손 형성 공간이라고 부르는 해석, 진입·이탈 통계
```

## 아직 없는 것

- 연속 공간, 질량, 관성, 힘과 열운동
- 이동의 에너지 비용
- 막 물질의 생성·파괴·휘어짐과 이동
- 크기와 모양에 따른 선택적 통과
- 결합 구조 전체의 병진·회전
- 인접한 물질 사이의 결합 충돌
- 복제, 수정, 자손 발생

특히 v1은 결합된 구조를 한 단위씩 움직이지 못하게 하므로 큰 구조의 이동을 지나치게 억제한다. 이는 이후
구조 전체의 국소 이동이나 힘 전달을 구현하기 전까지 명시적으로 남겨야 할 근사다.
