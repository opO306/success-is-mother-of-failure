# B가 A를 만드는 결정론적 세계 제작 언어 — 심화 설계 v1

상태: 구현 전 설계 초안  
목적: 확률 기반 scheduler-v1과 결과를 섞지 않는 새 `deterministic-kernel-v1` 계통 정의

## 1. 한 문장 목표

> 학습하고 진화하는 세계 제작 언어 B가 사람의 구상을 예외 없는 결정론적 물리 명세로 번역해 세계 A를 만들고, A는 실행 중 B의 개입 없이 독립적으로 역사를 만든다.

## 2. 전체 관계

```text
사람의 구상과 방향
        ↓
B: 진화하는 세계 제작 언어
        ↓
A 명세: 공간·물질·환경·국소 법칙·초기 상태
        ↓
불변 검증 헌법
        ↓
A: 결정론적 세계 실행
        ↓
읽기 전용 관찰기
        ↓
원시 기록·계보·실패·환경별 결과
        ↓
외부 평가와 인간 검토
        ↓
B의 복제본 수정·검증
        ↓
다음 B 버전이 다음 A 세계군 제작
```

B와 A는 별개의 목표가 아니다. **B가 A를 만드는 하나의 시스템**이다. 다만 A가 실행되는 동안 B가 결과를 바꾸지 못하도록 권한을 분리한다.

## 3. 세 구성요소

### 3.1 A — 결정론적 세계

A는 다음을 포함한다.

- 정확한 초기 상태
- 공간과 지형
- 물질 종류와 물성
- 위치·방향·속도·에너지
- 충돌·결합·절단·에너지 전달 규칙
- 물·열·광물·빛·흐름
- 실행 시간과 경계조건

A에는 난수 추첨이 없다. 같은 명세와 같은 초기 상태는 항상 같은 전체 역사를 만든다.

### 3.2 B — 진화하는 세계 제작 언어

B는 다음을 수행한다.

- 자연어 구상을 물리적 요구사항으로 분해
- 역사·과학 자료에서 환경 범위 정리
- A 명세 작성
- 계산 방법과 해상도 선택
- 검증 실패 원인 분석
- 복제본에서 자신의 번역·설계 구조 수정
- 성공·실패 설계 경험 보존

B는 실행 중인 A를 수정하지 않는다.

### 3.3 불변 검증 헌법

이것은 또 다른 지능이나 세계가 아니라 B의 권한 밖에 있는 고정 검증 계층이다.

B가 바꾸지 못하는 것:

- 물질·에너지 회계 검사
- 인과 순서 검사
- CPU·GPU 동일성 검사
- 금지된 고수준 명령 검사
- 기록 해시와 계보 무결성
- 실행 중 명세 변경 금지
- 외부 평가 데이터
- B 승격 승인 규칙
- 부모 B 버전과 A 결과 삭제 금지

## 4. 결정론의 정확한 의미

### 4.1 허용하지 않는 것

- 사건 가중치 추첨
- 실행 중 난수
- 확률적 복사 오류
- 확률적 충돌 결과
- seed가 다음 사건을 선택하는 구조

### 4.2 허용하는 차이

다른 역사는 다른 초기 상태와 환경에서 나온다.

```text
물질 하나의 위치 차이
→ 첫 충돌 차이
→ 결합 순서 차이
→ 구조와 환경 변화
→ 장기 역사 차이
```

### 4.3 결정론적 실험군

여러 가능성을 조사할 때 난수를 쓰지 않고 사전 정의된 초기 조건 목록을 사용한다.

- 위치를 일정 규칙으로 조금씩 이동
- 온도·농도·지형 범위를 격자로 분할
- 서로 다른 초기 충돌 방향 열거
- 저편향 결정론적 표본 순서 사용
- 모든 초기 조건을 결과 전에 해시로 봉인

결과를 본 뒤 유리한 초기 조건만 남기지 않는다.

## 5. A의 공간과 시간

### 5.1 고정 물리 tick

A의 시간은 컴퓨터 실행 시간이 아니라 고정된 물리 단계다.

```text
physical_tick = 0, 1, 2, 3, ...
```

모든 세계는 같은 tick 수만큼 비교한다. 컴퓨터가 느린 세계도 더 적은 물리시간을 경험하지 않는다.

### 5.2 공간 분할

초기 구현은 2차원 정수 격자로 시작한다. 격자를 겹치지 않는 작은 블록으로 나눈다.

예: 2×2 블록

```text
1단계: (0,0)에서 시작하는 블록 묶음
2단계: 한 칸 이동한 블록 묶음
3단계: 다시 원래 묶음
```

각 단계에서 한 블록은 이웃 블록과 칸을 공유하지 않는다. 따라서 GPU가 수천 블록을 동시에 계산해도 충돌이 없다.

### 5.3 이중 버퍼

```text
현재 상태 버퍼
→ 모든 블록 계산
→ 다음 상태 버퍼
→ 완성 뒤 교체
```

계산 중 일부 지역의 새 상태가 다른 지역에 먼저 보이는 문제를 막는다.

### 5.4 격자 방향 편향 방지

고정 블록 경계가 특정 방향을 유리하게 만들 수 있으므로 다음을 검사한다.

- 블록 시작 위치 교대
- 회전한 초기 상태 비교
- 좌우·상하 반전 상태 비교
- 평행이동한 상태 비교
- 격자 해상도 변경 수렴 검사

## 6. A의 물질 단위

각 물질 단위는 최소한 다음 물리 상태를 가진다.

```text
material_kind
position
movement_direction
momentum_or_speed
stored_energy
orientation
bond_ports
current_bonds
```

직접 넣지 않는 값:

```text
alive
cell
gene
fitness
intelligence
instinct
memory
reproduction_success
```

이 이름들은 관찰 결과로만 사용할 수 있다.

## 7. 결정론적 이동

### 7.1 기본 이동

각 물질은 현재 방향과 속도에 따라 이동한다. 이동 여부를 추첨하지 않는다.

### 7.2 충돌

같은 블록에서 물질이 만나면 다음 현재 상태로 결과가 결정된다.

- 입사 방향
- 상대 속도
- 물질 종류
- 결합면 방향
- 저장 에너지
- 주변 공간
- 기존 결합

### 7.3 구조 크기

큰 연결 구조가 구성원 수만큼 이동권을 얻지 않는다. 구조 전체의:

- 총질량
- 운동량
- 모양
- 주변 매질 저항

에 따라 이동 결과를 계산한다.

### 7.4 운동량과 에너지

충돌 전후에 다음을 검사한다.

- 총 물질량
- 총 운동량 또는 명시적 격자 운동량
- 총에너지

마찰·점성으로 줄어든 운동에너지는 열이나 매질 에너지로 이동하며 사라지지 않는다.

## 8. 결정론적 결합과 화학

### 8.1 결합 조건

결합 확률을 두지 않는다. 다음 조건이 모두 맞으면 결합한다.

- 실제 접촉
- 호환되는 물성
- 맞는 방향
- 필요한 활성화 에너지
- 결합 후 허용되는 공간 구조

### 8.2 결합하지 않는 경우

- 에너지 부족
- 방향 불일치
- 포트 점유
- 공간 충돌
- 물성 불일치

결합하지 않은 입자는 정해진 충돌 법칙에 따라 튕기거나 에너지를 교환한다.

### 8.3 가역 반응

정반응과 역반응을 별도 특혜로 만들지 않는다.

```text
반응물 구조 + 에너지
↔ 중간 구조
↔ 생성물 구조 + 방출 에너지
```

각 중간 구조가 실제 상태로 존재하므로 반응은 중간에 멈추거나 되돌아갈 수 있다.

### 8.4 촉매

촉매는 성공 확률을 높이는 숫자가 아니다.

- 반응물을 특정 방향으로 붙잡음
- 중간 구조를 안정화
- 필요한 활성화 에너지를 낮추는 실제 경로 제공
- 반응 후 원래 구조로 돌아갈 수 있음
- 손상·분해·오염 가능

### 8.5 농도 효과

농도라는 전역 숫자로 성공률을 정하지 않는다. 실제로 가까이 있는 물질 수가 충돌 횟수를 바꾼다.

```text
물질이 많은 지역
→ 실제 충돌이 많음
→ 반응이 빠르게 진행

물질이 적은 지역
→ 다음 재료가 도착할 때까지 중간 구조 대기
```

## 9. 여러 단계 과정

복사·막 성장·분열을 하나의 사건으로 만들지 않는다.

### 9.1 서열 성장 예시

```text
빈 끝 형성
→ 단량체 접근
→ 방향 맞춤
→ 임시 접촉
→ 에너지 전달
→ 골격 결합
→ 다음 끝 노출
```

모든 단계는 실제 구조 변화다.

### 9.2 먼저 시작해도 늦게 끝날 수 있음

과정 A가 먼저 시작했더라도:

- 재료 부족
- 에너지 부족
- 촉매 손상
- 경쟁 구조의 자원 소비
- 중간 결합 해제

때문에 멈출 수 있다.

나중에 시작한 과정 B가 자원과 에너지가 풍부하면 먼저 완성될 수 있다.

### 9.3 고수준 진행률 금지

`replication_progress = 0.7` 같은 목적 변수를 넣지 않는다. 실제 중간 구조와 소비된 자원이 진행 상태다.

## 10. 결정론적 변이와 진화

### 10.1 변이 발생

변이는 난수 명령이 아니라 실제 충돌 역사에서 생긴다.

- 원래 재료보다 다른 재료가 먼저 도착
- 방향이 맞는 다른 물질이 결합
- 에너지 충격으로 절단
- 광자·열·광물 표면 때문에 구조 변형
- 복사 중간체가 다른 구조와 충돌

### 10.2 같은 조건의 반복

초기 상태 전체가 같으면 변이도 같은 위치에서 같은 방식으로 발생한다.

### 10.3 진화

세계는 좋은 변이를 고르지 않는다.

- 구조가 유지될 수도 있음
- 즉시 분해될 수도 있음
- 빠르게 복사하고 자원을 고갈시킬 수도 있음
- 기능을 잃고 단순해질 수도 있음
- 기생 구조가 될 수도 있음

외부 관찰기만 계보와 장기 결과를 기록한다.

## 11. 독립 막 분열

현재 scheduler-v1의 `fold → 두 공간 → unfold`는 독립 분열이 아니다.

결정론 A에서 필요한 실제 경로:

```text
순환 경계 성장
→ 경계 두 부위의 물리적 접촉
→ 접촉 부위의 에너지·방향 조건 충족
→ 두 골격 결합의 절단
→ 네 끝의 국소 재결합
→ 두 개의 독립 순환 경계
```

가능한 실패:

- 한쪽만 봉합
- 열린 경계 생성
- 내용물 누출
- 즉시 재융합
- 경계 전체 붕괴

`DIVIDE_CELL` 명령은 없다.

## 12. 초기 지구 환경 계층

### 12.1 하나의 정답 지구를 만들지 않음

LUCA 이전 지구의 정확한 환경은 확정되지 않았다. B는 공개 연구에서 허용되는 범위를 정리해 여러 환경군을 만든다.

후보 환경:

- 해저 열수구
- 얕은 연못과 건습 반복
- 화산성 해안
- 다공성 광물 내부
- 얼음 아래 농축 지역

### 12.2 지역별 지형과 자원

각 위치에 다음이 다를 수 있다.

- 물 깊이와 흐름
- 온도
- 압력
- 광물 종류
- 용질과 기체
- 빛·자외선
- 열과 화학 에너지
- 산성·알칼리성에 해당하는 물성
- 산화·환원 상태
- 증발·강수·조석 주기

### 12.3 자원의 생성·이동·고갈

자원은 고정 보급 상자가 아니다.

```text
광물 풍화·용해
→ 물질 방출
→ 물과 열 흐름으로 이동
→ 광물 표면에 흡착·농축
→ 반응에서 소비
→ 침전 또는 다른 지역으로 이동
```

모든 공급원과 배출구는 물질·에너지 회계에 포함한다.

### 12.4 역사적 지구 모드와 일반 세계 모드

- **Earth-analogue mode:** 알려진 초기 지구 범위 안에서 명세 생성
- **Open-world mode:** 지구와 다른 법칙·환경에서도 발생 가능성 탐색

두 결과는 섞지 않는다.

## 13. CPU와 GPU 역할

### 13.1 CPU 기준 구현

먼저 단일 CPU에서 느리지만 명확한 참조 구현을 만든다.

역할:

- 국소 규칙의 기준 결과
- 보존 검사
- 계보 기록
- 구조 연결성
- GPU 결과 검증

### 13.2 GPU 구현

GPU는 같은 국소 규칙을 많은 블록에 동시에 적용한다.

적합한 작업:

- 입자 이동
- 겹치지 않는 블록 충돌
- 열·용질 전달
- 광물·물·빛 field 업데이트
- 여러 독립 세계 동시 계산

### 13.3 GPU에서 피할 것

- 순서가 정해지지 않은 부동소수점 합산
- 여러 thread가 같은 상태를 동시에 수정
- 하드웨어마다 결과가 달라지는 원자적 연산
- 충돌 시 먼저 실행된 thread가 이기는 구조

### 13.4 비트 단위 동일성

가능하면 정수·고정소수점 연산을 사용한다.

통과 조건:

```text
같은 A 명세
+ 같은 초기 상태
+ 같은 tick 수

CPU 최종 해시 == GPU 최종 해시
CPU 사건 해시 == GPU 사건 해시
```

GPU가 빠르지만 다른 세계를 만들면 최적화로 인정하지 않는다.

## 14. 관찰기

관찰기는 A의 물리 상태를 읽지만 수정하지 않는다.

기록:

- 물질 단위 계보
- 결합·절단 원인
- 고분자 복사 계보
- 구획 생성·분열·융합·소멸
- 중간 구조 유지 시간
- 지역별 자원 흐름
- 촉매 경로
- 결정론적 변이 원인
- CPU·GPU 해시

관찰용 ID와 이름은 A의 계산에 들어가지 않는다.

고수준 현상은 사후 판정한다.


## 17. B의 자기관찰과 자기수정

### 17.1 자기관찰

B는 자신의 모든 숫자를 그대로 읽는 대신 고수준 상태를 본다.

- 어떤 요청을 자주 오해했는가
- 어떤 규칙이 검증에서 자주 거부됐는가
- 어떤 모듈이 계산량을 많이 쓰는가
- 어떤 설계가 미지 환경에서 실패했는가
- 어떤 과거 경험을 재사용했는가
- 어떤 변경이 후속 설계를 개선했는가

### 17.2 구조 변경 후보

초기에는 제한된 변경 언어만 허용한다.

```text
ADD_REASONING_STAGE
REMOVE_UNUSED_STAGE
SPLIT_RESEARCH_ROLE
ADD_CONSTRAINT_CHECK
CHANGE_MEMORY_ROUTING
ADD_ENVIRONMENT_MODEL
FREEZE_MODULE
ROLLBACK_VERSION
```

B가 임의 코드를 자신의 본체에 바로 덮어쓰지 않는다.

### 17.3 복제본 실험

```text
현재 B는 불변
→ B' 복제
→ B' 구조 변경
→ B와 B'가 같은 숨겨진 설계 과제 수행
→ 결과 비교
→ 외부 승인
```

### 17.4 평가 항목

- 사람의 의도 번역 정확성
- 물리 헌법 준수
- 숨은 결과 강제 여부
- 알려지지 않은 환경으로의 적용
- CPU·GPU 동일성
- 설계 비용과 실행 비용
- 실패 설명의 정확성
- 과거 설계 복사 여부가 아닌 실제 일반화

## 18. 외부 평가

### 18.1 A 내부 존재의 외부 현실

A 내부 구조의 외부 평가는 별도 점수가 아니라 실제 환경이다.

- 자원 획득·고갈
- 충돌과 손상
- 에너지 비용
- 구조 유지·붕괴

A 내부에는 fitness 점수를 넣지 않는다.

### 18.2 B의 외부 평가

B는 실제로 제작 도구이므로 외부 평가가 필요하다.

평가 계층:

1. 고정 물리 헌법
2. 공개되지 않은 A 설계 과제
3. CPU 참조 결과
4. 다른 환경·크기·해상도 검사
5. 기존 연구와의 비교
6. 인간 설계자 검토

### 18.3 discovery mode에서 금지되는 평가

다음은 B 승격 기준으로 사용하지 않는다.

- 생명이 더 자주 나왔는가
- 세포가 더 오래 살았는가
- 복제가 더 많이 됐는가
- 복잡성이 증가했는가

그것을 승격 점수로 쓰면 B가 생명이 잘 나오는 세계를 몰래 설계하게 된다.

발견 모드의 B는 다음으로 평가한다.

- 요청한 물리 자유도를 정확히 표현했는가
- 법칙이 일관되고 예외가 없는가
- 결과를 강제하지 않았는가
- 검증과 기록이 가능한가

## 19. 버전과 권한

### 19.1 봉인 단위

모든 A 실행은 다음을 가진다.

- B 버전과 해시
- A 명세와 해시
- 컴파일러 해시
- CPU·GPU 실행기 해시
- 초기 상태 전체 해시
- tick 수
- 관찰기 해시
- 외부 평가 버전

### 19.2 실행 중 금지

- B가 A 명세 수정
- 관찰기가 A 상태 수정
- 실패 결과 삭제
- A 결과를 보고 초기 상태 변경
- GPU와 CPU의 다른 결과 허용

### 19.3 B 승격

B'가 통과해도 기존 B를 삭제하지 않는다.

```text
B v1 → B v2 후보
     ↘ B v1 유지
```

필요하면 언제든 과거 버전으로 돌아갈 수 있다.

## 21. 첫 프로토타입 범위

첫 구현에서는 초기 지구 전체를 만들지 않는다.

```text

반응: 이동·충돌·결합·분리만
CPU 참조 구현 우선
```

첫 질문:

> 무작위 없이 국소 충돌 규칙만으로 지속되는 구조와 다양한 결정론적 역사가 가능한가?

생명·복사·진화 주장은 하지 않는다.

## 23. 연구상 위치

결정론적 셀룰러 오토마타와 자기복제·진화, 분할 셀룰러 오토마타, 분자동역학, 자기수정 신경망은 각각 선행연구가 있다.

이 프로젝트의 차별화 후보는 다음 전체 연결이다.

```text
결정론적 보존 물리
→ 근거 기반 초기 지구 환경
→ 생명 이전 구조 출현
→ 유전·학습·자기개조의 연속 발생
→ 이를 제작하는 B의 자기관찰·외부평가·진화
```

신규성은 개별 알고리즘이 아니라 이 연결을 실제 증거로 완성할 때 판단한다.

## 24. 최종 원칙

1. B가 A를 만든다.
2. A는 실행 중 B와 분리된다.
3. A의 물리에는 난수가 없다.
4. 큰 과정은 작은 물리 사건의 인과 사슬로만 나타난다.
5. B는 복제본에서만 자신을 수정한다.
6. B의 내부 평가만으로 새 버전을 승격하지 않는다.
7. 외부 평가와 인간 검토는 A의 실행 결과를 조작하지 않는다.
8. 성공뿐 아니라 실패·퇴화·소멸을 모두 보존한다.
9. CPU는 기준 진실, GPU는 동일 결과를 빠르게 계산한다.
10. 결정론이라는 이름으로 임의 규칙을 숨기지 않는다.
