# Reality-Constrained Microstate Preparation Contract V0

2026-10-02 · DESIGN / RESEARCH ONLY · PROPOSAL · DESIGNER APPROVAL PENDING

문서 이름의 Contract는 검토할 계약 초안을 뜻한다. 실행 계약·헌법 해석·initializer 승인·C1-C production 확정이 아니다. **기존 파일럿 판정 E — REALITY_DATA_INSUFFICIENT를 유지한다. A/B/C로 승격하지 않는다.** M1–M4 중 어떤 방법도 최종 선택하지 않는다.

## 1. 설계자가 먼저 판단할 여덟 질문

1. **현실 자료만으로 실제 미시상태 하나를 알 수 있는가?** 온도·밀도·구조 통계만으로는 일반적으로 알 수 없다. 모든 원자의 위치와 움직임을 따로 측정한다는 더 강한 조건도, 측정 오차와 측정 중 상태 변화의 문제를 가진다.
2. **자료를 충분히 모으면 유일한 위치·운동량이 결정되는가?** 나열된 거시·구조 통계를 더 정확히 모으는 것만으로는 일반적으로 결정되지 않는다. 통계가 아니라 개별 상태를 구별하는 추가 관측이 필요하며, 무한 정확도의 동시 위치·운동량은 양자 측정의 뜻과도 맞지 않는다.
3. **우리가 추가로 선택해야 하는 것은 무엇인가?** 어떤 현실 준비 상태를 모델로 삼을지, 남은 자유도를 어떻게 채울지, 한 상태를 쓸지 여러 상태를 보존할지, 무엇을 어느 오차까지 대표해야 하는지를 선택해야 한다.
4. **하나를 canonical하게 선택하면 어떤 인공성이 생기는가?** 규칙적인 거리·방향·반대 운동량 짝, 위치와 속력의 결합, 좌표축·정렬에 따른 상관이 생길 수 있다. 반복 가능하다는 사실만으로 이런 선택이 현실적이 되는 것은 아니다.
5. **ensemble은 얼마나 줄일 수 있는가?** 서로 다른 선택의 영향을 드러내고 한 상태만 잘 골라 보여 주는 편향은 줄일 수 있다. 그러나 같은 편향을 공유한 상태를 많이 모으면 대표성이 생기지 않는다. 대상 분포·가중치·다양성과 오차 확인이 필요하다.
6. **physical preparation이 더 현실적인가?** 실제 용기·주변 물질과의 상호작용을 근거 있게 모델링하면 준비 과정을 더 잘 설명할 수 있다. 단순 온도 보정 장치는 그 근거를 대신하지 못하며, 환경 모델과 긴 준비 시간의 비용만 늘릴 수도 있다.
7. **가장 먼저 시험할 가치가 있는 방향은 무엇인가?** 승인 후의 저비용 연구로는 M2와 M3를 같은 조건에서 비교하여, 미시상태 선택 때문에 초기 통계가 얼마나 달라지는지 확인하는 설계가 우선 가치가 있다. 미래 궤적 결과의 강건성 비교는 C1-C 실행 계약이 준비된 뒤의 별도 단계다. 이번에는 시험도 실행하지 않고 어느 쪽도 production으로 승인하지 않는다.
8. **반드시 설계자가 해야 하는 결정은 무엇인가?** 실제 관측 상태가 필수인지, 현실과 양립하는 생성 상태를 허용할지, 무엇을 대표해야 할지, 허용 오차·준비 범위·ensemble 비용과 실패 처리 범위를 결정해야 한다.

## 2. 핵심 문제: 자료 부족과 비유일성은 별개다

[기존 파일럿](REALITY_CONSTRAINED_DETERMINISTIC_INITIAL_STATE_V0.md)은 같은 실험 상태점의 밀도/EOS·동위원소·구조 통계를 확보하지 못했다. 이는 **입력 자료의 부족**이다. 자료가 모두 확보된 경우에도 그 통계에서 하나의 실제 q,p로 돌아가는 역문제가 유일하다는 보장은 없다. 이는 **정보가 여러 상태를 구별하지 못하는 문제**다. 두 문제를 서로의 해결로 취급하지 않는다.

실험 조건 C가 가능한 상태들을 제한한다고 쓰면, `C → 허용 상태 집합`과 `C → 특정 상태의 유일한 복원`은 다르다. 또한 허용 상태 집합을 안다고 각 상태의 현실적 비중까지 아는 것은 아니다. 비유일성은 준비 연구의 이유이지, 관측된 q,p가 없으면 어떤 모델 세계도 시작할 수 없다는 결론은 아니다. 생성 상태 허용 여부는 미승인 설계 판단이다.

### 2.1 통계를 보존하면서 달라지는 상태

다음은 실행하지 않은 모델 수준의 논증이다. 같은 질량의 Ar 입자들에 대해 위치를 그대로 두고 두 입자의 서로 다른 운동량 벡터만 교환하면, 전체 운동에너지·총운동량·속력 목록·number density·조성·위치 기반 g(r)와 S(q)는 그대로다. 하지만 어느 위치의 원자가 어느 쪽으로 움직이는지가 달라진다. 위치와 운동량 레코드 전체를 함께 재명명한 것이 아니므로 일반적으로 물리 상태는 다르다. 추가 q-p 관측이 이런 교환을 구별할 수 있지만 위 목록만으로는 못 한다.

따라서 **실제 모든 위치를 안다고 해도 온도나 속력 분포만으로 운동량 배정이 유일해지지 않는다.** 온도 자체도 보통 ensemble/평형의 매개변수이며 작은 N의 순간 운동에너지를 고정하는 전체 상태 지도는 아니다. 정확한 COM=0 또는 고정 K를 추가하면 가능한 집합은 줄지만 그 추가 제약의 현실 준비 근거가 필요하다.

### 2.2 구조 통계도 개별 구조의 식별자가 아니다

동일한 산란 가중치·균질성·정규화 조건 아래 g(r)와 정적 S(k)는 두 점 상관의 실공간/파수공간 표현으로 연결된다. 이를 서로 독립인 완전한 원자 지도 두 개로 취급하지 않는다. 실제 유한 창·분해능·다성분 가중치·k=0 및 유한계 보정은 별도다. 이 문서의 k는 파수이며 원자 위치 q와 구별한다. [IUCr, liquid-state theory §4, 식31–33](https://journals.iucr.org/j/issues/2021/02/00/in5043/)

서로 다른 점 집합이 같은 autocorrelation/회절을 갖는 homometry의 수학적 예가 있다. 이는 pair 통계의 완전한 관측도 일반적인 구조 유일성을 보장하지 않는다는 반례다. 해당 논문은 준결정 등에서 논증하며, **이번 Ar 기체의 특정 두 상태를 실험으로 확인한 논문은 아니다.** [Grimm·Baake, Homometric Point Sets and Inverse Problems, 서론·§2](https://arxiv.org/pdf/0808.0094)

평형 pair correlation에서 조건부로 pair potential을 추정하는 inverse Henderson 문제의 유일성 결과도 **한 번의 미시상태 유일성**이 아니다. 이번 단계에서 그런 역문제를 사용해 동결 Ar 법칙을 재추정하지 않는다. [Frommer·Hanke, inverse Henderson 연구](https://arxiv.org/abs/2204.09293)

고차 구조 통계를 더 얻으면 제약은 강화될 수 있다. 그러나 정적 주변분포 일부가 전체 위치·운동량 결합분포를 정한다는 보장은 없다. 설령 전체 ensemble 법칙을 알더라도, 그 법칙에서 특정 실제 실현 하나를 식별하는 것은 별도 정보다.

## 3. 증거 등급과 A 경계 — 서로 자동 승격하지 않는다

| 구분 | 정확한 의미 | 아직 뜻하지 않는 것 |

| 현실에서 직접 관측한 microstate | 선언된 시각·시료에서 얻은 개별 관측과 분해능·불확실성·교란 기록 | 무한 정확도의 모든 고전 q,p |

기존 조건부 후보는 `CONDITIONAL_ASSUMED_PROXY_ONLY / NOT AN OBSERVED MICROSTATE`로 유지한다. 이름 `REALITY_CONSTRAINED_GENERATED_STATE`만으로 모든 현실 제약을 만족했다고 읽지 않는다. 위 증거 구분은 현재 `EXECUTED / REPLAY_VERIFIED / CERTIFIED` 실행 등급과도 별개의 축이다. 비트 재현·수치 검증은 현실성·대표성의 대체 증거가 아니다.

ensemble의 μ나 가중치는 **외부 준비·비교를 서술하는 통계 개념의 후보**다. A의 운동 법칙에 난수·확률 선택을 넣는 제안이 아니다. 각 A 역사에는 결정된 초기상태와 법칙만 전달하는 구조를 검토한다. 그렇더라도 RULES의 A 확률분포 금지와 양립하는 정확한 준비 경계는 설계자 승인 전 PENDING이다. 이 문서가 헌법 해석의 예외를 만들지 않는다.

여러 초기 세계는 설계자·외부 감사의 별도 역사다. ensemble 평균 상태를 세계에 넣거나 다른 역사끼리 물질·정보를 교환하지 않는다. **B에게 상태 복제·되감기·현실 데이터·ensemble 내부 지도를 제공하지 않는다.** 헌법 제24/26조와 RULES의 B 독립 표본 원칙을 유지한다.

M1–M4 모두 (1) 실제 필요한 문제인가 → (2) 규모를 늘리면 무엇이 깨지는가 → (3) CPU/GPU/메모리/검증·증명/유지보수 비용 → (4) 더 싼 구조 → (5) 그래도 필요할 때 장점 순서로 비교한다. 숫자 점수로 승자를 만들지 않는다. 비용은 구조식이며 초·원·GPU 가속률은 미측정이다.

## 5. M1 — Observed Microstate

**1. 필요성.** 특정 실험 사건의 재현이나 계측 장치와의 개별 상태 비교가 목적이면 가치가 있다. 일반 기체 물성을 모델링하는 데 실제 관측된 한 실현만 필수라는 전제는 별도 정당화가 필요하다. 목표가 통계 비교라면 엄격한 M1을 요구하는 비용이 질문과 맞지 않을 수 있다.

**2. 측정 가능성과 규모 한계.** 무한 정확도의 동일 순간 모든 q,p를 측정한다는 뜻의 M1은 양자역학적 상태 준비/관측과 맞지 않는다. 위치·운동량 표준편차에는 σqσp≥ħ/2 제약이 있다. 이는 장치의 모든 오차·교란 곱에 그대로 적용하는 공식이 아니며, 고전 유효모델에 정확한 숫자를 지정할 수 없다는 뜻도 아니다. **정확한 A 숫자는 모델 표현이며 현실의 무한 정밀도 측정 기록이 아니다.** [Coles 등, Rev. Mod. Phys. 89, 015002, 서론·§V 식255](https://link.aps.org/accepted/10.1103/RevModPhys.89.015002)

유한 해상도의 개별 원자 관측은 실제로 존재한다. 40K 광학 격자 원자 영상은 냉각하면서 위치 점유를 관측하며 영상 과정이 운동 상태에도 영향을 준다. 이를 200–300 K의 자유로운 중성 Ar 기체의 교란 없는 전체 q,p 동시 관측으로 옮길 수는 없다. [Cheuk 등, 원 논문 첫 페이지의 영상/냉각 설명](https://arxiv.org/pdf/1503.02648)

COLTRIMS는 반응으로 생긴 전하 조각들의 비행시간·검출 위치에서 3차원 운동량을 재구성한다. 연구팀은 냉각 표적의 이온 운동량 분해능 0.05 a.u.를 소개한다. **검출판의 위치는 원래 중성 기체의 원자 좌표 지도가 아니며**, 이 기술은 용기 속 모든 중성 Ar 원자의 반응 전 q,p를 같은 순간 비파괴적으로 얻는 방법이 아니다. [Frankfurt 실험팀의 장치 설명](https://www.atom.uni-frankfurt.de/research/10_COLTRIMS/)

작은 N은 원자 누락·분리·동기화의 장치 부담을 줄이지만 정확한 동시 q,p 문제를 없애지 않는다. 이번 제한된 조사에서는 Small-A N=4–64의 해당 온도 Ar 전체 상태를 필요한 해상도로 얻는 실증 방법을 확인하지 못했다. **유한 정확도 관측까지 근본적으로 불가능하다고 결론내리지는 않는다.** 필요한 δq·δp·시간 창은 관측량별 허용 오차와 모델 유효 범위가 미결이므로 숫자로 확정할 수 없다. 최소한 시간 창 동안의 이동, 입자 누락, 같은 시각의 q-p 대응, 측정 후 바뀐 상태와 원래 상태의 구분을 검토해야 한다.

기존 FX 위치/운동량 격자의 간격은 a0/2⁴⁸와 (ħ/a0)/2⁸⁰이다. 이 격자를 현실 계측 정밀도로 요구하지 않는다. 측정 불확실성 구간에서 모델 값을 하나 고르는 순간 이미 추가 준비 규칙이 생긴다. 더 많은 원자를 측정해도 그 불확실성이 A의 모든 원시 비트를 자동으로 결정하지 않는다.

**3. 비용.** 계측·시료 준비·동시성·교란 보정·누락 검증이 선행 비용이다. 상태 목록 자체는 O(N)이지만 all-pair 모델 적합성 진단은 O(N²), 허용 오차 전파는 별도다. GPU는 알려지지 않은 실제 상태를 복구하지 못한다. 증명은 측정 불확실성→모델 적합성 경로를 포함해야 하며, replay만으로 계측 오류를 없앨 수 없다. 유지보수는 장치 교정·좌표틀·단위·시각·동위원소·측정 모델에 의존한다.

**4. 더 싼 구조.** 개별 상태 요구를 완화하여 측정한 통계와 불확실성 집합을 준비 입력으로 사용하는 M2/M3를 검토한다. 이는 비용 절감 후보이면서 주장 자체의 변경이므로 승인 없이 M1 성공으로 대체하지 않는다.

**5. 장점.** 선언된 분해능 내에서 특정 관측 사건과 비교할 수 있다. 장치·준비 과정의 현실 근거가 강해질 수 있으나, 한 관측 상태가 전체 기체의 대표라는 증거는 아니다.

## 6. M2 — Single Canonical Reality-Compatible Microstate

**1. 필요성.** 한 역사를 정확히 재생하고 실행기 결함을 대조하는 데 단일 입력은 유용하다. 그 재현성 요구를 현실의 유일한 상태 요구와 구분한다. 물성/발생 가능성의 대표성을 묻는다면 단일 선택의 영향 평가가 따로 필요하다.

**2. 규모 한계와 추가 선택.** N·부피/준비 창·ensemble 종류·COM/에너지 제약·유한 통계 허용 오차·위치 생성·속력/방향/위치 결합·동위원소 개수 배정·tie 규칙·기준 좌표틀이 필요하다. 평균 동위원소 분율이 작은 N에서 정수 개수를 유일하게 주지 않는다. 작은 N의 discrete pair 목록을 매끈한 실험 g(r)에 점별로 정확히 맞추는 것도 일반적인 합격 조건이 될 수 없다.

선택 규칙은 세 가지로 표시해야 한다: **현실 준비 과정의 모델 / 통계 근거 있는 외부 구성법 / 재현을 위한 표준화**. 표준화는 새 운동 법칙은 아니지만 초기 상관을 정하므로 후속 물리에 영향을 줄 수 있다. 모든 추가 규칙을 무해하다고 숨기지 않는다. 반대로 초기조건의 선택 전부를 새 물리 법칙이라고 혼동하지도 않는다.

label 재명명·저장 행 변경은 물리 레코드 집합을 바꾸면 안 된다. 좌표축은 실제 용기/장치 방향이면 선언된 물리 조건이고, 임의 축이면 방향 편향의 원인이 될 수 있다. 모든 대칭을 엄밀히 보존하면서 한 비대칭 상태를 유일하게 선택할 수 있다고 약속하지 않는다. 필요하면 물리 대칭 아래 동치인 상태를 구분하는 gauge와, 실제 상관을 만드는 q-p 배정 규칙을 따로 기록한다. 격자 표현의 회전 한계도 준비 문제와 실행기 문제로 분리한다.

기존 파일럿의 격자·평면, 두 octant 집중, antipodal pair, 속력-z 상관, 정렬로 생긴 q-p 상관은 선택 규칙의 반례다. 해당 알고리즘을 'canonical'이라는 이유로 재사용 승인하지 않는다. 결과가 좋을 때까지 여러 tie/정렬/목적함수를 바꾸면 결과 선택 bias가 된다. 빈 제약 집합은 REFUSED이며 조용히 제약을 완화하지 않는다.

**3. 비용.** 단순 순열/수열은 O(N), 정렬 포함 시 O(N log N) 후보다. 구조 적합성을 반복 최적화한다면 I회 all-pair 진단의 기준 비용은 O(IN²)이다. I와 수치 정밀도는 미측정이다. 상태 저장 O(N); 역문제의 유일성 증명은 재현성 증명보다 훨씬 강한 별개 요구다. GPU는 최적화 계산을 도울 수 있지만 선택 bias·대표성·독립 검증을 해결하지 않는다. 목적함수·근거·버전·수치 tie의 유지보수가 필요하다.

**4. 더 싼 구조.** 실제 순간을 복원한다는 주장을 빼고 명시적 모델 표본으로 제한하며, 복잡한 inverse reconstruction 전에 저차/고차 및 q-p 진단으로 인공 상관을 점검한다. 단일 알고리즘을 더 정교하게 고치기 전에 M3의 선택 민감도 비교 설계를 검토한다.

**5. 장점.** 저장·재생·회귀 비교가 간단하고 이후 실행 비용이 한 역사분이다. 이 장점은 어떤 현실 통계/관측량을 대표하는지 명시하고 검증한 범위에서만 의미가 있다.

## 7. M3 — Deterministic Ensemble

**1. 필요성.** 실제 유일 상태를 복원하는 것이 아니라, 미결 선택이 결과에 미치는 영향과 대상 ensemble 관측을 연구하는 데 필요할 수 있다. 서로 다른 준비 가정을 비교한 목록과 하나의 분포를 근사하는 ensemble을 구별한다. 기존 30개 조건부 후보는 여러 알고리즘의 비교 목록이며 검증된 평형 ensemble이 아니다.

**2. 대표성의 뜻과 규모 한계.** 먼저 대상 μ(예: 명시한 Hamiltonian의 고전 NVT, COM 조건부 분포, 정해진 에너지 창의 NVE, 또는 실험 준비의 비평형 분포)를 정당화해야 한다. 이는 아직 선택하지 않은 후보다. 미시상태가 μ의 support 안에 있다는 것과 μ의 관측 평균/분산/꼬리를 대표한다는 것은 다르다. 최대 엔트로피나 균등 가중치도 추가 추론 규칙이지 현실이 직접 준 정보가 아니다.

검토할 표현은 상태 목록 x_j와 외부 가중치 w_j≥0, Σw_j=1 및 사전 정의한 관측량 집합 F다. 대표성은 예를 들어 `Σw_j f(x_j)`와 `∫f dμ`의 차이가 정한 오차 이내인지로 말한다. 특정 한 상태가 실험의 평균 g(r)를 그대로 가져야 한다고 요구하지 않으며, 작은 N에서 생겨야 할 요동까지 제거하지 않는다.

정해진 cubature/저불일치 점을 **전체 상태 공간**으로 변환하는 방법, 층화·가중 대표점, 대칭 궤도 보완을 후보로 검토할 수 있다. 3차원 공간에 N개 원자를 잘 배치하는 것과 약 6N 차원의 q,p ensemble 적분을 잘 근사하는 것은 다르다. q,p 결합·상호작용·고정 COM/에너지·희귀 근접·불연속 guard가 있으면 유효 차원과 매끄러움이 문제가 된다. QMC의 좋은 수렴률은 함수/변환의 조건에 의존하며 무조건적인 약속이 아니다. 무작위화된 방법의 오차 막대를 결정론 목록에 그대로 옮기지 않는다. [Owen, QMC 방법 설명의 초록](https://arxiv.org/abs/2608.17143), [Owen, QMC 오차 추정 연구의 초록](https://arxiv.org/abs/2501.00150)

한 상태의 회전·반사·ID permutation만 반복하면 같은 물리 대칭 궤도를 여러 번 센 것일 수 있다. 방향 평균에는 도움이 되어도 독립적인 속력·거리·고차·q-p 다양성의 대체가 아니다. antipodal pair를 모든 상태에 강제하면 같은 결함을 복제한다. 상태 수를 늘리는 것만으로 이런 편향이 없어지지 않는다. 비음수 가중치가 아닌 일반 적분 공식을 현실 표본 비중으로 해석하지도 않는다.

**3. 비용.** K개 상태의 초기 all-pair 진단은 O(KN²), 보존할 초기 목록은 O(KN)이다. 향후 동일 길이의 궤적은 아래 9절의 조건에서 대략 K배 연산량이다. 순차/batch 처리는 작업 메모리를 줄이지만 상태·실패·검증 이력 보존 의무는 줄이지 않는다. GPU는 서로 다른 상태를 병렬 처리할 여지가 있지만 실측 속도·메모리 한계와 verifier 비용이 남는다. 각 상태의 실행 건전성과 ensemble 대표성은 별개의 검증 의무다. 준비·가중치·coverage·오차·모든 상태 버전을 관리해야 한다.

**4. 더 싼 구조.** 완전한 분포 인증을 바로 요구하기보다, 사전 선언된 관측량에 대한 제한된 민감도 목록을 설계한다. 새 상태 생성 전 기존 목록의 동일 편향을 문서로 점검할 수 있다. 그 결과는 `SENSITIVITY SET`이며 μ를 대표하는 승인 ensemble이라고 부르지 않는다. 작은 F에 대한 해석적/저차 적분 참고값은 외부 감사 도구로만 검토한다.

**5. 장점.** 한 상태만 골라 좋은 결과를 보고하는 일을 줄이고 선택 민감도를 드러낸다. 어느 상태에서도 결과가 같다는 주장을 자동으로 만들지 않으며 실패·STOP·REFUSED도 원래 가중치와 함께 보존한다. 생존한 상태만으로 재정규화하면 survivor bias가 생긴다.

### 7.1 여러 상태의 결과가 비슷하면 단일 대표를 써도 되는가?

**제한된 근거는 생길 수 있지만 자동 승인은 아니다.** 먼저 대상 μ/대안 준비 가정, 관측량 F, 시간 창, 허용 오차, K 확대/별도 결정론 구성의 확인 방식, 실패 처리 및 대표 상태 선택 규칙을 결과 전에 정해야 한다. 같은 생성 편향을 공유하거나 같은 대칭 궤도만 조사한 결과 일치는 약한 근거다. 희귀 현상·장시간·새 N에는 새 검토가 필요하다.

관측 f에 대해 `|f(x*)−∫f dμ| ≤ |f(x*)−Σw_j f(x_j)| + |Σw_j f(x_j)−∫f dμ|`로 분해할 수 있다. 첫 항이 작다는 표본 결과만으로 두 번째 항이 작아지지 않는다. 따라서 '조사한 목록에서는 차이가 작다'와 '현실 ensemble을 대표한다'를 구분한다. 단일 x*를 후속 반복 계산의 대표로 쓸지 여부와 허용 범위는 설계자가 별도로 승인해야 한다. **다른 역사를 생략/대체하는 결정도 이 문서에서 하지 않는다.**

### 7.2 결과가 크게 다르면 무엇을 뜻하는가?

수치/검증 결함·준비 제약 위반·서로 다른 에너지/경계/조성·관측 정의 차이를 먼저 분리한다. 그 뒤 동일한 정당화된 준비 조건과 건전한 실행에서도 차이가 남으면, 그 관측량·시간·크기 범위에서 미시상태 선택이 중요하다는 증거다. 평균만 보고 차이를 숨기지 않으며 분포·범위·tail·조건별 차이를 함께 보고한다. 이를 곧바로 새로운 법칙, 모든 물성의 민감성, 초기상태 오류라고 결론내리지 않는다.

## 8. M4 — Physical Preparation Process

**1. 필요성.** 실제 실험의 용기·벽·주변 물질·열/물질 교환과 준비 역사가 관측 결과에 중요하면 가치가 있다. 자유로운 결과를 남겨야 하며 원하는 T/구조에 도달하도록 상태를 직접 보정하는 대안은 아니다. 단순 정적 기체 통계 비교를 위해 환경 전체를 먼저 만드는 것이 꼭 필요한지는 질문별로 판단한다.

**2. 규모 한계와 추가 모델.** 전체 시스템의 시작 상태, reservoir/벽의 물질·상호작용, 교환 법칙, 준비 시간/스케줄, 관측 창, 종료·분리 과정을 정의해야 한다. 환경의 초기 미시상태도 미결이므로 선택 문제를 없애지 않고 더 큰 시스템으로 이동시킬 수 있다. 유한 reservoir는 에너지와 온도가 바뀔 수 있다. 실제 환경 효과를 유효 모델로 대신하면 근거·영역·누락 경로가 필요하다.

| 준비 수단 후보 | 현실 대응·추가 의무 | 현재 취급 |
|---|---|---|
| 명시적인 물질 벽/유한 reservoir | 실제 물질과 계면 상호작용, 열·운동량·물질 장부, 환경 초기 상태, 준비·분리 이력 | M4의 물리 모델 후보, 미구현·미승인 |
| 물리적으로 검증된 유효 boundary | 대응하는 실제 장치와 교환 법칙, 결정론적 미시 원인/유효화 범위, 독립 검증 | 검토 후보, PBC 결정 아님 |
| Nosé–Hoover 등 extended thermostat | 계산적 ensemble 생성 모델과 실제 reservoir의 동일성은 별개, 보존량·영역·ergodicity 검증 | 결정론만으로 현실 준비 인정하지 않음 |
| Langevin/Andersen/stochastic rescaling | 난수·확률 충돌/보정 및 현재 A 규칙과 충돌 | 현 계약의 채택 후보로 자동 사용하지 않음 |
| 임의 damping, 속도 일괄 보정, 상태 snap | 실험 대응 없이 목표값을 강제 | 이번 요청에서 금지 |

통상 MD 문서에는 준비/온도 결합 방법이 다양하게 존재한다. Berendsen은 운동에너지 요동을 억제해 올바른 canonical ensemble을 만들지 못하며, stochastic rescaling에는 난수 항이 있다. 결정론적인 Nosé–Hoover도 보조 변수와 변경된 방정식을 가진 계산적 모델이다. **기존 소프트웨어가 지원한다는 이유로 A에 허용되는 것은 아니다.** [GROMACS 온도 결합 문서](https://manual.gromacs.org/documentation/current/reference-manual/algorithms/molecular-dynamics.html)

단순 조화 진동자에서 finite Nosé–Hoover chain의 비ergodicity를 논증한 연구도 있다. 이는 작은 deterministic thermostat에 보편적 표본 보증을 붙일 수 없다는 경고이며 Ar 기체의 모든 준비가 실패한다는 증거는 아니다. [Patra·Bhattacharya, Phys. Rev. E 90, 043304](https://doi.org/10.1103/PhysRevE.90.043304)

일정한 T 또는 긴 실행만으로 평형·μ 대표성·독립 표본을 증명하지 않는다. 여러 시작 조건/준비 시간의 차이, 에너지·구조·방향/유동·시간 상관·장부를 검토해야 한다. 종료 시점을 '목표 T를 처음 맞춘 순간'으로 고르면 상태 선택 bias가 될 수 있다. 준비 길이·관측 창·판정 규칙을 먼저 정하고, 실패를 보존한다. reservoir 제거에 따른 상호작용 에너지 변화·작업·잔류 상관도 기록하며 그냥 입자를 삭제하지 않는다.

**3. 비용.** reservoir 입자 수 R, 준비 step 수 P가 추가되면 직접 pair 모델 기준 준비 비용은 O(P(N+R)²)이고, 여러 준비 역사 K개면 그만큼 늘어난다. 벽/장치의 다른 자유도·상호작용·정밀도에 따라 추가 비용이 있다. 메모리는 환경 상태와 이력만큼 늘고 GPU·독립 verifier도 확대된 물리를 지원해야 한다. 환경·경계·교환·분리의 건전성, 현실 대응 및 표본 성질의 검증은 초기 기체 실행 검증에 추가되는 의무다. 모델 유지보수와 현실 자료 의존성도 증가한다.

**4. 더 싼 구조.** 실제 준비 결과의 통계/불확실성으로 M2/M3를 정의하는 외부 모델을 먼저 검토한다. 검증된 국소 reservoir 또는 유효 계면이 충분한지 조사할 수 있으나, 물리 경로를 비용 때문에 삭제하거나 hard cutoff/PBC를 여기서 확정하지 않는다.

**5. 장점.** 준비 과정을 세계 법칙으로 기록하고 현실의 준비 역사·교환·경계 효과를 연구할 수 있다. 그 비용을 지불할 이유가 해당 질문에 있을 때 가치가 있으며, 같은 T/n에 도달했다는 이유로 기억·상관·표본 문제까지 해결된다고 주장하지 않는다.

## 9. 비용과 확장 — 계층을 나눠 계산한다

여기서 N=기체 입자 수, K=준비 상태 수, S=향후 각 역사 step 수, R=환경 입자 수, P=준비 step 수, b=평균 수 표현 크기, c(b)=pair 평가/정밀도 비용이다. **모두 변수이며 공식 N/K/P/S를 선택하지 않는다.** 아래는 직접 계산하는 유한 pair 모델에 대한 구조식이고 아직 C1-C의 확정 사양이 아니다.

| 비용 층 | 기준 구조식 | 적용 한계 |
|---|---|---|
| M2 단순 생성 | O(N) 또는 정렬 포함 O(N log N) | inverse 최적화·분포 변환 비용은 별도 |
| K개 all-pair 초기 진단 | O(KN²) | 파수 bin·고차 통계·정밀도·목적함수 항 추가 |
| K개 미래 실행 | O(KSN²c(b)) | 동일 N/S·유한 pair 직접 계산 가정; 실제 시간은 미측정 |
| 초기 상태 영구 보관 | O(KNb) | provenance·가중치·메타데이터·고정 형식 overhead 추가 |
| 순차 실행 작업 상태 | O(Nb), M4 O((N+R)b) | checkpoint·proof buffer·색인은 별도, 보존할 역사는 줄지 않음 |
| 전 상태 checkpoint 기준 이력 | O(KSNb) | 무손실 변경분·압축 가능, 임의 복원 의무 유지 |
| pair별 witness를 매번 저장할 경우 | O(KSN² × witness 크기) | 필수 형식으로 선택한 것이 아님; replay/net witness와 비교 필요 |
| M4 준비 pair 평가 | O(KP(N+R)²c(b)) | 환경 종류·다체 항·계면·분리 기록 비용 추가 |

현재 96-bit q,p 여섯 성분만 packed 저장하면 상태 원자료는 **72NK bytes**다. 이는 산술상 최소 payload 예시이며 Python 객체·JSON·species/ID·해시·증명·실행 이력의 실제 메모리가 아니다. 작은 초기 목록이 작다는 사실로 전체 실행·검증 비용을 판단하지 않는다.

full periodic image 합, 다체 항, 근접 guard, adaptive precision, force accumulation 계약이 추가되면 위 식만으로 예산이 닫히지 않는다. GPU는 독립 역사 병렬성과 pair 처리에 이점이 있을 수 있지만 동일 결과 Gate·device 메모리·입출력·단일 GPU 경합·CPU verifier 병목이 남는다. GPU 용량에서 생산 N이나 K를 역산해 승인하지 않는다.

증거도 세 갈래로 나눈다: **준비 제약/대표성 검사**, **각 상태에 대한 실행 판정의 건전성**, **생성된 각 역사의 승인 독립 replay 검증**. 첫 상태의 replay 통과가 다른 상태를 인증하지 않는다. 전 궤적 사전 증명은 현재 세 층 분리의 연구 과제이며 ensemble 때문에 새 production Gate로 자동 복귀시키지 않는다. C1-C의 증거 요구는 별도 미결이다.
