# Small-A Neuron Stress-Test Roadmap V0

**상태: DESIGN ONLY / READY FOR DESIGNER REVIEW.** 인간 신경세포를 기준 대상으로 삼는 장기 로드맵 제안이다. 실행 계약·현재 Gate 종료·뉴런 구현·생명 발생 증거가 아니다. 작성 기준: 2026-10-02, HEAD `322def5987129ca48bee70e39cf33863702f2cfd`.

## 먼저 답할 여덟 가지

1. **Small은 무엇이 작은가?** 공간, 물질량, 계산 영역이다. 그 안에 선언한 물질과 상태에 필요한 물리를 비용 때문에 삭제한다는 뜻이 아니다. 작은 환경에서도 이온 고갈·전하 분리·열 교환·희귀 경로를 지원 범위에 포함해 판단해야 한다.
2. **왜 인간 뉴런인가?** 물·이온·막·단백질·화학·대사·주변 환경이 서로 영향을 주는 복잡한 기준 대상이기 때문이다. 한 가지 출력이 맞는지보다 A의 물리와 계산 구조가 이 결합을 감당하는지 시험한다. 지금 완성 뉴런을 넣으라는 뜻은 아니다.
3. **세 단계에서 무엇이 추가되는가?** Stage 1은 물·이온·전하·열·확산·막의 물질 기반, Stage 2는 실제 막 구성·채널·펌프·반응·ATP 등 세포 물리의 결합, Stage 3은 뉴런과 세포외액·주변 세포·기질·영양·산소·자극의 환경 결합을 다룬다. 단계는 지원 범위를 넓히는 순서이며 최종 목표를 줄이지 않는다.
4. **낮은 단계에서는 빠진 물리를 0으로 두는가?** 아니다. 지원할 수 없는 물질·상태·조건은 `UNSUPPORTED / NOT YET IMPLEMENTED / MODEL RANGE INSUFFICIENT`로 표시한다. 빠진 항을 0으로 계산한 뒤 결과를 현실 세계의 결과로 확정하지 않는다.
5. **여러 조건으로 무엇을 발견하는가?** 정상 조건의 평균뿐 아니라 구조·전하·물질·에너지 흐름과 드문 이상 상태가 어디서 어긋나는지 찾는다. 초기상태 의존성, 유한한 환경의 영향, 누락된 변수와 상호작용, 모델의 적용 한계를 분리하려는 시험이다.
6. **현실과 결과가 다르면 무엇을 하는가?** 실패 기록을 보존하고 계측·수치·준비·적용 범위·상태 변수·상호작용·물리 계층을 조사한다. 막전위나 발생 결과를 강제 수정하지 않는다. 원인과 독립 근거를 갖춘 변경안을 검토한 뒤 같은 실패 조건과 더 넓은 조건을 다시 시험하는 방향이다.
7. **계산량이 폭발하면 무엇을 줄이는가?** 중복 계산과 저장, 판정에 불필요한 정밀도 작업을 줄일 방법부터 조사한다. 병렬화·정확한 재사용·엄밀한 계산 경계를 검토한다. 물리 삭제, 정확도 저하, 간단한 뉴런 출력 모델로의 대체는 해결책으로 승인하지 않는다. 감당할 방법이 없으면 해당 목표 영역은 미지원으로 남긴다.
8. **성공하면 A가 무엇을 할 수 있는가?** 승인되고 현실 검증된 물질·조건·공간·시간 범위 안에서 뉴런 및 환경을 구성하는 물질계의 변화와 결합을 계산하고 넓게 관측하며, 불일치에 따라 확장할 수 있다. 모든 현실 조건·완전한 인간 뇌·생명 자연 발생까지 입증했다는 뜻은 아니다. 지금은 그 능력을 얻기 위한 설계만 있다.

## A. 목표와 이번 문서의 경계

Small-A는 작은 현실 실험실이다. **세계 구성 → 조건 변화 → 넓은 관측 → 현실 비교 → 불일치 보존 → 원인 분리 → A 변경안 → 독립 검증 → 더 넓은 재시험**을 반복하는 방향으로 설계한다. 뉴런이 원하는 전압을 내거나 항상 정상 작동하도록 만드는 것이 종료 기준이 아니다.

인간 뉴런은 물리 확장성의 reference target이다. 인간의 어떤 세포 유형·부위·연령·실험 준비·환경을 대상으로 할지는 미결이다. 다른 동물·정제 단백질·분자 시뮬레이션의 증거를 인간 뉴런 전체의 계약으로 옮기지 않는다. 미래에 현실 준비 표본에 대응하는 stress fixture를 검토하는 일도 A 안에서 L이 자연 발생했다는 주장과 구분해야 한다. **이번에 완성 뉴런·주변 세포 객체를 넣거나 L에 생명을 삽입하지 않는다.**

“모든 상황”은 선언한 물질과 상태 및 적용 범위에서 가능한 상호작용을 대상으로 한다. 무한한 현실 전체의 완전성을 주장하지 않는다. 선언 범위에서 필요한 현상이 빠졌다면 그 범위를 지원한다고 주장할 수 없다. 계산할 수 있는 일부 조건을 별도 연구하는 것은 허용 범위를 정직하게 표시하는 것이며, 원래 목표를 기능이 적은 세계로 바꾸는 승인이 아니다.

다음 상태를 그대로 유지한다.

- [Reality-Constrained Deterministic Initial State Pilot](REALITY_CONSTRAINED_DETERMINISTIC_INITIAL_STATE_V0.md): **E — REALITY_DATA_INSUFFICIENT**, A/B/C 승격 없음.
- [Reality-Constrained Microstate Preparation Contract V0](REALITY_CONSTRAINED_MICROSTATE_PREPARATION_CONTRACT_V0.md): **proposal / designer decision pending**, M1/M2/M3/M4 선택 없음.
- [C1-C Foundation](C1C_MULTIPARTICLE_GAS_FOUNDATION_V0.md): 제안 상태. 다원자 힘·production initializer·PBC·rounding·N·실행기 승인이 아니다.
- 현재 Gate와 승인 범위는 [CURRENT_STATE.md](../../CURRENT_STATE.md) 및 [세 층 분리 V1](../active/A_THREE_LAYER_SEPARATION_V1.md)을 따른다. 이 로드맵으로 C1-B1의 미해결 의무나 `NotCertified`를 없애지 않는다.

이번에는 문서 하나만 추가한다. 코드·신경망·뉴런 전용 phenomenological hack·action potential 강제 생성·임의 damping·상태 snap·출력에 맞춘 상수 조정·C1-C production 변경·D_valid·dt 변경·PBC 확정·GPU 구현·Vast·forward dynamics는 수행하지 않는다. 후보 모델이나 향후 시험 절차의 서술은 실행 승인과 다르다.

## B. 세 단계: 필요성부터 비용까지

모든 단계에서 **실제로 해결할 문제 → 확대 시 한계 → CPU/GPU/메모리/검증·증명/유지보수 비용 → 더 싼 방법 → 그래도 필요한 장점** 순서로 검토한다. 작은 시험 하나의 성공으로 전체 Small-A 구조를 승인하지 않는다.

| 단계 | 해결할 문제 | 커질 때 먼저 깨질 수 있는 곳 | 비용 및 더 싼 후보 | 필요한 장점과 승인 경계 |
|---|---|---|---|---|
| Stage 1 — Physical Foundation World | 물·이온·막·전하·열이 함께 존재하는 기본 물질계를 현실과 비교할 수 있는가 | 장거리 전기 상호작용, 분극, 물/막 자유도, 유한 크기 및 경계, 빠른 운동과 느린 확산 | 전 쌍 기준 계산, 분극/field 판정, 물질량과 정밀도별 상태·기록, 독립 계산 비용. 정확한 색인·타일링·오차 경계로 판정 비용을 줄일 후보 | 뉴런 전용 출력을 넣기 전 물질 기반의 실패를 분리. 현재 이 세계는 미구현이며 제한된 비반응 모델이 Stage 1 전체를 대신하지 않음 |

| Stage 3 — Neuron + Environment World | 물질계와 주변 환경의 교환·고갈·자극이 공동으로 만드는 결과를 계산할 수 있는가 | 환경 자유도, 공간별 농도/열/전하, 시냅스·세포·기질 결합, 긴 시간과 드문 사건, 전체 역사 | 환경 및 경계 입력, 장시간 실행·기록·replay·자료 관리 비용 추가. 정확한 분업·무손실 checkpoint·검증된 계층 계산 검토 | 고립 뉴런만의 결과로 놓치는 환경 원인을 발견. 인간 뉴런/몇 개/회로/조직 production 규모는 미결 |

단계 전환은 달력이나 action potential 하나의 일치로 결정하지 않는다. 해당 단계의 선언 범위, 미지원 항목, 넓은 현실 비교, 수치/검증 의무, 다음 단계에 필요한 추가 상태와 결합을 검토해 설계자가 판단해야 한다. 전 단계에서 발견한 미해결 문제는 목록과 재현 조건을 가지고 다음 단계에 이어진다.

### C2. 단계별 추가 상태·상호작용과 현재 미지원 범위

| 단계 | 추가해야 할 물리 및 상태 후보 | 현재 미지원 / 모델 선택에서 숨기면 안 되는 경계 |
|---|---|---|
| Stage 1 | 물과 주요 이온의 종·질량·q,p·구조, 전하, 분자 운동/충돌/상호작용, 열·압력·확산, 단순 막 구성과 투과, 전기장·분극 및 필요한 다체 효과 | 현재 Ar 법칙으로 계산 불가. 종 간 교차 상호작용도 필요. 고정 결합/고정 protonation의 비반응 물 모델은 결합 교환·해리·양성자 이동·pH 변화 지원이 아님 |
| Stage 2 | 실제 막 지질과 단백질 구성, 채널/펌프/수용체의 구조·화학 상태, Ca²⁺/Na⁺/K⁺/Cl⁻, 세포질·완충계, 전기화학 gradient, ATP/ADP/Pi 및 필요한 Mg·물·양성자, 결합/해리·반응·분자 간 결합 | 반응성 모델·필요한 전자 상태/유효 전자 모델·양성자/전하/에너지 장부·결합 실행/독립 검증 미구현. 단순 charge 전환이나 ATP 수량 감소로 펌프 작동을 지시하면 안 됨 |
| Stage 3 | 뉴런을 구성하는 물질과 세포외액, 물·이온, 시냅스 환경, 주변 세포/astrocyte·ECM, 영양·산소·대사, 열·field·물질 교환, 실제 자극 장치/경계와 환경 초기 상태 | 현재 모두 통합 미지원. 산소·영양 label만 넣어 대사를 지원한다고 할 수 없음. 필요한 반응/산화환원/수송·계면과 환경 물질량까지 선언해야 함 |

물의 분극·전하 침투·분산·반발 등을 분리해 다루는 경험적 potential의 연구 사례는 [Rackers 등, HIPPO](https://arxiv.org/abs/2106.13116)에서 확인했다. 이 사례는 Ar pair를 물 전체로 확장할 근거가 아니라 **새 물리 항과 검증 범위를 따로 검토할 필요**를 보여준다. 해당 모델 채택, 전자 전체의 explicit 계산, 반응 지원, 인간 세포에서의 유효성을 승인하지 않는다. 더 상세한 계산도 자동으로 현실에 더 정확하다고 판정하지 않는다.

Na⁺,K⁺-ATPase의 ATP/Pi/Mg 관련 서로 다른 상태를 다룬 [Kanai 등, 2022](https://doi.org/10.1073/pnas.2123226119)는 펌프 준비 상태를 단순 기능 flag로 대체하면 안 되는 근거 사례다. 읽은 구조 연구의 표본은 shark rectal gland 효소이며, 정적 cryo-EM 구조가 인간 뉴런의 순간 q,p나 완전한 pump dynamics를 제공하지는 않는다.

**같은 세계 상태에서 결합하기 위한 추가 설계 의무**는 다음과 같다.

- 공통 시간·단위·상태 및 상태 변경의 책임을 정의한다. 이온 이동→전하/field→분자 구조→반응→물질/에너지 흐름의 양방향 영향을 같은 법칙과 상태에서 계산해야 한다.
- 원소/종·총전하·결합·화학 및 기계/field 에너지·경계 교환 장부를 정의한다. 반응에서 분자 종 수는 바뀔 수 있으므로 “모든 종 개수 보존”을 요구하지 않는다. 폐쇄계와 개방계의 보존 의무를 분리한다.
- 명시적 물과 implicit dielectric/분극, 입자 Coulomb과 continuum field, 반응 에너지와 별도 ATP 보상, 명시적 solvent와 friction bath가 같은 효과를 중복 계산하는지 조사한다. 각 계면에서 누락·중복·동시 쓰기·에너지/전하 교환·관측 비간섭을 검증할 별도 계약이 필요하다.
- 전위의 기준(gauge), 총전하·counterion·외부 field·장거리 처리·경계를 정해야 한다. 수치 편의를 위한 배경 전하나 국소 전기중성 강제는 실제 전하 분리/막전위와 다른 법칙일 수 있다. PBC나 Ar tail 처리에서 자동 상속하지 않는다.
- 채널의 물리적 구조/상태 변화는 세계 법칙의 결과여야 한다. `전압 → open 추첨`, `ATP token → pump 명령`, `막전위 → spike 생성`을 숨은 법칙으로 넣지 않는다. HH 등 현상론 모델은 외부 비교 자산으로 검토할 수 있으나 이 목표의 뉴런 생성 법칙으로 승인하지 않는다.

### C3. 지원 판정이 먼저다

향후 모델마다 **물질·종·상태 변수·상호작용·조건·공간/시간 범위·오차 근거·미지원 경로·guard와 그 건전성 근거**를 대응시키는 지원 목록이 필요하다. 후보 조건을 넣기 전 이 목록으로 지원 여부를 판정하고 필요한 runtime guard를 사용한다. 이것은 제안이며 guard 구현/건전성이 지금 확보된 것은 아니다.

미구현 반응이 “실제로 일어나면 중단”한다고 쓰지 않는다. 그 반응을 아직 계산하지 못하면 발생 탐지 자체를 보장할 수 없다. 사전 범위 판정이나 검증된 경계로 안전한 실행 범위를 가릴 수 없으면 해당 조건은 `UNSUPPORTED`다. 빠진 항을 0으로 두고 실행한 결과를 지원되는 현실 결과로 부르지 않는다. 수치 범위/자원 문제의 `REFUSED`, 계산 불일치의 `INVALID`, 물리 적용 불가의 `UNSUPPORTED`도 서로 다른 이유로 기록해야 한다.

비반응 유효모델 같은 후보는 해당 조건·시간·규모에서 제외 경로의 영향을 평가하고 적용 범위와 오차를 입증한 뒤 검토할 수 있다. 물리적으로 존재하지 않는 0, 수치 표현의 승인된 반올림 0, 미지원이라 계산하지 못한 값은 별개다. 마지막 값은 0으로 직렬화하지 않는다.

## D. 조건 변화와 넓은 관측

### D1. 비교할 조건

시험 조건은 물리적으로 준비 가능한 조합으로 정의한다. T·압력·밀도·조성·에너지·pH를 서로 독립된 목표 숫자로 동시에 강제하면 모순된 준비가 될 수 있다. 상태방정식, 물질량, 실제 물질/에너지 교환과 준비 불확실성을 먼저 확인한다. 입력을 바꾸는 것은 외부 실험 조건 정의이며, B가 확정된 A 역사를 조작하거나 출력에 맞춰 준비 규칙을 바꾸는 권한이 아니다.

| 변화 축 | 준비/조건에서 먼저 확인할 것 | 함께 관측할 것 |
|---|---|---|
| T·에너지·압력·밀도 | 폐쇄/개방 준비, 열/일 교환, 물질량·기하와의 양립성 | 에너지 장부, 공간별 운동/열 지표, 압력/구조·상 변화 |
| Na/K/Cl/Ca 및 기타 조성·농도 | 이산 분자/이온 수, 전하와 counterion, 종 간 모델, 환경 고갈 | 농도 분포·전하 분리·flux·구조·수화·상관 |
| field·자극 | 전하/전극/경계 또는 외부 source 대응, 공급 일·교환 장부 | field·전위·전류·열·구조·반응의 동시 변화 |
| pH 관련 조건 | activity/완충계/해리/양성자 관련 모델과 실제 준비. pH label 또는 임의 charge 변경만으로 지원하지 않음 | 종/speciation·결합/해리·전하/에너지·구조/수송 |
| q,p·구조·막 구성 | 현실 제약·불확실성·준비 규칙, ID/ordering/axis 영향, M1–M4 미선택 | 방향·격자·antipodal pair·속력/방향·q-p 상관, 막 구조/전위/flux 및 결과 민감도 |
| 공간 크기·물질량·경계 후보 | 경계의 실제 대응, 유한 reservoir, 총전하/gauge. PBC 미확정 | 환경 고갈·경계층·finite-size 변화, 내부/환경 에너지·물질 교환 |
| Stage 2의 반응·단백질 구성 | 현실의 구조/화학 상태·물질 입력, 경로 및 계면 지원 | 구조 변화·이온 통과·화학 상태·에너지·전위·동역학 상관 |
| Stage 3의 주변 세포·기질·영양/O₂·교환 | 표본·환경·자극·반응 대응, 공간/시간 지원, 준비 및 교환 이력 | 내부와 외부의 농도/열/field·대사·flux, 시냅스 환경·드문 이상 상태 |

한 축의 변화, 축들 간 결합, 적용 경계, 유한 크기/기간 확대를 차례로 계획하되 조합 수를 미리 확정하지 않는다. 허용되는 조건을 결과가 나온 뒤 고르지 않는다. 미지원·모순된 준비·이상 결과도 이유와 함께 목록에 남긴다. 모델 fitting에 사용한 조건과 평가 조건은 구분하며, 필요하면 향후 독립 평가 조건을 사전에 정한다.

초기 microstate 비유일성과 물리 누락은 별도 원인이다. 여러 준비 상태를 비교하는 후보 실험은 결과 선택 bias를 줄이는 조사일 수 있지만 M3 승인이나 대표성 증명이 아니다. 서로 다른 상태의 모든 결과를 보존할 범위·가중치·관측량·오차를 정해야 한다. 결과가 비슷해도 단일 canonical 상태는 검토한 관측량/기간/조건에 한해 근거를 얻을 뿐이며, 차이가 크면 준비 민감도와 실제 물리 조건 차이를 먼저 조사한다.

### D2. 상태·측정·재구성의 구분

관측은 계산을 읽으며 세계 상태를 수정하지 않는다. 아래 배치는 비용 비교를 위한 후보다. 새 상태 schema, 저장 간격, 증거 등급, 관측 pipeline을 확정하지 않는다.

| 대상 | 실시간 유지할 후보 | 측정/재구성할 후보와 비용 경계 |
|---|---|---|
| 기본 물질 상태 | q,p·종/질량·전하·결합·화학 상태, 법칙이 요구하는 분극/전자/field 자유도, 경계 입력 | 정확한 checkpoint와 입력/사건/witness로 역사 재구성. 독립 field 자유도를 입자 위치만으로 복원할 수 있다고 가정하지 않음 |
| 에너지·전하·field·전위 | 전이에 필요한 상태와 경계 교환 장부 | 에너지 분해·전하 분포·field/전위 지도. electrostatic 파생값과 독립적인 동적 electromagnetic 상태는 구분. gauge·단위·법칙 표시 |
| T·압력·농도·막 구조 | 전이에 필요한 물질 상태 | 공간/시간 창을 선언한 estimator, 구조/막 분포. 작은 비평형계에서 단일 T/압력/농도가 전체 상태를 대표한다고 가정하지 않음 |
| 확산·flux·반응·결합/해리 | 법칙에 필요한 반응/경계 교환 사건 | 정의된 면 통과, 시간창, 추적 규칙·상관으로 계산. 확산 계수의 관측을 별도 임의 diffusion kick으로 되먹이지 않음 |
| 공간/시간 상관·희귀 이상 | 재구성 가능한 상태/입력·사건의 근거 | 요청한 window를 재생/분석. 통계 summary는 정확한 역사 복원이나 전 step 검증 원본을 대체하지 않음 |

매 step 모든 pair field·모든 상관을 영구 저장하면 계산과 저장이 함께 폭발한다. 파생 지도를 필요할 때 계산하거나 streaming 측정하고, 근거 상태는 무손실 복원 가능하게 남기는 후보를 비교한다. 기록 sparsening으로 필요한 실제 사건/원인을 잃는다면 비용 절감으로 승인할 수 없다. 해시·최종 summary만으로 원래 역사를 복원할 수 있다는 주장도 금지한다.

### D3. 현실 비교와 드문 사건

현실 비교에는 표본 종류·준비·계측 정의·시간/공간 해상도·불확실성·모델의 관측 대응을 기록한다. 인간 대상의 출발 문헌 후보로 [Eyal 등, 2016](https://doi.org/10.7554/eLife.16553)를 식별했으나 이번 조사에서 접근 문제로 본문/Methods를 안정적으로 검토하지 못했다. 특정 capacitance·막전위·인간 전체 parameter를 여기서 채택하지 않는다. [VU 연구기관 서지](https://research.vu.nl/en/publications/unique-membrane-properties-and-enhanced-signal-processing-in-huma/)로 저자·제목·DOI를 확인한 수준이다.

환경 결합의 제한된 근거 사례로 [Bataveljic 등, 2024](https://www.nature.com/articles/s41467-024-47681-y)는 astroglial Kir4.1과 K 제거/뉴런 과흥분을 다룬다. 이번에는 publisher 검색 발췌만 확인했으며, **Fragile X mouse model**의 결과를 인간 뉴런 계약으로 바꾸지 않는다. Stage 3의 환경을 단순 상수로 처리할 수 있는지 별도 근거가 필요하다는 조사 후보다. 현상론 모델/MD와의 일치는 현실 계측 일치와 별도 증거다.

희귀 반응·막 이상·드문 구조/수송 사건은 `관측되지 않음 ≠ 불가능`이다. 발생률을 모르면 **UNKNOWN / UNRESOLVED / UNSUPPORTED RATE**로 남긴다. A에는 난수 추첨을 넣지 않는다. 여기서 rate는 외부 반복 실험이나 선언한 ensemble/노출 범위의 관측·추론 개념이다.

경로를 유효모델에서 제외할 근거는 사전 기준과 독립 현실 자료/상한이어야 한다. 시간·물질량·공간·조건 전체에 대한 누적 영향과 단위를 계산하고 중복 기회를 주의한다. 조건이 달라지면 상한을 재검토한다. 표본에서 0회를 관측했다고 rate=0으로 두거나 rare path를 제거하지 않는다. 상한·영향 평가가 없으면 적용 범위 미해결이며, 필요한 경우 해당 범위의 현실 타당성 승인을 보류해야 한다. 평균/막전위/action potential 일치가 이를 대신하지 않는다. [L 원칙 V2](../reference/L_ORIGIN_AND_OBSERVATION_PRINCIPLES_V2.md)의 희귀 경로·가능성 차단과 유효한 미발생 구분을 보존한다.

| 누락 상호작용/잘못된 coupling | 교차 항·field/분극·반응/에너지·경계 장부의 누락/중복 | 같은 상태의 상호 영향과 계면 계약 추가. 독립 스크립트의 목표값 교환 금지 |
| 더 상세한 물리 계층 필요 | 기존 범위 내 수정으로 설명 못 하는 독립 자료와 다른 가설 비교 | 유효 전자/반응/환경 등 후보 비교·오차/지원 범위·비용·별도 승인. 모든 mismatch를 새 물리라고 단정하지 않음 |

실행/검증 불일치는 기존 세 층 분리에 따라 확정 상태와 미확정 구간을 구분한다. 현실 불일치는 **계산 이력이 검증됐어도 생길 수 있다**. 실제로 맞지 않는 모델을 구현한 세계일 수 있으므로 둘을 같은 실패 등급으로 혼합하지 않는다. 미래 C1-C/뉴런 구간의 `CONFIRMED` 최소 등급은 아직 미정이며 C1-B1의 규칙을 A 전체에 자동 복사하지 않는다.

향후 변경 절차 후보: 실패 조건·기록 고정 → 경쟁 원인/구분 시험 → 기존 법칙·숫자·계면과 달라지는 범위 공개 → 더 싼 대안/확장 비용 비교 → 설계자 판단 → 별도 구현 및 독립 검증 → 원 실패와 추가 조건 평가. 법칙 버전이 달라진 결과는 별도 역사로 남기고 과거 결과를 새 값으로 덮어쓰지 않는다. 어떤 증거가 다음 계층을 요구하는지 아직 결정할 수 없으면 `UNRESOLVED`로 남긴다.

## F. 확장 비용: 실제 수치는 미측정

다음은 비용 항목을 빠뜨리지 않기 위한 구조식이다. 실행시간·가격·GPU 가속률·production N·허용 기간을 측정/결정한 결과가 아니다. `N`: 물질 자유도를 표현하는 입자 수, `R`: 추가 환경 입자 수, `M`: field/전자 등 별도 자유도, `K`: 준비 상태/조건 수, `S`: 각 실행 step 수, `b`: 필요한 숫자 정밀도, `c(b)`: 연산 비용, `Q`: 반응/계면 계산 비용으로 둔다. 실제 상태 표현에 따라 식을 다시 세워야 한다.

| 비용 | 기준 구조/확대 원인 | 단계별 함정 |
|---|---|---|
| CPU 힘/전이 | 전 쌍 계산 후보는 `O(K S (N+R)^2 c(b))`; 분극/field/전자 solve와 반응 `Q`는 별도 | Stage 1의 모든 항이 pair일 것이라는 가정 금지. Stage 2 구조/반응, Stage 3 환경 solve로 비용 추가 |
| 시간척도 | 관측 기간 증가에 따라 S 증가. 빠른 진동/반응과 느린 구조/수송의 공존 | 작은 공간이어도 긴 준비·관측 기간이 필요할 수 있음. 기간·dt를 바꿔 비용을 숨기지 않음 |
| 작업 메모리 | 기본 상태 `O((N+R+M)b)` 후보, 색인·solver buffer·반응 자료 추가 | 모든 pair 저장은 `O((N+R)^2)` 규모가 될 수 있음. K 순차 실행은 동시 메모리만 줄이며 전체 작업은 남음 |
| 기록/저장 | 모든 상태 매 step 보존 후보 `O(K S (N+R+M)b)`, witness·경계·법칙/사건 별도 | checkpoint/무손실 기록/재구성 비용 교환. 환경 입력 또는 화학 상태를 버리면 정확 재생 불가 |
| GPU | 병렬 pair/field 등 후보의 산술·메모리 대역폭·host 전송·엄밀 판정/refinement 비용 | 부동소수점/계산 순서/반올림 변경이나 기존 Ar 가속률 상속 금지. 장비만 늘려 해결될지 미측정 |
| 검증/증명 | 전이/guard 건전성, 독립 양측 구현, witness 검사, 범위별 인증 비용 | 한 상태/표본/전 step replay/범위 인증/현실 타당성은 서로 다른 증거. 다원자라서 증명 불가능하다고 단정하지 않음 |
| 자료·유지보수 | 종/교차 항/반응·환경·오차·법칙 버전과 support map, 독립 검증 변경 | 모델 수뿐 아니라 조합·계면의 검증이 증가. 새 법칙의 자료 부족을 계산량 문제와 구분 |

실제 비용 조사가 승인될 때에는 물질량·field 자유도·기간·정밀도·조건 K를 각각 변화시켜 executor/관측/verifier/저장을 분리 측정하는 설계를 먼저 검토한다. 공식 C1-B1 verifier 비용은 지정 두 원자 witness 범위의 실측이므로 뉴런 비용 예측 계수로 사용하지 않는다. 현재는 측정 계획 제안만 있다.

작은 reservoir도 농도·화학퍼텐셜·열이 고갈/변화할 수 있다. 세포만 작게 떼어 주변을 항상 일정하게 재설정하면 다른 준비/경계 법칙이 된다. finite-size 변화는 시험 결과이자 모델 범위 판단의 근거이며, 목표값 snap으로 없애지 않는다.

## G. 물리를 줄이지 않는 저비용 후보

| 후보 | 줄이는 비용 | 물리/정확성 보존 의무와 아직 남은 문제 |
|---|---|---|
| 타일링·색인·병렬 분업, pair matrix 미저장 | 중복 탐색·메모리·독립 작업 wall time | 승인된 기준 상태/사건/인과 결과와 동일해야 함. 장거리 항을 이웃 바깥이라는 이유로 0 처리하지 않음 |
| 동일 입력의 정확한 cache/중복 제거 | 같은 force/판정/준비 입력 계산 | 법칙 버전·정확한 상태·전체 영향/경계 입력을 포함. 평균 T/농도/막전압은 충분한 key가 아님. 장거리 전기 영향에서 유한 causal key를 자동 가정하지 않음 |
| 구간 enclosure·adaptive refinement | 이미 판정 가능한 상태에서 불필요한 고정밀 작업 | 모든 필요한 판정의 건전성을 확보. 반올림 경계를 가로지르면 정밀화/정확 경로, 자원 부족이면 REFUSED. 어려운 상태를 표본에서 빼지 않음 |
| 장거리 계층 계산/FMM 계열 검토 | Coulomb의 반복 전 쌍 평가 후보 | 생략된 항의 엄밀 경계와 승인된 반올림 결과 동일성이 필요. 일반 finite expansion의 작은 오차만으로 현재 exact 계약 통과를 주장하지 않음 |
| 순차 조건 실행·정확한 checkpoint/무손실 저장·관측 재구성 | peak 메모리·중복 파생 기록 | 모든 상태/실패 보존 및 필요한 역사 재구성 가능성. 총 실행량과 긴 시간의 비용은 남음 |
| verifier의 streaming·중복 근거 재사용 | peak 메모리·증명/판정 반복 | 승인된 범위의 전 step 의무를 표본 검사로 대체하지 않음. 건전성이 확보된 fast path와 어려운 판정의 독립 exact 검사를 구분 |
| 정확한 표현 계층/요약 | 변하지 않는 동일 상태의 표현·계산 중복 | 실제 자유도와 경계 영향이 남고 기준 결과가 동일한지 입증. 손실 coarse-graining에서 microstate를 새로 만들어 펼치는 것은 별도 모델 변경 |
| 현실 검증된 유효이론/상세 계층 비교 | 특정 검증 범위에서 상세 계산 비용 | 실행 최적화와 다른 물리 서술이다. 적용 범위·알려진 오차·제외 경로 누적 영향·새 조건의 중단/전환 계약을 별도로 심사. 정확도 하향의 자동 허가가 아님 |

[Carrier–Greengard–Rokhlin, 1988](https://math.nyu.edu/~greengar/cgr_88.pdf)은 특정 2차원 Coulomb 문제에서 expansion 오차 경계와 지정 정확도에서의 비용 개선을 제시한다. 이 문헌은 장거리 계산의 다른 구조를 조사할 근거이며, 3차원 뉴런·다체/반응·exact rounding을 이미 해결했다는 증거가 아니다. 낮은 expansion 차수나 임의 cutoff를 비용 때문에 고르는 승인은 없다.

“필요한 상태만 exact 검사”는 명세상 필요한 판정만 계산하고 이미 엄밀히 결정된 값을 재사용한다는 의미에서 검토한다. 어려운 step이나 관심 밖 반응의 검증을 건너뛰고 전체 역사를 검증됐다고 부르는 뜻은 아니다. [A Execution Architecture V1](../reference/A_EXECUTION_ARCHITECTURE_V1.md)의 X2/X3/X4 기준과 multi-particle rounding 미결 상태를 보존한다.

더 좋은 수치법도 변경안을 비교할 대상이다. 적분법·dt·rounding을 바꾸면 결정론적인 이산 세계/수치 오차 계약이 바뀔 수 있으므로 단순 최적화로 끼워 넣지 않는다. 물리/정확성 조건을 만족하는 싼 구조가 없으면 비용 문제는 미해결로 기록하고 해당 목표 영역을 `UNSUPPORTED`로 남긴다. 그 목표를 폐기하거나 뉴런 전용 간이 법칙으로 대체하지 않는다.
