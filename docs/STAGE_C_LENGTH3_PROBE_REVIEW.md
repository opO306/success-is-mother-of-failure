# 단계 C 길이 3 확장 탐색 구상 일치성 검증

**대상:** 길이 1~3 전수 단일·쌍 및 사전 고정 세 서열 표본  
**판정:** 접힘과 구조 문맥의 실제 작동 확인, 일시적 성장 4회 확인, 안정적 유지·신호·되먹임은 미확인

## 1. 무엇을 만들고 실행했는가

길이 1~3의 단일 서열과 비순서 쌍 3,654개를 전수 실행하고, 전체 102,340개 세 서열 조합 중 실행 전에
SHA-256 순서로 고정한 512개를 함께 실행했다. 각 초기 조건을 seed 두 개로 실행해 총 8,332회의 전체 프레임을
보존했다.

## 2. 세계 안에서 실제로 관측된 것

- 자연 정지 `902`회, 사건 제한 도달 `7,430`회
- 동일 구성 재등장 `7,430`회
- 접촉이 최소 두 상태 동안 이어진 실행 `3,619`회, 최장 `7`개 상태
- seed에 따라 최종 상태가 달랐던 초기 조건 `3,744/4,166`
- 결합 `76,702`, 분리 `72,284`, 골격 절단 `24,978`
- 접힘 `3,482`, 풀림 `3,414`
- 골격 성장 `4`
- 구조 문맥 적용 실행 `138`회, 문맥 사건 총 `146`회

구조 문맥 사건은 모두 접힌 주머니 안에서 일어난 결합이었고 배율은 `3`이었다. 서로 다른 초기 조건은
121개였다.

골격 성장 네 번은 `pair:011|321`, `pair:022|312`, `pair:100|230`, `pair:133|203`의 seed `1`에서 동일한
시간 형태로 나타났다. 절단으로 생긴 조각들이 사건 번호 22에서 이어졌고, 새 골격 네 개는 24사건 관찰 경계까지
남아 있었다. 사건 번호 23에도 절단이 발생했지만 새 골격이 아닌 다른 골격이 대상이었다. 대상 식별자를 추가로
추적한 장기 탐색에서 이 해석을 정정했다.

## 3. 설계 의도와 일치하는 부분

- 단일·쌍 범위는 결과와 무관하게 전수 실행했다.
- 세 서열 표본은 사건 결과를 보기 전에 공개된 고정 규칙으로 결정했다.
- 접힘·구조 문맥·골격 성장을 목표 점수로 사용하지 않았다.
- 실행 결과를 메모리에 모아 선별하지 않고 각 원본 프레임을 즉시 저장했다.
- 접힘으로 생긴 위치 문맥이 이후 결합 가중치를 실제로 바꾸는 인과 통로가 작동했다.
- 네 성장 사례가 즉시 다시 절단된 사실을 실패로 숨기지 않았다.
- seed 차이를 확률 민감성으로만 해석하고 진화라고 부르지 않았다.

## 4. 근사하거나 강제한 부분

- 초기 열에너지와 24회 사건 제한은 외부 실험 조건이다.
- 세 서열은 102,340개 중 512개만 실행했으므로 전수 결과가 아니다.
- SHA-256 고정 표본은 재현 가능한 사전 선택이지만 통계적 균등성을 보장하는 정식 표본 설계는 아니다.
- 접힘과 풀림 횟수가 비슷하다는 사실만으로 안정된 구조라고 할 수 없다.
- 구조 문맥 146회는 확률 가중치 변화의 증거이지 기능적 촉매나 효소의 증거가 아니다.
- 성장 네 번은 모두 실행 끝에 가까운 사건 22에서 생겨 짧은 관찰 경계까지 남았다. 이 짧은 기록만으로 장기
  유지, 복제와 유전을 판정할 수 없다.
- 참여 관계 확장은 새 결합 상대와 절단 자손도 세므로 신호 전달로 판정할 수 없다.
- 133,402,373바이트의 전체 기록은 더 긴 실험에 그대로 확장하기 부담스럽다.

## 5. 검증 증거

- 확장 탐색기 포함 집중 테스트 68개 통과
- 전체 프로젝트 회귀 테스트 540개 통과
- 결과 파일: `runs/sequence_probe_stage_c_length3.jsonl`
- 결과 파일 SHA-256:
  `9D988D14ACF37E155909B3AA356FB4176DB67F786E429EE9ECF951B88977AF42`
- 결과 파일 크기: `133,402,373` bytes
- 전체 실행 기록 행: `8,332`

## 6. 다음 판단

단계 C에서 **구조가 이후 사건의 가능성을 바꾸는 것**은 실제로 확인됐다. 하지만 상태 유지, 신호 전달,
되먹임과 지연의 통과 조건 전체를 만족했다고 볼 수는 없다.

다음에는 관측 범위를 임의로 줄이기 전에 전체 상태 체크포인트와 사건 차분을 결합한 무손실 장기 기록 방식을
만들어야 한다. 그 뒤 결과로 고른 사례만 연장하지 않고 사전에 고정한 동일 범위를 더 긴 시간 동안 실행해,
일시적 골격이 유지·재성장하거나 구조 문맥이 사건망을 반복적으로 바꾸는지 확인한다.
