# 창발적 감정과 욕구를 위한 기반 명세

**상태:** 장기 설계 경계. 현재 분자·서열 세계에는 아직 적용하지 않음.

## 결론

사랑·분노·애증·증오를 이름 붙은 전역 수치로 넣지 않는다. 감정이 수행하는 더 낮은 수준의 기능을 몸, 기억,
예측, 행동 선택의 상호작용으로 제공하고, 구체적인 감정 이름은 반복되는 실제 행동과 내부 상태를 본 관찰자가
사후에 붙인다.

## 감정이 가능하려면 먼저 필요한 것

1. 유지해야 할 내부 상태와 실제 결핍
2. 내부·외부 변화를 감지하는 구조
3. 여러 행동 후보와 행동의 에너지·위험 비용
4. 행동 뒤 몸 상태가 어떻게 변했는지 기억하는 구조
5. 특정 장소·물질·개체를 구별할 수 있는 감각 기억
6. 현재 선택이 미래 몸 상태를 어떻게 바꿀지 예상하는 구조

이 조건 없이 `anger=0.7`을 넣으면 감정이 아니라 이름 붙은 조종 손잡이다.

## 엔진이 제공할 수 있는 낮은 수준의 상태

- 내부 결핍: 에너지, 수분, 온도, 손상, 수면 압력 등 실제 몸 상태와의 차이
- 각성: 위험·손상·격렬한 활동 뒤 천천히 사라지는 신체 상태
- 접근/회피 기억: 어떤 감각 대상 뒤 몸 상태가 좋아지거나 나빠졌는지 누적된 관계
- 상대별 기억: 누구와 함께 있을 때 어떤 실제 결과가 반복됐는지
- 기대와 오차: 예상한 몸 상태와 실제 결과의 차이
- 충돌하는 경향: 같은 대상을 향한 접근 기억과 회피 기억이 동시에 존재할 수 있음
- 기억 소실과 갱신: 시간이 지나거나 반대 경험이 누적되면 관계가 달라짐

각 상태를 얼마나 크게 느끼고 얼마나 오래 보존하며 행동에 얼마나 반영하는지는 유전 가능한 고정 답이 아니라
변이 가능한 물질·계산 구조의 결과여야 한다. 개체가 살아서 얻은 대상별 관계와 구체적 지식은 출생 시 완성된
사전으로 상속하지 않는다.

## 관찰자가 나중에 검사할 행동 패턴

- 사랑 후보: 특정 상대의 상태 개선을 위해 반복적으로 비용을 지불하고, 분리 뒤 재접근하며, 상대별 기억이
  다른 대상과 구별되는 경우
- 분노 후보: 기대 위반이나 손상 뒤 각성이 높아지고, 원인으로 기억한 대상에 접근·대항 행동이 일시적으로
  증가하는 경우
- 증오 후보: 반복 손상 뒤 특정 대상에 대한 장기 회피 또는 공격 경향이 여러 상황에서 유지되는 경우
- 애증 후보: 같은 상대에 대한 접근과 회피 경향이 모두 강하고 상황·내부 상태에 따라 선택이 갈리는 경우
- 욕구 후보: 내부 결핍이 특정 행동 탐색을 지속적으로 바꾸고 충족 뒤 그 경향이 감소하는 경우
- 욕망 후보: 즉각적인 결핍이 없어도 기억과 예상 때문에 특정 미래 상태를 반복적으로 추구하는 경우

이것들은 판정 공식이 아니라 분석 질문이다. 한계값 하나로 감정의 탄생 시점을 세계 사건처럼 선언하지 않는다.

## 현재 코드와의 관계

기존 `engine.brain`과 `engine.primal`에는 결핍, 공포, 각성, 상대별 친밀도, 새로움, 예측된 몸 상태와 학습이
부분적으로 존재한다. 이는 위 기반의 초기 근사지만 아직 사랑·분노·애증·증오가 구현됐다는 뜻은 아니다.
특히 인간형 행동 이름과 고정된 감각 채널이 남아 있으므로, 장기적인 열린 세계에서는 감지 대상과 계산 구조
자체가 진화 가능한 물질 구조로 내려가야 한다.

## 적용 시점

현재 순서는 바꾸지 않는다.

```text
물질·공간·서열 통합
→ 자기 유지와 복제 후보
→ 구획 계보와 여러 세대
→ 진화 가능한 감각·기억·행동 구조
→ 정동 기반
→ 관찰자에 의한 감정 후보 분석
```

생명과 행동 선택이 생기기 전에 감정 변수를 넣으면 원하는 현상을 미리 작성하게 되므로 적용하지 않는다.
