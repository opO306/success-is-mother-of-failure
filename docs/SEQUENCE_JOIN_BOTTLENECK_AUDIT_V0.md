# 골격 성장 후보 관문 감사 v0

**상태:** 단계 C 장기 기록 진단 명세  
**목적:** 성장을 늘리기 위한 법칙 변경 전에 현재 세계에서 어느 물리 관문이 실제로 막혔는지 분리

## 1. 관문

모든 상태를 다음 순서로 읽는다.

1. 골격 결합 비용 이상의 열에너지가 있는가
2. 외부 접촉이 두 개 이상인가
3. 접촉 둘이 같은 주형을 공유하는가
4. 서로 다른 두 조각인가
5. 각 조각이 그 접촉 하나만 가지는가
6. 각 조각 전체가 주형에 붙었는가
7. 두 조각이 주형의 인접 구간에 있는가
8. 실제 골격 성장 후보가 생성되는가

각 수치는 기존 후보 생성과 같은 검사를 공유한다. 감사 결과는 사건 가중치나 세계 상태에 들어가지 않는다.

## 2. 비교군

- 전체 8,332회에서 성장 후보가 한 번이라도 있었던 실행
- 후보가 있었지만 성장하지 않은 실행
- 성장한 98회에서 산물이 절단되기 전까지의 모든 상태
- 첫 성장 뒤 두 번째 성장 후보가 있었던 경우와 없었던 경우

성장 사례만 보면 후보가 드문지, 후보가 있어도 선택되지 않는지 구분할 수 없으므로 전체 실행을 같은 기준으로
복원한다.

## 3. 후보 경쟁

성장 후보가 있는 모든 상태에서 다음을 기록한다.

- 성장 후보 가중치 합
- 전체 사건 가중치 합
- 성장 선택 확률
- 실제로 선택된 사건 종류
- 분리 후보 가중치 합

이는 반사실적으로 다른 사건을 실행하지 않는다. 실제 상태에서 당시 존재했던 후보만 읽는다.

## 4. 해석 경계

- 후보 확률이 낮다는 사실만으로 가중치를 올리지 않는다.
- 분리가 많이 선택됐다는 이유로 분리를 제거하지 않는다.
- 고정 가중치가 결과를 편향했다면 이를 자연 선택 결과가 아니라 사람이 둔 수치 근사로 기록한다.
- 현재 자료는 seed 두 개뿐이므로 seed별 우열을 판단하지 않는다.
