# 세계 생성 언어의 설계 경계

## 장기 목표

1. **Life** — 자기 유지·복제·변이가 물질 과정에서 출현하는가.
2. **Intelligence & Culture** — 감각·계산·기억·통신·비유전적 전달 방식 자체가 진화하는가.
3. **Open History** — 지식과 환경 변화가 새 가능성을 만들며 열린 역사가 지속되는가.

우리는 생명, 지능, 언어, 문명 또는 그 아키텍처를 직접 구현하지 않는다. 그것들이 발생할 수 있는 공통 법칙과
물질적 자유도만 구현한다.

## 엔진에 허용되는 것

- 물질, 위치, 시간, 에너지와 보존 법칙
- 국소 이동, 충돌, 결합, 분리, 접힘, 절단, 재결합
- 실제 구조와 거리에 따른 신호 전달 비용과 지연
- 감각·계산·기억 구조가 될 수 있는 물질적 상태 변화
- 모든 실패, 정체, 붕괴와 멸종
- 세계 밖 관찰자의 재생·계보·호환성 분석

## 엔진에 직접 넣지 않는 것

- `COPY_GENE`, `MAKE_CELL`, `DIVIDE`, `FORM_LANGUAGE` 같은 결과 명령
- Transformer, 신경망, 입력·출력 노드 등 인간이 고른 최종 지능 구조
- 언어군, 종, 사회, 화폐, 국가, 전쟁, 과학이라는 내부 분류
- 생존·복제·복잡성 증가를 보장하는 점수나 구조 보상
- 중요하지 않아 보인다는 이유로 원인을 삭제하는 시간 건너뛰기

## 현재 이산 세계의 정확한 범위

현재 `engine.sequence`는 정수 격자와 이산 사건으로 정의한 실험 세계다. 이 모델 안에서 가능한 이동과 반응은
후보에서 결과를 보고 제거하지 않으며, 난수 기록으로 재생한다. 이것은 연속 현실의 근사 오차를 추적하는
하이브리드 물리 엔진이 아니다. 따라서 현재 결과는 **정의된 이산 법칙 아래 가능한 역사**라는 범위에서만
해석한다.

장차 연속장을 추가할 때는 다음 조건이 필요하다.

- 정확히 해석 가능한 구간만 사건 시점으로 건너뛴다.
- 중간 원인이 상태를 바꾸면 예약된 미래 사건을 무효화하고 다시 계산한다.
- 근사값과 수치 오차 범위를 함께 보존한다.
- 낮은 해상도가 미래 원인을 지울 가능성이 있으면 해상도를 높인다.
- 최적화 전후에 동일한 인과 궤적을 만든다는 검증 없이는 건너뛰지 않는다.

## 현재 통합 결정

서열의 각 자리는 실제 격자 좌표를 가진다. 같은 서열의 골격과 서열 사이의 접촉은 인접한 위치에서만 유지될
수 있다. 절단은 같은 물질 자리를 두 조각으로 다시 식별하며 물질을 만들지 않는다. 재결합은 두 조각의 끝이
실제로 인접할 때만 가능하다. 결합된 골격과 접촉 구조는 하나의 연결 성분으로 이동한다.

이 단계는 복제나 생명을 구현한 것이 아니다. 세계가 그런 관계를 표현할 수 있도록 공간·서열·구조 반응을 같은
물리 상태에 연결한 것이다.
