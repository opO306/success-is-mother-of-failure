# 08. B0 구현·학습 로드맵

*새 LLM을 처음부터 만들지 않고, 기존 모델을 한 기관으로 사용해 B의 구조부터 검증한다*

| **\[목표\]** B0의 목적은 “완성형 지능”이 아니다. World Language만 읽고 쓰면서 관찰 → 가설 → 실험 → 실패/이상치 보존 → 다음 실험의 루프가 실제로 돌아가는지 증명하는 최소 연구 시스템을 만드는 것이다. |
|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

# 1. 처음부터 새 신경망을 만들지 않는 이유

A, World Language, B 아키텍처, 새로운 신경망을 동시에 바꾸면 어떤 요소가 성능과 실패를 만들었는지 분리하기 어렵다. 따라서 기존 LLM을 언어·추론 코어로 쓰고, 기억·가설·탐색·검증을 외부 시스템으로 먼저 만든다.

# 2. B0 최소 구성

| **구성**                 | **초기 구현**                                         |
|--------------------------|-------------------------------------------------------|
| LLM Core                 | 기존 Qwen 등. 논문 읽기, 가설 후보, 설명, WSL 초안    |
| World Language Interface | A와 B 사이의 유일한 세계 정의·관측 통신 계층          |
| Validator                | 문법, 보존, 기하, 권한, 자원 충돌 검사                |
| Hypothesis Graph         | 가설 상태·조건·반례·부모/자식 계보 저장               |
| Research Memory          | SQLite/파일 기반으로 논문·실험·anomaly·계보 저장      |
| Broad Explorer           | 조건 조합 대량 실행 및 경계/이상치 탐색               |
| Deep Investigator        | 특이점 하나의 조건 제거·추가·반사실 분석              |
| Meta Controller          | 넓게 탐색 / 깊게 분석 / 기억 검색 / 실험 설계 중 선택 |

# 3. B0의 입력과 출력

```text
입력

- World Language 사전

- 현재 State / Event 기록

- 관련 Research Memory

- 이전 Hypothesis


출력

- 관찰된 패턴

- 복수 가설

- 각 가설의 적용 조건/반증 조건

- 다음 실험 제안

- anomaly 후보

- 필요하면 WSL 표현 한계 제안
```

최종적으로 사람에게는 자연어 설명을 보여주더라도, 내부 저장은 구조화된 가설·상태·사건으로 남긴다.

# 4. 학습은 무엇을 시키는가

처음부터 모든 논문 지식을 파라미터에 외우게 하기보다, 연구를 수행하는 방법과 논문을 구조화하는 능력을 학습시키는 쪽이 우선이다.

1.  논문 구조화: 주장, 전제, 실험 조건, 증거, 한계, 실패, 반증 조건을 분리한다.

2.  충돌하는 논문 비교: 하나를 즉시 정답으로 고르지 않고 여러 설명을 동시에 유지한다.

3.  실험 설계: 가설들을 구분하고 경계를 찾는 조건을 제안한다.

4.  A 세계 실험: B 예측과 A 실행 결과를 비교하고 가설 상태를 갱신한다.

5.  자기 연구 기록 활용: 성공·실패·anomaly·재조합 사례를 다음 B의 학습 자료로 사용할 수 있다.

# 5. 논문 데이터의 취급 원칙

논문은 가능한 한 많이 연구 기억에 넣되, 출판됐다는 이유로 “진실” 레이블을 붙이지 않는다. 실패 논문, 재현 실패, 철회 논문도 아이디어 계보와 실패 조건을 알려주는 중요한 연구 자산으로 보존한다.

| **좋은 저장 상태**          | **예시**                         |
|-----------------------------|----------------------------------|
| independently_replicated    | 독립 연구에서 반복 재현          |
| partially_replicated        | 일부 조건에서만 재현             |
| not_replicated              | 재현 시도에서 성공하지 못함      |
| contradicted_in_domain      | 특정 범위에서 후속 결과와 충돌   |
| retracted                   | 논문 자체가 철회됨               |
| theoretical/simulation_only | 실물 실험이 아닌 이론/시뮬레이션 |
| unknown                     | 현재 판단에 필요한 정보 부족     |

# 6. 첫 번째 실제 시험 세트

6.  WSL 표현 한계 찾기: World Language만 보여주고 표현 불가능한 상황을 제안하게 한다.

7.  의도적으로 이상한 물리 세계 관찰: 코드 없이 State/Event만 보고 보존·패턴 이상을 찾아내는지 본다.

8.  가설 다중 유지: 같은 관측에 대해 최소 3개 설명을 보존하고 실험으로 구분하게 한다.

9.  anomaly 보존: 99%와 다른 1% 사례를 noise로 삭제하지 않는지 본다.

10. 실수 추적: intended/actual 조건이 다른 실행을 원래 가설 검증에서 분리하면서도 별도 발견 후보로 보존하는지 본다.

11. 과거 실패 재사용: 새 조건이 등장했을 때 관련된 과거 실패 가설을 검색해 재조합하는지 본다.

# 7. 언제 새 신경망을 만들 것인가

B0를 실제로 돌린 뒤 반복적으로 나타나는 병목을 기록한다. 예를 들어 언어 모델이 세계 관계를 계속 놓치거나, anomaly 탐지가 약하거나, 장기 연구 기억을 제대로 활용하지 못하는 문제가 확인되면 그 모듈을 전용 신경망으로 교체한다.

```text
처음

기존 LLM + 외부 구조


실험 후 병목 확인

↓

World Representation이 약함? → 전용 world model 연구

Anomaly 탐지가 약함? → 전용 detector 연구

Meta Controller가 약함? → 정책/학습 구조 연구

언어 계층이 병목? → 자모/동적 압축 모델 연구
```

| **\[현재 가장 중요한 것\]** 새 모델을 크게 만드는 것보다, B가 세계를 “연구하는 루프”를 실제로 돌릴 수 있는지 먼저 증명한다. 그 루프가 성공하면 이후 신경망 구조는 실제 필요에 따라 바뀔 수 있다. |
