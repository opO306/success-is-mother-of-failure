# 07. 자연어 없이 생각하기와 자모 수준 학습

*자연어는 인터페이스로 두고, 내부 사고는 세계 표현·그래프·벡터·WSL로 수행하는 방향*

| **\[핵심 질문\]** B가 꼭 자연어 문장으로 생각해야 하는가? 대화에서의 결론은 “그럴 필요가 없다”는 방향이다. 사람에게 입력받고 설명할 때만 자연어를 사용하고, 내부에서는 더 직접적인 세계 상태 표현으로 사고할 수 있다. |
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

# 1. 자연어와 사고를 분리한다

```text
사람의 자연어

↓

언어 해석기

↓

내부 세계 표현

(물체 / 관계 / 상태 / 원인 / 가설 / 사건)

↓

B의 연구·추론

↓

WSL / A 실험 / Research Memory

↓

자연어 생성기

↓

사람에게 설명
```

예를 들어 “온도가 올라가면 왜 구조가 깨지는지 조사해”라는 요청을 받은 B가 내부에서 한국어 문장을 반복할 필요는 없다. 가설 노드, 변수 관계, 관측 증거, 다음 실험 같은 구조체나 벡터로 사고하고 마지막에만 설명을 만들 수 있다.

# 2. 기존 LLM을 그대로 진실 판정자로 쓰지 않는 이유

기존 LLM은 문법적으로 자연스럽고 문맥상 그럴듯한 문장을 만들 수 있지만, 그 문장이 물리적으로 가능한지는 별도 문제다. 따라서 자연어 주장 → 세계 표현 → Validator/A 실행의 단계를 둔다.

```text
자연어 주장:

"충돌 후 외부 에너지 없이 운동에너지가 2배가 됐다"


세계 표현:

KE_before = 10

KE_after = 20

external_energy = 0


Validator:

energy mismatch = +10

→ 자연어가 자연스러워도 물리 주장으로는 거부/미해결
```

# 3. 자모 수준 학습 아이디어

한국어를 큰 토큰 단위로만 보는 대신 자모·음절 같은 더 작은 구성요소부터 학습하면, 처음 보는 단어·활용·철자 변형을 더 근본적인 패턴으로 다룰 수 있다는 아이디어가 나왔다.

```text
먹었습니다

↓

먹 / 었 / 습 / 니 / 다

↓ 더 세분화 가능

ㅁ ㅓ ㄱ / ㅇ ㅓ ㅆ / ㅅ ㅡ ㅂ / ㄴ ㅣ / ㄷ ㅏ
```

장점 후보는 작은 사전, 희귀 표현 대응, 형태 변화 학습, 낯선 표현의 구조적 분석이다. 반면 단위가 작아질수록 입력 길이가 길어져 계산비가 커질 수 있으므로 “더 잘게 쪼개면 무조건 효율적”이라고 볼 수는 없다.

# 4. 학습하면서 내부 단위를 스스로 압축하는 방향

대화에서 가장 흥미로운 제안은 작은 단위를 계속 유지하되, 반복되는 패턴을 경험하면서 더 큰 내부 단위를 만들어가는 계층이다. 사람 아기가 작은 소리·패턴에서 시작해 단어와 개념을 익히는 비유와 비슷하지만, 실제 구현은 별도 검증이 필요하다.

```text
자모

↓

음절

↓

형태/단어

↓

구문

↓

개념

↓

관계

↓

세계 상태

↓

인과 구조
```

중요한 점은 이 단계들을 사람이 전부 고정된 규칙으로 박아 넣기보다, 반복되는 패턴을 압축해 새로운 내부 표현을 만들 수 있는 구조를 연구하는 것이다.

# 5. Attention을 없애는 것이 목표는 아니다

자모 수준 표현과 장거리 관계 처리는 별개의 문제다. 문자의 기본 구성은 잘 알아도 수백 문장 전의 개념과 현재 상태의 관계를 연결하려면 어떤 형태로든 장거리 기억·관계 계산이 필요하다. 따라서 목표는 “Attention 제거”보다 “각 표현 층에 맞는 계산 방식을 선택”하는 것이다.

| **\[검증 필요\]** 자모→동적 압축→세계 관계 표현이 실제로 기존 tokenizer+Transformer보다 유리한지는 실험해야 한다. B0에서는 기존 LLM을 사용하면서 내부 사고를 자연어 밖으로 분리하고, 언어 층의 새로운 신경망은 실제 병목이 확인된 뒤 설계하는 편이 안전하다. |
