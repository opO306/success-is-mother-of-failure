# 현재 강제 조건 감사

**기준:** `PROJECT_CONSTITUTION.md`  
**범위:** 기존 `engine.primal` 기준선과 새 `engine.living` 프로토타입  
**날짜:** 2026-09-17

이 문서는 코드가 실행되는지를 평가하지 않는다. 사람이 넣은 가정이 세계의 가능성을 어디까지 제한하는지
설계자가 판단할 수 있게 분류한다.

## 1. 유지할 세계 불변식

| 항목 | 이유 | 현재 상태 |
|---|---|---|
| 음수·NaN·무한 물질 금지 | 존재하지 않는 양과 계산 오류를 막는 장부 조건 | 구현됨 |
| 관찰자 이름과 내부 상태 분리 | 이름이 능력이나 행동이 되는 것을 막음 | 구현됨 |
| 기록·분석 결과의 세계 역류 금지 | 관찰자가 선택압을 만들지 않게 함 | 경계만 구현, 기록기 미구현 |
| 계보 없는 출생 금지 | 유전 변화의 원인을 추적하기 위한 인과 조건 | 새 언어에서 구현 예정 |
| 멸종 후 자동 보충 금지 | 실패와 소멸을 결과로 보존 | 원칙 확정 |
| 같은 seed와 사건 기록의 재생 | 우연을 제거하지 않고 검증 가능하게 함 | 미구현 |

## 2. 임시 근사이며 최종 법칙이 아닌 것

| 현재 구조 | 무엇을 강제하는가 | 처리 방침 |
|---|---|---|
| 익명 물질 채널 벡터 | 물질 종류와 차원 수를 사람이 먼저 정함 | 원시 실행 기반 실험용으로만 유지 |
| `BoundaryPhenotype` | 저장량·투과율·유지비·이동 능력을 직접 제공 | 발생 언어가 만들도록 교체 |
| 거리 감쇠 후 `tanh` 감각 | 잡음 없는 하나의 감각 곡선 | 확률적 수용·손실과 발생 수용체로 교체 |
| `material_weights` 보존 | 실제 에너지·운동량 대신 임의 가중합을 보존 | 반응별 장부 검증용 임시 모델 |
| Python dataclass 기반 `Genome` | 유전체가 실행 언어가 아니라 정해진 필드 묶음 | 진화 언어 v0로 교체 |

## 3. 새 최종 경로에서 제거할 강제 구조

| 현재 구조 | 문제 | 근거 |
|---|---|---|
| 흡수→반응→이동→유지 고정 순서 | 코드 순서가 자원 우선권과 생존을 결정 | 헌법 제1·4·16조 |
| 경쟁 반응의 동일 `common_scale` | 자연법칙이 아닌 공평성 정책 | 헌법 제4·14조 |
| 단일 `damage`와 사망 문턱 | 서로 다른 기능 붕괴를 하나의 점수로 축소 | 헌법 제5·6·21조 |
| `ProcessLaw.damage_delta` | 구조 회복을 거치지 않고 치유 결과를 직접 부여 | 헌법 제4·5조 |
| 고정 `BodyIntent` 행동 목록 | 언어가 만들 수 있는 작용 범위를 사람이 고정 | 헌법 제4·6조 |
| 비결정성을 결함으로 보는 문구 | 확률적 법칙과 재현 가능성을 혼동 | 헌법 제16조 |

이 항목들은 현재 프로토타입에서 즉시 삭제하지 않는다. 새 언어 경로가 준비될 때까지 비교와 회귀 확인을 위한
부트스트랩으로 보존하지만 최종 공동 진화 실행에서는 사용하지 않는다.

## 4. 기존 스크립트 생태 기준선

`engine.primal`과 `tools/validate_olduvai.py`에는 다음 강제가 있다.

- 종 이름별 먹이 목록
- 종 이름에 따른 사냥·도망·활동 시간
- 공격, 갈증, 사냥, 채집의 고정 우선순위
- 진단 개체의 정답 음식 목록

이는 과거 세계의 물질 흐름과 지형 오류를 찾기 위한 `scripted ecology baseline`이다. 새 생명 언어로 복사하지
않으며, 이 코드가 생존했다는 사실을 새 언어의 생존 가능성 증거로 사용하지 않는다.

## 5. 현재 테스트 분류

### 불변식 테스트로 유지

- 음수 자원과 차원 불일치 거부
- 관찰자 분류명을 바꿔도 물리 상태 동일
- 몸과 환경 사이 물질 장부 일치
- 이름·먹이·종 필드의 새 생명 상태 누출 방지

### 분포 테스트로 교체

- 정확한 감각 출력값
- 정확한 흡수·이동·손상량
- 반응 경쟁의 동일 비율
- 고정 횟수 뒤 사망

이 항목은 앞으로 단일 숫자를 정답으로 요구하지 않고, 기록된 조건에서 가능한 분포와 불변식만 검사한다.

### 관찰만 하며 통과 조건으로 쓰지 않음

- 특정 계통의 생존
- 포식자 수 유지
- 지능·복잡성 증가
- 언어·문화 발생
- 병렬형 또는 순차형 구조의 우세

## 6. 감사 결론

현재 새 코드는 의미 누출을 막는 경계 실험으로는 유효하지만 진화 가능한 언어 또는 최종 세계 법칙은 아니다.
다음 구현은 고정 몸 필드를 확장하는 작업이 아니라 관측 격리 기록기, 확률 사건원과 최소 실행 기반이어야 한다.
