## 2. 정확한 분수의 정규 표현

- 내부: Python `fractions.Fraction` — 항상 기약분수, 분모 양수, 0 = 0/1.
- **부동소수점 금지:** 생성 입력은 `int` 또는 `"분자/분모"` 문자열만 받는다. `float`가 들어오면 거부(테스트로 강제).
  `Fraction(0.1)` 같은 경로가 조용히 생기지 않게 `v5_number`가 유일한 생성 창구다.
- 직렬화: `[분자, 분모]` 정수 쌍(기약, 분모 > 0). 같은 물리값은 항상 같은 바이트 → 같은 해시. `2/4`와 `1/2`가 다른 해시를
  만들 수 없다.
- 벡터: `(x, y)` 두 분수의 튜플.

## 3. 명세 / 런타임 상태 / 실행 요청 — 세 가지를 섞지 않는다

### 3.1 세계 명세 (`v5_spec`) — 세계의 법칙과 처음 모습

```
format            "deterministic-causal-world-spec-v5"
units             질량·길이·시간 단위 이름 + SI 환산값(분수)        ← 필수 (E8)
materials[]       kind, mass(양의 분수), contact_half_width(양의 분수), ports ⊆ {N,E,S,W}
bond_rules[]      rule_id, (kind, port) 쌍 둘, threshold(에너지 단위의 분수 ≥ 0)
initial.elements[]    label(문자열), kind, position
initial.structures[]  members(label 집합), bonds[(label, port, label, port)], momentum, internal_energy
```

- 자유 입자도 멤버 하나짜리 구조로 적는다(표현 통일).
- **실행기용 캐시·사건 대기열·관측 간격은 명세에 없다.** 명세 digest는 세계만 정한다.
- 검증(거부): 부동소수점, 단위 누락, 겹침(두 몸의 내부가 겹침), 결합 멤버가 해당 포트 면으로 정확히 맞닿지 않음,
  같은 포트 이중 사용, 구조 멤버가 결합 그래프의 연결 성분과 다름, 음의 내부 에너지.

### 3.2 런타임 상태 (`v5_state`)

```
time                   현재 물리 시각 (분수)
elements               label → (kind, position)
structures             members, bonds, momentum, internal_energy
```

- 구조의 정체성은 **멤버 집합에서 유도**한다(별도 ID 없음 → 재명명 불변).
- 질량·속도·운동 에너지는 유도량 — 저장하지 않는다(E1).
- 정규 직렬화: 요소는 label 순, 구조는 정렬된 멤버 목록 순. 재명명 비교는 "사상한 뒤 다시 정렬"로 한다.

### 3.3 실행 요청 — 세계가 아니라 "어떻게 보나"

```
end_time               언제까지
observation_interval   관측 간격 (K1: 물리가 아님)
meter                  분모 측정 켬/끔 (7절)
```

실행 요청은 명세 digest에 들어가지 않는다. 같은 세계를 다른 간격으로 보는 것이 가능해야 한다.

## 4. 사건 처리 알고리즘 — 코드 전에 고정

```
state ← 명세의 처음 모습, time = 0
loop:
  1. 모든 "서로 다른 구조에 속한 요소 쌍"을 검사해 다음 접촉 시각을 구한다      (색인 없음 — 전부)
  2. 가장 이른 시각 t 를 찾는다. t > end_time 이면 end_time까지 이동하고 종료
  3. 모든 구조를 t 까지 등속 이동 (위치 += 속도 × (t − time))  — 정확한 분수
  4. 시각 t 에 일어나는 접촉 사건을 **전부** 모은다
  5. **사건 직전 상태를 동결**하고, 각 사건을 그 동결 상태 기준으로만 판정한다   (5절)
  6. 충돌 그래프를 만든다                                                         (6절)
  7. 하나라도 정의되지 않은 사건이면 → 기록 + 정상 종료(중단 결과)              (6.3)
     아니면 → 결합 그래프의 연결 성분마다 한 번에 병합                           (6.2)
  8. time = t, 반복
```

**접촉 시각 계산 (정사각형 두 개, K3):** 상대 위치 `d(t) = d₀ + t·Δv`, 폭 `w = hwA + hwB`. 축마다 "간격이 `w` 미만인 시각
구간"을 1차 방정식으로 구한다 — **닫힌 조건** `|dx| ≤ wx`, `|dy| ≤ wy` (보강 3). 상대 속도 0이면 항상 또는 절대.
두 닫힌 구간의 **첫 공통 시각**이 접촉 시각이다. 그 순간 한 축은 정확히 `=`, 다른 축은 `≤`이고,
**나중에 시작된 축이 접촉 면**을 정한다(x축이 나중 → 동/서 면). 두 축이 **같은 시각**에 `=` → 모서리 접촉.
`< w`로 쓰면 정확히 경계에서 닿는 접촉을 놓친다.
**다가오는 경우만** 접촉 사건이다: 이미 맞닿아 있으나 법선 방향으로 다가오지 않는 쌍은 사건이 아니다.

**하지 않는 것 (7번 원칙):** 공간 색인·해시·BVH 없음. 캐시 없음. 병렬화 없음. 부동소수점 없음. 휴리스틱 없음.
**순서를 정하려고 이름표를 쓰지 않음.** "성능 때문에" 후보를 생략하지 않음. 지독하게 느리고 지독하게 명백해야 한다 —
이 실행기의 존재 이유가 그것이다.

## 5. 판정은 사건 직전 상태로만

시각 t의 모든 사건에 대해, **아무것도 적용하기 전의 상태**로:

| 판정 | 기준 |
|---|---|
| 접촉 면 | 4절 계산 (모서리면 정의되지 않음) |
| 포트 | 두 요소 모두 그 면에 포트가 있고, **직전 상태에서** 비어 있는가 |
| 규칙 | (kind, port) 쌍에 맞는 결합 규칙이 있는가 |
| 문턱 | 두 **구조**의 직전 속도로 `½ μ |Δv|²` ≥ threshold (E5 — 전체 상대 운동 에너지) |

하나를 먼저 적용하고 다음 사건을 판정하면 처리 순서가 물리에 들어간다 — 금지.

## 6. 동시 사건 — 충돌 그래프

### 6.1 분류
- **결합 가능 사건:** 면·포트·규칙·문턱 모두 통과
- **정의되지 않은 사건:** 모서리 접촉(`CornerContact`), 비결합 접촉(`NON_BINDING_COLLISION_UNRESOLVED` — 포트·규칙이 없거나
  문턱 미달), 같은 요소의 같은 포트를 두 사건 이상이 요구(`ContestedContact`)

### 6.2 동시 다중 결합은 한 번에
결합 가능 사건들을 "구조를 잇는 선"으로 보고 **연결 성분**을 구한다. 성분 하나 = 병합 단위 하나.

```
      A - B              AB 먼저 → 그다음 C 가 아니다.
          |              {A, B, C} 를 한 번에:
          C              P' = ΣPᵢ, U' = ΣUᵢ + ΣKᵢ − K'  (E3 병합 보존식)
```

순차 병합은 쌍별 계산 순서에 따라 중간 속도가 달라질 수 있다 — 연결 성분 단위로만 병합한다.

### 6.3 중단도 정상적인 결과다
정의되지 않은 사건이 **하나라도** 있으면 시각 t의 어떤 사건도 적용하지 않고 종료한다. 결과:

```
outcome = "halted"
halt_time = t
state = 시각 t 로 이동한 직후, 아무 사건도 적용하지 않은 상태
unresolved = [정의되지 않은 사건들 — 종류, 참가자, 면]
```

**예외(프로그램 오류)와 구분한다:** 명세가 틀림·불변식 위반·내부 버그는 예외다. "세계가 정의되지 않은 물리에 도달함"은
정규화된 결과이며 해시·비교·census 대상이다.

### 6.4 같은 순간의 연쇄 — 인과 라운드 (P2, K4와 연결)

```
시각 t, 라운드 0:  t에 이미 일어나는 사건을 **전부** 찾는다 → 동결된 직전 상태로 동시에 판정
                   → 모호함 있으면 아무것도 적용하지 않고 중단, 아니면 동시에 적용
라운드 0의 결과 때문에, 그전에는 사건이 **아니었던** 접촉이 새 사건이 되면:
시각 t, 라운드 1:  새 상태를 동결 → **새로 활성화된** 사건을 전부 찾는다 → 같은 절차
반복
```

**라운드 1은 라운드 0에서 빼먹은 사건을 처리하는 곳이 아니다.** A-B 병합으로 AB의 속도가 바뀌어, 이미 옆에 닿아 있던 C를
그 순간부터 밀기 시작했다면 라운드 1이 정당하다. 반대로 라운드 0에서 A-B와 B-C가 **모두 이미 사건이었다면** 둘 다 라운드 0에서
처리해야 한다 — B-C를 라운드 1로 미루면 K4("처리 순서에 따라 결과가 달라질 수 있으면 중단") 위반이다.
구현: 라운드 k에서 찾은 사건 집합은 라운드 k−1의 사건 집합과 **겹칠 수 없다**(겹치면 내부 오류).
테스트: `same_time_existing_event_cannot_be_deferred_to_next_round`.

**끝난다는 증명:** 중단하지 않은 라운드는 적어도 하나의 결합 = 적어도 하나의 병합을 포함하므로 구조 수가 1 이상 줄어든다.
구조 수는 유한하고 1 미만이 될 수 없으므로, 같은 시각의 라운드는 유한 번 뒤 끝난다. 사건 기록에 라운드 번호를 남긴다.

## 7. 분모 측정 — 처음부터 계측 지점으로

`v5_meter`는 실행기가 사건마다 넘겨주는 **정규화된 상태의 사본**만 읽는다. 기록:

| 항목 | 사건마다 |
|---|---|
| 시각 | 분자·분모 비트 길이 |
| 위치·속도 (구조별 최대) | 분자·분모 비트 길이 |
| 운동·내부 에너지 | 분자·분모 비트 길이 |
| 각운동량 잔차 (E7) | 분자·분모 비트 길이 |
| 시간 | 산술에 쓴 시간 / 전체 시간 |

요약: 최대·중앙값·사건 수에 따른 증가 곡선. **측정을 켜도 끄도 정규화된 결과가 같아야 한다**(테스트).
측정 세계: 1만·10만 관측 시각, 충돌이 많은 세계 — 단 비결합 접촉이 중단시키므로(S7) "충돌이 많은 세계"는 결합 가능한
조합으로 설계해야 한다.

## 8. 검사 — 구현과 독립적으로

**독립 감사(`audit/independent_v5/`):** 실행 결과 JSON(명세 + 사건 기록 + 관측 스냅숏)만 읽고, 자기 분수 파서로 사건마다
재계산한다. `engine`을 import하지 않는다.

**사건 기록에 감사용 물리 상태를 담는다 (보강 2).** 관측 스냅숏은 사건 시각과 맞지 않을 수 있으므로, 결합 사건마다:

```
pre:   참가한 각 구조의 members, momentum, internal_energy, 멤버 위치
post:  병합된 구조의 members, momentum, internal_energy, 멤버 위치
```

질량은 감사기가 **명세의 재료에서 직접** 다시 계산한다. 감사기는 엔진이 써준 `kinetic_energy_absorbed`를 **믿지 않는다** —
`Mᵢ, Kᵢ, P', K'`를 스스로 계산해 `U' == ΣUᵢ + ΣKᵢ − K'`와 운동량을 검사하고, 엔진이 쓴 흡수량은 **검사 대상**으로 대조한다.
검사기가 피검사자의 답안지를 받아 그대로 채점하면 안 된다.

| 검사 | 내용 |
|---|---|
| 질량 보존 | 전 시각 |
| 운동량 보존 | 사건마다 정확히 |
| `K + U` 보존 | 사건마다 정확히 |
| 병합 보존식 | `U' = ΣUᵢ + ΣKᵢ − K'` — 사건 기록의 흡수량과 일치 |

**실행기 쪽 테스트:**

| 테스트 | 내용 |
|---|---|
| 재명명 불변 | label 치환 → 사상한 결과와 같음 |
| 입력 배열 순서 불변 | 요소·구조·결합·규칙 순서 섞기 |
| 관측 간격 불변 (K1) | 간격 1, 1/2, 1/3 → 공통 시각 상태 + 사건 기록 같음 |
| 갈릴레이 불변 (E6) | 모두에 속도 u 더함 → 같은 사건·같은 시각, 위치만 u·t 이동, U 같음 |
| 동시 사건 순열 불변 | 같은 시각 사건 목록 순서 섞기 |
| 접선 문턱 (E5) | 법선 속도 고정, 접선 속도만 변화 → 정의대로 통과 여부 변화 |
| 내부 에너지 가진 구조의 GROW | 기존 U가 넘어가는지 |
| 3개 이상 동시 병합 | 연결 성분 한 번 병합, 보존 |
| 홀짝 독립 | 짝수·홀수 간격 정면 접근 모두 접촉 |
| 중단 결과 | 모서리·비결합·다툼 각각 정규화된 중단 결과 (예외 아님) |
| 부동소수점 거부 | float 입력 거부 |
| **물리 모듈 float 유입 차단 (보강 4)** | `v5_number`·`v5_spec`·`v5_state`·`v5_reference`에 AST 검사: float 리터럴·`float()`·`math` 부동소수점 함수 금지. 결과 타입이 `int | Fraction`인지 확인 (`Fraction * 0.5`가 조용히 float가 되는 경로 차단). **`v5_meter`의 실행 시간(`perf_counter`)은 예외** — 물리가 아니며 정규화 결과에서 제외 |
| 라운드 미루기 금지 | `same_time_existing_event_cannot_be_deferred_to_next_round` |
| 측정 무영향 | 측정 켬/끔 같은 결과 |

**결함 주입 (`python -B`, 캐시 삭제):** 이름표로 순서 정하기 · 쌍별 순차 병합 · 병합식에서 `ΣU` 빠뜨리기 · 문턱을 전체 운동
에너지 합으로 · 하나 적용 후 다음 판정 · float 한 곳 섞기 · 관측 시각에 따라 사건 계산 · 모서리 판정 생략 · "다가오는 중"
조건 생략 · 중단 대신 한쪽 선택. 전부 잡혀야 한다.

## 9. 계획 중 드러난 결정 사항

| | 질문 | 권고 |
|---|---|---|
| P1 | 공간 경계 | **경계 없는 평면.** 순환 경계(torus)는 거울상 검사가 필요해 기준 실행기를 복잡하게 한다. 갈릴레이 검사 범위(E6)와도 맞다 |
| P2 | 같은 순간의 연쇄 (6.4) | **라운드 처리**, 기록에 라운드 번호 |
| P3 | 문턱 미달 접촉 | 비결합 접촉과 같이 **기록 + 중단** (S7 결정의 적용 — 확인 필요) |
| P4 | 처음 모습에서 맞닿아 있지만 결합 안 된 쌍 | 허용 (다가오지 않으면 사건 아님) |
| P5 | 질량 | 양의 분수 허용 |
| P6 | 구조 정체성 | 멤버 집합에서 유도, 별도 ID 없음 |

**P3은 알고 있어야 할 결과가 있다:** 모든 비결합 만남이 실행을 멈추므로, 입자가 많은 세계는 곧 멈출 가능성이 크다.
처음 측정 세계는 멈추지 않도록(결합 가능한 만남만 일어나게) 설계해야 하고, 멈춘 빈도 자체가 "다음에 충돌 역학을 열어야
하는가"의 데이터가 된다.

**구현 순서 (승인 뒤, 각 단계마다 테스트):** `v5_number` → `v5_spec` 검증 → `v5_state` 불변식 → 이동·접촉 시각 계산 →
판정·충돌 그래프·병합 → 중단 결과 → 불변 테스트 전부 → 독립 감사 → `v5_meter` → 결함 주입 → 측정 세계 → 그 다음 GEO v1B.
