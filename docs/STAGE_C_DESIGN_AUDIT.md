# 단계 C 자기 해석형 서열 설계 감사

**대상:** `docs/SELF_INTERPRETING_SEQUENCE_SUBSTRATE_V0.md`  
**판정:** 방향 통과, 수치 법칙 확정 전 구현 보류

## 1. 설계 의도와 일치하는 부분

- 완성 행동이나 뇌 구조를 명령어로 제공하지 않는다.
- 고정 코돈표와 중앙 해석기가 없다.
- 모든 서열이 정보와 작용의 양쪽 역할을 할 수 있다.
- 한 기호 변이가 전체 프로그램 오류가 아니라 결합 분포의 변화가 될 수 있다.
- 언어군은 이름표가 아니라 실제 상호 결합과 공동 발생의 차이로 관찰한다.
- 복제, 잠복, 촉진과 억제는 목표가 아니라 동일한 국소 사건 법칙의 가능한 결과다.
- CPU와 GPU의 역할은 세계 밖 실행 최적화로 남는다.
- 4차원 관찰자는 완료된 실제 역사와 별도 분기를 볼 뿐 미래를 세계 안에 누출하지 않는다.

## 2. 여전히 강제된 최소 구조

다음은 없앨 수 없는 선택이지만 정답 행동을 직접 지정하지 않는지 계속 감사해야 한다.

| 선택 | 필요한 이유 | 위험 |
|---|---|---|
| 네 종류 기호 | 변이 가능한 최소 재료 제공 | 네 개가 지나치게 생물 DNA를 모방할 수 있음 |
| 두 물리 축 | 부분 호환과 연속 효과 제공 | 특정 결합 구조를 선호할 수 있음 |
| 방향 있는 골격 | 순서와 주형 성장 가능 | 방향 자체가 문법 편향이 될 수 있음 |
| 국소 공간 | 몸과 경계가 생길 조건 | 격자 모양이 구조를 편향할 수 있음 |
| 에너지 장부 | 무제한 반응 방지 | 상수 선택이 생존 전략을 사실상 결정할 수 있음 |
| 구조 정렬 촉진 | 서열이 다른 반응에 영향을 줄 통로 | 구현이 숨은 효소 명령표가 될 수 있음 |

## 3. 제거한 강제

- `ACG`처럼 특정 문자열을 행동에 연결하는 표
- 유전자 시작점과 종료점
- 유전체/단백질/뉴런의 고정 자료형
- 복제 성공을 보장하는 내장 효소
- 서열 문법 오류와 자동 삭제
- 계통별 교배 허용표
- CPU형·GPU형 개체 분류
- 생존을 유지하기 위한 실행 중 상수 조정

## 4. 근사와 미구현

- 실제 분자 역학 대신 접촉 그래프를 사용할 예정이다.
- 물리 축의 정확한 결합식과 사건 발생률은 아직 미확정이다.
- 공간 차원과 격자 형식은 검증 세계 설정으로 남아 있다.
- 병렬 사건용 순서 독립 확률 표본은 아직 단계 B 기록기에 없다.
- 인간 번역기의 출력 자료 구조는 아직 정의하지 않았다.
- 자연 발생 가능성과 계산 시간은 아직 알 수 없다.

## 5. 구현 전에 반드시 반증할 질문

1. 기호 이름과 좌표를 함께 치환해도 결과가 달라지지 않는가?
2. 한 기호 변화가 지나치게 자주 전체 구조 붕괴로 이어지지 않는가?
3. 촉진 규칙 없이도 주형 성장이 가능하고, 촉진은 속도만 바꾸는가?
4. 특정 배열 순서나 GPU 스레드 순서가 사건의 승자를 정하지 않는가?
5. 수치 상수가 특정 길이·무늬·계통의 생존을 몰래 보장하지 않는가?
6. 번역기가 붙인 이름을 제거해도 세계 실행이 완전히 같은가?
7. 무작위 최초 발생 실험에 사람이 만든 검증 서열이 섞이지 않는가?
