# 자기 해석형 서열 골격 절단 수치 물리 v0

**상태:** 단계 C 기준 실행기 네 번째 조각  
**상위 수치 명세:** `docs/SEQUENCE_TEMPLATE_GROWTH_NUMERIC_V0.md`

## 1. 목적

노출된 선형 서열의 골격 결합이 확률적으로 끊어져 두 조각이 되게 한다. 절단은 실패 벌점이 아니라 성장과
같은 세계 법칙이며, 손상·결실·조각 재사용과 이후 재조합이 일어날 재료를 제공한다.

## 2. 절단 후보

길이 2 이상인 서열의 인접 기호 사이마다 골격 절단 위치가 있다.

다음 조건을 만족하면 절단 후보가 된다.

- 절단점 양쪽 기호가 측면 결합이나 접힘에 사용되지 않았다.
- 절단점이 선형 서열 내부에 있다.

접힌 구조나 주형 결합이 골격 자체를 영구 강화하는 것은 아니다. 현재 근사에서는 충돌이 접근할 수 있는지를
결정하여 일시적으로 절단 후보에서 제외할 뿐이다.

## 3. 사건 가중치와 에너지

모든 노출 골격 결합의 기본 절단 가중치는 `1`이다.

```text
cleavage_weight = 1
backbone_energy = 2
```

골격 하나가 끊어지면 저장되어 있던 에너지 2가 열에너지로 이동한다.

```text
긴 서열의 골격 결합 수 = 길이 - 1
절단 뒤 두 조각의 총 골격 결합 수 = 기존보다 1 작음
thermal_energy += 2
```

따라서 기존 총에너지 식이 보존된다.

## 4. 접촉 보존

절단점과 겹치지 않는 기존 측면 접촉은 사라지지 않는다.

- 왼쪽 조각에 있던 접촉은 왼쪽 자손 서열로 이전된다.
- 오른쪽 조각에 있던 접촉은 위치를 새 조각 시작점에 맞게 이동한다.
- 기존 접힘의 두 접촉면이 절단점 양쪽에 있었다면 절단 후 두 조각 사이의 일반 측면 결합이 된다.

절단점 양쪽 기호가 노출되어야 한다는 조건 때문에 하나의 접촉면을 중간에서 임의로 자르는 경우는 현재 없다.

## 5. 식별자와 계보

부모 서열은 세계에서 제거되고 왼쪽·오른쪽 조각이 각각 새 식별자를 받는다. 사건에는 다음을 기록한다.

- 부모 서열 식별자
- 절단 위치
- 두 자손 서열 식별자
- 절단 뒤 상태 해시와 열에너지

왼쪽이나 오른쪽 조각에 우수성이나 생존 우선권을 주지 않는다.

## 6. 허용되는 결과

- 단량체 방출
- 긴 서열의 중간 절단
- 주형 일부에 붙은 조각의 나머지 노출 부위 절단
- 접힌 두 영역 사이의 골격이 끊어져 두 조각이 서로 붙은 상태
- 절단 조각이 다른 주형 위에서 다시 성장

## 7. 현재 제한과 대가

- 모든 노출 골격의 절단 가중치가 같아 기호 문맥에 따른 화학적 안정성은 아직 없다.
- 충돌 입자나 위치를 직접 계산하지 않고 확률 사건으로 근사한다.
- 노출 여부는 실제 입체 표면이 아니라 현재 접촉 점유로 판단한다.
- 골격 생성 비용과 절단 방출 에너지가 같아 손실 없는 이상적 가역성을 가진다.
- 단계 C에서는 생존을 유지하려고 절단률을 자동 조절하지 않는다.

## 8. 통과 조건

- 길이 `n`의 완전히 노출된 서열은 `n-1`개의 절단 후보를 가진다.
- 절단 전후 기호 수와 총에너지가 정확히 같다.
- 접촉된 절단점은 보호되고 풀리면 다시 절단 가능하다.
- 절단점 밖의 기존 접촉은 올바른 자손 위치로 이전된다.
- 부모와 두 자손 계보가 사건에 기록된다.
- 기록된 선택으로 같은 절단 결과를 재생할 수 있다.
