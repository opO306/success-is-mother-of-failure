# 단계 C 결합 구조 전체 이동 v1 구상 일치성 검증

**대상:** `apply_component_move`, 동일한 한 칸 틈의 구조 모양 비교  
**판정:** 결합 구조의 병진과 전체 충돌 판정 통과, 질량·마찰·회전 부재가 강한 근사

## 1. 무엇을 만들었는가

한 단위에 이동 충격이 발생했을 때 현재 결합으로 이어진 전체 구조를 찾아 같은 방향으로 옮기는 이동 법칙을
만들었다. 구조 이름이나 출처가 아니라 실행 순간의 실제 결합망만 사용한다.

## 2. 세계 안에서 실제로 무슨 일이 일어나는가

위·아래가 막히고 가운데 한 칸만 열린 동일한 경계에서 세 구조를 오른쪽으로 이동시켰다.

- 단일체: 한 번에 틈을 통과
- 세로 이합체: 위 구성원이 장벽에 걸려 전체 이동 실패
- 가로 이합체: 두 번의 이동으로 결합을 유지한 채 두 구성원 모두 통과

실행 결과는 단일체 `moved`, 세로 이합체 `barrier_blocked`, 가로 이합체 `moved → moved`였다. 마지막 내부
단위는 각각 `[1]`, `[]`, `[1,2]`였으며 재현 기록에 전체 상태를 보존했다.

## 3. 설계 의도와 일치하는 부분

- 사람이 구조별 통과 가능 여부를 표로 정하지 않았다.
- 현재 결합으로 이어진 모든 구성원이 함께 움직인다.
- 구성원 하나라도 실제 장애물에 걸리면 전체 이동이 실패한다.
- 구조 출처, 계보, 기호 이름은 이동 판정에 사용하지 않는다.
- 실패한 큰 구조를 분해하거나 구조하지 않고 그대로 남긴다.
- 기존 결합과 상대적 위치를 보존한다.

## 4. 근사했거나 강제한 부분

- 한 구성원의 충격이 전체에 손실 없이 전달된다.
- 큰 구조는 단위 수만큼 충격 기회가 늘지만 질량과 마찰은 늘지 않는다.
- 이동에 에너지 비용이 없고 속도도 모두 한 칸으로 같다.
- 구조의 회전·굽힘·진동·결합각이 없다.
- 수동 비교 실험은 자연 발생 빈도를 보여 주지 않는다.
- 세로 이합체가 영원히 못 들어가는 것은 회전 미구현의 영향도 포함한다.

## 5. 검증 증거와 다음 결정 사항

- 공간·유전·국소 동역학 집중 테스트 `40`개 통과
- 전체 프로젝트 회귀 테스트 `591`개 통과
- 전체 성분 병진, 일부 구성원의 장벽 충돌, 외부 물질 점유 충돌 테스트 통과
- 균등 단위 충격 스케줄러가 결합 성분 전체를 찾는 테스트 통과
- 재현 기록: `runs/component_motion_v1_probe.json`
- 실행 조건과 코드·기록 해시: `runs/component_motion_v1_probe_manifest.json`

다음에는 회전을 고수준 명령으로 넣지 않고, 결합각 또는 유연성처럼 국소 구조 변화로 모양이 바뀔 수 있는
최소 물리를 설계해야 한다. 그 전까지 방향에 따른 통과 차이를 적응이나 선택의 증거로 해석하지 않는다.
