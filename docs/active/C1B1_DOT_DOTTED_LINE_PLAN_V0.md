## 0. 한 줄 요약

두 가지 새 방법을 **정보용으로만** 만들어 잰다. 세계 법칙·봉인 파일·production은 바꾸지 않는다.

- **점(M11):** 두 원자 충돌의 출구를 걸음 없이 정확한 해에서 바로 구하고, 기본 격자에 반올림한다.
- **점선(T0):** 경로를 따라가되, 걸음마다 아주 높은 차수의 식(테일러 급수)으로 크게 건너뛴다.

## 1. 쉬운 설명 (비유와 실제 의미를 나눔)

| | 비유 | 실제 기술 의미 | 쓸 수 있는 곳 |
|---|---|---|---|
| 붓펜(M10, 현재 후보) | 짧은 획을 이어 선을 그림. 앞 획의 떨림이 다음 획에 쌓여서 획을 잘게 쪼갬 | 4차 Chin 걸음 + 걸음·격자를 함께 줄이는 사다리 | 원자 여럿에도 원리상 가능 |
| 점(M11) | 설계도에서 도착 지점을 계산해 점 하나만 찍음. 쌓이는 떨림이 없음 | 에너지·각운동량 보존을 써서 1차원 반경 적분으로 출구를 계산 | **원자 두 개, 중심력만** |

점선에는 두 종류가 있다. 이 계획은 (나)만 다룬다.
- (가) 정확한 해로 **틱마다 점**을 찍는다.
  - 원자 두 개일 때만 된다.
  - 지금 붓펜도 충돌 중간 위치를 세계에 남기지 않는다. 그래서 지금은 필요 없다.
  - 여러 원자 세계에서 "충돌 중 세 번째 원자가 다가오는지" 볼 때 필요해질 수 있다(나중 과제).
- (나) 고차 테일러 걸음: 앞 점에서 다음 점을 계산하므로 떨림은 쌓인다. 대신 한 걸음이 아주 정확하다. 붓펜과 함께, 원자가 여럿일 때 쓸 수 있는 후보다.

## 4. M11 "점"의 정의 (세계 층 후보, survey_only)

**① 전제와 보존량:**
- 입력은 기본 격자(위치 2^-48, 운동량 2^-80)의 시작 상태다. 상대 좌표 q, p와 정확한 환산질량 μ(Fraction)를 쓴다.
- **|q0| = 20이 정확히 성립해야 한다**(canonical 상태는 그렇다, `state.py` 57행). 아니면 멈춘다(fail closed).
- 보존량: H = |p|²/(2μ) + V(|q|), L = q_x p_y − q_y p_x.

**② 되돌아오는 시간:**
- 전환점 r_t는 p_r²(r) = 2μ(H − V) − L²/r²의 첫 근이다.
- 장벽 꼭대기에서는 적분을 나눈다(cont2·quadref의 기존 처리).
- T_ret = 2·∫_{r_t}^{20} μ/p_r dr.
- 단일 전환점 근거(별도 검토가 확인): r ≥ 20에서 V < 0이고 b < 20이므로 바깥 전환점이 없다. r_t와 20 사이에서는 첫 근의 정의상 p_r² > 0이다.

**③ 출구 틱:**
- k* = ⌈T_ret / 40⌉. 정확한 궤적에서 "r ≥ 20, p_r > 0인 첫 틱"이다.
- 붓펜의 출력 틱 규칙(모든 트랙의 첫 출구 틱 중 최댓값)과는 정의가 다르다. **M11은 비트뿐 아니라 출구 틱의 법칙도 바꾼다.** T7에서는 두 규칙의 결과가 51/51 같았다.

**④ 출구 반경 역산:**
- 정해진 틱 k(기본은 k*, P 시험에서는 붓펜의 출력 틱)에 대해 τ = 40k − T_ret ≥ 0이다.
- ∫_{20}^{r_e} μ/p_r dr = τ를 뉴턴법으로 푼다. 이 꼬리 구간은 전환점에서 멀어서 매끈하다.

**⑤ 출구 상태:**
- 휩쓴 각: θ = 2·∫_{r_t}^{20} L/(r²p_r) dr + ∫_{20}^{r_e} L/(r²p_r) dr
- 위치: q = r_e(cos(φ0+θ), sin(φ0+θ)), φ0 = atan2(q0)
- 운동량: p = p_r r̂ + (L/r_e) θ̂, 여기서 p_r = +√p_r²(r_e)

**⑥ 반올림:** `ladder2.round_back`과 같은 꼴이다.
- 위치: q_raw = 2·round_half_even(q/2·2^48)
- 운동량: p_raw = round_half_even(p·2^80)
- 휩쓴 각은 반올림된 위치로 각을 옮겨 기록한다(`pen.py` 76–81행과 같음).

**두 법칙 변형:** 별도 검토 지적 1 때문에 둘을 나눠 잰다.

| | M11a "올바른 반올림" | M11b "고정 절차" |
|---|---|---|
| 계산 | ②–⑥을 **60자리와 80자리**로 두 번 | ②–⑥을 40자리로 한 번 |
| 판정에 쓰는 값 | 80자리 값 y_H | 40자리 값 |
| 거부(Undecided) | 판정 대상 y마다 여유 m_y = max(100·\|y_60 − y_80\|, 10^-30·\|y\|)를 둔다(격자 단위, 아래 정의). 거리 < m_y이면 멈춤. 두 정밀도 중 어느 쪽 안전장치라도 걸리면 Undecided | 반올림 경계 1e-15 격자 단위 안이면 멈춤(붓펜 1e-30과 같은 성격) |
| 비트의 뜻 | 계산 방법과 무관해야 한다(설계 주장). 다른 구현과 **비트 일치**를 시험할 수 있다 | 이 절차의 결과일 뿐이다(붓펜과 같음). 다른 방법과는 허용 오차로만 비교한다 |
| 예상 비용 | 측정치(40+60자리 10–39 s)보다 1.5–3배(추정) | 측정치(40자리 4–16 s)와 비슷 |

- 판정 대상 y와 그 격자 단위:
  - 출구 틱: x = T_ret/40, 거리 = \|x − round(x)\|
  - 위치 성분: q_k/2·2^48
  - 운동량 성분: p_k·2^80
  - 반올림 거리 = \|frac(y) − 1/2\|
- 10^-30은 cont2가 60자리에서 멈추는 적분 허용 오차 10^-(dps/2)를 상대값으로 쓴 것이다(규칙, 증명 아님).
- 이 여유로 생길 Undecided 확률(추정): 운동량 성분당 약 7e-5, 충돌당 약 2e-4.
- `LangForceFX2.V`는 호출마다 V′·V″까지 계산한다. V만 계산하는 변형은 최적화(D1.1)로 미룬다.

**두 독립 구현(M11a의 비트 일치 시험용):**
- **A(세계 후보):**
  - `c1b1_cont2.scatter`의 전환점·다리 함수를 읽기 전용으로 import한다. V는 `c1b1_t7.lang_fx2.LangForceFX2.V`다.
  - ①–⑥과 반올림은 `c1b1_dot/a.py`에 새로 쓴다.
  - cont2 파일 자체는 바꾸지 않는다(T7 봉인 코드).
- **B(검증 층):**
  - **별도 모듈** `c1b1_dot_b/`에 둔다.
  - `c1b1_method_bench.quadref.legs`(r1 = 20)로 T_ret와 2A를 구한다(80자리, `reference_potential`).
  - 꼬리 역산·상태 구성·반올림은 B가 따로 쓴다. A의 결과를 출발점으로 쓰지 않는다.

  - 이것은 닫힌 식 시험(6절 1–2)과 붓펜 일관성 관문(6절 P)이 맡는다.

**세 층 분리와의 관계(공개):**

## 6. 시험과 판정 (D1, 실행 전 고정)

**부품 시험(노트북):**
1. **자유 비행(V ≡ 0) 닫힌 식:** 정확한 유리수 계산으로 출구 틱과 반올림된 raw를 구한다. M11a의 A·B가 이것과 **비트 동일**해야 한다.
   - 입력 3개. b > 2(cont2의 r_lo = 2), b ≠ 0.
2. **α/r² 닫힌 식**(벤치 T2): 출구 틱·raw가 닫힌 식과 비트 동일해야 한다(입력 3개).
3. **동점 거부:** 자유 비행에서 T_ret = −2μ(q0·p0)/\|p0\|²는 유리수다. 시험용 유리수 μ와 2^-80 격자의 p0를 골라 동점을 만든다.
   - T_ret가 정확히 40의 배수인 입력(출구 틱 동점)
   - 출구 위치가 정확히 반올림 경계인 입력
   - 두 입력 모두 Undecided여야 한다.
4. **결함 주입:** 시험이 다음을 잡아야 한다.
   - 꼬리 생략(r_e = 20)
   - 출구 틱을 ⌈⌉ 대신 ⌊⌋로 계산
   - 각 부호 뒤집기
   - 동점 안전장치 제거(동점 입력이 값을 내면 실패)
   - 반올림을 가장 가까운 값 대신 내림으로 계산
5. **import 금지 AST 시험:**
   - A·B 모두 a_reference·a_numeric·engine·audit를 import하지 않는다.
   - B는 cont2·`c1b1_dot`을 import하지 않는다.
6. **봉인 불변:** T7 `load()`의 코드 해시와 PES 해시 검사를 그대로 통과해야 한다. D1 실행 도구도 PES sha256을 확인한다.
7. **정밀도 위생:** 모든 Fraction → mpf 변환(μ, 시작 상태)은 각 정밀도 블록 안에서 한다. T7 시험 1차 실패가 정밀도 밖 변환이었다.

**개발 패널 실행(원격 PC, 별도 디렉터리 `/root/dotpkg`):**
- `/root/t7pkg`는 건드리지 않는다. 시작 전·후 해시를 확인한다.
- **한 묶음 실행**: 6 workers. A·B·붓펜 C1.1 작업을 입력 순서대로 섞어서 넣는다.

**입력별 분류(M11a):**
- AGREE: A raw = B raw(k*, q_raw, p_raw 전부)
- DISAGREE: 둘 다 값을 냈는데 하나라도 다름
- A_REFUSED / B_REFUSED: 거부(Undecided 또는 적분 fail-closed). B는 quadref 자신의 fail-closed `ValueError`만 거부로 센다. 나머지 예외는 error로 센다.
- 세 층 문서 4절대로, 거부는 불일치가 아니라 미확정이다.

| 항목 | 판정 | 예측 |
|---|---|---|
| X_bit (M11a) | DISAGREE = 0 | 0 |
| R_ref | A_REFUSED = 0이고 B_REFUSED ≤ 2이면 정상. 넘으면 판정 보류(원인 분석). M11 실패로 세지 않음 | A_REFUSED 0, B_REFUSED 0–3(ρ < 0 B 입력, 불확실) |

  - P 실패는 붓펜 추정과 A 중 어느 쪽이 틀렸는지부터 가린다.
- K가 빗나가는 것은 실패가 아니다. "그 변형은 보통 충돌에서 붓펜보다 싸지 않음"으로 기록한다. 그 경우 설계자 결정 ①에서 다음을 올린다.
  - M5 혼합
  - 점 최적화(D1.1: V만 계산, 해석적 도함수, 고정 Gauss–Legendre)

## 7. T0 "점선" 측정 (정보용, 실행 전 고정)

**무엇:** `c1b1_taylor/`(survey_only)에 정수 고정소수점 테일러 산술을 만든다.
- 급수 덧셈·곱셈·나눗셈·제곱근·exp 점화식. 계수 정밀도는 고정 P = 320비트.
- Lang V′(r)을 **직접** 급수로 합성한다: 지수×다항, Tang–Toennies 감쇠, BO 유리식(분모 계수가 모두 양수라 물리 범위에서 수렴을 막지 않음, 검토 확인). dV/dt ÷ r′ 방식은 전환점(r′ = 0)에서 특이하므로 쓰지 않는다.
- 운동 방정식: q′ = p/μ, p′ = −(V′(r)/r)·q
- 한 걸음 = m틱(m ∈ {1, 2, 5, 10}), 차수 N ∈ {8, 12, 16, 20, 24}
- 틱마다 다항식을 계산해 출구(r ≥ 20, p_r > 0)를 붓펜과 같은 규칙으로 판정한다. 휩쓴 각은 틱마다 부호 있는 각을 더한다(틱당 각 변화 ≪ π).
- 내부 격자는 아주 곱게 둔다(위치 2^-128, 운동량 2^-160). 그래서 주로 절단 오차를 본다. 이것은 가정이고, 정수 오차는 P를 바꿔 따로 확인한다.

**부품 시험:**
- 급수 연산을 mpmath 고정밀 계산과 대조한다(각 연산, 차수 24까지).
- V′(r(t)) 급수 **전체**를 mpmath Taylor 전개와 차수 N까지 대조한다(시험용 다항식 r(t)).

**측정:**
- 입력 4개: G1, G3, B3, H1.
- 각 (m, N)마다 다음을 기록한다.
  - 출구 휩쓴 각·시간 오차(기준 둘: M11a A의 80자리 값과 붓펜 C1.1)
  - (m, N)을 바꿀 때의 자기 수렴
  - 걸음당 CPU
  - 계수 감소에서 추정한 수렴 반경
- 주의(검토 지적): H1의 벽 근처에서는 수렴 반경이 약 550–1,700 au로 추정된다. 따라서 m = 5–10(200–400 au)은 N ≤ 24로도 1e-10에 못 미칠 수 있다.

**T1(점선 사다리 구현)로 갈지의 기준(실행 전 고정):**
- 두 기준 모두에서 오차 ≤ 1e-10을 지키는 가장 싼 (m, N)의 충돌당 CPU를 잰다.
- 거기에 3배를 곱한다(붓펜처럼 비교 트랙·반올림 확인 트랙이 필요하므로).
- 그 값이 같은 기계의 붓펜 C1.1보다 G 입력에서 작거나, B3에서 5배 이상 작을 때만 T1을 설계자에게 올린다.
- 아니면 "파이썬 구현에서는 이득 없음"으로 기록하고 C3(빠른 엔진)와 함께 다시 본다.

**예측(불확실, 넓은 범위):**
- 걸음당 CPU: N = 16에서 5–15 ms
- 보통 충돌 하나: 10–80 s(붓펜 C1.1 25.9 s와 비슷하거나 더 비쌈)
- B3: 붓펜보다 3–30배 쌈

T0는 M11의 **직교 확인**이 된다. 시간 걸음은 보존량·반경 적분 공식을 쓰지 않는다. 다만 T0는 D1 판정 뒤에 돌고 입력이 4개뿐이라, D1 판정의 근거로는 쓰지 않는다.

**E. 문제가 왜 발생했는가?**
- 붓펜 비용이 큰 근본 원인은 "선 그리기"의 구조다. 경계 근처 민감도가 ∝ 1/\|ρ\|이라서 걸음당 오차를 tol·\|ρ\|까지 줄여야 한다.
- 직접 적분이 세계 층에 오지 않은 이유는 방법 비교 계획의 G절이다. "M4·M5를 A의 실제 법칙에 넣는 방법"을 범위 밖으로 두었고, S3c 설계자 결정으로 직접 적분은 검증 층에 배치됐다.
- 사전 검토의 공백: 그때는 비용 비교(T7 붓펜 CPU)가 없었다.
- 이 계획 초안의 공백: 2^-80 격자의 올바른 반올림에 필요한 정밀도를 계산하지 않았다(별도 검토 지적 1).

## 자기반박

- **가장 약한 증거:** "정확한 해의 반올림이라서 방법에 의존하지 않는다"는 주장은 수치 적분의 경험적 오차 추정과 자릿수 비교에 기대고 있다. 구간 산술 같은 엄밀 상한이 없다.
- **이번 검토가 바꾼 핵심:** 올바른 반올림은 생각보다 비싸다(60+80자리). 그래서 "점이 보통 충돌에서도 싸다"는 기대가 약해졌다. 싼 변형(M11b)은 붓펜과 같은 "절차 법칙"으로 돌아간다.
- **시험 뒤에도 남는 위험:** 개발 패널 14개는 아르곤의 일부 영역이다. 경계 ±1e-9보다 가까운 곳과 1/20 De 미만은 보지 않는다.
- **공유 경로:** Lang 매개변수 해석, PES 파일, canonical 시작 상태 생성, 반경 적분 공식, 같은 구현자(A·B 공통).
- **구조적 한계:** 점은 원자 두 개 전용이다. 여러 원자 세계의 엔진 문제는 남는다(붓펜·점선·C3).
- **비용 판단의 약점:** A·붓펜 모두 파이썬 구현이다. native에서는 비율이 달라질 수 있다.
