# ADAPTIVE_EXECUTION_REAL_LEARNING_PILOT_A_RESUME_V1 — 봉인 기준

기준은 `37a5abd3`이며 N14/T1000/p163/WALL_MIN의 제한 연구 A만 다룬다. 과거 실패는 `REAL_LEARNING_FAIL`로 보존한다. 기존 V0/V1 계산기, 검사관 프로세스 하나, 관리자와 V2 저장·재판독 기능을 재사용한다. 새 계산기·새 검사관·운영 연결은 만들지 않는다.

첫 호출은 명시적 SERIAL이다. 실제 저장 원본의 바이트·V2 내용·과거 시작 지문 관계·요청·배치·정밀도·결과를 확인하고, 새 세션 CPU 재현 한 번을 만든 뒤 기존 별도 검사관이 첫 관문 영수증을 서명한다. 실행 담당은 서명, 현재 원본 해시, 세션·소스·프로토콜·검사 범위를 확인한다. 이 전체 과정이 성공하기 전 W6 호출은 0회다. SERIAL_0은 정식 첫 표본이고 중복 계산하지 않는다.

10회 교대 순서와 1.25 반복 편차를 유지한다. 각 원본은 CANDIDATE이며 검사관이 10개 원본·지문 측정·요청 비용 파일·새 replay를 직접 읽어 발급한 `REAL_SESSION_COST_CHECKED`만 관리자가 받는다. 관리자 연구 승인 후 새 요청 한 번을 수행하고 별도 검사관이 결과를 확인한다. 이전 요청의 스냅샷은 유지한다. 서명된 LEGACY 복귀 후 새 정책 조회로 확인하며 추가 물리 계산은 없다. 실패하면 다음 요청은 STOP한다.

성능 표에는 저장·재판독·주 지문 측정 파일 기록까지 포함한 요청 전체 시간을 사용한다. 기존 계산 관측 시간을 덮어쓰지 않고 별도 원본 연결 비용 파일을 둔다. 비용 파일 자신의 기록과 ledger 기록은 관리·전체 할당 비용에 속한다. 경량 비용은 전체 요청에서 저장 전 관측을 뺀 보수적 상한이며 호출 준비도 포함한다. wall 상한은 계산 관측의 1%다. CPU 비용, RSS 차이, 추가 바이트를 따로 기록한다. RSS 차이는 순간 최대 메모리라는 뜻이 아니다. replay·심층 검사·승인·복귀는 경량 비용과 분리한다.

WALL_MIN의 기존 5% 동률/CPU 우선 규칙은 그대로다. SERIAL이 선택되거나 실측 개선이 없으면 NOT_READY이며 W6를 강제하지 않는다. 학습 순환 성공과 비용 회수 성공은 별도다. 시작 전 준비·전송·대기부터 정지 확인까지 전체 할당을 사용해 회수 횟수를 올림 계산하고 관측 재사용 1회만 인정한다. 실제 청구서는 없으면 요금 추정으로 표시한다.

동적 시험은 승인된 Vast에서만 한다. 기존 202개와 새 결함 시험의 정확한 총수는 새 코드 봉인에 고정한다. CPU 1개, wall/누적 CPU 각각 120초, AS 512MiB, 물리/GPU 0이며 실패·skip은 STOP한다. 실제 A는 CPU 최대 W6, 프로세스 트리 RSS 2GiB, 호출별 최대 480초다. 전체 임대 60분·계산 54분·회수 마감 57분·정지 확인 180초, 시간당/전체 임대 각각 $0.25를 넘지 않는다.

프랑스 machine 56006의 기존 정지 인스턴스 54815136은 후보다. 이전 승인은 만료됐으며 이번 코드·프로토콜·세션에 대한 새 사람의 승인이 필요하다. 외부 감시기를 먼저 ARMED하고 지속 heartbeat를 전달하며 실패/완료/기한에 종료한다. 확인은 실제 actual=exited/stopped로 한다. 장기 통신 장애 및 실제 물리 실패 종료의 실증은 아직 없다.

`RwForce`는 공유된다. 이 단계의 독립성은 별도 프로세스·서명·원본 재판독과 CPU 재현 범위이며 독립 수식 검증 또는 형식 인증은 아니다. 세 역할은 같은 UID 아래이므로 운영체제 권한 분리는 추가 과제다. N12/GPU/CPU_MIN 실측, 실제 서비스 적용, push/master 병합은 이번 범위 밖이다.
