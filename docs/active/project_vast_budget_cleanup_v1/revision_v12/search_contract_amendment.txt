별도의 보충 측정 93회는 추가하지 마세요.
V12 계획서의 '개별 반복 결과' 요구는 기존 승인 기준에 없던 추가 조건이므로 철회합니다.
원래 봉인된 A320과 검색 측정 코드를 변경하지 않고 그대로 실행하세요.
검색 측정은 기존 계약대로 100·1,000·10,000건 각각 31회 수행하고, 원래 정의된 중앙값·최댓값 및 완료 증거를 검증하면 됩니다.
개별 반복값이 없다는 이유로 기존 측정을 실패 처리하거나 새로운 측정을 강제하지 마세요.
단, 실제 31회 실행 여부와 결과 파일의 작성 완료 여부는 기존 코드 및 실행 증거로 확인해야 합니다. 중앙값·최댓값만으로 개별 측정값까지 확인했다고 주장해서는 안 됩니다.
추후 측정값의 분포를 상세 분석할 필요가 생기면 별도 연구로 제안하면 됩니다.
지금 우선순위는 A320 완료, 원래 검색 측정 완료, 결과 원본의 안전한 회수입니다.
