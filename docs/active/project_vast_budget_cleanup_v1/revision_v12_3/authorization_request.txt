코드를 확인한 결과 안전하게 구현할 수 없었다.

- 감시기 lease에는 생성 전에 고른 machine_id가 고정되어 있다(campaign.py:334). 같은 창에서 다른 기계로 넘어가면
  제어 프로그램이 죽었을 때 감시기가 새 서버를 찾지 못해 과금이 남을 수 있다.

"미생성 해제" 장부 사건을 새로 설계해 설계자 승인을 받아야 한다. 이 한계는 보고서에 공개한다.
