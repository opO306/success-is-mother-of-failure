## 0. 결론

- **경로 판정: ROUTE B** — wall(R ∈ [5.35, 7])은 w-progress로 해결 가능하다. 한 번의 wall 방문이 에너지 여유의 28〜83%로 닫힌다. 그러나 우물/궤도 영역(R ≳ 7.1)은 저에너지에서 국소 progress가 **실제로** 없으므로 별도의 체류 상한이 필요하다. wall **방문 횟수**의 상한도 거기서 와야 한다.
- **사건 압축 판정: LIMITED.** 데이터로는 ④에 필요한 거친 결과(바깥으로 나감, R_min, 에너지)가 매우 둔감하다. 85개 통과 전부 R_min ≥ 5.75이고, 실행기의 실제 E~ 변화는 통과당 \|ΔE~\| ≤ 7.7·10⁻¹⁵ hartree(변형 포함 ≤ 6.4·10⁻¹³)였다. 하지만 사건을 **인증**하려면 통과 전체를 묶는 증명 방법이 필요하다. 그것이 지금 실패하는 바로 그 문제(누적)이므로, 사건 형식만으로는 증명이 생기지 않는다.

## 1. wall 영역의 작용(w-progress) — 스크래치 해석 하한

한 KDK step: **w_(k+1) − w_k = q_k·J_k + (α\|P_h\|² + d·P_h) + q_(k+1)·J_(k+1)**. 중심력이라 q·J_exact = −V′(R)·R·h/2이다. 반발(V′ < 0)이면 양수이고 \|J − J_exact\| ≤ U다. drift 항 ≥ α·p_h,lo² − D·p_h,hi이며 p는 E2(E~ ∈ [−10⁻⁶ De, 12.5 De])로 묶는다. 둘째 kick은 저장 이동 ≤ 0.03 안의 이웃 셀들의 극값으로 묶는다.

**공개(계산 실수 한 번):** 첫 계산(v1)은 둘째 kick·운동량 cap·1-step 예산을 폭 0.076짜리 **넓힌 셀 하나**로 묶었다. R ≈ 5.35에서 넓은 셀은 구간이 크게 부푼다([Field Map 조사](C1B1_FIELD_MAP_SURVEY_V0.md) 2.4). 그 결과 "6.69부터 progress 없음", "방문당 에너지가 여유의 21〜25배"라는 **잘못된 비관 결론**이 나왔다. v2는 **같은 1/64 해상도**에서 이웃 셀들의 극값을 쓴다(세분 증가 아님). 두 결과 모두 보존했다.

| 영역(v2, 1/64 셀) | Δw 하한 c | 방문당 step 상한 | 방문당 에너지 상한 | 여유 대비 |
|---|---|---|---|---|
| [5.35, 6.0] | 0.720〜2.221 | 6,241 | 3.20·10⁻⁴ | **0.28** |
| [5.35, 6.3] | 0.356〜2.221 | 15,775 | 5.91·10⁻⁴ | 0.52 |
| [5.35, 6.6] | 0.154〜2.221 | 38,718 | 9.40·10⁻⁴ | 0.83 |

- [5.35, 7]의 **모든 셀에서 Δw 하한 > 0**이다.
- 방문 한 번 = 들어옴(w < 0) → 전환 → 나감(w > 0). w가 단조 증가하므로 R은 한 번 내려갔다 올라가고, 셀마다 두 번 이하로 지난다. 셀 i의 step 수 ≤ 2·R_b·p_cap,i / c_i + 2로 두고 dE_i를 곱해 더했다.
- 관측(증명 아님): 실제 통과의 R < 7 step 수는 226〜315다. 상한 6,241보다 약 20배 작다.

**질문별 답(관측 수준):**
- 전체 궤적을 버려도 되는가: ④에 필요한 것(나감, R_min, 에너지 범위, 출구 \|P\|)은 요약으로 충분하다. 편향각·출구 시각은 궤도 경계 근처에서 입력에 민감하다.
- 결정적인 입력: 연속 역학으로는 **E, \|L\|** 두 스칼라(평면 방향은 회전 공변. 30° 회전의 영향 ≤ 10⁻⁹). 격자 수준의 정확한 출력은 raw 상태 전체에 달려 있지만 거친 packet에는 영향이 없다.
- 반지름 부호·위상: canonical 입력(R = 20 inbound)으로 고정하면 필요 없다. 출발점이 다르면 에너지 차이를 통해 궤도 경계 근처에서 결과가 갈라진다.
- 입력 box를 넓히면 언제 갈라지는가: 궤도 경계 \|ρ\| ≲ 10⁻³에서 편향각과 체류가 급격히 변한다. D_valid F 부분은 \|ρ\| ≥ 약 0.003〜0.01이라 경계 바로 위는 아니다.

## 5. 사건 압축 판정 근거 (LIMITED)

| 기준 | 평가 |
|---|---|
| 필요한 입력 변수 | 2개(E, \|L\|) + 평면 방향(회전 공변). canonical 입구 가정 |
| 같은 output packet으로 묶이는 범위 | 거친 packet(나감·R_min ≥ 5.35·에너지 여유): 관측한 모든 입력. 정밀 packet(편향각·step 수): 궤도 경계에서 멀면 넓고, \|ρ\| ≲ 10⁻³에서 좁다 |
| orbiting boundary 민감성 | 체류는 로그 발산(자릿수당 +4,200 step), 편향각 증폭 약 10⁴(ρ = 10⁻⁴) |
| 예상 계산 절약 | 통과당 2·10³〜3·10⁴ step의 step별 누적을 사건 하나로 |
| 추가 증명 비용 | **높음.** 사건을 인증하려면 입력 box 전체에서 통과 전체를 묶는 방법(검증된 통과 적분, 또는 E·L 유효 퍼텐셜 + 전환점 상한)이 필요하다. 현재 도구(1-step 누적, 통과당 수천 step × 10⁻⁹〜10⁻⁶)는 관측한 실제 에너지 변화보다 **10⁸배 이상** 느슨하고, 그것이 ④ v0의 실패 원인이다 |

압축 형식이 증명을 만들어 주지는 않는다. 증명 방법(유효 퍼텐셜 체류 상한)이 생기면 그 결과를 사건 packet으로 **저장·재사용**하는 것이 자연스러운 다음 단계다. 그래서 PROMISING이 아니라 LIMITED로 둔다.

## 6. 다음 후보 (설계자 판단용, 구현 안 함)

1. **wall 방문 lemma(ROUTE B의 해결된 절반):** [5.35, 6.0](또는 6.3) 방문 한 번의 step·에너지 상한을 v2 방식으로 정식화한다(여유의 28〜52%).
2. **우물/궤도 영역의 체류 상한:** E·\|L\|로 유효 퍼텐셜 V_eff = V + L²/(2μR²)을 쓴다. E − V_eff가 양수로 떨어진 R 구간은 반지름 속도 하한 → 셸 귀납으로 통과 step을 묶는다. 궤도 경계(V_eff 최대 ≈ E)는 D_valid의 \|ρ\| 하한을 입력으로 쓰는 별도 상한이 필요하다(로그 발산이라 유한). wall 방문 횟수는 여기서 온다(보통 1회).
3. 위 둘이 되면 Σ N_i·dE_i ≤ 여유를 조립할 수 있고, 그 결과를 사건 packet으로 남기는 것은 그다음이다.
