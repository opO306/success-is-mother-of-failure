## 0. 한 줄 요약

연습 문제(T1–T6)에서 다듬은 붓펜 사다리(M10)를 실제 아르곤 퍼텐셜(Lang 2024)에 **한 번만** 돌린다. 모든 충돌이 사건 기준(각도·시간 ≤ 1e-9)을 지키는지 확인한다. 결과를 본 뒤 방법을 바꾸면 새 버전이 되며, 이번 결과는 지우지 않는다.

## 1. 후보 방법

- **M10 붓펜**(`c1b1_method_bench/pen.py`, S3f와 같은 규칙)
  - h = 40/2^j, 격자 64 + 4j / +32
  - 걸음 쌍 추정 + 마지막 +16비트 반올림 확인
  - 상한 j_max = 6
  - 기본 격자 (48, 80)에서 출발하고 출구에서 기본 격자로 되돌린다
- 수준 0(production 격자 Chin40)의 오차도 함께 기록한다(비교용, 후보가 아님).
- S3e의 M9(두 축)는 S3f에서 같은 정확도에 더 비쌌으므로 T7 후보에서 뺀다(구현자 권고, 설계자 확인 대상).

## 3. 필요한 새 부품(구현 전, 모두 survey_only)

1. **아르곤 퍼텐셜의 V'·V''**
   - Chin 4A에는 힘의 기울기가 필요하다. 기존 독립 파서 `c1b1_o1.model`은 V만 계산한다.
   - 항마다 해석 미분을 새로 쓴다(지수×다항식, Tang–Toennies 감쇠 dD/dr = η e^(−x) xⁿ/n!, 유리함수 항).
   - 시험에서 mpmath 수치 미분과 대조한다.
   - production(`a_reference`)은 import하지 않는다.
2. **canonical 초기 상태의 독립 재구현**
   - 시험: O-1 입력 중 canonical 규칙으로 만든 것(boundary_* 등)의 raw를 비트 그대로 재현해야 한다.
3. **정확한 아르곤 환산질량**(`c1b1_o1.model.MASS` 분수)을 쓴다. 벤치의 53비트 MU는 쓰지 않는다.
4. **기준 두 개**
   - 주 기준: continuous V2(`c1b1_cont2`).
   - 교차 기준: 벤치 quadref(V만 필요)를 묶음 O와 S의 ρ > 0 일부에 쓴다.
   - 두 기준이 1e-18 넘게 다르면 그 입력은 판정 불가(UNRESOLVED)로 기록하고, 방법의 실패로 세지 않는다.

## 4. 판정 항목 초안(봉인 때 고정)

- V: 출력 실제 오차 > 1e-9(각도 또는 시간)인 수. 예측 0.
- U: 추정 < 실제인 수. 예측 0.
- C: |ρ| ≥ 1e-10에서 cap_stop인 수. 예측 0.
- R: 반올림 확인 D_round > est_step/100인 수. 예측 0.
- D: 반복 2건 동일.
- 단계 예측: S3c 최악 모형(1, 1, 2, 3, 3, 4, 5). 아르곤 상수가 다를 수 있으므로 깊이 차이는 보고만 한다.
- H 묶음은 survey_only다. 10 De 초과 입력이 기준을 넘어도 production 범위 판정에 쓰지 않는다.

## 5. 비용 추정(범위, 미측정)

- 아르곤 V 한 번은 벤치 퍼텐셜보다 훨씬 무겁다. continuous V2가 아르곤 한 입력에 28–93 s였다.
- 해석 미분을 쓰면 Chin 걸음당 약 1–3 ms로 추정한다(벤치 0.3 ms의 3–10배).
- ρ = 1e-10 입력 하나가 Chin 걸음 약 200–300만 번이므로 1–3시간이다.
- 기준 계산(입력당 5–10회 × 30–90 s)도 상당하다.
- 전체: 노트북 4 workers로 **약 8–30시간**(폭이 넓다). 원격 PC(Ryzen 5600 6C/12T)와 나눠 돌리면 줄어든다.
- 줄이는 선택지:
  - ρ 스캔을 ±1e-8까지만: 1e-10 6개를 빼면 비용이 크게 준다.
  - 에너지를 0.5 De 하나로: S 묶음이 30개에서 10개로 준다.

## A–H 요약

- **A 왜:** 설계자가 정한 순서(도구 수정 → S3b → P4 → S4)다. 연습 문제 결과가 실제 아르곤에서도 성립하는지 확인한다.
- **B 가정:**
  - 아르곤에서도 걸음 오차와 반올림이 1/|ρ|로 커진다(S3에서 측정한 연습 문제의 성질, 아르곤은 미확인).
  - 독립 파서 `c1b1_o1.model`이 production PES와 같은 함수다(O-1에서 8/9 일치, 차이는 dt 때문으로 진단됨).
- **C 틀리면:** V·U가 0이 아니면 M10은 아르곤에서 실패다. 결과를 지우지 않고 새 버전으로만 고친다.
- **D 영향:** production 0. 새 survey_only 부품·도구·시험만 추가한다.
- **E 문제 발생 이유:** O-1 STOP → ④ 정책 → P4 → 벤치.
- **F 입증:** 부품 시험(canonical raw 비트 재현, 미분 대조) + 두 기준 교차 + 봉인 판정.
- **G 모름:**
  - 실제 비용
  - 아르곤의 오차 상수
  - 10 De 초과 Lang PES의 적용 범위
  - production 반올림과 재구현의 비트 동일성(대조하지 않았다)
- **H 권한:** 설계자 확인 전에는 구현만 하고 봉인과 실행은 하지 않는다. 무료 PC만 사용하고, Vast와 push는 하지 않는다.

- 비교 기록 "수준 0(production 격자 Chin40)"은 정확하지 않았다. M10의 수준 0은 Chin h = 40, 격자 (64, 96)이다.
