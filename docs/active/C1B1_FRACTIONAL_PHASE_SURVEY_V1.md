## 정확한 정규형

`n`은 양의 FX 상대 좌표 raw 정수, `R=n·2^-48`, `I`는 운동량 ULP(`2^-80`) 단위다.
따라서 양의 축에서 `I=-20 V′(R)/2^-80`다.

PES의 지수항을 분리하면

\[
 I(n)=P(n)/Q(n)+\sum_\lambda e^{-\lambda n2^{-48}}A_\lambda(n2^{-48}).
\]

`A_lambda`는 정확한 유리수 계수의 Laurent 다항식이며 지수 그룹은 9개다.
retardation 분모를 `D(R)`, leading potential 분자를 `N(R)`라고 쓰면 그 도함수 분자는
`RD N′-(6D+RD′)N`, 분모는 `R^7D^2`다.
inverse-power 도함수까지 합쳐 공통 분모 `R^17D^2`를 만들었다.
유리수 다항식 gcd는 1이며, raw 좌표를 대입하고 공동 정수 content를 제거한 결과:

| 항목 | 정확한 결과 |
|---|---|
| `P(n)` | 정수 계수 22차, 계수 23개 |
| `Q(n)` | 정수 계수 29차, 계수 13개, 모두 양수 |
| 분모 인수분해 | **`Q(n)=390625·n^17·D_int(n)^2=5^8·n^17·D_int(n)^2`** |
| `D_int(n)` | `D(n·2^-48)`의 분모를 없애고 content를 제거한 양의 계수 6차 정수 다항식 |
| `D_int` content | 1 |
| 공동 정수 content | 1 |
| 고정 분모? | 아님; 모든 domain에서 `Q(n)` 엄격 증가 |
| 2의 거듭제곱 분모? | 이 **약분 전 Q**는 항상 5의 인수를 가지므로 아님 |
| 점별 약분 | `gcd(P(n),Q(n))`에 의존. 끝·중간 3점은 진단 witness일 뿐 가족 전체의 약분 증명이 아님 |

정확한 전체 계수와 24개 domain의 모든 분수는
[fixture](../../a_reference/fixtures/c1b1_fractional_phase_survey_v1.json)에 저장했다.
분모가 약분되어도 약분 전 `Q`에 대한 최소 간격은 안전한 하한이지만 느슨할 수 있다.

## Signed residual과 수치 guard

각 양의 반지름 monomial의 양 끝값으로 전 구간의 정확한 범위를 감싼다.
음의 지수도 단조 방향을 보존한다. 각 지수 함수는 정수 Taylor enclosure와
4096-bit 증명 격자에서 평가한다. cutoff는 `4096·LN2_UPPER`에 따라
`[0,2^-4096]`을 사용한다. 오차를 숨기거나 정확히 0으로 바꾸지 않는다.

각 항의 부호를 보존해 합친 `[L_exp,U_exp]`와 기존 실행기 endpoint 오차 `E_p`를 따로 기록하고,
최종 범위를 **`P/Q+[L_exp-E_p,U_exp+E_p]`**로 유지한다.
`E_p`는 parent 물리 range의 폭이 아니라 기존 실제 실행 산술에 대한 점별 endpoint 오차 상한이다.

shell 3〜20의 잔여항은 전 구간에서 양수로 증명됐다. shell 0〜2, 21〜23은
현재 enclosure로 부호가 결정되지 않는다. 뒤의 세 domain은 특히 4096-bit cutoff와
항별 구간 합이 부호 정보를 잃는 경우다. 실제 부호 변화나 실제 tie를 발견했다는 뜻이 아니다.

## 가장 값싼 간격 조건의 결과

non-tie 유리식에 대한 `s=1/(2Q_max)`와
`max(|L_exp-E_p|,|U_exp+E_p|)<s`를 정확한 분수로 비교했다.

## Exact tie와 modular 구조 조사

양의 Q에 대해 `r=2P mod 2Q`이고 half-integer 거리는 정확히 `|r-Q|/(2Q)`다.
음의 P도 같은 식이다. tie는 `r=Q`, 곧 `v2(P)+1=v2(Q)`를 필요로 한다.

`n=2^t u`, u 홀수로 분류한다. 계수 valuation의 최소 항이 유일하면
다항식의 valuation이 정확히 정해진다. 동일 최소 항은 상쇄될 수 있으므로 성공으로 취급하지 않는다.
해당 분류만 u의 홀수 합동류 mod 256으로 조사하고, 필요 시 mod 4096/65536까지 세분한다.
각 분류가 원래 구간과 교차하는지 정수 ceil/floor로 확인한다.
정규화한 정수 다항식의 mod `2^bits` 값이 0이면 valuation을 미결정으로 남긴다.

분모의 제곱 구조는 추가로
`v2(Q)=17t+2v2(D_int(n))`임을 준다. 따라서 `v2(Q)`의 홀짝은 t의 홀짝과 같다.
P valuation이 알려진 분류는 이 홀짝만으로도 tie를 제외할 수 있다.

이 방법으로 **23개 domain은 모든 rational tie가 제외**된다.
shell 23의 마지막 미해결 합동류는 `t=53, u=119 mod 65536`이고,
원래 domain 안의 해당 입력 수를 먼저 세면 **정확히 한 점**이다:

`n=1071856711314178048=119·2^53`, `R=3808`.

이 점은 정확 정수 평가에서 `v2(P)=1557`, `v2(Q)=1555`로 tie가 아니다.
실제 전체 impulse도 기존 finite-point 인증기에서 256-bit 이하로 인증되며 기존 checker가 확인한다.
이 증거를 유리식 tie 판정과 별도로 보존했다. 64점 fallback 한도를 먼저 확인하며
큰 input scan으로 바꾸지 않는다. **유리식 tie 배제는 유한 fallback 포함 24/24개**다.
정확 impulse 전체가 tie에 오지 않는다는 전 구간 결론은 guard가 충분한 5개에만 적용할 수 있다.

홀수 n에서는 `v2(P)=411`, `v2(Q)=0`이다. 그러므로 모든 홀수 `(2k+1)`에 대해
`2P-(2k+1)Q`는 홀수이며 valuation은 0이다.
현재 2-adic 정보만으로 그 정수의 절댓값을 1보다 크게 강제할 수 없다.
이는 더 큰 modulus를 사용한 실제 residue-distance 하한이나 다른 논증이 불가능하다는 뜻은 아니다.
**19개에 대한 더 강한 family phase 하한은 아직 없으며 null로 기록**했다.
