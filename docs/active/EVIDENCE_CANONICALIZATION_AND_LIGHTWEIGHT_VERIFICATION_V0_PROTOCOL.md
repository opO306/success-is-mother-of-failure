## 결정

원본 raw SHA256과 초기 상태의 내용 SHA256을 구별한다.
INITIAL_STATE_CANON_V2는 정확히q,p 두 필드, 순서 보존 중첩 배열, 정확한 유한 수치 문자열을 받는다.
UTF-8 JSON sort_keys=True/separators=(',',':')/ensure_ascii=True/allow_nan=False 바이트의SHA256이다.
숫자로 변환·반올림·정규화하지 않는다. JSON의 모든 중복 키, 누락/추가 초기 상태 필드를 거부한다.
배열의 원자·좌표 순서는 의미가 있으므로 그대로 유지한다. 운동량p와 정밀도p를 구별한다.

기존 initial_sha256은q 다음p 매핑에 기본 json.dumps를 쓴LEGACY_QP_JSON_V1로 유지한다.
새 record와session은명시적evidence_version=2, 규약hash와initial_content_version을 가진다.
record에는initial_hash_version, initial_content_sha256도 추가한다. 새 실행에서 버전 누락/낮춤/변경은거부한다.
과거 무버전 증거는봉인된프랑스원본의전용재검토에서만읽는다. 일반실행에버전자동추정fallback을두지않는다.

저장즉시실제파일을strict JSON으로재판독하고전체객체와두지문·요청·정밀도·배치·초기상태를검사한다.
이 단계는원본무결성관문이며VERIFIED 승격이아니다. 실패하면원본/거부를보존하고다음계산전에예외로멈춘다.
별도물리재계산은호출하지않는다. 기존inspector는원본을스스로판독해정확성·비용검사를유지한다.
기존같은세션replay를원본hash/코드/환경/N/T/p/초기상태와함께재사용하며세션간캐시는추가하지않는다.

FORMAT_EQUIVALENT는표현차이와출처를확인한정정가능판정이다. CONTENT_MISMATCH는STOP,
PROVENANCE_UNKNOWN은승격보류/거부, VERIFIED_CONTENT는지정범위내용검증이다.
검사관은정정한실행자료를쓰지않고메타데이터영수증만서명한다. 별도정정증명서는원본rawSHA,
legacy/content 지문·규약·원인·검사코드·검사관영수증·관리승인PENDING을담는다.
기존관리자는검사관서명·파생증명서·원본hash를다시검사한다. 명시적서명검토승인은LEGACY를유지하고
과거자료검토승인만기록한다. 이단계에서새성능프로필이나공식지식을활성화하지않는다.
