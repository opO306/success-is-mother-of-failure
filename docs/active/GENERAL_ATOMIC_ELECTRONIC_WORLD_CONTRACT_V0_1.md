## 2. 신규 조항

### N1. 결정론과 현실성은 다른 조건이다

- **결정론적** = 같은 상태에서 다시 실행하면 항상 같은 다음 결과가 나온다. 난수·추첨을 쓰지 않는다.
- **현실 물리와 같음** = 그 계산 규칙 자체가 현실의 물리를 제대로 재현한다.

예: "공을 던지면 항상 정확히 10m 날아감"은 결정론적이지만 현실과 틀린 세계다.

A는 둘 다 만족해야 하며, **하나를 만족했다고 다른 하나가 따라오지 않는다.**

```
A의 실행 방식        = 결정론적
A가 사용하는 법칙의 목표 = 현실 물리를 가능한 한 충실하게 재현
```

**A 세계의 정의(설계자 결정, Gate 0-A DECIDED):** 현실 물리에 근거해 승인된 법칙을, 난수 없이 동일 입력에서 동일 결과가 나오도록 실행해서
만들어진 상태와 역사. 단, 현실 양자물리의 결과 확정 과정을 결정론적으로 어떻게 재현할지는 아직 미해결이며
임의 규칙을 발명하지 않는다(N2).

이 정의는 기존 C1-B1 계약(세계 = 승인된 이산 법칙의 실행, 검증 = 그 법칙의 독립 재계산,
현실 비교 = 관측 층)과 같은 방향이다([A_THREE_LAYER_SEPARATION_V1.md](A_THREE_LAYER_SEPARATION_V1.md)).

### N2. 양자 결과 확정은 UNRESOLVED

현실 양자물리에서 측정 결과가 하나로 나타나는 과정을 "현실도 이런 결정론적 규칙으로 하나를 고른다"고
확정할 근거가 없다.

금지:

```
확률 60%인 쪽을 항상 선택
가장 확률이 큰 결과만 남기고 나머지를 지움
초기 상태 hash로 결과를 고름
```

이런 규칙은 현실 재현이 아니라 **새 물리의 발명**이다. 난수 금지를 지키기 위한 편의로 도입하지 않는다.

**확률 계산과 사건 선택을 구분한다(개정 1).**
양자 상태를 "몇 개의 갈래"로 나누는 방법은 하나가 아니다(같은 상태를 빨강+파랑으로도, 밝음+어두움으로도 나눌 수 있다).
그래서 기준 없이 "갈래의 비율"을 말하면 뜻이 정해지지 않는다. 대신 다음 순서를 따른다.

1. **무엇을 측정하는 실험인지 먼저 선언한다.** 예: "전자 검출기가 왼쪽/오른쪽 중 어디서 검출되는가."
   선언은 관측 층의 질문이며 결과를 보기 전에 봉인한다. 선언이 세계 계산을 바꾸지 않는다(WORLD → Observer).
2. **그 측정의 각 결과 확률을 계산한다.** 예: 왼쪽 30%, 오른쪽 70%. 이 계산에는 난수가 필요 없다.
3. **"이번 한 번의 사건에서 실제로 어느 쪽이 일어났는가"를 고르는 것**에만 난수 또는 새 규칙이 필요하다. 이것이 UNRESOLVED다.

**측정의 두 종류(개정 2).** 컴퓨터 안에서는 전자 상태를 아무 기준으로나 나눠 "결과 A 30%, 결과 B 70%"라고 물을 수 있다.
그 질문이 현실의 장치로 구별 가능한지는 별개다. 선언할 때 둘 중 하나로 표시한다.

| 종류 | 조건 | 쓸 수 있는 곳 |
|---|---|---|
| `INTERNAL` 내부 연구용 측정 | 수학적으로 정의 가능하면 사용 가능 | A 내부 연구·진단. 현실 이전 후보로 올리지 않음 |
| `TRANSFER` 현실 이전용 측정 | 현실에서 구현 가능한 측정 방법을 함께 제시: 어떤 장치·원리로 결과들을 구별하는지, 분해능·검출 효율 같은 한계 | 현실 이전(N4) 비교·예측 |

- `TRANSFER` 측정의 장치 한계(구별하지 못하는 결과를 합치는 것, 검출 효율 등)는 N5의 변환 오차 칸에 기록한다.
- `INTERNAL` 측정 결과를 결과 확인 뒤 `TRANSFER`로 바꿔 표시하지 않는다. 현실 이전용으로 쓰려면 측정 방법을 제시해 새로 선언·봉인한다.
- 가상 실험실에서만 존재하는 질문을 현실 예측인 것처럼 들고 가는 것을 막기 위한 구분이다.

```
고전적/이미 정해진 부분            : 결정론적 실행 가능
선언한 측정의 결과 확률 계산         : 결정론적 실행 가능
이번 사건이 어느 결과였는지 하나 고르기 : 현실과 맞는 결정론적 처리법 UNRESOLVED
```

현재 허용되는 것: 결과를 고르지 않는 양자 진화와, 선언한 측정에 대한 결과 확률의 보고.
이것은 표준 양자역학의 확률 규칙을 쓰되 "하나를 고르는" 가정만 쓰지 않은 것이며 새 규칙을 더하지 않는다.
비용 문제는 남는다.

알려진 후보(ensemble 평균 힘, 확률 도약, 결정론적 숨은 변수 해석 등)는 각각 버리는 물리 또는 추가 가정이 있다.
특히 확률 도약류는 난수를 쓰므로 현재 규칙상 불가다. 어느 것도 이 문서에서 승인하지 않는다.

### N3. A의 두 쓰임

| 쓰임 | 필요한 것 | N2의 영향 |
|---|---|---|
| **가상 실험실** (현실 이전) | 선언한 측정의 결과 확률, 수율, 속도, 분포 같은 통계 | 막히지 않음. 현실 실험이 재는 대상이 대부분 통계다 |
| **진화하는 세계** (L, 세계 안의 B) | 이번 사건이 어느 결과였는지 정해진 하나의 역사 | 막힘. Gate 0-B |

두 쓰임의 요구를 섞지 않는다. 가상 실험실에서 통과한 것을 진화하는 세계의 준비 완료로 승격하지 않는다.
첫 일반 pilot(§30〜§32)은 가상 실험실 쪽 요구로 정의할 수 있다.

### N4. Reality Transfer Requirement

> 정규 A에서 발견된 현상은 현실의 물질·조건으로 옮길 수 있는 구체적인 실험 조건을 제시할 수 있어야 하며,
> 현실 실험으로 확인되기 전까지는 현실 발견으로 취급하지 않는다. 현실에서 재현되지 않으면 A의 법칙·근사·
> 적용 범위·초기조건을 다시 검토한다.
>
> 현실에서 구현 불가능한 조건에서만 존재하는 현상은 A 내부 현상으로 기록할 수 있지만, 현실 이전 성과로 세지 않는다.

재현 대상은 원자 하나하나의 궤적이 아니라 **현상과 측정 가능한 결과**다:
같은 반응이 일어나는가, 같은 생성물이 나오는가, 같은 조건에서 같은 구조가 안정한가,
반응 속도나 분포가 비슷한가, 같은 종류의 새로운 현상이 나타나는가.

단계:

```
A에서 현상 발견
  ↓ 1. A 내부 재검증 (계산 오차, 경계 효과, 빠진 물리, 반올림, Observer 버그 제거)
  ↓ 2. 현실 이전 자격 검사 (온도·압력·재료·장 구현 가능성, 빠진 상호작용, 법칙의 유효 영역, N5 변환)
  ↓ 3. 현실 실험
현실에서도 재현 → 비로소 현실 발견 후보
```

불일치는 실패 보고로 끝내지 않고 원인(A의 물리, 빠진 변수, 근사, 초기조건 차이, 실험 측정)을 조사한다.
"시뮬레이션에서는 됐으니 현실이 이상하다"로 처리하지 않는다(N6의 비대칭 규칙).

### N5. 작은 세계 → 현실 조건 변환

현실 실험은 대개 매우 많은 분자, 온도, 압력, 용매 같은 큰 계의 조건에서 일어난다.
원자 몇 개의 A 세계에서는 온도 같은 양이 그대로 정의되지 않을 수 있다.
따라서 다음 같은 변환이 필요하다.

```
한 번의 충돌 결과(단면적, 선언한 측정의 결과 확률) → 속도 상수
작은 계의 계산 → 큰 계의 성질
```

- 이 변환은 추론이며 고유한 오차가 있다. §7의 원인별 장부에 **변환 오차** 칸을 따로 둔다.
- 변환 방법 자체도 현실 근거와 적용 범위를 가진다. 변환 방법이 승인되지 않은 비교는 `NOT COMPARABLE`이다.

### N6. Reality Evidence Is Fallible — 현실 자료도 틀릴 수 있다

```
현실 그 자체              ← 직접 읽을 수 없음
   ↑
실험 / 관측 / 논문         ← 현실에 대한 불완전한 증거
   ↑
A
```

> 현실 실험·관측·논문은 A의 현실성을 평가하는 증거이지 절대적인 정답 파일이 아니다. 자료마다 측정 오차,
> 실험 조건, 분석 방법, 이론 의존성, 독립 재현 여부와 출처를 기록한다. 서로 충돌하는 현실 자료가 있으면
> 한쪽을 임의로 정답으로 선택하지 않는다. A와 현실 자료가 충돌하면 A의 오류, 빠진 물리, 적용 범위 오류,
> 실험 오류, 분석 오류를 모두 조사한다. 현실에서 독립적으로 재현되기 전에는 A와 기존 자료의 불일치를
> 새로운 발견으로 승격하지 않는다.

A의 목표는 논문을 복제하는 것이 아니라 현실을 복제하는 것이다.

**자료 등급(이름은 가칭, 확정은 설계자).** 실험 결과는 현실을 본 증거이고, 다른 계산 결과는 다른 계산기의 주장이다.
둘을 한 등급표에 섞지 않는다(개정 1).

REALITY EVIDENCE — 현실 측정에 대한 증거의 강도:

| 등급 | 뜻 | 현실 검증에서의 역할(개정 2) |
|---|---|---|
| R-A | 여러 독립 실험이 반복해서 비슷하게 직접 측정 | 주 검증 자료 |
| R-B | 한두 실험에서 직접 측정 | 주 검증 자료 |
| R-C | 실험값 + 모델로 간접 추정 | 간접 자료. 일치는 "간접 근거"로만 표시하고 사용한 모델을 함께 기록 |
| R-D | 저자의 가정·추정이 섞인 값 | 참고 전용. **A와 일치해도 "현실과 맞았다" 판정 금지** |

A와 R-D의 일치는 `AGREE`가 아니라 `REFERENCE_ONLY`로 기록한다(아래 비교 판정).

THEORY REFERENCE — 다른 계산의 결과. 현실 증거가 아니다:

| 등급 | 뜻 |
|---|---|
| T-A | 독립 고정밀 계산. 사용한 법칙·근사가 명시되고 수렴·오차 추정이 있음 |
| T-B | 그 밖의 계산값(근사 수준이나 오차가 불명확) |

논문에 적혀 있다는 이유만으로 전부 같은 권위를 주지 않는다. 같은 양에 대한 여러 자료는 하나를 고르지 않고
서로의 일치 정도, 각 측정 오차, 실험 조건, 직접/간접 여부를 함께 저장한다.

THEORY REFERENCE와의 일치는 현실성 증거로 세지 않는다. 다만 **A와 같은 법칙·근사를 쓴 T 자료**는
A의 수치 오차(§6, 실행기 ↔ 법칙) 교차 확인에 쓸 수 있다. 다른 법칙을 쓴 T 자료와의 비교는 두 모델의 차이일 뿐이다.

**A의 입력도 현실 증거다.** 핵 질량, 기본 상수 같은 법칙 입력값은 측정에서 온다. 출처와 판(예: CODATA 연도)을
법칙 fingerprint에 기록한다. 입력으로 쓴 자료는 아래 3번의 보정 자료이므로, 그 자료와 A의 일치를 검증 성공으로 세지 않는다.

**같은 것끼리 비교한다.** 예: 핵 고정 계산이 주는 평형 결합 길이·우물 깊이(r_e, D_e)와, 실험이 흔히 주는
진동 평균 길이·영점 에너지를 뺀 해리 에너지(r_0, D_0)는 다른 양이다. 이 사이의 환산은 모델을 쓰는 간접 단계(R-C)다.

**안전장치 — 이 원칙이 핑계가 되지 않게 한다(구현자 제안):**

1. **비교 전 봉인.** 무엇을 비교할지, 각 자료의 등급, 허용 차이, 불일치 시 판정 규칙을 A 결과를 보기 전에 봉인한다.
   결과를 본 뒤 자료 등급을 낮추거나 허용 차이를 넓히지 않는다.
2. **비대칭 규칙.** A가 R-A 자료와 어긋나면 기본 판정은 `A_SUSPECT`(A 쪽 원인 우선 조사)다.
   기존 측정을 의심하려면 최소한 A의 아래 물리 법칙에 대한 독립 검증, 해당 계산의 독립 checker 통과,
   변환 단계(N5)의 검토가 있어야 하며, 그래도 현실 독립 재측정 전에는 발견으로 승격하지 않는다.
3. **보정 자료와 검증 자료를 분리한다(개정 1).** 현실 자료로 모델의 값을 정하는 것(보정)은 정상적인 연구이며 금지하지 않는다.
   금지하는 것은 **어떤 자료에 맞춘 뒤 그 같은 자료와의 일치를 검증 성공으로 세는 것**이다.

   ```
   자료 A → 모델의 값을 정하는 데 사용(CALIBRATION) → A는 검증 자료로 사용 금지
   자료 B, C (A와 독립) → 현실 검증(VALIDATION)에 사용
   ```

   - 어떤 자료를 보정에 쓰고 어떤 값을 정할지는 검증 비교 전에 기록한다.
   - 검증 결과를 본 뒤 모델을 고치면, 그 검증 자료는 보정 자료로 바뀐다. 검증 성공을 주장하려면 새 독립 자료가 필요하다.
   - 보정 기록 없이 결과를 본 뒤 몰래 맞추는 것은 §33의 "결과를 만들려고 법칙 조정"과 같은 실패다.

**비교 판정:**

| 판정 | 뜻 |
|---|---|
| `AGREE` | R-A/R-B 자료와 봉인한 허용 차이 안에서 일치. 현실성 증거 증가(전체 승인 아님) |
| `AGREE_INDIRECT` | R-C 자료와 일치. 간접 근거이며 사용한 모델을 함께 기록 |
| `REFERENCE_ONLY` | R-D 자료 또는 THEORY REFERENCE와의 비교. 일치해도 현실 검증 통과 근거로 쓰지 않음 |
| `A_SUSPECT` | 강한 현실 자료와 불일치. A 쪽 원인 조사 중 |
| `DISAGREE_UNDER_INVESTIGATION` | 불일치. 원인 미정 |
| `REALITY_REFERENCE_DISAGREEMENT` | 현실 자료끼리 충돌. 한쪽을 임의로 정답으로 고르지 않음 |
| `NOT_COMPARABLE` | 조건이 다르거나 변환 방법이 승인되지 않음 |
| `UNSUPPORTED` | A가 그 현상에 필요한 물리를 지원하지 않음 |

### N7. Known-Reality Regression의 의미

Known-Reality Regression은 **이미 알려진 현실 측정과 A를 비교해서 현실성과 이상 징후를 검사하는 시험**이다.
기존 논문 숫자를 정답으로 보고 A가 똑같은 숫자를 내야 하는 시험이 아니다.

```
A와 실험 일치   → 현실성 증거 증가
A와 실험 불일치 → 즉시 A FAIL 아님 → 원인 조사 (N6 판정·안전장치 적용)
```

이 regression을 통과하지 않은 법칙·영역에서 나온 새 현상은 현실 이전 후보로 올리지 않는다.
H₂ benchmark(§29)는 이 단계에서 측정 자료와의 비교 시험으로 쓸 수 있다.

### N8. 시험 세계 제외

B나 계산기를 시험하려고 만든 가짜 법칙 세계(합성 세계, 탐침 세계 등)의 발견은 현실 이전 후보가 아니다.
현실 물리에 근거한 정규 A에서 나온 것만 현실 이전 대상으로 올린다.

### N9. 경계(boundary)를 명시한다

§30의 "승인된 boundary"는 계약 항목이다. 경계는 물리를 바꾼다.

- 반사 벽: 떨어져 나간 전자나 원자가 되돌아와 가짜 재충돌을 만들 수 있다.
- 흡수 벽·열린 경계: 나간 물질과 에너지를 외부 장부에 기록해야 한다(RULES §1 보존).
- 주기 경계: 자기 자신의 복제와 상호작용하는 효과가 생긴다.

각 실행은 경계 종류를 선언하고, 경계가 결과에 영향을 줬을 수 있는 사건을 Observer 보고에 표시한다.

### N10. 보존량 장부

장부로 검사할 양을 실행 전에 선언한다. 후보: 에너지, 선운동량, 각운동량, 전자 수, 양자 상태의 확률 총합(norm),
그리고 스핀(비상대론 법칙에서 보존). 경계(N9)를 통해 나간 양은 외부 장부에 기록한다.
선언한 보존량의 위반은 다음 단계로 넘어가지 않는 사유다.

### N11. 동일 입자 대칭

전자는 페르미온이므로 전자 상태는 교환 반대칭이어야 한다. 핵을 양자로 다루면 같은 종류의 핵도 그 핵의 통계
(보손/페르미온)를 따라야 한다. 표현 공간이 이 대칭을 깨거나 일부 대칭 성분만 허용하면 §22의 "가능성 차단"으로 공개한다.

### N12. 상위 유효 모델의 승인 기준을 미리 정한다

모든 것을 직접 계산하는 일반 정확 계산법은 큰 세계로 확장되지 않는다는 것이 알려져 있다. 따라서 큰 세계에는
언젠가 상위 유효 모델(§4C)이 필요할 가능성이 높다. 그 승인 기준(무엇을 표현하지 못하는지 공개, 아래 물리와의
비교 방법, 증거 등급, 적용 범위 이탈 시 fail-closed)은 **비용 압박이 생기기 전에** 정한다.
"싸니까"가 승인 근거가 되지 않게 하기 위함이다.

### N13. UNSUPPORTED 경로의 보고 형식

지원하지 않는 물리 경로가 있는 실행은 결과와 함께 다음을 보고한다.

```
경로: 예) 전자기 복사
상태: UNSUPPORTED
이 실행에서 영향이 있었을 수 있는 시간 규모의 대략값과 근거
이 경로가 있었다면 달라질 수 있는 결과 종류
```

예: 복사 방출은 대개 충돌 시간보다 훨씬 긴 시간 규모라서 짧은 pilot에서는 영향이 작을 수 있다. 그러나
"작을 수 있다"는 추정이며 근거와 함께 적는다. 결합 형성이 관측되지 않았다면 그 원인 후보에 이 경로를 남긴다.

### FUTURE OBSERVABLE (L) — 미시 변화에 대한 거시적 강건성 (개정 3, 본선 작업 아님)

질문: 미시적인 상태 차이가 생명체 규모까지 얼마나 자주 살아남아 증폭되고, 얼마나 자주 중간 구조에서 사라지는가.
"생명은 안정해야 한다"를 코딩하지 않는다. 실제로 생긴 구조가 그런 안정성을 갖게 되는지 관측한다.
고전적인 부분의 증폭(혼돈)은 0-B 없이도 설계자/검사 권한의 쌍둥이 실행으로 볼 수 있다. 착수는 A의 핵·전자 동역학이 닫힌 뒤.

## 3. 수정 조항

### §6 (수정) 오차는 세계 상태가 아니다 — 두 종류의 오차

N1의 세계 정의에 따라 세계 상태는 승인된 법칙을 실행한 결과다. 오차는 두 종류로 나눈다.

| 오차 | 무엇과 무엇의 차이 | 확인 방법 | 장부 |
|---|---|---|---|
| 수치 오차 | 실행기 출력 ↔ 승인된 법칙의 정확한 수학 | 범위 계산, 독립 replay 검증 | 검증 층 |
| 모델 오차 | 승인된 법칙 ↔ 현실 | 현실 증거와 비교(N6, N7) | 관측 층 |

어느 쪽도 세계가 실제로 퍼져 있다는 뜻이 아니다. V0 §6의 "범위는 컴퓨터가 어디까지 아는지에 대한 증거"라는
뜻은 유지한다. §7의 원인별 장부는 이 두 종류 아래의 세부 칸이며, N5의 변환 오차 칸을 추가한다.

### §13 (수정) spin / sector

비상대론 Coulomb 법칙에서는 전체 스핀이 법칙에 의해 보존된다. 따라서 sector는 세계에 붙이는 이름표가 아니라
**초기 상태의 성질이며 법칙이 유지하는 성질**이다. 계산 공간을 sector별로 나누는 것은 계산 기술이다.
단, 자기장·스핀-궤도 상호작용·빛(§18)을 넣으면 sector끼리 섞일 수 있으므로, sector별 분할의 정당성은
전자기 Gate의 결정에 의존한다.

### §26 (수정) 정확한 분수와 실제 물리

V0 §26의 원칙(값을 억지로 분수로 바꾸지 않고, 참값을 포함하는 경계를 정수/분수로 검증)을 유지한다.
**RULES §1의 "정수 또는 정확한 분수를 사용한다"의 의미를 바꾸는 해석이므로 RULES 개정이 필요하며, 설계자 결정 사항이다.**
N1의 정의 아래에서는 "승인된 법칙"이 이산 실행 규칙(반올림 규칙 포함)까지 정하면 세계 상태 자체는 그 규칙이
정한 값으로 결정되고, 범위 계산은 한 step의 건전성 검증에 쓰인다(C1-B1과 같은 구조).

### §27 (수정) 결과가 하나로 결정되지 않으면 계속 계산한다 — 적용 범위

이 조항은 **계산 판정**(반올림 결정, 표현 전환 판정, 범위 비교)에 적용한다.
양자적으로 결과가 갈라지는 물리(N2)에는 적용하지 않는다. 선언한 측정의 결과가 30% / 70%로 나오는 것은
계산의 미결이 아니라 계산이 끝난 답이다. "이번 사건이 어느 쪽이었나"를 정밀화로 결정하려 하거나 한쪽을 고르는 것은
N2 위반이다(Gate 0-B UNRESOLVED).

장시간 실행에서 모든 궤적의 범위를 끝까지 추적하는 것은 혼돈계에서 폭이 빠르게 커질 수 있다. 이것은
[A_THREE_LAYER_SEPARATION_V1.md](A_THREE_LAYER_SEPARATION_V1.md)의 결정대로 Gate가 아니라 연구 과제다.
Gate는 한 걸음의 건전성이다.

### §28 (수정) 확장성 — 전제

V0 §28 유지. 덧붙여, 모든 전자 양자 상태를 일반적으로 정확하게 저장·진화시키는 방법은 전자 수에 따라 비용이
급격히 커진다는 것이 이미 알려져 있다(2026-10-04 Hotline/Tensor 조사도 작은 계에서 이득을 찾지 못했다).
따라서 확장성은 "나중에 발견할 병목"이 아니라 **처음부터 계약에 들어간 조건**이다.
표현은 교체 가능한 부품(§2.2)으로 두고, 어떤 표현이든 수치 오차 장부(§6)를 정직하게 채우면 바꿔 끼울 수 있게 한다.

### §35 (수정) 아직 확정하지 않은 것 — 추가 항목

V0 §35의 8개 항목에 다음을 더한다.

```
이번 사건이 어느 결과였는지 정하는 방식 (N2, Gate 0-B) — 진화하는 세계(N3)의 전제
보정 자료 / 검증 자료 기록 형식 (N6-3)
THEORY REFERENCE 등급 이름·기준 (N6)
경계 종류와 경계 밖으로 나간 물질·에너지의 장부 (N9)
현실 자료 등급의 이름·기준과 비교 전 봉인 형식 (N6)
작은 세계 → 현실 조건 변환 방법의 승인 기준 (N5)
RULES §1 "정확한 분수" 조항의 개정 문구 (§26)
```

### §36 (수정) 다음 Gate — 순서안

의존성 기준 구현자 제안. 확정은 설계자.

## 4. 승인 범위와 승인하지 않는 것

승인(설계자, 2026-10-04, 개정 2 반영 조건): 이 계약의 원칙·구분·판정 체계 — V0 조항, N1〜N13, 수정 조항.

승인하지 않는 것:

- 결정된 물리 선택은 Gate 0-A(A 세계 정의) 하나뿐이다.
- 핵 운동 방식, 사건 결과 확정 방식(0-B), 전자기장, 표현, 경계의 어떤 선택도 승인하지 않는다.
- RULES §1 개정을 하지 않았다. 필요성만 표시했다. **일반 핵·전자 계산기 구현 전에 정식 문구를 승인해 RULES와 이 계약의 충돌을 없앤다.**
- 현실 자료(R)·이론 참조(T) 등급 이름과 세부 기준은 가칭이다. 등급별 검증 역할(개정 2)은 승인 범위에 포함된다.
- H₂ 연구 결과의 상태(PARTIAL, QZ UNRESOLVED, NOT CERTIFIED)는 그대로다.

**다음 단계(설계자 판정):** H₂를 더 붙잡지 않는다. Gate 1 전에 (1) RULES §1 개정 문구를 닫고,
(2) 첫 일반 가상 실험실이 요구하는 최소 조건을 정한다.

**검증:** 문서만 변경했다. 코드·시험·동결 계약·fixture 변경 없음. LOCAL FULL 생략 / 문서만 변경 / 공식 기준선 미갱신.
