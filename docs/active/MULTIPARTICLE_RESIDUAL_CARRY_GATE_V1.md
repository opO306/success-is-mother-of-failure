## 최종 판정: **B — U_AND_L_EQUIVALENT_BUT_COST_UNRESOLVED**

봉인된 판정 규칙을 독립 checker가 적용한 결과다.

1. **설계자의 누적 carry(U)와 검토자의 ledger(L)는 같은 법칙이다: `SAME_SEMANTICS_DIFFERENT_NORMALIZATION`.**
   실제 운동량 p = P + r과 drift 결과가 모든 시험에서 같았다. 다른 것은 P/r로 나누는 방식뿐이다.
   예: +0.6, −0.6, +0.6 → U는 (P = 0, r = 0.6), L은 (P = 1, r = −0.4). 둘 다 p = 0.6.
   → 아래에서는 하나의 후보 **R (Residual/Carry)** 로 부른다.
2. **정확한 유리수 충격량에서 R은 핵심 조건 9개를 모두 통과했다.** P·T·C가 각각 잃던 것을 R은 하나도 잃지 않았다.
3. **하지만 실제 물리 충격량에는 그대로 쓸 수 없다.** Lang 포텐셜의 충격량은 지수함수·제곱근에서 나오는 값이다.
   RULES §1(기록값은 정확한 분수, 구간으로 결정)에 따라 r도 유한 격자 2⁻⁽⁸⁰⁺ᵏ⁾에 둬야 한다.
   그렇게 하면 R은 **더 고운 격자에서의 P와 비트 단위로 같다**(k = 8, 16, 32 모두 확인).
   **P의 손실이 사라지는 게 아니라 2⁻ᵏ배로 작아진다.** k를 얼마로 할지, 그 비용이 얼마인지는 미결이다.

## 미리 공개할 발견 3개

**1. 정확한 잔여(r)는 일반 유리수 입력에서 상태 크기가 무한히 커진다.**
분모가 매번 달라지는 충격량 열(±1/(k+2))을 넣으면 r의 비트 수가 250 step에 693, 2,000 step에 5,750으로 거의 선형으로 늘었다.
분모가 제한된 입력(T12 본 시험, 10,000 step)에서는 r이 18 bit 이하로 유지됐다.
즉 R이 상태를 유한하게 유지하려면 r의 격자를 정해야 하고, 그게 위 판정 3번이다.

**2. 실제 물리에서는 R = 더 고운 격자의 P (원거리 Ar 배치, 중심 원자 x 성분, 정확값 ≈ 3.0316 u).**

| 잔여 격자 k | 중심 원자 결과 (coarse u) | 손실 |
|---|---:|---:|
| P (k = 0) | 0 | 3.03 |
| 8 | 775/256 | 4.2 × 10⁻³ |
| 16 | 198679/65536 | −2.4 × 10⁻⁵ |
| 32 | 6510261487/2³¹ | −1.2 × 10⁻¹⁰ |

36개 pair 중 0이 아닌 고운 충격량은 27개였다. 나머지 9개는 상대 x 좌표가 정확히 0이어서 x 성분 자체가 0이다.
**손실이 0이 되는 k는 없다.** k를 늘리면 원자당 r 저장 비트가 k만큼 늘고, P처럼 0이 아닌 pair를 하나하나 결정해야 하는 거리도 길어진다(A-Fabric 비용과 직결).

**3. 위치에도 같은 문제가 이미 있다 (R과 별개, C1-B1 drift 법칙의 성질).**
drift는 R의 잔여를 포함한 p를 정확히 읽었다(T11 통과, P만 읽는 음성 대조군은 실패로 검출됨).
하지만 C1-B1 v2 drift는 매 step 변위를 위치 격자로 반올림한다. 그래서 일정한 속도에서 오차가 계통적으로 쌓인다.
합성 단위 시험에서 한 step 변위 0.6이 매번 1로 반올림돼, 1,000 step 뒤 위치가 1,000이 됐다(정확값 600).
T12에서도 10,000 step 뒤 위치 격자 결과와 정확값의 차이가 −1,945 / −302 / +1,806 단위였다.
위치도 정확하게 누적하는 exact mode는 기준과 완전히 일치했다.
**실제 C1-B1 크기에서는 위치 단위가 2⁻⁴⁸ bohr라 한 step 효과는 매우 작다.** 다만 구조적으로는 운동량의 P 문제와 같은 "작은 변위의 계통적 손실"이다. 별도 판단 대상이다.

## 상태 크기와 비용

- 상태는 원자당 2개 값 (P, r)이고, pair별 숨은 상태는 없다. **O(N).**
- 같은 N=4 전수 입력(531,441 경우)에서 Python 실행 시간: U 25.1 s, L 26.6 s, P 3.9 s, T 7.6 s, C 10.0 s.
  R이 P보다 약 6.5배 느렸지만, 이건 유리수 객체 비용이다. 구조적 비용 비교는 아니다.

## 한계

- 합성 입력은 정확 유리수다. 실제 물리 입력은 원거리 Ar 배치 1개뿐이다.
- 장기 시험은 N=3, 합성 충격량 열 10,000 step이다. 실제 궤적이 아니다.
- 벽·접촉은 합성 장부 입력일 뿐이고, 물리 법칙으로 구현하지 않았다.
- 검사는 작성자 코드의 독립 checker(표준 라이브러리만, 실행기 import 없음)다. 외부 감사는 아니다.
