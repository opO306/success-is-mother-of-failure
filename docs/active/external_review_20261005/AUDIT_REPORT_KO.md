## 2. 실제로 계산하는 대상

원문이 정의하는 상태는 연속 운동방정식의 정확해 자체가 아니라, 반올림 없는 KDK 지도 T_h를 n번 적용한 값이다.

```text
p_half = p_n + (h/2) F(q_n)
q_next = q_n + (h/m) p_half
p_next = p_half + (h/2) F(q_next)
```

여기서 h=40이고, 힘은 고정 Lang 식의 지연 보정(retardation) ON 버전이다. A는 일반 수식 DAG, B는 대수 단순화가 있는 DAG, C는 초기값부터 구간 계산을 다시 하는 replay다.

각 시점의 위치·운동량을 격자에 사영한 숫자는 시험용 측정이며, 세계 상태에 다시 넣지 않는다. `build_kdk`와 `decide`의 데이터 흐름에서 이 분리는 확인된다.

따라서 다음 세 명제는 다르다.

1. 정확하게 정의된 식 T_h^n(x0)를 표현한다.
2. 그 식의 값을 포함하는 구간과 유일한 관측 격자값을 얻는다.
3. T_h^n(x0)가 현실 또는 연속 기준 방정식의 해에 목표 오차 이내로 가깝다.

1의 성립은 2의 모든 입력에서의 완료도, 3도 보장하지 않는다. 반올림 규칙이 다른 기존 C1-B1의 궤적 정리를 그대로 승계할 수도 없다. 공통 퍼텐셜의 국소 정리 등은 전제가 같음을 확인하여 재사용할 수 있다.

## 4. F-DOMAIN-1: 단순화가 안전검사까지 지운다

### 위치

- `dag.py:55-77`의 `lin`
- `dag.py:88-96`의 `mul`
- `dag.py:117-138`의 `evaluate`

### 정확한 입력

```python
q0 = [(0, 0, 0), (0, 0, 0)]
p0 = [(0, 0, 0), (0, 0, 0)]
steps = 1
dt = 40
```

같은 위치에 있는 두 입자라서 R=0이며, 원래 힘의 정의역 밖이다. 이것은 지원되지 않는 입력을 양쪽 경로가 일관되게 거부하는지 보는 검사다. 봉인된 네 시나리오가 이 상태를 방문했다는 주장이 아니다.

실행 결과:

```text
A: ValueError, 거리 정의역 위반으로 거부
B: RETURNED, 위치·운동량의 12개 성분을 모두 0으로 반환
B의 reachable node kind: c만 남음
```

B는 `G(0) * 0`을 0으로 접는다. 최종 root에서 G 노드가 사라져, evaluator가 그 노드에서 수행하던 거리 검사를 실행하지 않는다.

`0*x=0`은 x가 실수일 때의 항등식이다. 정의되지 않은 `G(0)`을 안전한 실수로 바꾸는 규칙이 아니다. 따라서 “값이 존재하면 같다”와 “실행 가능·거부 여부도 같다”를 분리해야 한다.

필요한 증명 의무는 값 계산 DAG와 별도로 원래 계산의 정의역 의무를 유지하는 것이다. 모든 소거된 하위식이 정의된다는 증명 없이 그 하위식의 의무를 제거해서는 안 된다. 이것은 물리 상태의 보정이나 정확도 목표 변경 없이 처리할 수 있는 문제다.

## 5. 검사기가 증명하지 않는 것

### 5.1 힘 evaluator를 공유한다

`checker.py:20`은 실행기와 동일한 `lang_iv`를 import하고, `my_replay`에서 같은 `G_of_R2`를 호출한다. 시간 전개 코드의 독립 작성과 힘 평가 구현의 독립성은 별개다.

원문의 교차시험도 힘 참값의 포함성을 증명하지 않는다. `tests/test_exact_expression_gate_v0.py`는 네 반경에서 두 구간의 교집합이 비어 있지 않은지 검사한다. 두 구간이 겹친다는 것만으로 새 구간이 참값을 포함한다고 결론낼 수 없다. 기존 구간이 참값을 포함해도 마찬가지다.

예를 들어 참값 0, 기준 구간 [-e,e], 새 구간 [e/2,3e/4]는 e>0일 때 겹치지만 새 구간은 0을 포함하지 않는다. e를 매우 작게 해도 논리적 문제는 그대로다.

이것은 현재 힘 공식이 틀렸다는 반례가 아니다. 엄격한 독립 인증의 증명 연결이 없다는 판정이다. 같은 힘 구현을 신뢰기반으로 명시하고 “적분 경로만 독립 검증”으로 범위를 제한하는 것과, 힘 계산까지 독립 검증되었다고 하는 것은 다르다.

## 6. F-ENERGY-1: 실제 Lang 모델의 정확한 에너지 반례

### 6.1 반박하는 명제

“반올림을 없애고 KDK 계산을 정확한 식으로 보존하면 물리 에너지 H=K+V가 정확히 보존된다.”

이 명제는 거짓이다. 원문 protocol이 이를 이미 증명했다고 주장하는 것은 아니다. `RULES.md`의 엄격한 에너지 보존과 새 후보를 양립시키려 할 때의 구조적 검사다.

### 6.2 입력

원문과 동일한 Lang 공식·상수·질량·h=40을 사용한다.

```text
q_left  = (-71/20, 0, 0)
q_right = ( 71/20, 0, 0)
p_left = p_right = (0, 0, 0)
m = 399623831237000000 / 5485799090441
R0 = 71/10
```

이것은 봉인된 A2_bound와는 운동량이 다른 추가 수학적 입력이다. 원래 Ar–Ar 공식의 지원 반경 안에 있다.

대칭성으로 오른쪽 입자의 운동량만 쓰면:

```text
p_half = -20 V'(R0)
R1     = R0 + (80/m) p_half
p1     = p_half - 20 V'(R1)
ΔH     = p1²/m + V(R1) - V(R0)
```

왼쪽 운동량은 항상 반대 부호다. 두 입자의 운동에너지 합이 p1²/m인 점에 주의한다.

독립 정확 유리수 구간 계산 결과:

```text
R1 ∈ [7.100000208028432041311409,
      7.100000208028432041311410] bohr

ΔH ∈ [-16161056 / 10^24,
       -16161055 / 10^24] hartree
```

구간 전체가 음수이고 0을 포함하지 않으므로 H1 != H0다. 초기와 최종 반경이 지원 범위 안이고, 이 경우 반경은 바깥 방향으로 증가한다.

### 6.3 왜 단순 수치 증거가 아닌가

`independent_energy_check.py`의 증명 연산은 다음으로 닫힌다.

1. 모든 입력 상수는 정확한 유리수다.
2. 각 사칙연산의 하한·상한을 정확한 Fraction으로 계산하고, 2^-256 격자 바깥 방향으로만 반올림한다.
3. 양의 y<=1/2에 대해 S_n(y)=sum(y^k/k!, k=0..n)을 계산한다.
4. exp(y)의 양의 나머지는 첫 누락항을 a_(n+1)라 할 때 a_(n+1)/(1-y/(n+2)) 이하이다. 다음 항들의 비가 y/(n+2) 이하이기 때문이다.
5. 양수 구간을 역수로 바꾸고 제곱하여 exp(-x)의 참값 포함 구간을 얻는다.
6. 퍼텐셜에 합·곱·역수·지수함수의 미분 규칙을 적용해 V'의 구간을 만든다. 실행기의 힘 코드를 import하거나 정답으로 사용하지 않는다.
7. 최종 ΔH 포함 구간이 엄밀하게 음수다.

급수의 참값 포함성, 구간 연산 규칙, 자동미분 규칙을 전제로 하는 컴퓨터 보조 반례다. 256-bit 점 계산 두 번의 일치를 증명이라고 부른 것이 아니다.

에너지 차이가 작다는 사실은 “정확히 0”이라는 명제를 살리지 못한다. 반대로 이 한 반례만으로 허용 오차가 있는 모든 사용 목적에서 부정확하다고 단정할 수도 없다. 그 평가는 별도의 승인된 오차 계약을 필요로 한다.

### 6.4 봉인된 A2_bound 초기값 그대로의 추가 반례

다른 초기값에만 의존하지 않기 위해, protocol에 봉인된 A2_bound도 첫 한 스텝을 별도로 계산했다.

```text
q_left  = (-71/20, 0, 0)
q_right = ( 71/20, 0, 0)
p_left  = ( 1, -3, 0)
p_right = (-1,  3, 0)
h = 40
```

초기 위치·운동량·질량·시간 간격을 바꾸지 않았다. 독립 정확 유리수 구간 결과는:

```text
R1 ∈ [7.098902779947443360866622,
      7.098902779947443360866623] bohr

ΔH ∈ [174246863802 / 10^24,
      174246863803 / 10^24] hartree
```

이번 구간은 전체가 양수다. 즉 봉인된 입력에서도 H1 > H0가 성립한다. 반경의 정의역 위반을 이용한 반례도 아니다. drift 동안 상대 x좌표의 양 끝이 모두 R_MIN보다 크고 x좌표가 선형으로 변하므로, 전체 drift에서 상대 거리가 R_MIN보다 크다.

오른쪽 입자와 상대 위치를 사용한 독립 계산식:

```text
ph_x = -1 - 20 V'(R0)
ph_y = 3
D_x  = R0 + (80/m) ph_x
D_y  = (80/m) ph_y
R1   = sqrt(D_x² + D_y²)
p1_x = ph_x - 20 V'(R1) D_x/R1
p1_y = ph_y - 20 V'(R1) D_y/R1
ΔH   = (p1_x²+p1_y²-10)/m + V(R1)-V(R0)
```

제곱근은 이진 격자로 스케일한 정수의 isqrt로 하한·상한을 구한다. 하한은 제곱이 입력 하한 이하이고, 상한은 제곱이 입력 상한 이상이 되도록 구성한다. 따라서 새로 포함된 제곱근도 점 근사나 부동소수점에 의존하지 않는다.

자료: `energy_sealed_a2_certificate.json`, `audit_execution_log.json`의 `ENERGY_SEALED_A2`, `independent_energy_check.py`의 `run_sealed_a2()`.

이는 봉인된 입력의 첫 스텝에 대한 수학적 반례다. 원래 10/100/1000-step 캠페인을 실행하거나 그 결과 파일을 검증했다는 뜻은 아니다.

## 7. 증명 가능한 핵심 정리

### 7.1 수식 보존

각 DAG 노드에 수학적 의미를 대응시킨다. c 노드는 유리수, lin 노드는 유리수 계수의 유한 선형 결합, mul은 곱, G는 선언된 정의역 안의 실수 함수다.

자식 노드의 의미가 유지된다고 가정하면 부모 노드도 유지된다. 상수 접기·항 병합은 실수체의 항등식이므로, 원래 모든 피연산자의 정의역을 확보하면 식의 값을 보존한다. 공유 노드는 동일한 식을 한 번 저장할 뿐이다. 생성 순서에 따른 귀납으로 유한 KDK 식 전체에 적용된다.

이 정리는 F-DOMAIN-1을 무효화하지 않는다. 정의역 전제를 증명하기 전에 잘못 소거했기 때문이다.

### 7.2 포함 구간의 유일 사영

ρ를 같은 눈금의 round-half-even 사영이라고 하자. ρ는 실수 순서를 보존하는 비감소 함수다. x가 [l,u]에 있고 ρ(l)=ρ(u)=k이면:

```text
k = ρ(l) <= ρ(x) <= ρ(u) = k
```

따라서 ρ(x)=k다. 동점 경계도 동일한 반올림 규칙을 양 끝에 적용하면 이 논증에 포함된다.

하지만 x∈[l,u] 자체는 이 정리가 보장하지 않는다. 그 부분은 구간 evaluator의 별도 증명 의무다. 유한 FX 포맷의 overflow 처리도 별도다.

### 7.3 운동량·각운동량

각 입자쌍의 kick은 같은 벡터 J를 한 입자에 더하고 다른 입자에서 뺀다. 따라서 총운동량 변화는 J-J=0이다. drift는 운동량을 바꾸지 않는다. 유한 스텝 수에 대한 귀납으로 보존된다.

쌍 힘이 두 입자를 잇는 방향과 평행하므로 쌍 토크도 0이다. drift에서는 각 입자에 대해 (h/m p)×p=0이어서 각운동량이 보존된다.

이것은 정확한 내부 상태에 대한 정리다. 관측 숫자를 성분별로 별도 반올림한 뒤 더한 값까지 똑같은 보존식을 만족한다고 자동 주장하지 않는다.

### 7.4 힘 공식의 수학적 미분 경로

단거리 항 e^(-aR)P(R)의 미분은 e^(-aR)(P'(R)-aP(R))다.

감쇠함수 f_n(x)=1-e^(-x)sum(x^i/i!, i=0..n)의 미분은 e^(-x)x^n/n!이다. 따라서 x=eta R를 넣으면 eta 계수가 곱해진다. 장거리 항 -C D(R) R^(-2k)의 미분에는 D'와 R^(-2k)의 미분 두 항이 모두 필요하다. `lang_iv.py`는 이 구조를 사용한다.

retardation 분모는 R>0에서 양의 상수항 1과 양의 계수 항들의 합이므로 0이 아니다. 이는 수학적 공식의 유효성을 지지한다. 라이브러리와 모든 구현 경로의 검증을 대체하지 않는다.

## 8. 추가 한계와 UNRESOLVED

### 8.1 반드시 판정이 끝나는가

유일 사영의 건전성과 유한 시간 완료는 다르다. 예를 들어 정확한 값 x가 반올림 경계 b와 같고 구간이 모든 p에서 [b-2^-p,b+2^-p] 형태라면 폭은 0으로 수렴해도 양 끝 사영은 계속 다를 수 있다.

이것이 봉인된 시나리오에서 실제 발생했다고 주장하지 않는다. 현재 자료로 “모든 유효 입력에서 유한 정밀도로 끝난다”를 증명할 수 없다는 뜻이다. 특정 식에서의 경계 분리 또는 정확 동점 판정 정리가 필요하다. 자원 cap에서의 UNDECIDED는 이 수학적 명제의 거짓 증거도 아니다.

### 8.2 장기 물리 오차

수식의 정확한 표현은 시간 간격 h의 적분 오차를 지우지 않는다. 연속 기준해 대비 정확도에는 유효 영역, 해의 존재, 국소 절단 오차, 오차 증폭, 구간 합성, 관측량 변환이 필요하다. 기존 C1-B1 증명의 전이식·상태 영역을 새 지도와 대조하지 않고 승계할 수 없다.

이 Gate의 코드에는 endpoint 힘 정의역 검사가 있지만, 기존 C1-B1이 명시한 drift 선분 전체의 최소 거리 검사는 그대로 이식되어 있지 않다. 새 의미론에서 어떤 과정까지 유효성의 대상으로 삼는지와 그 보장은 별도로 고정해야 한다. 기존 안전 보장이 자동 유지됐다는 판정은 하지 않는다.

### 8.3 F-SENS-1: 진단값의 실제 시간

`campaign.py:70-107`은 ValueError를 잡은 뒤 완료 스텝 수 없이 현재 q,p를 반환한다. `campaign.py:211-234`의 민감도 진단은 이 값을 요청한 체크포인트 상태로 사용한다.

겹친 입자 입력과 x축 2^-100 미소 변형 입력은 둘 다 시간 0에 거부되지만, 1000 스텝 요청의 반환값으로부터 민감도 증폭 log2=0처럼 보이는 값을 만들 수 있었다. 이는 진단 자료의 시간 의미가 보장되지 않는 반례다. 봉인된 네 시나리오의 기록에 이런 오류가 실제 섞였다고 확인한 것은 아니다.

더구나 두 interval의 midpoint 차이는 일반적으로 두 정확 궤적의 차이가 아니다. 이런 진단은 완료 여부와 폭을 명시해야 하며, 처음부터 원문이 표시한 대로 certificate가 아니다.

### 8.4 유한 FX 폭과 무한 격자

`campaign.cell`은 눈금에 대한 정수 반올림만 한다. 위치 2^47을 F=48로, 운동량 2^15을 F=80으로 사영하면 모두 raw=2^95를 반환한다. 이는 signed 96-bit 최대치 2^95-1보다 크다.

무한 격자 사영을 뜻한다면 계산은 맞다. 실제 FX(96,F)의 유효 값을 보장한다면 범위 검사가 빠져 있다. protocol의 “FX grid”가 눈금만 뜻하는지 유한 포맷까지 뜻하는지 엄격히 구분해야 한다.

### 8.5 크기와 정밀도의 증명 범위

자유 비행은 q_n=q_0+n h p_0/m으로 닫히므로, 살아 있는 상수 노드 개수는 O(1)로 줄일 수 있다. 그러나 p_0!=0인 성분의 정확한 유리수 분자는 n과 함께 커져 저장 비트 수는 일반적으로 Θ(log n)이다. 노드 수 O(1)을 바이트 수 O(1)로 바꾸어 말하면 안 된다.

현재 DAG의 `nodes/index`는 더 이상 root에서 도달하지 않는 과거 노드도 보유한다. protocol은 reachable과 created를 나누므로 두 지표를 그대로 분리해서 해석해야 한다.

고정된 유한 N에서, bounded flattening과 현재의 모든 쌍 순회는 노드·간선 수에 O(N² t)의 상한을 주는 구조다. 정수 계수 길이와 정밀도 비용은 이 상한에 포함되지 않는다. 네 사례의 정밀도 증가를 모든 물리 궤적의 하한 또는 보편적인 O(t²) 정리로 승격할 수 없다. 원문도 이를 가설로 표시한다.

## 9. 승격 전에 필요한 최소 증명 의무

1. **정확히 어떤 지도를 인증하는지 고정한다.** 반올림된 C1-B1과 새 unrounded KDK를 혼합하지 않는다.
2. **값과 정의역 의무를 함께 보존한다.** 소거되는 식의 정의 가능성을 별도 증명하거나 그 의무를 계속 추적한다.
3. **힘 evaluator의 신뢰 범위를 정한다.** 공유 구현을 신뢰기반으로 인정한 상대적 검사인지, 힘까지 독립 exact checker로 검증하는 것인지 구분한다.
4. **자료 완전성을 긍정 판정의 전제로 둔다.** 확인 0건, 필수 결과 누락, 잘못된 protocol, 미확인 extended 결과를 정상적인 긍정 근거로 삼지 않는다.
5. **물리 에너지와 궤적 오차를 별도 다룬다.** 반올림 제거로 해결됐다고 가정하지 않으며, 반례 때문에 상태를 강제로 보정하지 않는다.

큰 무작위 시험을 추가하기 전에 이 작은 논리적 연결부터 닫는 것이 우선이다. 상위 목표·허용 오차·유효 영역 변경은 이 감사의 권한으로 승인하지 않는다.
