## 0. 판정: **CIRCULAR**

`R_min ≥ 5.35`는 승인된 장벽 lemma로 **"모든 저장 상태에서 E~ ≤ E_hi"** 하나로 줄어든다. L, 연속 H, 전환점 분석은 모두 필요 없다. 그러나 **실행기에는 정확히 보존되는 에너지가 없고**, 지금 가진 에너지 정리는 모두 step당 변화 상한이다. 그래서 E~ ≤ E_hi를 전 구간에서 보이려면 **N(체류 step 수)이 다시 들어간다.** R_min-only 경로는 ④ v0의 실패 지점을 우회하지 못한다. 실제로 ④ v0이 이미 "장벽으로 R ≥ 5.35 유지"였고, 유효 퍼텐셜은 거기에 L 항을 더할 뿐이다.

## 1. R_min ≥ 5.35에 실제로 필요한 것 (문항 3, 11)

승인된 Energy Barrier lemma(장벽 [5.32, 5.35], V ≥ 12.6897 De):
> R_n ≥ 5.35, \|P_h\| ≤ P_half_cap, **E~_(n+1) ≤ E_hi** → R_(n+1) ≥ 5.35.

- \|P_h\| cap은 E2로 **E~_n ≤ E_hi**에서 나온다(④ v0: E_hi = 12.5 De에서 21.15, 한 step 0.0232 < 두께 0.03).
- 따라서 필요한 변수는 **E~의 상한 하나**다. 모든 n에서 E~_n ≤ E_hi이면 귀납으로 R_min ≥ 5.35다.
- **직접 barrier inequality는 이미 있다:** R ∈ [5.32, 5.35]인 상태는 \|P\|² = 2μ(E~ − V) + h²V′²/4 ≥ 0에서 E~ ≥ V − h²V′²/(8μ) ≥ 12.69 De − (작은 항) > E_hi. 설계자 우선순위 1("R < 5.35가 에너지상 불가능하다는 직접 부등식")이 바로 이것이다. 한 step에 장벽을 건너뛸 수 없다는 조건(0.0232 < 0.03)이 이것을 R < 5.32 전체로 넓힌다. 정확한 R_min 계산이나 근 분리는 필요 없다.

## 2. 연속 H는 필요한가 (문항 4)

**아니다.** 장벽 lemma와 E2는 **수정 에너지 E~**로 직접 쓰여 있다(\|P\|² = 2μ(E~ − V) + h²V′²/4는 저장 상태의 항등식이다). 초기값도 저장 상태에서 `energy_of_state`로 구간으로 감싼다. H ↔ E~ 교량은 필요 없다. D_valid의 E_rel ≤ 10 De(H) → E~_0 ≤ H_0 ≤ 10 De는 E~ = H − (비음수 항)이라 정확하다.

## 3. E~만으로 가능한가 (문항 5)

**E~ ≤ E_hi가 모든 step에서 알려져 있다면 가능하다.** 문제는 그것을 아는 방법이다.
- 실행기의 정확한 불변량: 총 운동량(정수 덧셈, 정확), 시간역전 대칭(lemma TR). **에너지형 정확 불변량은 없다.** 반올림 없는 KDK도 위치 의존 힘에서는 정확히 보존되는 에너지가 없다(수정 해밀토니안은 점근 급수일 뿐이다).
- 승인된 E1은 성공 step마다 \|ΔE~\| ≤ dE다. 전 구간 상한은 E~_n ≤ E~_0 + Σ_(k<n) dE(R_k)이고, 이 합은 **N에 의존**한다.
- 1-step 잔차(사다리꼴 잔차 ≈ M3·\|chord\|³/12와 반올림 항)를 합에서 상쇄하거나 망원(telescoping) 형태로 바꿀 구조는 찾지 못했다. Σ\|chord\|³ ≤ (최대 chord)²·(경로 길이)로 바꿔도 경로 길이가 다시 시간(N)이다.
- **결론: E~만으로는 가능하지만, E~의 전 구간 상한이 N 없이는 닫히지 않는다.**

## 4. L은 필요한가, N 없이 감쌀 수 있는가 (문항 6, 7)

- **R_min ≥ 5.35에는 L이 필요 없다.** 금지 판정은 \|P\|² ≥ 0만 쓰며, 이것이 정면충돌(L = 0)이라는 최악의 경우다. L ≠ 0이면 \|P\|² = p_r² + L²/R²이고 V_eff = V + L²/(2μR²) ≥ V이므로 장벽이 **높아지기만** 한다.
- L이 도움이 되는 곳(참고): L이 큰 상태는 여유가 커진다. 예: 10 De, b = 14에서 R = 5.35의 원심 항은 약 68 De로, 에너지 여유가 약 2.7 De에서 약 70 De가 된다. 그러려면 L의 전 구간 하한이 필요하다. L의 step당 변화 상한(④-1 angular, ≈ D·P_cap + 2bU ≈ 10⁻¹³)을 누적하면 **역시 N 의존**이다. 다만 L ≈ 10²에 비해 아주 약해서 N ≲ 10¹³까지 쓸 수 있다. 정면충돌 계열에는 소용이 없으므로 **균일한 개선이 아니다.**
- 관측(증명 아님): 직전 조사에서 실행기 L의 통과당 변화 ≤ 3.7·10⁻¹².

## 5. 전환점 세 종류 (문항 8〜10)

장벽 논증은 **속도의 방향이나 크기에 대해 아무것도 가정하지 않는다.** 각 step에서 "(저장 위치, E~)가 금지 셀에 있을 수 없다"와 "저장 이동 < 장벽 두께"만 쓴다.
- **A. 일반 전환점(반지름 속도 0):** 추가 처리 불필요. 전환점의 R은 V(R) ≤ E~ + h²V′²/(8μ)를 만족해야 하므로 장벽 밖이다.
- **B. 궤도 경계 준정지(반지름 속도 ≈ 0, 접선 속도 ≠ 0):** 장벽 논증은 R_min에 대해서는 영향을 받지 않는다. 오래 머무는 것이 R을 작게 만들지는 않는다. 그 R은 V_eff 꼭대기 근처(0.5 De에서 R_b = 9.73)라 장벽과 멀다. **그러나 오래 머무는 동안 E~ 드리프트가 누적된다.** 체류 시간이 영향을 주는 곳은 R이 아니라 **에너지 전제**다. 이것이 순환의 실체다.
- **C. 정면충돌 순간 정지(P = 0):** \|P\| = 0은 E2의 하한 경우다. 전환점 R에서 V(R) ≈ E~ ≤ 10 De(10 De에서 R ≈ 5.505)이며 장벽 밖이다. 정지 순간의 한 step 이동은 α·\|P_h\|로 작다. 추가 처리 불필요.

## 6. N은 어디에 들어가는가 (문항 12, 13)

| 고리 | N 의존 |
|---|---|
| 장벽 금지 판정(V ≥ 12.69 De) | 없음(위치만) |
| 한 step < 두께 | 없음(E~_n ≤ E_hi → cap) |
| \|P_h\| cap | 없음. **단 E~_n ≤ E_hi가 주어졌을 때** |
| **E~_n ≤ E_hi(모든 n)** | **있음: E~_0 + Σ_(k<n) dE(R_k)** |
| L(쓸 경우) | 있음(약함: N ≲ 10¹³) |

순환: R_min을 묶으려면 에너지가 필요하고, 에너지를 묶으려면 N이 필요하다. N을 묶는 것은 체류 상한(ROUTE B의 우물/궤도 영역, 즉 Liveness 쪽 재료)이다. **"R_MIN-ONLY FAILS DUE TO CIRCULAR DEPENDENCY"**(에너지 전제를 통해).

## 7. 그래도 남는 정보 (다음 작업의 모양)

R_min-only가 실패해도 N이 **얼마나 거칠어도 되는지**는 정확히 말할 수 있다(모두 기존 수치).
- 장벽 침범에는 누적 드리프트 ≥ 여유(E_hi − E~_0 ≥ 12.5 − 10 = 2.5 De ≈ 1.13·10⁻³ hartree)가 필요하다.
- 위치별 1-step dE: [5.35, 7] ≤ 1.5·10⁻⁶, [7, 8] ≤ 9.1·10⁻⁹, [8, 12] ≤ 1.2·10⁻⁹, [12, 20] ≤ 9.0·10⁻¹²([inner 조사](C1B1_INNER_EVENT_SURVEY_V0.md) 2절).
- wall 방문 한 번의 상한은 **N 없이** w-progress로 닫힌다(여유의 28〜83%, ROUTE B).
- 따라서 R_min ≥ 5.35에 필요한 N 정보는 정확한 체류 시간이 아니라 **거친 두 숫자**면 된다: (a) wall 방문 횟수 ≤ 1(또는 여유가 허락하는 몇 회), (b) [7, 20] 체류 step ≲ 10⁵〜10⁸(구간별). 관측 통과는 2·10³〜3·10⁴ step, wall 방문 1회였다(증명 아님).

## 8. ④에서 해결되는 부분 / 남는 부분 (문항 15, 16)

- **해결되는 것:** 없음(판정 CIRCULAR). 다만 "Safety 조각 R < 5.35 침범 불가"의 **논리 형태가 확정됐다:** 장벽 lemma + E~ 상한 하나. L, H 교량, 전환점 분석, R_min 근 분리는 필요 없다.
- **여전히 남는 것:**
  - Safety 조각에 필요한 **거친 체류 상한**(wall 방문 횟수, [7, 20] 체류 step).
  - 별도의 **Liveness**(유한 시간에 outbound로 R ≥ 20 도달). 거친 체류 상한이 증명되면 그것이 이 Liveness의 핵심 재료이기도 하다. 두 문제는 **같은 부품**(체류 상한)을 공유하지만 다른 명제다.
