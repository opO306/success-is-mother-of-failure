# C1-B1 Field Map 조사 v0 — 공간(R)에 인증된 물리 성질을 미리 붙이는 방식

**상태:** survey_only, 문서만. 저장소 코드 변경 0, 새 시험 0. 설계 승인·구현 지시가 아니다. 날짜 2026-09-30. 기준 HEAD `44240ef`.
**지시(설계자 2026-09-30):** 입자를 따라가며 증명하는 대신, R에 대한 1차원 구간 지도(V·F 범위와 부호, 도함수 상한, 거기서 확실히 말할 수 있는 동역학 성질)를 만들 수 있는지 조사. inbound V1을 갈아엎지 않는다. 실행기·D_valid·dt = 40·동결 계약 불변, 궤적 survey로 지도를 맞추지 않는다, inner·A-EV 시작 안 함.
**수치의 성격:** 아래 수치는 모두 저장소 밖 **스크래치 계산**(읽기 전용)이다. 동결 Lang 2024와 기존 구간 코드(`c1b1_outer_bound.derivatives`, 셀 하나가 약 0.3〜0.5초)만 썼다. R < 20에서는 `derivatives`의 범위 guard(20 ≤ a)만 스크래치 사본에서 뗐다. 수학은 R > 0에서 같다. **증명이나 인증이 아니다.**

## 0. 결론

**판정: 새 "Field Map" 계층은 도입 불필요(기존 구조로 충분). 다만 조사로 드러난 두 가지 사용법은 채택 후보다.**

1. **기존 `Shell`/`derivatives`가 이미 R ≥ 20의 1차원 구간 지도다.** V, V′, V″, V‴를 셀 전체에서 outward로 감싼다. 새 지도를 만들면 같은 수를 다시 담는 wrapper가 된다.
2. **실제로 새 정보를 준 것은 "지도"가 아니라 "그 지도를 에너지와 함께 쓰는 방법"이었다.** 셀마다 V 범위가 있으면 에너지 보존에서 그 셀 안의 속도가 정해진다(\|P\|² = 2μ(H − V)). 스크래치 변형에서 이 **에너지 기반 운동량 상한**은 inbound V1이 못 닫던 저에너지 상태 6개(E = 1e-8·1e-4·1e-2 De, 출발 R 25·200)를 **전부 닫았다**. 힘의 부호(인력)만 쓰는 변형은 **하나도 못 닫았다.**
3. **inner(R < 20)에서는 지금 구간 계산 자체가 약점이다.** R = 3에서 폭 1/8 셀의 V′ 구간이 [−721, 602]인데 참값은 [−0.90, −0.76]이다(약 1000배). 원인은 Tang–Toennies 감쇠 항의 상쇄(R = 3에서 감쇠 전 분산 항이 약 100 hartree). 이것을 고치지 않으면 inner "지도"는 또 하나의 전수 분할이 된다. 대신 **에너지 장벽 셸**(D_valid 에너지로는 들어갈 수 없는 얇은 R 구간)은 싸게 인증된다. R ∈ [5.32, 5.35]에서 셀 3개로 V > 12.69 De였다.

## 2. Field Map이 추가로 줄 수 있는 정보 — 측정

### 2.1 힘의 부호(inward/outward)
- 기존 5/4 셀로는 V′ > 0(인력)이 **R ∈ [20, 48.8]에서만** 인증된다. 그 너머는 참 힘이 인력인데도 구간 아래 끝이 음수라 "모름"이다. V″의 부호는 5/4 셀 어디에서도 인증되지 않는다.
- **inbound 저에너지에 대한 효과: 없음.** 반 kick 항 bK를 인력 셀에서 bU로 바꾼 스크래치 변형이 저에너지 6개 중 0개를 닫았다(모두 w 천장 실패). 운동량을 kick 누적으로 묶는 한 느린 상태의 step 수가 병목이기 때문이다.

### 2.2 셀별 V 범위 + 에너지 → 셀별 속도 범위 (**결정적**)
- 셀 [a − g, b]에서 V ∈ [V_lo, V_hi]이고 H ∈ [H_lo, H_hi]이면 \|P\|² ∈ [2μ(H_lo − V_hi), 2μ(H_hi − V_lo)]다. H의 폭은 입구 H와 ④-1의 1-step 수정 에너지 예산 합, 끝점 보정 h²F²/(4μ)이다. kick 누적 p ± 2nK 대신(또는 함께) 쓴다.
- **스크래치 변형 결과(증명 아님, `runs/c1b1_field_map_survey_20260930/lowE.*`):**

| E/De, b, 출발 R | inbound V1 | 부호만 | **에너지 기반** | 에너지 기반 handoff w 천장 |
|---|---|---|---|---|
| 1e-8, 7, 25 | NC | NC | **인증**(cap ρ 1/16, 44,795 step) | −2.29 |
| 1e-8, 7, 200 | NC | NC | **인증**(1억 6148만 step) | −4.31 |
| 1e-4, 7, 25 | NC | NC | **인증**(40,539 step) | −2.53 |
| 1e-4, 7, 200 | NC | NC | **인증**(311만 step) | −4.45 |
| 1e-2, 7, 25 | NC | NC | **인증**(9,320 step) | −10.99 |
| 1e-2, 7, 200 | NC | NC | **인증**(32만 step) | −11.58 |
| 0.1, 14, 25 | 인증(ρ 1/16) | 인증 | 인증(ρ 1/1024, 더 작은 cap) | −25.96 |

- 인증된 천장은 물리적으로 말이 된다. 예: E = 1e-8 De에서 R = 20의 실제 \|P\| ≈ √(2μ\|V(20)\|) ≈ 0.28이라 w ≈ −R\|P\| ≈ −5.6이고, 천장 −4.3은 그보다 느슨하지만 유효한 쪽이다.
- **데이터는 이미 있다**(`Shell.radial[0]`). 필요한 것은 귀납이 그것을 쓰는 방법이다(inbound V1 판정 요청 V1-2 (b)). outgoing도 같은 한계를 가지므로(E = 1e-4 De 실패) **양방향 공용 개선**이다.
- 스크래치의 ε 회계(입구 H, 끝점 보정에 셀의 F를 쓴 점, zero-impulse 구간 없음)는 정식 유도가 아니다. 채택하면 유도·결함 주입·독립 감사가 필요하다.

### 2.3 에너지 장벽 셸(inner, r_min 거리)
- D_valid의 E ≤ 10 De는 V(R) = 10 De인 R ≈ **5.505 bohr** 안쪽으로 들어갈 수 없다(연속 역학 기준). V(r_min)은 약 3979 De다.
- **이산 궤적용 논증:** 셸 [c, d]에서 V_lo > E_hi(에너지 예산 포함)이고 셸 두께 d − c가 한 step 최대 이동 g보다 크면, R ≥ d인 저장 상태는 다음 저장 상태에서 R < c로 건너뛸 수 없다(\|δ\| ≤ g). [c, d)에 들어가면 운동에너지가 음수가 되어 모순이다. 그러면 저장 상태는 R ≥ d에 머문다.
- **측정:** [5.32, 5.35]를 폭 0.01 셀 3개로 덮으면 V > **12.69 De**가 인증된다(참값 V(5.35) ≈ 14.80 De). 0.03 bohr는 E ≲ 13 De의 한 step 이동(≈ 0.02)보다 두껍다. 1초 남짓.
- **의미:** 에너지 예산이 인증된 궤적이라면, D_valid 에너지에서 r_min(2.27)과 그 근처의 해석 곤란 구간은 **도달 불가**로 잘라낼 수 있다. IN-4에서 설계자가 요구한 "D_valid 전체에서 guard 비대칭 무관"의 **후보 근거**가 된다(아직 증명 아님: inner 궤적 전체의 에너지 예산이 먼저 필요하다).
- 넓은 셀로는 안 된다: [5.3, 5.4] 한 셀은 V/De ∈ [−7.1, 38.6], [4.5, 5.4]는 [−599, 3908].

|---|---|---|---|
| 3 | 1/8 | [−721, 602] | [−0.904, −0.760] |
| 3 | 1/64 | [−82.6, 79.7] | [−0.904, −0.885] |
| 4 | 1/64 | [−0.885, 0.468] | [−0.200, −0.195] |

- R ≥ 7.5는 쓸 만하고, R ≈ 5는 1/64 셀이 필요하며, **R ≤ 4는 1/64 셀로도 부호조차 모른다.** 자연 구간 확장의 과대평가는 셀 폭에 1차로 비례하므로 R = 3에서 쓸 만한 폭은 대략 10⁻⁵ bohr 수준(추정)이다. 곧 bohr당 10⁵ 셀, **또 하나의 전수 분할**이다.
- 원인: 감쇠 인자 1 − e^{−x}Σ_{j≤n} x^j/j!(작은 x에서 1에 가까운 두 수의 차)와 큰 C_{2k}/R^{2k}(R = 3에서 최대 약 100 hartree)의 곱. **상쇄 없는 재정식화**(e^{−x}Σ_{j>n} x^j/j!와 나머지 상한), 또는 중심형/Taylor 모형 같은 2차 방법이 필요하다(새 수학·코드, 감사 대상). 에너지 장벽 셸 덕분에 D_valid에는 R ≳ 5.3만 필요할 수 있다는 점이 비용을 크게 줄인다.
- **적응형 부호 지도 측정:** [r_min, 20]을 V′ 부호가 인증될 때까지 이등분(최소 폭 2^−20)하자 **셀 예산 4,000개를 넘겨 끝나지 않았다**(1,690초). V″ 부호 지도는 시간 한도(3,000초)에 잘려 결과가 없다. 현재 구간 계산으로 R < 20 부호 지도를 만들면 전수 분할이 된다는 직접 증거다(`runs/c1b1_field_map_survey_20260930/radial_map.*`).

## 3. 여섯 질문에 대한 답

1. **필요한 문제를 해결하는가?** 부호 지도는 아니다(0/6). **V 범위 + 에너지는 해결한다**(6/6, 스크래치). 에너지 장벽은 inner의 도달 영역을 잘라내는 새 사실이다. 셋 다 데이터는 기존 셀에서 나온다.
2. **계산량이 주는가?** R ≥ 20: 셀 28개 10.7초로 이미 싸다. 새 지도는 줄이지 못한다. 에너지 기반 상한은 더 작은 cap으로 닫혀(0.1 De에서 ρ 1/16 → 1/1024) 셀 guard가 좁아진다. 실행 시간 절감은 측정하지 않았다(스크래치의 두 번째 변형은 같은 프로세스의 셀 캐시를 재사용해 시간 비교가 무효). inner: 상쇄를 고치지 않으면 R ≤ 4에서 셀 수가 폭발한다. 장벽 셸로 R ≳ 5.3만 다루면 폭 1/64급 셀 수백 개 규모로 추정한다(계산 안 함).
3. **정확도를 떨어뜨리는가?** 기존 `derivatives`만 쓰면 떨어뜨리지 않는다. 셀 속성은 구간 전체에서 증명된 것만이고 모르면 "?"다. 궤적으로 맞춘 곳은 없다(cap 사다리와 셀 분할 규칙은 실행 전에 고정).
4. **기존 구조와 중복인가?** 데이터 계층은 **완전 중복**(`derivatives` = 셀, `_covered_shell` = 분할 + 캐시)이다. 새로운 것은 부호·V 범위를 **쓰는 귀납**과 **에너지 장벽**이라는 새 명제다.
5. **inner 가치:** 크다. 단 선행 조건 두 가지: (i) 상쇄 없는 도함수 구간, (ii) inner 궤적의 에너지 예산. 그 위에서 "큰 셀로 되는 곳"(R ≥ 7.5, 인력 꼬리·우물 바닥 근처)과 "세밀한 곳"(반발 벽 5.3〜6, V′ = 0 근처 R_e ≈ 7.1)을 나눌 수 있다. R < 5.3은 장벽으로 제외 후보.
6. **궤적과의 관계:** 셀 속성은 동결 PES만의 함수다(위치 → 사실). 세계 상태를 읽거나 바꾸지 않고 궤적을 강제하지 않는다. 귀납이 "이 위치 구간에서 이미 증명된 사실"로 참조할 뿐이다.

## 4. 도입한다면 최소 데이터 구조(참고, 권고 아님)

```
RadialCell(a, b)                       # 정확 유리수 끝점, 불변
  V, V1, V2, V3 : Iv                   # derivatives(a, b) 그대로(outward, 160 bit)
  sign_V1, sign_V2 : '+' | '-' | '?'   # 구간이 0을 포함하면 '?'
  provenance : model fingerprint, BITS, method, source hash
RadialMap = 정렬된 셀 목록 + (a, b) 키 캐시     # 겹침 없음, 빈틈은 'unknown'
query(R 구간) → 덮는 셀들, 없으면 unknown
```

`Shell` + 부호 플래그 + 색인이다. 저장량은 셀당 유리수 10여 개(160 bit)라 수천 셀도 수 MB 이하다. 비용은 셀당 derivatives 한 번(0.3〜0.5초)이다.

## 5. R 분할과 규모

- R ≥ R_J: 셀 불필요(zero-impulse, 기존).
- 20 ≤ R < R_J: 기존 5/4 기하 분할(28셀). 부호가 필요하면 R > 49에서 세분(현재 불필요: 부호 정보의 효과가 측정상 없음).
- R < 20: **요구 속성 기반 적응 분할.** 속성(예: V′ 부호, V > E 장벽, M3 상한 ≤ 목표)이 인증될 때까지만 이등분하고, 최소 폭에 닿으면 unknown으로 둔다. 구조점(R_e: V′ = 0, V″ = 0, 장벽 R ≈ 5.5)에서는 셀이 깊어진다. 적응 분할의 셀 수는 변화가 큰 곳에만 몰리므로 전수보다 작다. **단 R ≤ 4에서는 상쇄 문제로 적응 분할이 사실상 전수가 된다.**
- 셀 수 N이면 계산은 N × 0.4초, 저장은 N × 수백 바이트. 귀납 쪽 비용은 셀 수에 선형이다.

## 6. 숨은 비용·위험, 더 싼 대안

**위험:** (i) Shell과 같은 수를 담는 두 번째 추상화(불일치 위험, 감사 대상 증가). (ii) 셀을 궤적에 맞추고 싶은 유혹(금지: 분할 규칙은 요구 속성만으로 정한다). (iii) 모델 fingerprint가 바뀌면 지도 전체가 무효(캐시 무효화 규칙 필요). (iv) 구간 과대평가 때문에 "인증된 부호"가 적은데도 지도가 있다는 사실만으로 과신할 위험. (v) 상쇄 문제를 모른 채 inner 지도를 만들면 셀이 폭발한다.

**더 싼 대안(권고):**
1. **새 계층 없이** 기존 셀의 `radial[0]`(V 범위)을 inbound·outgoing 귀납의 **에너지 기반 운동량 상한**에 쓴다. 저에너지 문제의 직접 해결 후보.
2. 부호가 필요해지면 `_CoveredShell`에 플래그 하나만 더한다.
3. inner 전에 `derivatives`의 **상쇄 없는 감쇠 재정식화**(독립 부품, 결함 주입·감사). 이것이 inner "지도"의 실제 선행 조건이다.
4. **에너지 장벽 셸 lemma**(얇은 셸 하나 + step 이동 상한). 셀 몇 개로 끝나고, IN-4의 "D_valid 전체" 질문과 inner 도달 영역에 직접 쓰인다.
