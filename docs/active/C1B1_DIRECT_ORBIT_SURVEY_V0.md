## 0. 판정: **HYBRID**

- **예측 정확도는 뛰어나다.** 연속 중심력 궤도를 (E, L)로 직접 계산하면 실행기의 R_min(≈10⁻⁵ bohr), 편향각, step 수(±1)를 21개 사례 모두에서 맞힌다. 궤도 경계 ρ = ±10⁻⁴에서도 맞는다.
- 그러나 HYBRID로 둔다. 이유는 둘이다.
  1. 궤도 경계는 쌍곡 안장이고 **한 바퀴당 편차 증폭 A ≈ 3.4·10⁵**이다. 관측 일치는 좋지만, 엄밀한 교량 정리의 오차는 경계 근처에서 이 배율로 커진다. 경계 근처는 별도 엄밀 처리나 step 실행이 필요하다.
  2. **계산 절감은 수 배〜수십 배에 그친다.** D_valid 통과가 10³〜3·10⁴ step뿐이고 실행기 step이 싸다(약 1 ms).
- "N바퀴 묶기"는 이득이 거의 없다. D_valid 산란은 1.65바퀴 이하이고, 경계 근처의 바퀴는 반복이 아니라 쌍곡 이탈이다.

## 1. 대표 입력 (21개, canonical R = 20 inbound, 평면)

| 부류 | 사례 |
|---|---|
| 낮은 E 일반 | 0.01 De(b = 0, 7, 14), 10⁻⁴ De(b = 7) |
| 중간 E | 0.5 De(b = 0, 6) |
| **궤도 경계 양쪽** | 0.5 De, b = b_orb(1 + ρ), b_orb = 11.719, ρ = ±0.1, ±0.01, **±0.005**, ±10⁻³, ±10⁻⁴ |
| 높은 E | 5 De(b = 0, 7, 13), 10 De(b = 0, 14) |

- **D_valid 경계에 가까운 허용 사례:** ρ = ±0.005(0.5 De F 부분 "validated" 영역, 기존 domain 시험의 사례).
- \|ρ\| ≤ 10⁻³은 D_valid의 inside_band/uncertain_edge 쪽이다. **민감성 조사용일 뿐 formal domain이 아니다.**

## 2. 직접 계산 방법

- 입력: 입구의 정확한 \|P\|, V(20)(동결 PES의 160-bit 구간 중점)로 **H(연속 에너지)**, 정확한 L = q × P.
- V_eff(R) = V(R) + L²/(2μR²).
- R_min: R 20 → 5.4를 0.01 간격으로 E − V_eff 부호를 훑은 뒤 이분법 90회.
- Δθ = 2∫_{R_min}^{20} L/(R²√(2μ(E − V_eff))) dR, T = 2∫ μ/√(2μ(E − V_eff)) dR. 치환 R = R_min + s²로 전환점 특이성을 없애고, E가 V_eff에 가장 가까워지는 점(장벽 꼭대기)을 분할점으로 둔다(mpmath tanh-sinh, 30자리).
- step 수 추정 = T/40. 출구 편향각(P 방향 변화) = sgn(L)(Δθ − π + 2α), sin α = \|L\|/(20·\|P_20\|).
- **실행기:** 같은 입력으로 R = 20 outbound(w > 0)까지 실행하며 위치각을 매 step 풀어서 누적, R_min, step 수, 편향각, 매 step의 L을 기록했다.

## 4. 궤도 경계 민감성과 "한 바퀴 반복" 구조

- 경계 = V_eff 장벽 꼭대기의 **불안정 원궤도**(E = 0.5 De: R_b = 9.733, 한 바퀴 T_rev = 4.56·10⁵ au ≈ 11,400 step). 반지름 불안정 계수 λ = √(−V_eff″/μ) = 2.79·10⁻⁵/au, **한 바퀴당 증폭 A = e^{λT_rev} ≈ 3.4·10⁵**.
- 예측: 장벽에서 튕기는 궤도(ρ > 0)는 ρ 한 자릿수당 ln10/lnA = **0.181바퀴**, 장벽을 두 번 넘는 궤도(ρ < 0: 들어갈 때·나올 때)는 **0.362바퀴**가 늘어난다.
- 직접 계산으로 관측: ρ > 0 → 0.177, 0.180. ρ < 0 → 0.371, 0.363. **이론과 일치한다.**
- 의미:
  - 경계 근처의 추가 체류는 "비슷한 바퀴의 반복"이 아니라 **쌍곡 안장 통과**다. 1-orbit return map × N 방식으로 묶을 반복이 없다.
  - 편차는 한 바퀴당 3.4·10⁵배 커진다. 편향각의 입력 민감도는 약 1/\|ρ\|(ρ = 10⁻⁴에서 약 10⁴배, 이전 조사와 일치).
  - return map이 의미 있는 곳은 속박 궤도(E < 0, D_valid 밖)의 준주기 운동이다.

## 5. E와 L의 실제 보존 (실행기)

- **L은 정확히 보존되지 않는다.** step당 \|ΔL\| ≤ 8.9·10⁻¹⁴(격자 drift δ×P와 충격량 반올림), 통과당 누적 \|ΔL\| ≤ 3.7·10⁻¹²(L ≈ 10¹ 규모에서 상대 약 10⁻¹³). 정면 사례(L = 0)는 정확히 0을 유지한다.
- **에너지:** 실행기가 보존에 가까이 유지하는 것은 수정 에너지 E~이고, 통과당 \|ΔE~\| ≤ 7.7·10⁻¹⁵ hartree(이전 조사). 직접 계산은 연속 H를 썼다. R = 20에서 H − E~ = h²F²/(8μ) ≈ 6·10⁻¹⁸ hartree로 무시할 수 있지만, 궤도 안에서 KDK의 그림자 해밀토니안은 H와 O(h²)만큼 다르다. 경계 근처 편향각 차이(10⁻⁴ rad)는 이 차이가 1/ρ로 증폭된 것으로 **추정한다**(분해 계산 안 함). **교량 정리는 만들지 않았다.**

- **측정된 절감:** 1〜15배(길수록 크다).
- **추정:** 격자 훑기를 괄호 탐색으로 바꾸면 V 평가 수백 회 → 긴 통과에서 수십 배. **수천 배는 아니다.** D_valid 통과 자체가 짧고 실행기 step이 싸기 때문이다.
- 설계자가 예로 든 "150,000 step 통과"는 이번 대표 사례에 없었다(최대 31,480, 10⁻⁴ De). 그 규모는 극저에너지의 바깥 비행이나 경계에 훨씬 가까운 입력에서 나올 것이다.

## 7. formal certification으로 가려면 새로 필요한 정리

1. **교량(shadowing) 정리:** 실행기(KDK + FX 반올림)의 궤적이 연속 궤도(또는 그림자 해밀토니안의 궤도)와 통과 전체에서 ε 이내임을 입력 box 전체에 대해 보인다. 경계 근처에서는 오차가 바퀴당 A ≈ 3.4·10⁵배 증폭되므로 따로 다뤄야 한다.
2. **보존량 교량:** 실행기 L과 E~의 통과 전체 변화 상한. per-step 상한(④-1 angular·energy)을 곱하는 방식은 너무 느슨하다(④ v0의 실패와 같은 구조).
3. **직접 적분의 엄밀화:** 전환점과 Δθ·T 적분을 구간 산술로 감싼다(특이점 치환, 장벽 근처 로그 특이성의 해석적 처리).
4. 위 셋이 있어도 출력은 "연속 궤도 ± ε"다. 실행기의 **비트 단위** 상태를 대신하지 못한다. 세계 상태는 계속 실행기가 만든다.

## 9. 다음 최소 작업 (제안)

- ④ 목표(R ≥ 5.35 유지)에 쓰려면 **R_min만** 필요하고, 관측상 R_min은 가장 둔감한 출력이다(10⁻⁵ bohr 일치, 경계에서도). 첫 후보: **유효 퍼텐셜 전환점 하한 정리.** E ≤ E_hi, \|L\|의 인증된 범위, V 구간 → R_min ≥ r*(E, L)를 구간 산술로 보이고, 실행기 E~·L 변화 상한과 결합한다. 편향각이나 출구 시각은 필요 없다.
- 이것은 직전 조사(ROUTE B)의 "우물/궤도 영역 체류 상한"과 같은 재료(V_eff, E, L)를 쓴다. 다만 목표가 **체류 시간이 아니라 최소 거리**라서 더 쉽고, 경계 근처의 쌍곡 증폭과 무관하다(R_min은 장벽 바깥 전환점이나 벽 전환점으로 둘 다 유계).
