## 7. 이번 세션에서 배운 원격 작업 함정

- `remote_exec` 응답이 시간 초과되어도 명령은 노트북에서 계속 돈다. 그동안 새 `remote_exec`는 "A command is already running"으로 막힌다. 긴 대기는 `remote_job_start`로 하거나 `sleep`을 120 s 이하로 둔다.
- cmd 줄 안에서 `\"`로 감싼 python 코드에 `|`가 있으면, cmd가 그것을 파이프로 해석해 명령이 깨진다(탐침 1차 실패). 코드는 파일로 보내 실행한다.
- base64 조각을 붙인 뒤에는 반드시 `base64 -d`로 풀고 SHA256을 대조한다. 한 번 풀지 않고 저장한 실수가 있었는데, 해시 불일치로 잡았다.
- 파일 전송(`remote_push`)은 업로드 키가 필요해서 쓸 수 없다. tar.gz → base64 → 7000자 조각 `echo >>` → 해시 대조 방식이 동작한다.
- WSL 배포판 이름 `Ubuntu`는 없다. `wsl -u root`(기본 배포판)를 쓴다.
- `pkill -f 패턴`은 패턴이 들어 있는 자기 bash도 죽인다.
- 원격 명령 안 `ps`·`pgrep -fc` 결과에는 자기 자신이 섞인다.
