## 0. 한눈에

1. **전제 정정(먼저 공개):** 코드상 D_valid는 "7개 에너지의 b 한 줄"이 아니다. **넓은 두 영역(저에너지·장벽 위, 모든 b, 임의 3D 배치) + 7개 에너지의 짧은 구간 14개**다. 이 잘못된 요약은 구현자가 계약 V1 2.2절에 쓴 것이고, 설계자의 L0 판정과 이번 지시가 그 요약 위에 서 있다(2절).
2. **기존 형식 증거는 D_valid를 거의 덮지 않는다.** 인증된 14 region은 전부 **+x축 위의 1차원 입력**이다. 7개 에너지 구간의 궤적(b≈10.4〜14.1 bohr, 평면 운동)과는 겹치지 않는다(2.2절).
3. **Liveness 문제는 세 부분으로 나뉜다:** 어떤 입력이 나오는가(도달), 평가기 구간이 얼마나 좁은가(오차), 정확한 값이 반올림 경계에서 얼마나 떨어져 있는가(간격). 오차는 쉽다. **간격이 전부다**(3절).
4. **정량 Liveness**(모든 판정이 16384 bit 안에서, 또는 정밀도 상한이 있는 증명으로 해결)의 **싼 경로는 찾지 못했다.** 모든 D_valid 궤적이 지나는 안쪽(R<20)은 exp 항이 지배해서 기존 유리식·합동류 방법이 원리적으로 성립하지 않는다. 경계 전수 방법은 평면/3D에서 폭발한다.
5. **새로 찾은 싼 전역 결과(구현자 유도, 인증 아님):** 포텐셜의 모든 계수가 유리수이고 exp 항 9개의 지수가 서로 다르므로, Lindemann–Weierstrass 정리로 **모든 격자 입력(q_k≠0)에서 정확한 충격량은 유리수가 아니다. 따라서 정확한 반올림 tie는 원리적으로 불가능하다.** 영역 크기·차원과 무관하다. 다만 "언젠가는 판정된다"(정성)만 주고 "16384 bit 안에서 판정된다"(정량)는 주지 않는다(6.1절).
6. 그래서 **D_valid 전체를 열거 없이 닫는 유일한 후보는 "전역 tie 배제 + 엄밀 유리수 구간 point prover"의 정성적 Liveness**다. 이 길이 열리는지는 설계자 판정 두 개에 달렸다(7절 Q2, Q3).

## 3. Liveness 문제를 세 부분으로

한 판정에서 정확한 값을 x(q), 가장 가까운 반올림 경계까지의 거리를 d(q), 정밀도 p에서 평가기 구간 폭을 w_p(q)라 하자.
d(q) > w_p(q)이면(여유 포함) p에서 RESOLVED다. 따라서

```
정량 Liveness:  도달 가능한 모든 q에서  d(q) > w_16384(q)          (또는 정밀도 상한이 있는 승인 certificate)
정성 Liveness:  도달 가능한 모든 q에서  d(q) > 0 (정확한 tie 없음)  + 필요한 만큼 정밀도를 올리는 승인 prover
```

| 부분 | 질문 | 현재 | 난이도 |
|---|---|---|---|
| **도달(R)** | 어떤 q가 실제로 나오는가 | 바깥은 ④-2 귀납(예시 상태만), 안쪽은 **형식 enclosure 없음** | 중간〜높음(inner/global shadowing 의무와 같은 일) |
| **오차(E)** | w_p(q)의 상한 | 축 위는 source-bound numeric error lemma가 있음. 3D는 √(q²) 오차 항 추가 필요 | **낮음** |
| **간격(G)** | d(q)의 하한 | 축 위 일부 shell만(rational spacing 19〜23, hard-case 16〜18, 경계 역상 24〜26) | **높음** — 지금까지의 1D 작업 전부가 이 부분 |

실행 조사의 관측(판정 약 2.3억 회, 전부 ≤256 bit, 가장 가까운 경계 거리 약 2^-27 ulp)은 d(q)가 보통 w_256보다 훨씬 크다는 뜻이다. **survey_only이며 증명이 아니다.**

반올림과 별도로, "D_valid의 모든 run이 r_min 침범·overflow·포획 없이 실제로 R_J에 도착한다"는 동역학 의무가 있다. 계약 V1의 Liveness 문구는 판정만 말하므로 이 의무를 포함하는지 판정이 필요하다(7절 Q4).

## 4. 후보 경로

각 항목: 증명 대상 / 계산량 / 확장 시 폭발 / 새 수학 / 기존 재사용 / 실패 지점 / 판정.

### R1. 기존 outgoing 축 인증 재사용·확장
- 대상: +x축 입력의 간격(G). shell 15 이하로 확장.
- 계산량: shell 14 조사 약 5시간·인증 약 17시간, shell 13은 약 27·88시간(shell 15 실측 기반 추정). shell 0〜4는 경계 수가 격자점보다 많아 원리적으로 불가.
- 폭발: 예. shell 하나 내려갈 때마다 약 5배.
- 새 수학: 없음(0〜4는 필요). 재사용: 높음.
- 실패 지점: **D_valid에서 축 입력을 쓰는 상태는 L·H의 정면충돌뿐**이다. F는 0. 안쪽은 대상이 아니다.
- 판정: **Liveness 경로 아님.** 방법은 이미 STOP.

### R2. 시간 역전으로 inbound를 outgoing에서 가져오기
- 사실(구현자 유도, 시험 안 함): KDK에서 충격량은 위치만의 함수이고 half-even 반올림은 대칭(round(−x) = −round(x))이다. 그래서 (q₁, −p₁)에서 한 step 가면 정확히 (q₀, −p₀)가 된다. **격자 동역학이 정확히 시간 가역이다.**
- 대상: inbound 입력 = 반전 상태의 outgoing 입력.
- 계산량 0(lemma 하나). 폭발 없음. 새 수학 없음. 재사용: ④-2 귀납 구조를 inbound에도 공유.
- 실패 지점: 판정 입력은 **위치**이고, 시간 역전은 위치 집합을 줄이지 않는다. 간격 문제가 그대로 남는다.
- 판정: **보조 lemma.** 기록·시험할 가치는 있지만 Liveness를 닫지 않는다.

### R3. 안쪽 R<20의 w256 해석적 상한 (오차 부품)
- 대상: R 5〜20(3D)에서 w_p(q) 상한. 바깥 조사의 "256-bit 폭 ≤ 2^-126 ulp"도 같은 방식으로 수식화할 수 있다.
- 계산량: 작음. shell/cell 수십 개, 기존 axis error lemma에 √ 단계 추가.
- 폭발: 없음(격자점을 세지 않는 균일 상한). 새 수학: 낮음. 재사용: `axis_impulse_error`, source-bound lemma.
- 실패 지점: **이것만으로는 아무 판정도 보장하지 않는다.** "d(q) > 2^-(p−c)이면 p에서 해결"로 바꿔 줄 뿐이고, d(q) 하한(간격)이 따로 필요하다.
- 판정: **정량 경로라면 필수 부품이지만 단독으로는 불가.**

### R4. 구간 전체 exact rational / modular-distance (간격 부품)
- 대상: 충격량 = 유리식 P/Q + exp 잔여항에서, 잔여항 guard가 1/(2Q)보다 작으면 d(q) ≥ 1/(2Q) − guard를 구간 전체에 준다.
- 계산량: 성립하는 곳에서는 작다(shell 19〜23을 이 방법으로 닫음). 폭발: 없음.
- 새 수학: 평면 입력은 R = √s(s는 유리수)라 2차 대수수가 되어 norm 하한이 필요하고, 분모가 대략 제곱으로 커진다. 그러면 guard 조건이 축보다 나빠진다(추정, 미계산).
- 재사용: fractional phase·family checker·modular-distance 조사.
- 실패 지점: **축 위에서도 shell 0〜3(R 20〜39)은 이미 guard ≥ ½ ULP**다(④-4c-1). 안쪽 R<20은 exp 항이 주항이라 "유리식 + 작은 잔여"라는 틀 자체가 성립하지 않는다(구현자 판단). **모든 D_valid 궤적이 안쪽을 지나간다.**
- 판정: **먼 바깥 전용 보조.** Liveness를 닫지 못한다.

### R5. hard-case 경계 탐색의 평면/3D 확장
- 대상: 격자 줄마다 1D 탐색. 1D shell 15에서 이미 교차 약 2.5억 개였다.
- 폭발: shell당 격자 줄이 10^16〜10^17개 규모(추정)라 1D 비용에 그만큼 곱해진다.
- 판정: **불가.**

### R6. 전역 exact tie 배제 (Lindemann–Weierstrass) — 새 후보
- 대상: 모든 격자 입력(q_k ≠ 0, R > 0)에서 정확한 충격량 성분이 반올림 경계(반정수 × 2^-80)와 같지 않다는 것. 실제로는 더 강하게 **유리수가 아님**을 준다. 6.1절 참조.
- 계산량: 정확 다항식 검사 한 번. 이번 스크래치 확인에서 9개 exp 계수함수 중 5개는 양의 근이 없고, 9개의 공약수는 1이다.
- 폭발: **없음.** 영역 크기·차원·에너지 범위와 무관하다. 3D, L·H·F 전체, 입장 영역 전체에 한 번에 적용된다. **도달 집합을 몰라도 된다.**
- 새 수학: 낮음. 고전 정리(1882〜1885)를 적용하는 논문식 증명이고 새 연구는 아니다.
- 재사용: `c1b1_axis_decision_bounds._representation`의 정확 항등식(실행기 평가 대조 시험 있음).
- 실패 지점: (a) **정성뿐**이다. tie가 없다는 것이지 경계에서 2^-16000보다 멀다는 것이 아니다. (b) "실행기의 정확 모델 = 이 식"이라는 연결에 의존한다(A-EV와 같은 층). (c) 증명 보조기 검증이 아니다.
- 판정: **이번 조사에서 가장 싼 전역 결과.** 단독으로는 정성적 Liveness의 절반이다.

### R7. point prover completeness (정성) — R6과 결합
- 대상: "D_valid의 모든 입력에서 prover가 반드시 결론을 낸다." prover는 실행기와 다른 독립 코드로 **엄밀한 유리수 구간**(예: e^{-x}를 명시적 Taylor 나머지로 감싼 유리수 상·하한, √s의 유리수 상·하한)을 필요한 정밀도까지 계산한다. 작은 verifier가 모든 부등식을 정확 산술로 다시 확인한다.
- R6 때문에 모든 입력에서 d(q) > 0이다. 구간 폭은 정밀도와 함께 0으로 가므로 **prover는 반드시 끝난다.**
- 계산량: 실제 STOP이 났을 때만 돈다(관측상 0회). 폭발: 없음.
- 새 수학: 낮음. 필요한 것은 작은 정확 유리수 검사기와 Taylor 나머지 lemma다.
- 재사용: 이 독립 구간 힘 평가기는 계약 V1이 별도 과제로 남긴 **A-EV 강화에 필요한 부품과 같다.**
- 실패 지점: (a) **이런 certificate가 P1a의 B 범주인지 설계자 판정이 필요하다**(7절 Q3). (b) 필요한 정밀도의 사전 상한이 없다. (c) prover·wrapper 구현이 필요하다.
- 판정: **D_valid 전체를 열거 없이 닫는 유일한 후보.** 단, 정성적이다.

### R8. transcendence measure로 정량 간격 (effective Lindemann–Weierstrass / Baker 계열)
- 대상: 모든 입력에 대한 d(q)의 균일 하한 → 정밀도 상한.
- 계산량: 문헌 조사와 상수 계산. 폭발: 없음. 새 수학: 높음.
- 예상(구현자 추정, 문헌 미확인): 알려진 유효 하한은 계수 높이·항 수에 대해 매우 약해서, 2^-16384보다 훨씬 작은 하한만 나올 가능성이 높다. 그러면 cap 16384 안의 정량 Liveness에는 쓸 수 없다.
- 판정: **문헌 확인만 할 가치가 있다.** 구현 대상이 아니다.

### R9. b 구간 Proof Box / 궤적 다발
- 새로 확인한 정확한 구조(구현자 유도): 운동량이 u_p의 배수만큼 다른 두 상태라도 위치 반올림 결과가 같으면 **위치열이 완전히 같다.** 충격량이 위치만의 함수라서 운동량 차이가 정확히 보존되기 때문이다. 1 raw 운동량 차이가 한 step 위치에 주는 영향은 2^-42.8 격자다. 그래서 실행 한 번이 매우 많은 초기 상태를 정확히 대표한다.
- 그러나 F 구간 하나(2^72〜2^75 상태)의 서로 다른 격자 궤적 수는 대략 **2^45〜2^52**로 추정된다(step마다 분할점 약 2^32개 × step 수, 바깥 비행 약 10^6 step 포함). 열거할 수 없다.
- 구간 전체를 한 상자로 묶으면, 궤도 포획 경계 옆이라 산란각이 크게 달라져 상자가 거시적으로 벌어진다. 공통 출력은 불가능하고 결국 점별 간격 문제로 돌아간다.
- 판정: **불가.** 다발 사실은 point prover·Proof Cache 설계에 쓸 수 있으므로 기록한다.

### R10. 7개 고정 에너지로 차원 축소
- 전제가 성립하지 않는다(2.1절). F에 한정해도 판정 입력은 **위치(평면 2D)**이고, b 구간이 평면의 한 영역을 쓸고 지나가므로 입력 차원은 줄지 않는다. 에너지 고정은 도달 enclosure를 조금 얇게 할 뿐이다.
- 판정: **효과 없음.**

## 6. 새로 확인한 구조 사실

### 6.1 전역 exact tie 배제 (구현자 유도 — 인증 아님, 외부 수학 검토 필요)

1. 정확 모델(`_representation`, 실행기 대조 시험 있음): V(R) = 유리함수(retardation −c·N(R)/(R⁶·D(R)), D의 계수 전부 양수) + 짝수 역거듭제곱(R^-6〜R^-16) + Σ_{i=1..9} e^{−λ_i R}·L_i(R).
   λ_i는 **서로 다른 양의 유리수 9개**(1.0525〜6.9264)이고, L_i는 유리수 계수 Laurent 다항식이다. 다른 초월함수는 없다.
2. 충격량 성분은 J_k = −(h/2)·V′(R)·q_k/R, h/2 = 20이다. V′(R) = A(R) + Σ e^{−λ_i R}·B_i(R)이며 A는 유리함수, B_i = L_i′ − λ_i L_i는 유리수 계수 Laurent 다항식이다.
3. 입력 q는 dyadic 유리수 좌표이므로 R = √s(s는 양의 유리수)는 대수적 수다. J_k가 유리수 c라면(q_k ≠ 0)
   `[A(R) − c·R/(20·q_k)]·e⁰ + Σ B_i(R)·e^{−λ_i R} = 0`이다(부호는 c에 흡수).
   지수 0, −λ_1R, …, −λ_9R은 서로 다른 대수적 수이고 계수들도 대수적이다. **Lindemann–Weierstrass 정리(Baker 형태)**에 따르면 이것이 성립하려면 **모든 계수가 0**이어야 한다. 특히 B_1(R) = … = B_9(R) = 0이 필요하다.
4. 스크래치 정확 계산(sympy, 저장소 코드 아님): λ = 6.926, 3.659, 1.668, 1.052, 3.916에 해당하는 B_i의 분자 다항식은 **양의 실근이 없다.** 9개의 gcd는 1이다. 따라서 모든 R > 0에서 적어도 한 계수가 0이 아니고, **J_k는 유리수가 될 수 없다.** q_k = 0이면 실행기가 정확히 0을 낸다(tie 아님).
5. 같은 논리로 입장 검사(E ≤ 10 De) 비교의 정확한 동점도 배제될 가능성이 높다. V 자체의 exp 계수함수 검사가 필요하며 이번에는 하지 않았다.

한계: 정리 적용과 계수함수 검사는 구현자가 한 것이고 Lean/Coq 검증이 아니다. **정성적 결론뿐이다.** 기존 rational tie 배제(24/24 domain)는 유리식 근사의 간격 증명에 필요했던 것이므로 이 결과가 그 작업을 무효로 만들지 않는다.

### 6.2 격자 동역학의 정확한 시간 가역성 (유도, 시험 안 함)

p_h = p₀ + J(q₀), q₁ = q₀ + round(h·p_h/m), p₁ = p_h + J(q₁)에서 (q₁, −p₁)로 한 step 가면 −p_h, q₀, −p₀ 순서로 정확히 돌아온다. round(−x) = −round(x)(half-even)와 위치만의 함수 J가 조건이다. drift 선분 domain 검사도 선분 대칭이다.

### 6.3 운동량 offset 다발 (유도)

위치열이 같으면 충격량이 같고, 그러면 운동량 차이는 정확히 상수다. 다발 내부의 모든 초기 상태는 **판정 입력을 완전히 공유한다.** Proof Cache의 한 witness가 다발 전체에 유효하다는 뜻이다.

## 8. 판정에 따른 다음 작업 (제안)

- **Q2 = 정성, Q3 = 허용:** ① "전역 exact tie 배제 lemma v0": 문서 증명 + 정확 검사(survey 코드) + 결함 주입(계수함수를 조작하면 검사가 잡는지). ② point prover 설계: 엄밀 유리수 검증기, certificate 형식, binding. A-EV 강화 부품과 겸용. ③ 그 뒤 runtime wrapper. R2 시간 가역성은 ①과 함께 시험으로 고정할 수 있다.
- **Q2 = 정량:** 정직한 평가로, 알려진 방법으로는 cap 16384 안의 D_valid 전체 정량 Liveness가 닫힐 전망이 낮다. 가능한 다음은 R8 문헌 확인(구현 없음) 정도이며, 계약 수준의 선택은 설계자에게 넘긴다.
- **어느 경우든:** R3(오차 상한)은 정량 경로에서만 필요하다. R1·R5·R9 방향으로는 더 투자하지 않기를 권한다.
