# 10. EN은 특히 감사할 것

공식 input comment는:

```text
approximate energy EN
below a true energy
```

라고 되어 있습니다.

이 값이 inverse iteration/root selection에 사용될 가능성이 있으므로:

```text
Pachucki reference energy를 EN으로 넣기
```

를 자동으로 하지 마십시오.

그러면 reference leakage가 됩니다.

먼저 source에서 EN의 정확한 역할을 추적하십시오.

그리고 Pilot용 EN 생성 규칙을 **reference를 보지 않고** 사전에 정의하십시오.

예:

```text
낮은 Ω의 자체 계산
또는
넓게 떨어진 generic safe hint
```

등을 후보로 검토하되, 정확한 방법은 source 의미를 확인한 뒤 봉인하십시오.

archive hash mismatch
