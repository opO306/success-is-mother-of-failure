# A의 법칙은 현실 물리에 근거한다 — B는 현실을 모른다 (설계 원칙 v1)

**문서 분류: 공통 참조 원칙·검증 기준.** 승인·초안·구현·보류의 범위는 본문 판정을 그대로 따른다. 이 폴더 배치는 새 승인이나 동결이 아니다.
현재 상태는 [CURRENT_STATE.md](../../CURRENT_STATE.md)를 본다.


**상태:** 설계자 승인 (2026-09-24). RULES 2절 반영. **검토 보강 (같은 날):** 정규 A / 시험 세계 구분(1.1), 근거 등급 수정(5절),
현실 이전 관문(3.1), 현실-A 비교는 세계 밖 사람의 일(3.2).
**출발점:** sol의 제안(LAMMPS·ReaDDy·ReaxFF·patchy particle 비교, "A = 현실 지구의 근사")을 설계자가 **절반만** 채택.

## 1. 설계자 결정 — 한 문단

> A(세계)의 **물리 법칙**은 현실 지구의 실제 물리를 기준으로 한다. 문명·지능·생명 같은 **결과**를 기준으로 하는 것이
> 아니다(헌법 제1조 그대로). B(연구자)는 **현실이 어떤지 모른다** — 현실과 비교하는 연구를 하지도 않고 할 수도 없다.
> B는 오직 A를 통해 실험하고 배운다. B는 동결된 신체·감각·도구·자원(헌법 제26조)과 A의 물리적 제약 안에서
> 실험 대상을 자유롭게 선택한다. A의 법칙이 현실에 근거하므로, **B가 A에서 찾은
> 결과는 현실에서도 도움이 될 가능성이 있다.** 그것이 이 구조의 가치다.

### 1.1 이 원칙이 적용되는 세계 — 정규 A와 시험 세계

| | 정규 A (canonical) | 시험 세계 (non-canonical) |
|---|---|---|
| 무엇 | 현실을 근사하려는 실제 연구 세계 | B·실행기·감사기를 검증하려는 세계 (합성 세계 S01~S03, 홀드아웃, 벤치마크, 탐침 시험 세계 등) |
| 현실 근거 | **의무** | 현실에 없는 법칙 **허용** |
| 표시 | — | 반드시 `NON_CANONICAL_TEST_WORLD`로 표시 |
| 현실 이전 | 논할 수 있는 **유일한** 계열 | 여기서 나온 발견은 현실 이전 후보로 **취급 금지** |

이 구분이 없으면 B를 시험하려고 만든 가짜 세계들이 이 원칙의 위반자가 된다. 시험 세계는 원래 현실과 다르게 만드는 것이
목적인 경우가 많다(B가 모르는 법칙을 찾아내는지 보려고). 지금 있는 세계들의 분류: 합성 세계·벤치마크·v5 측정 세계·
탐침 시험 세계는 시험 세계다. 정규 A는 아직 없다 — v5와 환경 세계가 그 후보의 바닥이다.

## 2. 채택한 것과 거부한 것

| sol의 제안 | 결정 |
|---|---|
| A의 법칙을 임의로 지어내지 않고 현실 물리(근본 / 유효 / 실험 / 근사)에 근거시킨다, 출처를 남긴다 | **채택** |
| A 내부의 법칙은 A 안에서 절대적, B의 이해는 언제나 잠정적 (A는 닫혀 있고 B는 열려 있다) | **채택** (기존 블라인드 구조와 같다) |
| B가 현실 관측 데이터와 A를 비교해 "현실-A 불일치"를 연구한다 | **거부** — B는 현실을 모른다 |
| B가 현실 데이터·현실 이론을 참조한다 | **거부** |
| B가 A 수정을 제안한다 | 기존대로 금지 (헌법 제25조: A를 직접 바꾸지 않는다) |

## 3. 세 층 — 누가 무엇을 아나

```
현실 지구 ──(설계자가 물리를 가져옴, 출처 기록)──> A의 법칙
                                                    │
                                                    │  B는 A만 본다. 현실은 모른다.
                                                    ▼
                                             B의 발견 (A 안에서 재현 가능)
                                                    │
                  (세계 밖에서, 사람이) ─────────────┘
                  "이것이 현실에서도 쓸모 있나?" 를 판단·시험
```

- **현실 → A:** 설계자가 한다. 법칙마다 출처와 근사 수준을 남긴다.
- **A → B:** 헌법 제25·26조 그대로. B는 A의 법칙도, 현실도 모른 채 관측·실험한다.
- **B → 현실:** B가 하지 않는다. B의 발견을 현실에 가져가 볼지는 세계 밖의 사람이 판단한다.
  B가 이 일을 알면 안 된다 — 알면 B의 탐색이 "현실에 쓸모 있을 것" 쪽으로 기울고, 그것은 B에게 목표를 주는 것이다
  (외부 평가에 맞춰 탐색이 휘는 것 — Goodhart).

### 3.1 현실 이전 관문 (세계 밖, B에게 보이지 않음)

현실 근거는 **필요조건이지 충분조건이 아니다.** 법칙이 전부 진짜여도 온도·압력·농도·재료 값이 엉뚱하면 발견은 현실로 옮겨지지
않는다. 이전 가능성은 최소한 법칙의 현실 근거 × 적용 범위 일치 × 재료 값의 현실성 × 빠진 상호작용의 크기 × 근사에 대한
결과의 강건성에 달렸다. 그래서 B의 발견을 현실 가설로 올리기 전에 사람이 다음을 거친다:

1. 발견에 관여한 법칙들의 출처(근거 등급) 확인
2. 발견이 일어난 조건이 각 법칙의 적용 범위 안인지 확인
3. 추상(근거 없는) 값이 결과를 지배하는지 확인 — 지배하면 이전 불가
4. 근사를 조금 바꿔도 현상이 유지되는지 확인
5. 더 현실적인 A 버전에서도 재현되는지 확인
6. 통과한 것만 현실 실험 후보로 승격

정규 A에서 나온 발견만 이 관문에 들어갈 수 있다(1.1).

### 3.2 현실-A 비교는 세계 밖 사람의 일이다

"비교 금지"는 **B에게만** 적용된다. A를 현실에 가깝게 만들려면 설계자와 외부 감사자는 현실 측정값과 A의 결과를 **반드시**
비교해야 한다. 다만 그 비교 결과, 현실 데이터, A를 수정한 이유는 **B에게 보이는 정보(`research_store.b_visible`)에 들어가지
않는다.** 예전의 "B가 현실-A 불일치를 연구한다"는 폐기됐지만, 프로젝트의 현실 검증 능력은 사라지지 않는다 — 그 역할이
B에서 세계 밖의 사람·감사기로 옮겨갔을 뿐이다.

## 4. 법칙의 출처 표기

A에 법칙(또는 재료 값)을 넣을 때 설계 문서에 다음을 적는다.

| 항목 | 뜻 |
|---|---|
| 근거 등급 | **근본**(확립된 기본 물리, 예: 운동량 보존) / **유효**(특정 규모에서 검증된 법칙) / **실험**(측정값으로 보정된 관계) / **근사**(계산 못 하는 미세 현상의 효과 모델) |
| 출처 | 이론·논문·측정값 |
| 적용 범위 | 길이·시간·에너지·온도 규모 |
| 알려진 한계 | 이 근사가 틀리는 조건 |

**금지:** 현실에 근거가 없는 법칙을 "현상이 나오게 하려고" 넣는 것. 원하는 현상(분열 등)이 나오지 않으면 그 현상을 만드는
규칙을 추가하는 것이 아니라, 현실 물리 중 무엇이 빠졌는지를 찾는다. (RULES "법칙은 최소 근본 수준으로"와 같은 방향.)

**현실에서도 아직 모르는 부분:** 지어내지 않는다. 필요 없으면 넣지 않고, 필요하면 "미해결 영역"으로 명시한다.

## 5. 지금 A의 위치 — 정직하게

| | 근거 등급 | 비고 |
|---|---|---|
| v5 운동량 보존 | **근본** | 보존 원리 |
| v5 운동 에너지 `½mv²` | **유효** | 저속·비상대론 영역의 고전역학 식 |
| v5 등속 직선 운동(외력 없음) | **유효** | 외력이 없는 고전역학 영역. 힘·퍼텐셜은 아직 없음 |
| v5 결합 시 상대 운동 에너지 `½μ|Δv|²`를 내부 에너지로 | **근사(모델)** | 에너지 보존을 지키는 완전 비탄성 결합 모델. 실제 화학 결합 법칙 그 자체가 아님(결합 에너지·장벽·방출 없음) |
| v5 정사각형 몸, 면 = 결합 자리 | **근사, 근거 약함** | 정확 계산을 위한 선택(K3). 현실 원자·분자의 모양이 아님 — 설계자가 v5 한정으로만 승인 |
| v5 결합 규칙(재료 종류·면 쌍·문턱) | **근거 없음(추상)** | 실제 원소·결합 에너지가 아님 |
| 환경 세계 열·물·용질 이동 | 유효(확산 형태) | 계수는 추상값 |

**따라서 지금 A에서 B가 찾는 결과가 현실에 도움이 될 가능성은 아직 낮다.** 현실 근거는 현실 이전의 필요조건이고, 그 위에
적용 범위·재료 값·빠진 상호작용·근사 강건성이 더해져야 한다(3.1 관문). 게다가 지금 있는 세계는 모두 시험 세계다(1.1).
이 원칙은 앞으로 A에 법칙을 더할 때의 기준이고, 이미 만든 추상 부분을 당장 갈아엎자는 뜻이 아니다.

## 6. sol의 기술 제안은 어디로 가나

입자 표현 통일, patch(위치·방향·결합 수를 가진 물리적 결합 부위), 충돌 그래프 동시 처리, 이웃 목록(계산 색인), 에너지 기반
결합·절단 — 이것들은 **현실 근거를 높이는 방향**이라 이 원칙과 맞는다. v5가 이미 일부(구조 = 결합 그래프, 충돌 그래프 동시 병합)를
갖고 있다. 나머지는 GEO v1B 뒤 A의 다음 설계(GEO v2 이후)에서 이 문서의 출처 표기와 함께 다룬다.
