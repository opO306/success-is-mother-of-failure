# 후기 B 연구 자산 — 보존

**상태: DEFERRED TO LATE STAGE, NOT CANCELLED.** B는 취소·폐기하지 않았다.
A의 물리 기반이 우선이고, L은 그 기반이 충분해진 뒤 A 안에서 자연 발생·진화하는 계통으로 진행한다. A·L 기반의 작은 세계가 돌아가는 후기 단계에서 B를 본격적으로 만든다.
기존 B-classic 구현·문서·시험은 비교군/연구 자산으로 보존한다. 사람이 적은 연구 절차를 학습형 신경망이나 자율 과학 발견 전체로 과장하지 않는다.
