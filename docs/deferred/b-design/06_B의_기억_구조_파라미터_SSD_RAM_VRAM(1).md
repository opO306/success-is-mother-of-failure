# 06. B의 기억 구조: 파라미터·SSD·RAM·VRAM

**문서 분류: 후기 B 연구 자산 / 보존.** B는 취소·폐기하지 않았으며, A·L 기반의 작은 세계가 돌아가는 후기 단계에서 본격 개발한다. 기존 설계·구현·시험은 비교군/연구 자산으로 보존한다.
현재 상태는 [CURRENT_STATE.md](../../../CURRENT_STATE.md)를 본다.


*지식을 모두 모델 파라미터에 압축하지 않고, 경험과 연구 역사를 외부 기억으로 보존한다*

| **\[핵심\]** B는 “어떻게 생각할지”는 모델이 배우고, “무엇을 실제로 경험했는지”는 외부 연구 기억에 정확한 계보와 조건을 붙여 저장하는 구조가 적합하다는 방향으로 정리됐다. |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

# 1. 각 저장층의 역할

| **층**           | **비유**            | **저장할 것**                                            |
|------------------|---------------------|----------------------------------------------------------|
| Model Parameters | 몸에 밴 능력        | 언어 이해, 일반 추론, WSL 문법 사용법, 실험 설계 습관    |
| SSD/HDD          | 장기 연구 기록      | 논문, 전체 실험, 실패, anomaly, 가설 계보, 원본 조건     |
| RAM              | 현재 작업대         | 활성 가설, 관련 반례, 경계 사례, 현재 세션의 요약·인덱스 |
| VRAM             | GPU의 초고속 작업대 | 지금 계산할 batch, 텐서, 병렬 세계 상태                  |
| CPU/GPU          | 계산 장치           | 깊은 분석과 넓은 병렬 탐색 실행                          |

# 2. RAM은 연산 공간이 아니라 Working Set

RAM은 “남는 계산 공간”이라기보다 지금 생각하는 데 필요한 자료를 가까이 올려두는 작업대다. 계산 자체는 CPU/GPU가 하고, RAM은 이미 계산된 결과와 현재 필요한 상태를 캐싱하여 재계산을 줄인다.

```text
SSD: 100,000,000개 전체 실험 기록

↓ 필요한 것만

RAM: 현재 가설과 관련된 20,000개 결과 + 경계/이상치

↓ 현재 batch

VRAM: 다음 50,000개 조건

↓

GPU 실행

↓

RAM에서 비교/요약

↓

중요 결과 SSD 영구 저장
```

# 3. 계산된 것을 “고정”하되 절대 진실로 얼리지 않는다

이미 조사한 영역을 다시 매번 계산할 필요는 없다. 다만 새로운 변수가 추가되면 예전 결과의 적용 범위가 바뀔 수 있으므로, “정답”이 아니라 조건부 결과로 저장한다.

```text
H12 result

valid_under:

no catalyst

pressure 1~5

temperature 20~60


새 catalyst X 발견

→ H12 삭제/확정 아님

→ catalyst=X 영역은 아직 미검증으로 표시
```

# 4. 논문도 파라미터에 진실로 박지 않는다

논문은 최대한 많이 연구 기억에 넣을 수 있지만, 출판됐다는 이유만으로 진실로 학습시키지는 않는다. 주장·조건·증거·한계·후속 재현 여부를 구조화하여 저장한다.

| **저장 필드 예시** | **내용**                              |
|--------------------|---------------------------------------|
| claim              | 논문이 실제로 주장한 관계             |
| conditions         | 온도·압력·재료·대상 집단 등 적용 조건 |
| evidence           | 실험·관측·시뮬레이션 근거             |
| limitations        | 논문 스스로 밝힌 한계                 |
| replication_status | 독립 재현, 부분 재현, 미재현, 철회 등 |
| contradictions     | 충돌하는 후속 연구                    |
| open_questions     | 설명되지 않은 결과나 누락 변수 후보   |

실패했거나 나중에 틀린 것으로 보이는 논문도 가치가 있다. “왜 당시 가능하다고 생각했는지”, 어떤 조건에서 실패했는지, 후속 연구가 무엇을 바꿨는지를 보존하면 나중에 다른 변수와 재조합할 수 있다.

# 5. 연구 기억의 핵심은 계보

```text
H-0041: A + B → C

status: contradicted_in_domain

failure_conditions: low temperature, no catalyst

possible_missing_variables: catalyst, surface


후일 H-238 발견:

"X가 활성 장벽을 낮춘다"


Memory retrieval:

H-0041 + H-238

→ A + B + X → C ? 재검사
```

| **\[정리\]** 파라미터는 연구 능력, 외부 기억은 연구 역사다. B가 강해질수록 모든 지식을 파라미터에 넣기보다 정확한 경험·조건·실패를 외부에 남기고 필요할 때 불러오는 구조가 중요해진다. |
