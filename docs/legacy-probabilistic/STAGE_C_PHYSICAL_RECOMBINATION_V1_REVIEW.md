# 단계 C 물리적 절단·혼합 계통 결합 v1 구상 일치성 검증

**대상:** `connected_materials`, 절단 후 교차 출처 결합 재현 실험  
**판정:** 유전자 블록 없는 물리 조각과 혼합 계통 형성 통과, 생식·복제·자손 발생은 미구현

## 1. 무엇을 만들었는가

현재 물질 결합망을 읽어 실제 연결된 덩어리를 찾는 관찰기를 만들었다. 부모가 같다는 이유로 한 덩어리로 묶지
않고, 부모가 다르다는 이유로 분리하지도 않는다. 경계는 오직 현재 결합 경로가 결정한다.

## 2. 세계 안에서 실제로 무슨 일이 일어나는가

한 출처의 `0-3-0` 사슬과 다른 출처의 `3` 단위를 같은 세계에 놓았다. 사슬의 마지막 결합이 기존 공통 법칙으로
끊어진 뒤, 떨어진 `0` 조각이 다른 출처의 `3`과 결합했다.

- 첫 사건: `bond_broken`
- 둘째 사건: `bond_formed`
- 마지막 연결 성분: 원래 사슬에 남은 단일 출처 성분 하나, 두 출처가 섞인 성분 하나

## 3. 설계 의도와 일치하는 부분

- 유전자 위치, 코돈, 형질 블록과 교차 지점을 미리 정하지 않았다.
- 절단과 결합에 새로운 유전 전용 법칙을 추가하지 않았다.
- 한 부모의 물질도 실제 결합이 끊어지면 서로 다른 조각이 된다.
- 다른 부모의 물질도 실제 결합하면 하나의 물리 성분이 된다.
- 혼합 여부는 외부 관찰 결과이며 물리 계산의 조건이 아니다.
- 불리하거나 기능 없는 혼합도 오류로 제거하지 않는다.

## 4. 근사했거나 강제한 부분

- 충돌 두 번의 순서를 실험자가 지정했으므로 자연적인 교배 확률을 보여 주지 않는다.
- 물질은 새 자손으로 이동하거나 복제되지 않았고 같은 완전 혼합 세계 안에 있다.
- 연결 성분은 구조 경계일 뿐 유전적 기능 단위라는 뜻이 아니다.
- 공간과 막이 없어 어떤 조각이 생식세포에 들어가는지는 구현할 수 없다.
- 기호·포트·친화도는 공통 국소 동역학 v1의 사람이 정한 최소 물성이다.

## 5. 검증 증거와 다음 결정 사항

- 유전·국소 동역학 집중 테스트 `24`개 통과
- 전체 프로젝트 회귀 테스트 `575`개 통과
- 재현 기록: `runs/physical_recombination_v1_probe.json`
- 실행 조건과 코드·기록 해시: `runs/physical_recombination_v1_probe_manifest.json`
- 부모 이름과 물리 성분을 분리하는 테스트 통과
- 절단 뒤 연결 성분 분리 및 교차 출처 결합 뒤 혼합 성분 형성 테스트 통과
- 실제로 연결되지 않은 단위를 하나의 성분이라고 거짓 표시하는 시도 거부 테스트 통과

다음에는 위치와 경계막을 먼저 넣어야 한다. 그래야 사람이 조각을 골라 자손에게 전달하지 않고, 실제로 막의
안팎을 이동한 물질만 자손 형성 공간에 들어가게 만들 수 있다.
