# 단계 C 능력 탐색기 구상 일치성 검증

**대상:** `engine/sequence/probe.py`, `run_sequence_probe.py`, 최초 전수 소형 탐색 결과  
**판정:** 편향 없는 소형 탐색·원본 보존 통과, 구조 기능·신호·되먹임 출현 증거 없음

## 1. 무엇을 만들었는가

길이 1~2의 모든 내부 서열로 단일 세계와 두 서열 세계를 만들고, 각 세계를 두 seed로 실행하는 탐색기를
만들었다. 각 실행의 모든 상태와 사건을 보존하면서 관측값을 서로 분리해 계산한다.

## 2. 실제로 관측된 것

- 초기 조건 230개, 총 실행 460회
- 자연 정지 `176`회, 외부 사건 제한 도달 `284`회
- 동일 구성 재등장 `284`회
- 동일 접촉이 최소 두 상태 동안 유지된 실행 `38`회, 최장 `5`개 상태
- 참여 관계에 새 식별자가 들어온 사건이 있는 실행 `170`회
- 구조 문맥 배율 사건 `0`회
- 전체 사건: 결합 `2184`, 분리 `2026`, 골격 절단 `558`
- 접힘·풀림·골격 성장 사건 `0`회
- 같은 초기 조건에서 두 seed의 최종 상태가 달랐던 경우 `126/230`

단일 서열 실행 40회 중 32회가 자연 정지했고 8회가 사건 제한에 도달했다. 두 서열 실행 420회 중 144회가
자연 정지했고 276회가 사건 제한에 도달했다.

## 3. 설계 의도와 일치하는 부분

- 정해진 작은 범위 안에서는 모든 서열과 모든 비순서 쌍을 빠짐없이 사용했다.
- 결과가 좋아 보이는 초기 조건을 사후 선택하지 않았다.
- seed별 실행을 합치거나 평균 개체로 바꾸지 않았다.
- 성공 점수, 순위와 번식 선택을 만들지 않았다.
- 자연 정지 176회를 구조하거나 결과에서 제외하지 않았다.
- 460회의 초기 상태, 난수, 사건과 전체 후속 상태를 모두 보존했다.
- 관측과 요약은 완료된 실행 뒤에만 계산되어 세계에 역류하지 않는다.
- 126개의 seed 차이를 확률 민감성으로만 기록하고 진화라고 부르지 않는다.

## 4. 근사하거나 강제한 부분

- 길이 1~2와 서열 최대 두 개는 계산 가능한 최초 시험 범위이지 자연스러운 생태 규모가 아니다.
- 기호당 초기 열에너지 `2`와 사건 제한 `16`은 외부에서 고정한 실험 조건이다.
- 동일 구성 재등장의 대부분은 결합과 분리의 왕복일 가능성이 높으며 기억 증거가 아니다.
- 참여 관계 확장에는 절단으로 생긴 새 식별자나 새 결합 상대도 포함되므로 신호 전달로 해석할 수 없다.
- 접촉 지속은 정확히 같은 접촉 식별자만 세며 절단 뒤 이어진 구조적 연속성은 추적하지 않는다.
- 구조 문맥이 0회인 것은 현재 범위에서 출현하지 않았다는 뜻이다. 구조 문맥 법칙이 불가능하다는 증명은 아니다.
- 전체 프레임 파일은 약 3.45 MB이며 더 큰 전수 탐색에서는 그대로 확장하기 어렵다.

## 5. 검증 증거

- 능력 탐색기 포함 집중 테스트 65개 통과
- 전체 프로젝트 회귀 테스트 537개 통과
- 결과 파일: `runs/sequence_probe_stage_c.jsonl`

## 6. 다음 판단

이번 결과만으로 단계 C의 “원시 요소만으로 상태 유지, 신호 전달, 되먹임과 지연이 실제 구성 가능” 조건을
통과시킬 수 없다. 다음 탐색은 성공 구조를 직접 배치하지 않은 채 범위를 길이 3 이상과 세 서열 세계로 넓혀
접힘·성장·구조 문맥이 자발적으로 사건망에 들어오는지 확인해야 한다.

다만 전수 조합은 급격히 늘어난다. 따라서 다음에는 먼저 길이 3 전수 단일·쌍 범위의 계산량을 산정하고,
세 서열 세계는 실행 전에 고정한 균등 표본 규칙을 사용한다.
