# 단계 C 공통 국소 동역학 v1 구상 일치성 검증

**대상:** `engine/sequence/local_dynamics.py`와 최초 20,000충돌 탐색  
**판정:** 행동별 가중치 제거·공통 결합 법칙 통과, 공간 부재와 고정 포트가 강한 새 근사

## 1. 무엇을 만들었는가

`bind`, `unbind`, `join`, `cleave`별 후보 가중치 대신 모든 물질 단위에 같은 네 포트와 같은 충돌 법칙을
적용하는 별도 엔진을 만들었다. 명시적 충돌을 주면 세계 전환은 결정적이며, 확률 사건원은 성공 여부가 아니라
마주칠 포트 쌍만 균등하게 고른다.

## 2. 실제로 일어나는 일

- 성공 가능한 충돌만 고르지 않고 서로 다른 단위의 모든 포트 쌍에서 하나를 고른다.
- 빈 포트의 물질 친화도가 양수이면 결합이 생긴다.
- 같은 결합 포트가 다시 만나고 열에너지가 충분하면 결합이 끊어진다.
- 다른 결합으로 점유됐거나 호환되지 않으면 상태 변화 없이 시간만 흐른다.
- 결합 생성과 파괴 모두 동일한 결합 세기와 에너지 장부를 사용한다.

## 3. 최초 탐색 결과

기호 네 종류를 두 개씩 둔 8개 단위 세계를 seed 0과 1로 각각 10,000충돌 실행했다.

| 관측 | seed 0 | seed 1 |
|---|---:|---:|
| 결합 생성 | 269 | 278 |
| 결합 파괴 | 258 | 266 |
| 비호환 무반응 | 541 | 532 |
| 점유 포트 충돌 | 8,932 | 8,924 |
| 최종 결합 수 | 11 | 12 |
| 최대 결합 수 | 15 | 15 |
| 최대 단위 연결 차수 | 4 | 4 |
| 서로 다른 결합 위상 | 505 | 515 |

두 실행 모두 초기·최종 전체 에너지는 `8`로 같았고, 전체 20,000충돌을 기록된 난수로 재생했다.

## 4. 구상과 일치하는 부분

- 성장, 복제, 골격과 분리를 고수준 명령으로 두지 않았다.
- 결합 생성과 파괴에 별도 사건 가중치를 두지 않았다.
- 실패 충돌도 제거하지 않고 시간과 기록으로 남겼다.
- 같은 결합 법칙만으로 선형이 아닌 최대 4갈래 구조가 생겼다.
- 명시적 충돌에는 난수가 필요 없으며 스케줄러만 외부 교체 가능하다.
- 기존 가중치 사건계와 결과를 섞지 않았다.

## 5. 근사하거나 강제한 부분

- 포트 4개와 한 포트 한 결합은 사람이 정한 기하학이다.
- 위치가 없어 모든 단위가 항상 서로 만날 수 있는 완전 혼합 근사다.
- 점유 포트 충돌이 약 89%여서 이 근사가 시간 대부분을 지배한다.
- 물질 친화도에는 여전히 기존 `pair_score` 수식이 있다. 성공 공식은 아니지만 사람이 정한 물성이다.
- 열에너지가 전역이라 멀리 떨어진 국소 사건도 같은 저장고를 사용한다.
- 초기 열에너지 8에서는 형성된 세기 2 결합을 끊을 에너지가 항상 충분해 `bond_held`가 관측되지 않았다.
- 구조가 발생했지만 유전, 복제, 감각과 사고는 아직 없다.
