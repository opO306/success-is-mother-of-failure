# 길이 3 확장 능력 탐색 명세 v0

**상태:** 단계 C 확장 탐색 명세  
**목적:** 접힘이 가능한 길이까지 전수 범위를 넓히고, 세 서열 세계를 결과와 무관하게 사전 표본화

## 1. 실행 전 고정한 범위

길이 1~3의 내부 서열은 총 84개다.

- 단일 서열 및 비순서 쌍 전수: 3,654개 초기 조건
- 세 서열 중복 허용 조합 전체: 102,340개
- 세 서열 사전 표본: 512개
- 총 초기 조건: 4,166개
- 조건마다 seed `0`, `1`: 총 8,332회
- 실행당 외부 사건 제한: 24회

## 2. 세 서열 표본 고정 방법

세 서열 전체를 실행한 결과에서 좋은 사례를 고르지 않는다. 모든 조합을 정규 표현한 뒤
`stage-c-triples-v1`이라는 공개 선택 키와 함께 SHA-256으로 해시하고, 해시 순서가 앞선 512개를 실행 전에
고정한다.

이 방식은 통계적 무작위 표본을 완전히 증명하는 방법은 아니다. 다만 운영체제의 순서, 실행 seed와 관측 결과에
의존하지 않으며 누구나 같은 512개를 다시 만들 수 있다.

## 3. 데이터 흐름

```text
전수 단일·쌍 3,654 + 사전 고정 세 서열 512
                    ↓
             seed별 세계 실행
                    ↓
      실행 하나가 끝날 때 원본 JSONL 한 행 저장
                    ↓
       완료 뒤 관측값 집계와 구상 일치성 감사
```

모든 실행을 메모리에 모은 뒤 저장하지 않는다. 하나씩 실행하고 즉시 기록해 범위가 커져도 세계 상태와 관찰
결과가 섞이지 않게 한다.

## 4. 이번에 새로 확인할 질문

- 접힘과 풀림이 실제 사건으로 나타나는가
- 접힌 주머니가 나중 결합의 문맥 배율을 바꾸는가
- 절단으로 생긴 여러 조각이 주형에서 다시 연결되는가
- 연결된 골격이 여러 사건 동안 유지되는가

출현 횟수만 확인하며 이를 효소, 복제, 기억 또는 지능이라고 자동 명명하지 않는다.

## 5. 규모와 한계

전체 프레임을 보존하면 실행 시간보다 저장량이 먼저 커진다. 이번 범위까지는 원본 상태를 전부 저장하지만,
더 긴 시간축에서는 주기적 전체 체크포인트와 사건 차분을 함께 저장하는 무손실 방식이 필요하다.
