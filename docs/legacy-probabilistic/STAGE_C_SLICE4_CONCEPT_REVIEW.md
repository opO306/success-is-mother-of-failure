# 단계 C 골격 절단 조각 구상 일치성 검증

**대상:** `engine/sequence/substrate.py`의 골격 절단과 접촉 이전  
**판정:** 절단 조각 통과, 문맥별 안정성과 실제 충돌 공간은 미구현

## 1. 무엇을 만들었는가

길이 2 이상인 모든 선형 서열의 노출 골격이 확률적으로 끊어질 수 있게 했다. 부모 서열은 두 새 조각으로
바뀌고, 기호와 기존 접촉은 사라지지 않은 채 자손 위치로 이전된다.

## 2. 세계 안에서 실제로 일어나는 일

- 길이 `n`의 완전히 노출된 서열에는 `n-1`개의 절단 후보가 생긴다.
- 접힘이나 다른 서열 접촉이 절단점 양쪽 기호를 차지하면 그 지점에는 현재 충돌이 접근하지 못한다.
- 노출된 절단 사건이 선택되면 부모 골격 하나가 사라지고 열에너지 2가 나온다.
- 왼쪽·오른쪽 조각은 각각 새 식별자를 받는다.
- 절단점 밖의 기존 접촉은 해당 조각의 새 위치로 이동한다.
- 풀려난 조각은 다른 주형에서 다시 결합하고 성장할 수 있다.

## 3. 설계 의도와 일치하는 부분

- 절단을 실패 벌점이나 개체 처벌로 구현하지 않았다.
- 모든 노출 골격에 같은 기본 법칙을 적용한다.
- 특정 서열, 계통과 생존 상태를 절단률 계산에 사용하지 않는다.
- 접촉에 의한 보호는 이름표가 아니라 실제 위치 점유에서 생긴다.
- 절단 전후 기호 수와 총에너지가 정확히 보존된다.
- 부모와 두 자손 식별자, 절단 위치가 외부 사건에 기록된다.
- 접촉 정보가 절단 때문에 임의로 삭제되지 않는다.
- 성장→주형 해제→절단의 전체 순환에서도 총에너지가 같다.
- 기록된 선택으로 같은 절단 위치와 자손을 재생할 수 있다.

## 4. 근사하거나 강제한 부분

- 모든 노출 골격의 절단 가중치가 1로 같다.
- 실제 충돌 입자와 방향을 계산하지 않는다.
- 접촉된 두 기호가 절단점에 있으면 완전히 보호된다고 근사한다.
- 결합 생성 비용 2와 절단 방출 에너지 2가 같아 열손실 없는 이상적 가역성을 가진다.
- 기호 문맥, 장력, 서열 길이와 주변 온도에 따른 안정성 차이가 없다.
- 새 조각의 식별자는 중앙 실행기가 발급하지만 사건 선택에는 사용하지 않는다.
- 실제 3차원에서 접촉 이전이 가능한지 아직 검증하지 않는다.

## 5. 검증 증거

- 새 서열 테스트 30개와 기록 계층 테스트를 합쳐 39개 통과
- 전체 프로젝트 테스트 511개 통과
- 길이 4 노출 서열의 절단 후보 3개 확인
- 접촉으로 보호된 골격과 해제 뒤 재노출 확인
- 절단점 밖 접촉의 자손 위치 이전 확인
- 성장·해제·절단 순환의 기호 수와 에너지 보존 확인
