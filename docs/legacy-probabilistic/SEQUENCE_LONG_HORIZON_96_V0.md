# 길이 3 장기 96사건 탐색 명세 v0

**상태:** 단계 C 장기 관찰 명세  
**목적:** 초기 조건을 결과로 선별하지 않고 관찰 시간만 네 배로 늘려 일시적 구조의 유지와 반복을 확인

## 1. 고정 조건

- 길이 1~3 단일·비순서 쌍 전수: 3,654개
- 실행 전에 고정한 세 서열 표본: 512개
- seed: `0`, `1`
- 총 실행: 8,332회
- 사건 제한: 96
- 체크포인트 간격: 8
- 초기 에너지와 모든 물리 법칙: 24사건 탐색과 동일

24사건 결과에서 성장했던 네 사례만 고르지 않는다. 이전과 동일한 모든 초기 조건을 다시 실행한다.

## 2. 연속성 검증

각 장기 실행의 처음 24개 사건을 이전 24사건 기록과 직접 비교한다. 초기 조건, seed 또는 실행 법칙이 달라져
한 갈래가 바뀌면 장기 연장으로 인정하지 않는다.

## 3. 추가 관측

- 골격 성장 횟수와 발생 시점
- 성장한 정확한 골격 식별자가 유지된 상태 수
- 같은 실행에서 두 번째 성장이 일어나는지
- 성장 골격이 절단, 재결합 또는 관찰 끝까지 유지되는지
- 구조 문맥 사건이 같은 실행에서 반복되는지
- 24사건 이후 새로 자연 정지하는 실행이 있는지

## 4. 해석 경계

- 긴 유지 시간은 자기 유지의 증명이 아니다.
- 두 번째 성장이 없으면 재생산 또는 되먹임으로 부르지 않는다.
- 구조 문맥 반복은 구조 영향의 반복이지 신호나 학습의 자동 증명이 아니다.
- 사건 제한까지 계속되는 왕복 반응을 생존이라고 부르지 않는다.

## 5. 보존

실행 조건과 당시 물리 엔진 파일의 SHA-256은 별도 manifest에 기록한다. 압축 archive에는 모든 난수와 사건,
8사건 간격 체크포인트가 들어가며 전체 재생 검증을 거친다.
