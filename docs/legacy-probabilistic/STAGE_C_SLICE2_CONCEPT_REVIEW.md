# 단계 C 접힘 조각 구상 일치성 검증

**대상:** `engine/sequence/substrate.py`의 내부 접힘·풀림  
**판정:** 접힘 조각 통과, 실제 3차원 형상과 주형 성장은 미구현

## 1. 무엇을 만들었는가

서로 다른 서열을 붙이던 것과 같은 기호 결합 법칙을 한 서열 내부의 떨어진 두 구간에도 적용했다. 두 구간이
붙으면 접힘, 떨어지면 풀림으로 기록된다. 접힌 위치는 다른 접힘이나 외부 서열 결합에 사용할 수 없다.

## 2. 세계 안에서 실제로 일어나는 일

- 한 서열 안에서 겹치지 않고 최소 한 위치 떨어진 모든 같은 길이 구간을 찾는다.
- 기존 대칭 기호 좌표로 순 결합 점수를 계산한다.
- 양의 점수를 가진 노출 구간만 접힘 후보가 된다.
- 접힘은 결합 에너지를 열로 내놓고, 풀림은 같은 열에너지를 사용한다.
- 먼저 일어난 접힘이 이후 반응 가능성을 바꾸므로 발생 이력이 실제 상태가 된다.

## 3. 설계 의도와 일치하는 부분

- 특별한 머리핀 문자열, 접힘 명령과 잠복 스위치가 없다.
- 서열 사이 결합과 내부 접힘이 같은 점수·에너지·사건 선택 법칙을 공유한다.
- 접힘으로 가려진 위치는 실제 외부 결합 후보에서 제외된다.
- 풀리면 위치가 다시 노출된다.
- 접힘과 풀림 전후 총에너지가 정확히 같다.
- 기록된 선택으로 같은 접힘 사건과 상태를 재생할 수 있다.
- 평면 구조만을 강요하지 않도록 교차 접촉을 이름만으로 금지하지 않았다.

## 4. 근사하거나 강제한 부분

- 실제 3차원 좌표 대신 접촉 그래프만 사용한다.
- 사슬 두께, 자기 통과 금지, 매듭, 꼬임과 회전을 표현하지 못한다.
- 두 구간 사이 최소 한 기호가 있어야 한다는 고리 길이는 사람이 선택한 최초 근사다.
- 가능한 모든 구간 길이를 검사하여 긴 서열에서 후보 수가 빠르게 증가한다.
- 공간적으로 멀어서 실제로 만나지 못하는 두 구간도 현재는 접힘 후보가 될 수 있다.
- 접힌 모양이 주형 성장이나 촉진을 바꾸는 단계는 아직 없다.

## 5. 검증과 규모 측정

- 새 서열 테스트 16개와 기록 계층 테스트를 합쳐 25개 통과
- 전체 프로젝트 테스트 497개 통과
- 기준 패턴 한 서열의 접힘 후보 생성 측정:

| 서열 길이 | 후보 수 | 실행 시간 |
|---:|---:|---:|
| 8 | 12 | 약 0.13 ms |
| 16 | 128 | 약 1.02 ms |
| 32 | 1,184 | 약 11.71 ms |
| 64 | 10,176 | 약 134.76 ms |

이 측정은 현재 컴퓨터의 단일 실행 참고치이며 성능 보장이 아니다. 길이 64에서도 짧은 검증은 가능하지만,
개체 수와 시간이 늘어나는 진화 실험 전에 후보 갱신 방식 개선이 필요하다는 증거다.
