# 자기 해석형 서열 수치 물리 v0

**상태:** 단계 C 기준 실행기 첫 조각의 확정 수치 명세  
**범위:** 선형 서열 두 개 이상 사이의 가역 결합·분리와 에너지 장부

## 1. 내부 기호와 표시 이름

실행기 내부 기호는 `0, 1, 2, 3`이다. A/C/G/T는 관찰 화면에서 사용하는 기본 표시 이름일 뿐이다.

| 내부 기호 | 물리 좌표 | 기본 표시 |
|---:|---:|---:|
| 0 | (-1, -1) | A |
| 1 | (-1, +1) | C |
| 2 | (+1, -1) | G |
| 3 | (+1, +1) | T |

표시 이름을 다른 문자로 바꿔도 내부 상태와 사건은 변하지 않는다.

## 2. 기호 사이의 결합 점수

두 기호 `a`, `b`의 좌표를 각각 `(ax, ay)`, `(bx, by)`라고 할 때:

```text
pair_score(a, b) = -(ax × bx + ay × by)
```

가능한 결과는 `+2, 0, -2`다.

- 두 축이 모두 반대: `+2`
- 한 축만 반대: `0`
- 두 축이 모두 같음: `-2`

정렬된 두 서열 구간의 결합 점수는 각 위치의 `pair_score` 합이다. 총점이 양수일 때만 결합 사건 후보가 된다.
최소 길이 코돈이나 특별 문자열은 없다.

## 3. 정렬

두 선형 서열의 가능한 모든 상대 오프셋을 검사한다. 각 오프셋에서 실제로 겹치는 최대 구간 하나를 사용한다.

- 서열 식별자가 작은 쪽을 항상 첫 번째로 두어 후보 순서를 정규화한다.
- 이미 다른 결합이 차지한 위치가 하나라도 있으면 그 정렬은 현재 후보가 아니다.
- 배열 입력 순서가 사건 우선권이 되지 않도록 후보를 물리 식별자와 위치로 정렬한다.

## 4. 사건 가중치

### 결합

```text
bind_weight = total_pair_score
```

양의 정수 점수만 후보가 된다. 점수가 큰 정렬은 더 자주 선택될 수 있지만 결합이 보장되지는 않는다.

### 분리

결합이 형성될 때 저장된 점수를 `bond_energy`라고 한다.

```text
ideal_score = 2 × overlap_length
defect       = ideal_score - bond_energy
break_weight = max(1, thermal_energy - bond_energy + 1)
               × 2 ^ min(defect, 20)
```

열에너지가 `bond_energy`보다 작으면 분리는 현재 후보가 아니다. 불일치가 많을수록 분리 가중치가 커지고,
강하게 상보적인 긴 결합은 상대적으로 오래 유지된다. 지수 상한은 정수 폭발을 막는 실행 한계이며 세계 법칙
지문에 포함한다.

## 5. 사건 선택

모든 국소 후보의 양의 정수 가중치를 합한다. 확률 사건원에서 `[0, 총합)`의 정수 하나를 뽑아 누적 구간에
해당하는 사건 하나를 선택한다.

이 첫 조각은 사건 순서와 에너지 장부 검증을 위해 한 사건마다 이산 시간 1을 진행한다. 연속 사건 시간은
성장·이동과 결합하기 전에 별도 명세한다.

## 6. 에너지 보존

결합이 생기면 결합 퍼텐셜 에너지가 `-bond_energy`가 되고 같은 양이 열에너지로 나온다. 분리할 때는 같은 양의
열에너지를 사용한다.

```text
total_energy = thermal_energy - 모든 결합의 bond_energy 합
```

결합·분리 전후 `total_energy`는 정확히 같아야 한다.

## 7. 현재 의도적인 제한

- 선형 서열만 실행한다. 고리형 서열은 다음 조각에서 추가한다.
- 한 기호 위치는 동시에 하나의 측면 결합만 가질 수 있다.
- 공간 이동, 접힘, 골격 성장, 촉진과 분해는 아직 실행하지 않는다.
- 사건 시간은 이산 단계이며 실제 반응률 시간이 아니다.
- 현 단계의 목적은 생존이나 복제가 아니라 대칭적 결합, 가역성, 기록과 에너지 보존 검증이다.

이 제한은 최종 언어의 의미로 승격하지 않는다.
