# 단계 C 최소 반응망 실험기 구상 일치성 검증

**대상:** `engine/sequence/experiment.py`와 `SequenceState.configuration_hash()`  
**판정:** 세계 밖 시간축·재생·근접 인과 관찰 통과, 상태 유지·신호·되먹임의 실제 출현은 아직 미검증

## 1. 무엇을 만들었는가

짧은 서열 세계를 지정한 사건 수까지 실행하고 매 순간의 상태를 보존하는 최소 실험기를 만들었다. 실행이 끝난
뒤에만 사건 수, 같은 구성의 재등장과 참여 서열 기반 근접 인과망을 계산한다.

## 2. 세계 안에서 실제로 일어나는 일

- 각 순간에 현재 상태로 가능한 사건 후보를 다시 만든다.
- 후보 가중치 합에서 난수 한 번을 뽑아 사건 하나를 실행한다.
- 가능한 사건이 없으면 개입하지 않고 `quiescent`로 끝난다.
- 사람이 정한 사건 수에 도달하면 `event_limit`로 끝난다. 이것을 세계의 죽음으로 해석하지 않는다.
- 각 프레임에는 후보 수, 총 가중치, 난수 표본, 사건과 사건 뒤 전체 상태가 들어간다.

## 3. 설계 의도와 일치하는 부분

- 기록기와 분석기는 세계 전환 함수의 입력이 아니다.
- 관찰 결과를 번식·선택 점수로 사용하지 않는다.
- 같은 초기 상태와 같은 seed는 프레임 전체가 동일하다.
- 기록된 난수 표본만으로 사건열과 최종 상태를 완전히 재생한다.
- 시간 포함 상태 해시와 시간 제외 구성 해시를 분리했다.
- 사건 제한과 자연적인 무사건 상태를 구분해 실패나 정지를 숨기지 않는다.
- 인과망은 세계의 명령이 아니라 사건 참여 관계를 사후에 잇는 번역 결과다.
- 기억, 학습, 사고와 생명이라는 이름을 관찰 결과에 미리 붙이지 않는다.

## 4. 근사하거나 강제한 부분

- 작은 실험을 위해 매 사건 뒤 전체 상태를 저장하므로 장기 실행에는 메모리 비용이 크다.
- 근접 인과망은 같은 서열 식별자가 참여한 직전 사건만 연결한다. 열에너지나 공유 환경을 거친 간접 원인은
  아직 표현하지 않는다.
- 구성 해시는 서열 식별자와 다음 식별자도 포함한다. 따라서 물리 모양이 같아도 계보가 다르면 같은 구성으로
  세지 않는다.
- `event_limit`는 세계 법칙이 아니라 컴퓨터 실험의 외부 경계다.
- 현재 시간은 사건마다 1씩 증가하는 이산 시간이며 연속적인 물리 시간은 아니다.
- 사건 횟수와 반복 구성은 관측값일 뿐 상태 유지, 신호 전달 또는 되먹임의 증거가 자동으로 되지 않는다.

## 5. 검증 증거

- 서열 실험기·기반·기록 계층 집중 테스트 56개 통과
- 전체 프로젝트 회귀 테스트 528개 통과
- 사건이 없는 길이 1 서열은 난수를 한 번도 쓰지 않고 `quiescent`로 종료
- 같은 seed로 두 번 실행한 모든 프레임이 동일
- 외부 기록 전후 최종 상태 해시와 난수 소비량이 동일
- 기록된 난수만 사용한 전체 실행 재생이 원본과 동일
- 결합 두 번 뒤 골격 성장 사건의 근접 부모가 두 선행 결합으로 연결됨
