# 단계 C 맥락 의존 유전 컨테이너 v1 구상 일치성 검증

**대상:** `engine/sequence/inheritance.py`, 맥락 전환 4충돌 재현 실험  
**판정:** 기여분 비평균·계보/물리 분리·실제 자리 경쟁 통과, 생식과 발달은 미구현

## 1. 무엇을 만들었는가

두 부모를 하나의 숫자로 섞거나 미리 정의한 유전자 블록으로 교차하지 않고, 각 출처의 물질 구조를 그대로
공통 발생 공간에 넣는 컨테이너를 만들었다. 출처 이름은 관찰 기록에만 남기고 세계의 물리 계산에서는 제외했다.

## 2. 세계 안에서 실제로 무슨 일이 일어나는가

최소 실험에는 같은 성질의 두 기여 단위와 둘 모두와 결합 가능한 맥락 단위 하나가 있다.

1. 첫 기여 단위가 맥락 단위의 0번 포트와 결합한다.
2. 둘째 기여 단위도 같은 포트를 만나지만 이미 점유되어 있어 결합하지 못한다.
3. 첫 결합이 다시 충돌해 풀린다.
4. 둘째 기여 단위가 비워진 포트에 결합한다.

관측 결과는 순서대로 `bond_formed`, `ports_occupied`, `bond_broken`, `bond_formed`였다. 둘째 기여분은
가려진 순간에도 삭제되지 않았고, 맥락이 바뀐 뒤 같은 공통 법칙으로 작용했다.

## 3. 설계 의도와 일치하는 부분

- 부모의 기여분을 평균하거나 우수한 쪽으로 고르지 않는다.
- `우성`, `열성`, `유전병`, `좋은 궁합`을 실행 분기 이름으로 넣지 않았다.
- 가려짐은 실제 포트 점유 때문에 일어나며 기여분은 그대로 남는다.
- 부모 이름을 바꾸거나 입력 순서를 바꿔도 물리 상태가 같다.
- 부모에게서 이미 온 내부 결합도 별도 유전 법칙이 아니라 공통 세계 결합으로 변환된다.
- 작용 실패를 고치거나 구조하지 않고 사건으로 남긴다.

## 4. 근사했거나 강제한 부분

- 부모 기여분은 사람이 직접 골라 컨테이너에 넣으며 생식 과정에서 생성되지 않는다.
- 실험 충돌 순서는 현상을 명확히 확인하려고 수동으로 정했다. 자연 발생 빈도를 측정한 것이 아니다.
- 현재의 숨음은 한 포트 자리 경쟁 사례뿐이며 현실의 조절 유전자·후성유전·발달 시기를 재현하지 않는다.
- 기호 네 종류, 포트 네 개, 완전 혼합 세계와 `pair_score` 물성은 이전 국소 동역학의 근사 그대로다.
- 출처 기여분의 경계가 아직 명시적이다. 최종적으로 “유전자 블록” 경계를 자연법칙처럼 고정해서는 안 된다.
- 유전병이나 유리한 궁합이 발생했다는 증거가 아니다. 그런 결과를 오류가 아닌 관측 대상으로 둘 기반만 만들었다.

## 5. 검증 증거와 다음 결정 사항

- 유전 컨테이너와 공통 국소 동역학 집중 테스트 `19`개 통과
- 전체 프로젝트 회귀 테스트 `570`개 통과
- 재현 기록: `runs/inherited_context_v1_probe.json`
- 실행 조건과 코드·기록 해시: `runs/inherited_context_v1_probe_manifest.json`
- 동일 물리를 유지하면서 관찰 이름만 달라지는 테스트 통과
- 부모 입력 순서가 물리 상태를 바꾸지 않는 테스트 통과
- 가려진 기여분의 보존과 이후 작용 테스트 통과

다음 구현은 고정된 유전자 블록을 교차하는 방식이 아니라, 물리적으로 이어진 서열이 복제 중 끊기고 다시
붙으며 자손 형성 공간으로 전달되는 과정이어야 한다. 그 전에는 이 컨테이너를 완성된 유전이나 교배로 부르지
않는다.
