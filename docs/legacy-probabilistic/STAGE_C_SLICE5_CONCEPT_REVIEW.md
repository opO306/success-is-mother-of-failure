# 단계 C 구조 문맥 조각 구상 일치성 검증

**대상:** `engine/sequence/substrate.py`의 접힘 주머니 체류 배율  
**판정:** 최초 구조 촉진·억제 통과, 실제 3차원 농도와 반응 장벽은 미구현

## 1. 무엇을 만들었는가

접힘 접촉면 사이의 노출 구간을 임시 주머니로 정의했다. 그 안에서 새로운 결합을 만드는 사건은 재료가 오래
머무는 것으로 근사해 가중치가 증가한다. 접촉면 자체는 기존 점유 법칙으로 다른 사건을 차단한다.

## 2. 세계 안에서 실제로 일어나는 일

- 접힘이 없으면 기존 기본 가중치가 그대로 사용된다.
- 후보 위치가 접힘 주머니 안에 있으면 해당 접힘 에너지가 체류 배율에 더해진다.
- 여러 주머니가 겹치면 서로 다른 접힘 에너지가 합쳐진다.
- 최종 가중치는 기본 가중치와 배율의 곱이다.
- 접힘이 풀리면 그 구조가 주던 촉진과 위치 억제도 함께 사라진다.

## 3. 설계 의도와 일치하는 부분

- 특정 문자열을 효소나 기능으로 지정하지 않았다.
- 현재 접촉 형상과 사건 위치만 배율 계산에 사용한다.
- 같은 기본 결합도 열린 상태와 접힌 상태에서 다른 발생 기회를 가진다.
- 접힘 주머니가 측면 결합, 추가 접힘과 골격 성장에 모두 같은 체류 원리로 작용한다.
- 접촉면 억제는 별도 명령이 아니라 위치 점유의 결과다.
- 분리·풀림·절단은 이 체류 배율로 바꾸지 않는다.
- 기본 가중치와 구조 배율을 사건에 따로 기록해 사후 인과 설명이 가능하다.
- 기록된 최종 가중치로 같은 사건을 재생할 수 있다.

## 4. 근사하거나 강제한 부분

- 선형 서열에서 접촉면 사이를 실제 3차원 주머니로 간주한다.
- 후보 위치 하나만 안쪽에 있어도 후보 전체가 같은 배율을 받는다.
- 주머니 부피, 입구, 방향과 실제 재료 수를 계산하지 않는다.
- 접힘 결합 에너지가 클수록 체류 촉진도 강하다고 가정한다.
- 촉진은 결합 형성 사건에만 작용하고 분해 사건에는 작용하지 않는다.
- 배율 상한 64는 계산 폭주를 막기 위한 사람이 정한 실행 한계다.
- 여러 주머니가 상한에 도달하면 그 이상의 구조 차이가 가중치에 나타나지 않는다.

이 구현은 실제 효소 화학이 아니라 구조가 기능 차이를 만들 수 있는 최초 인과 통로다.

## 5. 검증 증거

- 새 서열 테스트 35개와 기록 계층 테스트를 합쳐 44개 통과
- 전체 프로젝트 테스트 516개 통과
- 동일 기본 결합 가중치가 열린 상태 `2`, 주머니 안 `6`으로 달라짐
- 주형 안 골격 성장 가중치가 기본 `1`, 구조 문맥 적용 후 `3`으로 달라짐
- 풀림과 절단 배율은 `1`로 유지됨
- 32개 중첩 접힘에서도 배율이 명세 상한 `64`를 넘지 않음
- 사건 기록에서 기본 가중치와 문맥 배율을 독립적으로 확인

## 6. 다음 작업

실험기**를 만든다. 특정 구조를 정답으로 넣지 않고, 짧은 서열 집합에서 발생한 사건망과 시간적 인과를 외부
번역기가 읽을 수 있게 해야 한다.
