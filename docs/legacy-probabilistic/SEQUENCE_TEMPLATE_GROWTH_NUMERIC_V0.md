# 자기 해석형 서열 주형 성장 수치 물리 v0

**상태:** 단계 C 기준 실행기 세 번째 조각  
**상위 수치 명세:** `SEQUENCE_PHYSICS_NUMERIC_V0.md`, `SEQUENCE_FOLDING_NUMERIC_V0.md`

## 1. 목적

노출된 서열 옆에 짧은 서열 조각들이 각각 결합하고, 이웃한 조각 사이에 새 골격 결합이 생겨 더 긴 사슬로
이어지게 한다. 완성 복사본을 한 번에 생성하는 `COPY` 명령은 사용하지 않는다.

## 2. 단량체와 조각

별도 단량체 자료형을 만들지 않는다.

- 길이 1인 서열은 자유 기호 조각처럼 작용할 수 있다.
- 길이 2 이상인 서열도 전체가 주형에 붙어 있다면 다른 조각과 이어질 수 있다.
- `유전체`, `복사본`, `효소`라는 내부 종류는 없다.

따라서 성장으로 만들어진 조각이 다시 다른 서열의 주형 또는 구조물이 될 수 있다.

## 3. 골격 결합 후보

두 서로 다른 서열 조각이 다음 조건을 모두 만족하면 골격 결합 후보가 된다.

1. 같은 제3의 주형 서열에 측면 결합되어 있다.
2. 두 측면 결합이 주형의 바로 이웃한 구간을 차지한다.
3. 각 조각의 전체 길이가 주형에 붙어 있다.
4. 각 조각은 그 주형 외의 다른 측면 결합을 가지고 있지 않다.
5. 사용할 수 있는 열에너지가 골격 결합 비용 이상이다.

특정 기호나 문자열은 골격 결합 자격을 얻지 않는다. 주형과의 실제 결합과 공간적 이웃 관계만 사용한다.

## 4. 사건과 에너지

v0의 새 골격 결합 비용은 정수 에너지 `2`다.

```text
backbone_join_weight = 1
backbone_cost        = 2
```

두 조각이 이미 올바르게 나란히 머문다는 사실이 성장 기회를 만들며, 추가 문자열 점수는 주지 않는다. 강한
주형 결합은 오래 유지되는 방식으로 간접적으로 성장 기회를 늘린다.

사건이 일어나면:

- 두 부모 조각과 그 주형 접촉을 제거한다.
- 주형에서 왼쪽에 있던 조각의 서열 뒤에 오른쪽 조각을 잇는다.
- 새 물리 식별자를 가진 하나의 서열을 만든다.
- 두 접촉을 합친 하나의 주형 접촉을 만든다.
- 열에너지 2를 새 골격 결합 에너지로 이동한다.

전체 에너지는 다음으로 계산한다.

```text
total_energy = thermal_energy
             + 2 × 모든 서열의 골격 결합 수
             - 모든 측면 접촉의 bond_energy 합
```

## 5. 식별자와 계보

새 사슬은 현재까지 사용한 어떤 서열 식별자보다 큰 새 식별자를 받는다. 식별자 크기는 물리 성질이나 사건
우선권을 주지 않는다. 두 부모 식별자와 새 식별자는 `sequence.backbone_join` 사건에 기록한다.

장기적인 계보는 외부 기록기가 이 사건들을 연결해 복원한다. 세계 상태에는 부모의 의미나 계통 이름을 넣지 않는다.

## 6. 허용되는 결과

- 두 단량체만 붙은 짧은 조각
- 기존 조각 끝에 단량체가 붙은 연장
- 두 긴 조각의 결합
- 주형 일부만 덮은 불완전 사슬
- 중간에 조각이 풀려 성장이 중단되는 경우
- 잘못 맞은 기호가 포함된 사슬

완전 상보 사슬이나 전체 복제를 보장하지 않는다.

## 7. 현재 제한

- 두 조각을 잇는 사건만 있고 골격 절단은 아직 없다.
- 가지 친 골격은 없고 방향 있는 선형 사슬만 만든다.
- 실제 3차원 끝점 거리 대신 주형에서 이웃하다는 조건을 사용한다.
- 골격 결합 가중치는 1로 고정한 최초 근사다.
- 동일한 두 조각이 주형 없이 직접 이어지는 반응은 아직 없다.
- 연속 사건 시간이 아니라 이산 사건 시간을 사용한다.

## 8. 통과 조건

- 길이 1 서열 두 개가 주형 위에서 두 단계 결합 후 하나의 길이 2 서열이 될 수 있다.
- 한 번의 사건으로 완성 복사본이 생기지 않는다.
- 주형에 붙지 않았거나 떨어진 위치의 조각은 이어지지 않는다.
- 성장 전후 기호 수와 총에너지가 보존된다.
- 부모·자손 식별자와 주형 위치가 기록된다.
- 기록된 사건 선택으로 같은 성장 결과를 재생할 수 있다.
