# 자기 해석형 서열 능력 탐색기 v0

**상태:** 단계 C 전수 소형 탐색 명세  
**목적:** 정답·적합도·선별 없이 현재 최소 물리가 실제로 만드는 사건 양상을 원본 프레임과 함께 관찰

## 1. 탐색 범위

기본 탐색은 내부 기호 `0..3`으로 만들 수 있는 길이 1~2의 모든 서열을 사용한다.

- 단일 서열 세계: 20개
- 두 서열의 비순서 중복 허용 조합: 210개
- 전체 초기 조건: 230개
- 초기 조건마다 seed `0`, `1`: 총 460회
- 실행당 외부 사건 제한: 16회

서열 이름은 관찰용 태그일 뿐 세계 상태나 사건 선택에 들어가지 않는다. 비순서 쌍을 사용해 단순히 좌우 입력
순서만 다른 중복 세계를 제거한다.

## 2. 고정한 실험 환경

초기 열에너지는 전체 기호 수의 두 배다. 이는 자연의 절대값이 아니라 같은 작은 공간을 비교하기 위한 실험
조건이다. 사건 제한도 컴퓨터 실행 경계이지 세계의 수명이나 죽음이 아니다.

탐색기는 실행 도중 이 값들을 바꾸거나 관찰 결과가 좋은 세계에 자원을 더 주지 않는다.

## 3. 분리해서 기록하는 관측값

- 자연 정지 또는 외부 사건 제한
- 사건 종류별 횟수
- 서로 다른 물리 구성 수
- 같은 구성의 재등장 묶음 수
- 동일 접촉이 연속 상태에 존재한 최장 길이
- 참여 서열을 공유하는 근접 인과 연결 수
- 이전 참여 관계에 새 서열 식별자가 들어온 사건 수
- 구조 문맥 배율이 1보다 컸던 사건 수
- 최종 상태 해시

이 값들을 합쳐 단일 점수, 순위 또는 적합도로 만들지 않는다.

## 4. 원본 보존

각 실행은 다음을 한 JSONL 행에 전부 보존한다.

- 초기 상태
- seed와 사건 제한
- 종료 이유
- 분리된 관측값
- 매 사건 직전 후보 수와 총 가중치
- 실제 난수 표본
- 원본 사건
- 사건 뒤 전체 상태

따라서 요약 수치만 남기고 실패 과정을 버리지 않는다.

## 5. 해석 경계

- 구성 재등장은 순환 후보이지 기억의 증명이 아니다.
- 접촉 지속은 상태 유지 후보이지 항상성의 증명이 아니다.
- 참여 관계 확장은 상호작용 전파 후보이지 신호의 증명이 아니다.
- 구조 문맥 사건은 구조가 확률을 바꾼 흔적이지 효소나 사고의 증명이 아니다.
- seed에 따른 최종 상태 차이는 확률 민감성이지 진화의 증명이 아니다.

## 6. 확장할 때 다시 볼 것

길이와 개체 수가 커지면 전수 조합 수와 전체 프레임 저장량이 빠르게 증가한다. 다음 범위부터는 전수 탐색과
무작위 표본을 구분하고, 표본 규칙을 실행 전에 고정해야 한다. 저장은 체크포인트와 사건 차분으로 바꿀 수 있지만
어느 시점의 상태도 동일하게 복원되어야 한다.
