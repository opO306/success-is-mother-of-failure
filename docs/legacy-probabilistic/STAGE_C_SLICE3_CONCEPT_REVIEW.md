# 단계 C 주형 성장 조각 구상 일치성 검증

**대상:** `engine/sequence/substrate.py`의 골격 결합  
**판정:** 부분 성장 조각 통과, 골격 절단과 촉진은 미구현

## 1. 무엇을 만들었는가

길이 1 이상의 두 서열 조각이 같은 주형의 바로 이웃한 구간에 전체 길이로 붙어 있을 때, 열에너지를 사용해
하나의 더 긴 선형 서열로 이어질 수 있게 했다. 새 서열은 새 물리 식별자를 받고 두 부모 식별자는 사건 기록에
남는다.

## 2. 세계 안에서 실제로 일어나는 일

- 자유 단량체도 길이 1인 평범한 서열이다.
- 각 조각은 기존 측면 결합 법칙으로 주형에 따로 붙는다.
- 이웃 위치에 붙은 두 조각만 골격 결합 후보가 된다.
- 사건이 선택되면 두 조각의 기호 순서를 이어 새 사슬을 만든다.
- 두 측면 접촉은 하나의 긴 주형 접촉으로 합쳐진다.
- 열에너지 2가 새 골격 결합에 저장된다.
- 새 조각은 다시 단량체나 다른 조각과 이어질 수 있다.

## 3. 설계 의도와 일치하는 부분

- 단량체·유전체·복사본을 서로 다른 내부 자료형으로 만들지 않았다.
- 완성 사슬을 한 사건으로 만드는 `COPY` 연산이 없다.
- 특정 문자열이나 기호에 성장 권한을 주지 않는다.
- 주형에 실제로 결합하고 서로 이웃한 관계만 성장 조건으로 사용한다.
- 기호 수와 총에너지가 성장 전후 정확히 보존된다.
- 불완전 조각과 중간 중단이 정상 상태로 남는다.
- 기존 조각 끝에 단량체 하나가 이어지는 점진적 성장이 가능하다.
- 부모·자손 식별자와 주형 식별자가 외부 사건에 기록된다.
- 기록된 확률 선택으로 같은 자손 서열을 재생할 수 있다.

## 4. 근사하거나 강제한 부분

- 골격 결합 에너지 비용 2와 사건 가중치 1은 사람이 선택한 최초 물리 상수다.
- 실제 3차원 끝점 거리 대신 주형에서 바로 이웃한다는 조건을 사용한다.
- 조각 전체가 한 주형에 붙어 있을 때만 이어질 수 있다.
- 골격 절단이 없어 현재 골격 성장은 비가역적이다.
- 가지 친 사슬과 원형 사슬을 만들 수 없다.
- 활성 단량체를 별도 상태로 두지 않고 열에너지가 충분하면 결합할 수 있다고 근사한다.
- 새 식별자는 중앙 실행기가 단조 증가값으로 발급하지만 물리 계산에는 영향을 주지 않는다.
- 연속 반응 시간이 아니라 이산 사건 시간이다.

현재 단계는 **부분 상보 사슬 성장 가능성**을 만든 것이며 자기복제 생명체가 탄생했다는 뜻이 아니다.

## 5. 검증 증거

- 새 서열 테스트 23개와 기록 계층 테스트를 합쳐 32개 통과
- 전체 프로젝트 테스트 504개 통과
- 길이 1 조각 두 개의 결합 후 길이 2 생성 확인
- 길이 2 조각과 단량체 결합 후 길이 3 생성 확인
- 떨어진 주형 위치와 에너지 부족 상태에서 골격 결합이 생기지 않음
- 한 사건으로 자유 단량체 전체가 완성 복사본이 되지 않음
- 성장 전후 기호 수와 총에너지 동일

## 6. 다음 작업

다음 조각은 골격 결합이 충돌과 에너지에 의해 끊어지는 **골격 절단과 조각 재사용**이다. 성장만 있고 절단이
없으면 세계가 긴 서열로 일방적으로 굳고, 결실·재조합·손상 같은 진화 재료가 생기지 않는다.

절단 이후에 접힌 구조가 정렬과 머무는 시간을 바꾸어 결합·성장·절단 속도에 영향을 주는 촉진을 추가한다.
