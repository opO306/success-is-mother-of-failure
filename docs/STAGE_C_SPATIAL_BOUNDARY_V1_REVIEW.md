# 단계 C 2차원 위치와 물리 경계막 v1 구상 일치성 검증

**대상:** `engine/sequence/spatial_dynamics.py`, seed 17의 1,000회 이동 탐색  
**판정:** 위치 기반 진입과 관찰 격리 통과, 막·이동·구조 크기는 강한 최소 근사

## 1. 무엇을 만들었는가

각 물질에 2차원 위치를 주고, 인접한 두 칸 사이에 불활성 장벽을 놓을 수 있는 별도 공간 계층을 만들었다.
장벽이 없는 한 칸은 틈이 되며 모든 물질은 같은 이동 법칙을 사용한다.

## 2. 세계 안에서 실제로 무슨 일이 일어나는가

5×3 격자의 왼쪽에 네 물질을 놓고, x=2와 x=3 사이 위·아래를 장벽으로 막되 가운데 y=1만 비웠다.
이후 1,000번 동안 매번 모든 물질×네 방향 중 하나를 균등하게 골라 이동을 시도했다. 영역 안팎의 구분은
실행 후 x=3..4의 위치를 읽어 관찰했다.

- 이동 성공 `494`회
- 장벽 차단 `59`회
- 점유 칸 충돌 `157`회
- 세계 경계 충돌 `290`회
- 관찰 영역 진입·이탈 `19`회
- 한 번이라도 내부에 들어간 단위 `2, 3, 4`
- 마지막에 내부에 있던 단위 `4`

19회의 진입·이탈은 모두 가운데 실제 틈 `(2,1)↔(3,1)`을 통과했으며 장벽을 가로지른 사례는 없었다.

## 3. 설계 의도와 일치하는 부분

- 엔진이 특정 물질을 자손용으로 고르지 않는다.
- 막 내부 구성은 실제 위치와 이동 역사로만 정해진다.
- 물질 기호나 계보에 따른 전용 통과 규칙이 없다.
- 실패할 이동을 미리 제거하지 않고 같은 확률로 뽑아 기록한다.
- 영역의 이름과 진입 통계는 세계 밖 관찰이며 이동에 되먹이지 않는다.
- 장벽을 통과한 결합처럼 공간상 모순된 상태를 허용하지 않는다.

## 4. 근사했거나 강제한 부분

- 2차원 격자, 한 칸 한 단위와 상하좌우 이동은 사람이 정한 기하학이다.
- 막의 위치와 가운데 틈은 실험 초기조건으로 사람이 배치했다.
- 무작위 보행에는 힘, 질량, 에너지 비용과 실제 확산 속도가 없다.
- 장벽은 생성·손상·이동하지 않는 절대 구조다.
- 모든 단위 크기가 같아 크기나 구조에 따른 선택적 투과가 없다.
- 결합된 구조는 단일 단위 이동만으로 결합 길이를 유지해야 하므로 사실상 지나치게 고정된다.
- 이 공간을 자손 형성 공간이라고 해석할 수 있지만 아직 자손은 존재하지 않는다.

## 5. 검증 증거와 다음 결정 사항

- 공간·유전·국소 동역학 집중 테스트 `36`개 통과
- 전체 프로젝트 회귀 테스트 `587`개 통과
- 장벽 차단, 틈 통과, 점유, 세계 경계와 결합 제약 테스트 통과
- 관찰 영역 질의가 위치만 읽는 테스트 통과
- 모든 단위×방향을 성공 필터 없이 표본하는 테스트 통과
- 멀리 있거나 장벽으로 분리된 단위의 결합 차단과 인접 단위의 공통 결합 테스트 통과
- 기록한 난수 추출만으로 50회 이동을 완전히 재생하는 테스트 통과
- 1,000회 확률 탐색 기록: `runs/spatial_boundary_v1_probe.json`
- 실행 조건과 코드·기록 해시: `runs/spatial_boundary_v1_probe_manifest.json`

다음에는 이 결과를 보고 결합 구조 전체의 이동과 인접 물질 충돌을 추가할지 판단한다. 현재 상태로 복제와
자손 형성을 넣으면 움직이지 못하는 큰 구조가 사람의 구현 순서 때문에 부당하게 탈락할 수 있다.
