# 자기 해석형 서열 접힘 수치 물리 v0

**상태:** 단계 C 기준 실행기 두 번째 조각  
**상위 수치 명세:** `docs/SEQUENCE_PHYSICS_NUMERIC_V0.md`

## 1. 목적

한 서열의 서로 떨어진 두 구간이 같은 측면 결합 법칙으로 붙고 떨어지게 한다. 접힌 구간은 다른 결합에서
실제로 사용할 수 없으므로, 서열 문맥에 따른 노출·잠복이 세계 상태가 된다.

`접어라`, `발현을 꺼라`, `다시 켜라` 같은 명령은 추가하지 않는다.

## 2. 접힘 후보

같은 선형 서열에서 다음 조건을 만족하는 두 연속 구간을 선택한다.

- 두 구간의 길이가 같다.
- 두 구간은 겹치지 않는다.
- 두 구간 사이에는 최소 한 기호의 고리 간격이 있다.
- 두 구간의 모든 위치가 현재 다른 측면 결합에 사용되지 않았다.
- 기존 기호 좌표식으로 계산한 순 결합 점수가 양수다.

가능한 모든 시작 위치와 길이를 후보로 둔다. 특별한 머리핀 문자열이나 접힘 표는 없다.

## 3. 접힘과 풀림 사건

접힘 가중치는 서열 사이 결합과 동일하다.

```text
fold_weight = total_pair_score
```

풀림도 기존 분리식을 그대로 사용한다.

```text
ideal_score   = 2 × contact_length
defect        = ideal_score - bond_energy
unfold_weight = max(1, thermal_energy - bond_energy + 1)
                × 2 ^ min(defect, 20)
```

접힘은 `sequence.fold`, 풀림은 `sequence.unfold` 사건으로 기록하지만 에너지와 사건 선택 법칙은 서열 사이
결합·분리와 동일하다. 이름은 관찰 편의를 위한 사건 분류이지 별도 물리가 아니다.

## 4. 노출과 잠복

한 기호 위치는 동시에 하나의 측면 결합에만 참여할 수 있다.

```text
노출 위치 → 외부 서열 결합 또는 내부 접힘 후보가 될 수 있음
결합 위치 → 다른 후보에서 제외됨
결합 해제 → 다시 후보가 될 수 있음
```

따라서 같은 서열도 먼저 어떤 사건이 일어났는지에 따라 이후 가능한 반응이 달라진다. 이것이 v0에서의 가장
초기적인 문맥과 발생 이력이다.

## 5. 3차원에 대한 현재 근사

v0는 실제 좌표를 푸는 대신 접촉 그래프만 저장한다. 서로 교차하는 접촉을 금지하지 않는다. 평면 그림에서는
교차해 보여도 3차원에서는 서로 다른 방향으로 지나갈 수 있기 때문이다.

반면 다음 현상은 아직 표현하지 못한다.

- 사슬이 자기 몸체를 통과할 수 없는 배제 부피
- 매듭과 꼬임
- 접힘으로 인한 실제 거리 변화
- 구조의 회전과 입체적인 결합면

따라서 현재 접힘은 3차원 분자 구조가 아니라 **어떤 위치가 서로 접촉하고 가려졌는지 나타내는 인과적 근사**다.

## 6. 계산 비용

길이 `n`인 한 서열의 모든 두 구간과 길이를 검사하므로 단순 기준 구현은 최악의 경우 대략 `O(n^3)` 후보를
만든다. 이 구현은 짧은 서열의 정확한 기준 결과를 위한 것이다.

장기 실행 전에 국소 공간 색인과 점진적 후보 갱신이 필요하지만, 최적화 전후 후보 집합이 동일하다는 비교
테스트를 먼저 만들어야 한다.

## 7. 통과 조건

- 별도 접힘 문자열 표 없이 접힘 후보가 생긴다.
- 접힘과 풀림 전후 총에너지가 같다.
- 접힌 위치는 외부 결합 후보에서 빠진다.
- 풀리면 같은 위치가 다시 반응 가능해진다.
- 기록 유무가 접힘 사건을 바꾸지 않는다.
- 기록된 확률 선택으로 같은 접힘 역사를 재생할 수 있다.
