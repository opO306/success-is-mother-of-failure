# 단계 C 첫 실행 조각 구상 일치성 검증

**대상:** `engine/sequence/substrate.py`  
**판정:** 첫 조각 통과, 자기 해석 언어 전체는 미완성

## 1. 무엇을 만들었는가

네 종류의 익명 기호로 된 선형 서열들이 서로 다른 위치에 정렬되어 가역적으로 결합·분리되는 작은 기준
실행기를 만들었다. 결합 세기는 특정 문자열 표가 아니라 각 기호의 두 대칭 물리 축으로 계산한다.

결합하면 같은 양의 에너지가 열 장부로 이동하고, 분리할 때 다시 소비된다. 모든 사건 후보를 정규화한 뒤
기록 가능한 확률 표본 하나로 실제 사건을 선택한다.

## 2. 세계 안에서 실제로 일어나는 일

- 가까이 있다고 가정한 모든 서로 다른 서열 쌍의 상대 정렬을 조사한다.
- 겹친 기호들의 물리 좌표로 순 결합 에너지를 계산한다.
- 순 에너지가 양수이고 위치가 비어 있으면 결합 후보가 된다.
- 기존 결합은 충분한 열에너지가 있을 때 분리 후보가 된다.
- 후보 가중치에 따라 한 사건이 발생하고 이산 시간이 1 진행한다.
- 외부 기록기는 사용된 확률 표본과 사건 사본을 사후에 받을 수 있다.

## 3. 설계 의도와 일치하는 부분

- 내부 상태는 A/C/G/T 문자가 아니라 0~3의 익명 물질 종류를 사용한다.
- 표시 문자를 한글 등으로 바꿔도 물리 상태와 사건 후보는 변하지 않는다.
- `COPY`, 유전자 시작점, 종료점과 행동 명령이 없다.
- 길이 1 이상의 모든 내부 서열은 문법 오류 없이 존재한다.
- 한 기호 변이는 결합 점수를 국소적으로 바꾼다.
- 입력 배열 순서와 관찰자 이름은 사건 우선권을 만들지 않는다.
- 세계 전환 함수는 기록기를 받지 않는다.
- 결합·분리 전후 총에너지가 정확히 보존된다.
- 기존 `engine.living`의 Genome, BodyIntent와 BoundaryPhenotype을 재사용하지 않는다.

## 4. 근사하거나 강제한 부분

- 아직 실제 공간 이동이 없어 같은 반응 용기 안의 모든 서열 쌍을 만날 수 있다고 근사한다.
- 현재는 선형 서열과 서열 사이 측면 결합만 있다.
- 한 위치는 한 결합만 허용한다.
- 접힘, 주형 성장, 골격 손상, 촉진, 억제와 공간 경계는 없다.
- 결합·분리 가중치 식은 사람이 선택한 최초 물리법칙이며 절대적인 현실 법칙이 아니다.
- 사건마다 시간이 1 증가하므로 아직 연속적인 국소 사건 시간이 아니다.
- CPU 기준 실행만 있으며 GPU 실행과 병렬 사건 주소 난수는 없다.

이 제한들 때문에 현재 결과를 생명, 유전체, 복제 또는 진화라고 부르지 않는다.

## 5. 검증 증거

- 새 서열 기반 테스트 10개 통과
- 기존 기록 계층과 함께 실행한 집중 테스트 19개 통과
- 전체 프로젝트 테스트 491개 통과
- 동일 seed의 기록 유무가 상태와 난수 소비를 바꾸지 않음
- 기록된 선택으로 같은 사건과 상태를 재생함
- 기호 결합 점수가 대칭이고 가능한 값이 `-2, 0, +2`뿐임

## 6. 다음 작업

다음 조각은 공간이나 생존을 넣기 전에 한 사슬 내부의 비인접 구간 결합을 허용하는 **접힘**이다. 접힘으로
서열 일부가 실제로 가려지고 다시 노출되어야 잠복과 문맥 의존성이 단순 설명이 아니라 세계 사건이 된다.

접힘 구현 전에는 자기 교차, 인접 골격 구간의 잘못된 결합, 고리형 서열의 시작점 편향과 접힘 후보 폭발을
어떻게 처리할지 수치 명세를 먼저 추가한다.
