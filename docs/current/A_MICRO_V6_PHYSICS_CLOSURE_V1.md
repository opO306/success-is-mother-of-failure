# A-MICRO v6 물리 폐쇄 v1 — 기능 목록이 아니라 의존성 지도

**상태:** **설계자 판정 반영 2판 (2026-09-24, 8절).** Z1 조건부 승인(전하 계층 명시 → 반영), Z2~Z5 승인. 코드 없음.
**다음:** C0 수치 후보 비교 → C0 구현 → C0 폐쇄 판정 전부 통과 후 C1.
**상위:** `A_V6_DEFORMABLE_MATERIAL_ARCHITECTURE_V1.md`(조건부 승인). **참고:** `A_MICRO_V6_PARTICLE_DESIGN_V1.md`(초안) — 그 문서의
결정 M-A~M-F는 이 문서의 폐쇄 묶음 안으로 재배치된다(9절). **완료의 뜻이 바뀐다:** "기능이 돌아간다"가 아니라 **"그 현상을 지탱하는
물리 의존성이 모두 닫혔으니 이제 그 결과를 주장할 자격이 있다"**(7절 주장 장부).

## 0. 왜 — v5가 실패로 증명한 패턴

| 막힌 곳 | 빠져 있던 연결 |
|---|---|
| 충돌을 넣음 → 중심 벗어난 충돌 | 힘이 작용한 위치 → 토크 → 각운동량 |
| 회전을 봄 → 모서리·요람 | 국소 압축 → 내부 힘 → 유한 속도 파동 |
| 구속을 결과로 → 에너지 행방 | 낮은 에너지 상태로 내려갈 때 **차이가 갈 곳**(다른 자유도) |
| `e < 1` 금지 | 열 = 많은 내부 자유도 |

법칙 하나가 틀린 것이 아니라 **주변 연결망이 끊겨 있었다.** 증상마다 기능을 붙이면 다음 빈자리가 드러날 뿐이다. 이 문서는 목표 범위의
의존성을 먼저 전부 펼치고, **서로 끊을 수 없는 것을 묶음(Closure)으로 한꺼번에** 만든다.

**구현자 반성 (2건):**
- 제 쪽 권고(C1 → 회전 검토 → 결합 = 결과)도 같은 증상 추적이었다. 입자 설계 초안의 "결합·끊어짐·열이 한 법칙에서 나온다"는 에너지
  전달 조건을 빠뜨린 과장이었다.
- 1판에서 그것을 고친다며 쓴 **"결합에는 제3체가 필요하다"도 과장**이었다(설계자 지적). 정확한 명제는 3절 B-4. 제3 입자는 여러 에너지
  수용처 중 하나일 뿐이다.

## 1. 범위 선언 — A-MICRO v6가 최종적으로 책임질 것

> **저에너지 · 비상대론적 · 고전적 · 분자 규모**에서 운동, 응집, 구조 형성, 반응, 열적 운동, 물질·에너지 전달까지.

### 1.1 범위 밖 (선언된 빈자리 — 결과 해석 때 반드시 함께 읽는다)

| 빠진 것 | 그래서 A에서 달라지는 것 |
|---|---|
| **양자 효과** — 영점 에너지, 터널링, 진동 준위의 불연속 | 저온 열용량이 현실과 다름(고전 등분배). 가벼운 입자의 반응률 틀림. **결합·반응의 근원 자체가 양자** → 퍼텐셜은 근거 등급 "근사(유효 모델)" |
| **전자 들뜸, 광화학** | 빛으로 일어나는 반응 없음. 복사는 C3에서 유효 모델로만 |
| **복사로 에너지 내보내기** | 빛을 내며 안정 포획되는 경로 없음 → 포획은 **다른 입자·내부 자유도로 에너지를 넘길 때만**(3절 B-4) |
| 상대론, 핵반응 | 해당 에너지 범위 밖 |
| 중력 | 분자 규모에서 무시. **C3의 침전·대류가 필요해지면 다시 봄** |
| (2D로 시작할 경우) 3차원 | 충돌 빈도·포획률·구조 종류가 현실과 다름 → "근사" 선언 |

### 1.2 전하·정전기·분극 — **C0·C1에서는 열지 않음, C2의 장기 범위 안** (설계자 Z1 조건)

물·이온·염·산-염기·극성 분자 — 전기적 상호작용은 **화학 한복판**이다. 이것을 적지 않으면 C2가 "반응 가능한 물질 전체"처럼 보이지만
실제로는 현실 화학 상당 부분을 표현할 수 없다. 그래서 C2를 둘로 나눈다(4절).

| | 범위 | 표현 못 하는 것 |
|---|---|---|
| **C2-N** 중성·단거리 유효 화학 | 전하 없는 반응성 퍼텐셜 | 이온, 염의 녹음, 산-염기, 극성 용매화, 수소 결합의 전기적 성분 |
| **C2-Q** 전하·정전기·분극 (장기) | 위의 것들 | — (설계 시 다시 정함) |

C2-Q 설계 때 정할 것: 전하가 **고정**(종류의 매개변수)인가, **배치에서 유도**되는가, 전하 평형화(charge equilibration)처럼 **내부 자유도**가
필요한가 — 마지막이면 전하가 새 물리 상태 또는 매 순간 풀리는 유도량이 된다(상태 세 층 계약과 연결).

**쿨롱과 정의의 충돌 — 해소 (2026-09-24):** 쿨롱 상호작용은 거리 제한이 없는데 상위 V1 1판은 MICRO를 "유한 거리의 상호작용"으로
정의했었다. 설계자가 정의 자체를 넓혔다(상위 문서 1절: 상호작용은 유한 범위 또는 장거리, 유한 범위는 C0~C2-N 초기 모델의 선택일 뿐).
C2-Q에서 (a) 장거리 합산(주기 경계에서는 에왈드 계열), (b) 거리 자르기(근사) 중 무엇을 쓸지는 **수치 방법·근사 문제**로 그때 정한다.

## 4. 폐쇄 묶음 — 묶음 단위로 구현, 닫히기 전 상위 주장 금지

```
C0 역학 ─→ C1 응집 ─┬─→ C2-N 중성 화학 ─→ C2-Q 전하 (장기)
                    │         │
                    └─→ C3-T 비평형 수송     │
                              └──────┬──────┘
                                     └─→ C3-R 비평형 반응 환경
```

C3-T는 C2 없이 C1 위에서 닫을 수 있다. 구현 단계를 꼭 둘로 나눌 필요는 없지만, **의존성과 판정은 나눈다** — "열류는 정상인데 화학
네트워크가 이상하다"를 가려낼 수 있어야 한다.

### C0 — 역학 바닥
**넣는 것:** 공간·시간, 질량·위치·운동량, **반발만 있는 보존적 쌍 상호작용**, 시간 대칭 적분.
**나오는 것:** 운동, 충돌, 산란, 운동량 전달, 전체 각운동량 보존, 반발 기체, 빽빽한 반발 기체(또는 상자에 가둔 반발 결정)의 음파.
**여기서 확인하는 것:** 산란과 운동량 전달이지 "물체의 회전"이 아니다 — 반발만으로는 몸이 없다(Z2).
**금지 주장:** 몸, 형상, 구속, 결합, 열적 비탄성.

### C1 — 응집 물질
**넣는 것:** 인력 + 반발(한 퍼텐셜), 다체 구성, 내부 진동 자유도(결과로).

안정 포획, 탈출.

### 경계 원칙 (Z4 승인)
- **확률적 열욕·무작위 주입 금지** — A는 난수 금지.
- "결정론적 열욕"이라는 이름만으로 안전하지 않다 — 특정 동역학적 편향이나 에르고딕하지 않은 문제를 만들 수 있다. **처음에는 실제 자유도를
  가진 경계가 가장 깨끗하다:**

```
[큰 뜨거운 입자 저장소]  ↕ 실제 충돌  [관측 영역]  ↕ 실제 충돌  [큰 차가운 입자 저장소]
```

- 유한 저장소는 시간이 지나면 온도가 변한다 → 정상 상태를 오래 유지하려면 결국 외부 구동이 필요하다. 구동은 **세계 명세**다.
- **경계 감사 (필수):**
  1. 경계 구동의 주기·위상이 내부 현상의 주기를 강제로 만들지 않는가
  2. 경계에서 멀리 떨어진 벌크에서도 결과가 유지되는가
  3. 경계 위치·크기를 바꿔도 같은 거시 현상이 나오는가
  4. 공급을 끄면 예상대로 평형 쪽으로 가는가

## 5. 각 묶음의 폐쇄 판정

**공통 원칙:** 통계·거시 법칙(분포, 푸리에 법칙, 반응률 등)은 작은 유한계에서 정확히 나와야 하는 절대 법칙이 아니다. **적용 가능한 규모와
조건에서 그 관계로 수렴하는가**로 판정한다.

| 묶음 | 닫혔다고 말하려면 |
|---|---|
| C0 | 두 입자 산란각이 해석해로 수렴 · 운동량 정확 · 각운동량 보존 · 재명명·입력 순서 무관 · 가파른 극한에서 v5 탄성 결과 · 빽빽한 반발 기체의 음속 · **시간반전(물리):** 시간반전된 초기 조건의 해가 역방향 해로 수렴(시간 간격을 줄일수록) |

**모든 묶음 공통 — 수치 계약과의 연결:** `energy_balance_residual`(± 기록)이 **주장하는 물리 에너지 흐름보다 충분히 작아야** 그 주장을 할 수
있다. 예: 포획으로 옮겨 간 에너지가 잔차보다 작으면 "포획됐다"는 수치 착시일 수 있다. 수렴은 두 종류로 본다(짧은 시간 궤적 / 긴 시간 관측량).

**물리 판정과 수치 요구를 나눈다 (설계자 수정):** 연속 방정식의 시간반전 대칭(물리)과, 전진 N번 → 속도 반전 → N번이 **비트 단위로**
처음 상태로 돌아오는 것(수치)은 다른 요구다. 시간 대칭 적분기도 반올림 때문에 비트 가역이 아닐 수 있다. **비트 가역성은 수 체계 후보
평가 항목**이지 C0 폐쇄의 필수 조건이 아니다.

## 6. 실패 진단 절차 — 실패를 버그로 단정하지 않는다

```
현상이 안 나옴
  → 의존성 지도에서 그 현상의 행을 찾음
  → 의존 항목이 모두 현재 묶음 안에 있나?
       아니오 → "표현 불가(엔진 결손)" 기록. 실험 결과 아님
       예     → 물리적 이유 후보 점검 (아래 예)
               → 수치 원인 점검 (잔차, 시간 간격 수렴)
               → 그래도 모르면 버그 후보
```

예: **두 입자가 포획되지 않음** → 두 입자뿐이고 에너지 수용처가 없는가(B-4: 포획되지 않는 게 정상) · 우물이 얕은가 · 접근 운동 에너지가
큰가 · 수용처가 있어도 그 조건에서 에너지 전달이 충분한가(수용처가 있다고 무조건 포획되지는 않는다) · 시간 간격이 너무 커서 우물을 건너뛰는가.

**이 구분이 필요한 이유:** 나중에 "이 세계에서 생명이 자연적으로 안 생겼다"고 말하려면, 그 전에 생명에 필요한 자유도가 **구현되어
있었는지**가 확보돼야 한다. 아니면 실험 결과가 아니라 엔진 결손을 잰 것이다.
