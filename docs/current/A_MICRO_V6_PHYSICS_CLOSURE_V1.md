# A-MICRO v6 물리 폐쇄 v1 — 기능 목록이 아니라 의존성 지도

**상태:** 초안 (2026-09-24). 설계자 방향 전환을 받아 작성. **코드 없음. P0(구현 착수) 정지.**
**상위:** `A_V6_DEFORMABLE_MATERIAL_ARCHITECTURE_V1.md`(조건부 승인). **참고:** `A_MICRO_V6_PARTICLE_DESIGN_V1.md`(초안) — 그 문서의
결정 M-A~M-F는 이 문서의 폐쇄 묶음 안으로 재배치된다(9절). **완료의 뜻이 바뀐다:** "기능이 돌아간다"가 아니라 **"그 물리 영역에 필요한
의존성이 닫혔다"**.

---

## 0. 왜 — v5가 실패로 증명한 패턴

| 막힌 곳 | 빠져 있던 연결 |
|---|---|
| 충돌을 넣음 → 중심 벗어난 충돌 | 힘이 작용한 위치 → 토크 → 각운동량 |
| 회전을 봄 → 모서리·요람 | 국소 압축 → 내부 힘 → 유한 속도 파동 |
| 결합을 결과로 → 에너지 행방 | 낮은 에너지 상태로 내려갈 때 **차이가 갈 곳**(내부 자유도·제3체) |
| `e < 1` 금지 | 열 = 많은 내부 자유도 |

법칙 하나가 틀린 것이 아니라 **주변 연결망이 끊겨 있었다.** 증상마다 기능을 붙이면 다음 빈자리가 드러날 뿐이다. 이 문서는 목표 범위의
의존성을 먼저 전부 펼치고, **서로 끊을 수 없는 것을 묶음(Closure)으로 한꺼번에** 만든다.

**구현자 반성:** 제 쪽 권고(C1 → 회전 검토 → 결합 = 결과)도 같은 증상 추적이었다. 특히 직전 초안의 "결합 = 결과로 두면 결합·끊어짐·열이
한 법칙에서 나온다"는 **두 입자만으로는 결합이 생기지 않는다**는 점(3절 B-4)을 적지 않아 과장이었다.

## 1. 범위 선언 — A-MICRO v6가 최종적으로 책임질 것

> **저에너지 · 비상대론적 · 고전적 · 분자 규모**에서 운동, 응집, 구조 형성, 반응, 열적 운동, 물질·에너지 전달까지.

### 1.1 범위 밖 (선언된 빈자리 — 결과 해석 때 반드시 함께 읽는다)

| 빠진 것 | 그래서 A에서 달라지는 것 |
|---|---|
| **양자 효과** — 영점 에너지, 터널링, 진동 준위의 불연속 | 저온 열용량이 현실과 다름(고전 등분배). 가벼운 입자의 반응률 틀림. **결합·반응의 근원 자체가 양자** → 퍼텐셜은 근거 등급 "근사(유효 모델)" |
| **전자 들뜸, 광화학** | 빛으로 일어나는 반응 없음. 복사는 Closure 3에서 유효 모델로만 |
| **복사로 에너지 내보내기** | 두 입자가 빛을 내며 결합하는 경로 없음 → 결합은 **제3체·내부 자유도로만**(3절 B-4) |
| 상대론, 핵반응 | 해당 에너지 범위 밖 |
| 중력 | 분자 규모에서 무시. **Closure 3의 침전·대류가 필요해지면 다시 봄** |
| (2D로 시작할 경우) 3차원 | 충돌 빈도·제3체 결합률·구조 종류가 현실과 다름 → "근사" 선언 |

**원칙:** 범위 밖의 것 때문에 나타나지 않는 현상은 **"A에서 안 나왔다"가 아니라 "A가 그 현상을 표현할 수 없다"**로 기록한다.

## 4. 폐쇄 묶음 — 묶음 단위로 구현, 닫히기 전 상위 주장 금지

### C0 — 역학 바닥
**넣는 것:** 공간·시간, 질량·위치·운동량, **반발만 있는 보존적 쌍 상호작용**, 시간 대칭 적분.
**나오는 것:** 운동, 충돌, 산란, 전체 각운동량 보존, 반발 기체.
**설계자 원안 수정 — 정직하게:** 원안은 C0에 "여러 입자의 회전, 압축파"를 넣었는데, **반발만 있으면 몸이 생기지 않는다**(흩어짐). 그래서
회전하는 몸·몸 속 응력파는 C1로 옮긴다. C0에서 나오는 압축파는 **빽빽한 반발 기체(또는 상자에 가둔 반발 결정)의 음파**까지다.
**금지 주장:** 결합, 몸, 형상, 열적 비탄성.

### C1 — 응집 물질
**넣는 것:** 인력 + 반발(한 퍼텐셜), 다체 구성, 내부 진동 자유도(결과로).
**나오는 것:** 몸, 회전, 변형, 응력파, 진동, 열, 상, 압력, 열전도, 제3체 결합, 해리.
**금지 주장:** 분자(원자가 포화가 없으면 "분자"는 무한 덩어리와 구별 안 됨), 반응, 선택성.

### C2 — 반응 가능한 물질
**넣는 것:** 배치 의존 상호작용(결합 차수 계열), 각도 항, 여러 종류.
**나오는 것:** 분자, 결합 교환, 장벽, 반응 속도, 촉매 비슷한 현상, 반응 네트워크.
**금지 주장:** 비평형 화학, 자기 유지 구조, 생명 이전 조건.
**근거:** 반응성 퍼텐셜은 양자 화학의 요약 = "근사". 매개변수를 실제 원소 값에 맞추면 "실험 보정"으로 올린다.

### C3 — 환경과 에너지 흐름
**넣는 것:** 에너지·물질 공급/배출 경계 조건, 용매, 압력 경계, (필요 시) 복사 유효 모델.
**나오는 것:** 비평형 정상 상태, 구배, 흐름 속 화학 — **LUCA 이전 화학의 바닥.**

**C3의 A 원칙 충돌 (설계자 판단 필요):**
- 표준 도구 대부분이 **확률적**이다(랑주뱅 열욕, 무작위 입자 주입). A는 난수 금지 → **결정론적 경계만** 허용된다
  (예: 명시적 벽 입자 층을 결정론적으로 구동, 결정론적 열욕).
- 경계 조건은 **법칙이 아니라 세계 명세**다. 그러나 경계가 세계를 "어디로 끌고 가는지" 정하므로, 경계 설계가 결과를 미리 정하지 않는지
  감사해야 한다(엔진이 결정하지 않는다는 원칙의 경계판).

## 5. 각 묶음의 폐쇄 판정 — 교과서 값

| 묶음 | 닫혔다고 말하려면 |
|---|---|
| C0 | 두 입자 산란각이 해석해와 일치 · 운동량 정확 · 각운동량 보존 · **시간을 뒤집으면 처음으로 돌아옴**(정수 연산이면 비트 단위 가능 — 후보 시험) · 재명명·입력 순서 무관 · 가파른 극한에서 v5 탄성 결과 · 반발 기체의 음속 |
| C1 | 등분배(고전) · 맥스웰–볼츠만 분포 · 상태 방정식 · 격자 음속 = 강성에서 계산한 값 · 두 입자만으론 결합 안 됨 + 제3체 있으면 결합 · 해리율이 온도에 따라 · 비스듬한 충돌로 몸 회전 · 열전도(푸리에 법칙 형태) |
| C2 | 원자가 포화(한 원자가 받는 결합 수 상한이 결과로) · 반응 장벽 높이 측정 · 반응률의 온도 의존 · 결합 교환 경로 존재 |
| C3 | 두 경계 사이 정상 열류 · 엔트로피 생산 양수 · 구배 유지 · 공급을 끊으면 평형으로 복귀 |

**모든 묶음 공통 — 수치 계약과의 연결:** `energy_balance_residual`(± 기록)이 **주장하는 물리 에너지 흐름보다 충분히 작아야** 그 주장을 할 수
있다. 예: 결합 형성으로 방출된 에너지가 잔차보다 작으면 "결합했다"는 수치 착시일 수 있다. 수렴은 두 종류로 본다(짧은 시간 궤적 / 긴 시간
관측량).

## 6. 실패 진단 절차 — 실패를 버그로 단정하지 않는다

```
현상이 안 나옴
  → 의존성 지도에서 그 현상의 행을 찾음
  → 의존 항목이 모두 현재 묶음 안에 있나?
       아니오 → "표현 불가(엔진 결손)" 기록. 실험 결과 아님
       예     → 물리적 이유 후보 점검 (아래 예)
               → 수치 원인 점검 (잔차, 시간 간격 수렴)
               → 그래도 모르면 버그 후보
```

예: **두 입자가 결합하지 않음** → 두 입자뿐인가(B-4: 결합하지 않는 게 정상) · 우물이 얕은가 · 접근 운동 에너지가 우물보다 큰가 · 남는
에너지가 빠질 제3 자유도가 있는가 · 시간 간격이 너무 커서 우물을 건너뛰는가.

**이 구분이 필요한 이유:** 나중에 "이 세계에서 생명이 자연적으로 안 생겼다"고 말하려면, 그 전에 생명에 필요한 자유도가 **구현되어
있었는지**가 확보돼야 한다. 아니면 실험 결과가 아니라 엔진 결손을 잰 것이다.
