# C1-B1 — 두 Ar 원자 동역학: 설계 초안 v1

**상태:** v2 (2026-09-26). 초안(1~3절) → **설계자 11판: 수정 조건부 승인, 계약으로 기록(4절)** → 구현 1~3단계(기준 의미 계층·독립 감사·
Δt 후보 측정) 완료 → Δt 측정 보고(5절) → **설계자 12판: Δt = 40 a.u. 채택, binary64 절대 위치 탈락, FX(64,32) 주 후보 제외(6절)** → 감사 보강·stress·넓은 FX·민감 사례 측정 완료 → 보고(7절) → **설계자 13판: 적분기 유효범위 계약, 세 가지 거부 분류, 위치 FX(96,48)·운동량 FX(64,48) 후보, 비용 실측(8절)** → 1~3단계 완료 → **보고(9절), 수 표현 동결 판정 대기.** B0는 그 뒤.
**전제:** C1-A 동결(`C1A_AR2_FREEZE_V1.md`) — V(R)·F(R)의 의미는 이미 정해졌다. 여기서 정할 것은 **위치 벡터에서 R을 만들고, 힘을 두 원자에 적용하고,
시간을 진행시키는 규칙**이다.
**범위 밖(10판):** 다입자 힘 합산, 액체, 고체, thermostat, 3체, Cencek 퍼텐셜. 세계 최종 수 체계와 fast profile도 여기서 고르지 않는다.

## 1. 결정 항목

### D1. 질량과 그 단위 변환

- 질량 선택지: (a) ⁴⁰Ar 한 동위원소(존재비 99.6%) (b) 자연 평균 원자량 39.948 u — 평균은 **어떤 한 원자의 질량도 아니다**.
- 단위 변환 u → mₑ 에 쓸 상수도 C1-A의 a₀와 같은 **출처 고정** 문제다(CODATA 판).
- **추천:** (a) ⁴⁰Ar. 질량(AME 판)과 u/mₑ(CODATA 판)을 C1-B1 계약에 출처 판과 함께 적고, A 전체 상수는 여전히 따로 정한다.
  동위원소 혼합은 다종 세계에서 종(species) 문제로 다룬다.

### D2. 상태 변수

- 위치 `r_i`(3D), **운동량** `p_i`(속도가 아니라). C0 계획 11절: 운동량을 상태로 두면 `±J`를 같은 수로 적용해 총 운동량이 수 체계에 따라
  비트 단위로 보존될 수 있다.
- **추천:** 위치·운동량, 질량은 종 상수.

### D3. Δr을 만드는 규칙 (가장 중요한 결정)

| 선택지 | 뜻 | 장점 | 단점 |
|---|---|---|---|
| **(a) 정확한 차이** | `Δr = r_j − r_i`를 **반올림 없이** 정확한 수로 둔다(두 저장 값의 차는 항상 정확한 유리수) | 이동 불변(두 원자를 같이 옮겨도 Δr 동일), 교환 반대칭(i↔j면 정확히 −Δr), 연산 순서 무관 | 실행기가 넓은 정수를 다뤄야 함(binary64 두 수의 차는 최대 약 2,100비트) |
| (b) 성분마다 한 번 반올림 | `Δx = round(x_j − x_i)` | 싸다 | binary64에서는 절대 위치가 클수록 Δr 오차가 커짐 — **세계의 원점이 물리에 새어 들어간다** |
| (c) 평범한 연산 순서 | Fortran식 | 가장 싸다 | 의미가 알고리즘에 묶임(C1-A가 거부한 방식) |

FX에서는 두 위치의 차가 넘침만 없으면 **원래 정확**하므로 (a)=(b). binary64에서만 갈린다.
**추천:** (a). C1-A의 원칙("값은 정확한 수학 값을 한 번 반올림")을 쌍 수준으로 넓힌 것이다.

### D4. R의 수치 의미

- (a)를 택하면 `R² = Δr·Δr`은 정확한 유리수이고 `R = √(R²)`는 대개 **무리수**다. 그러면 퍼텐셜 입력을 "R을 먼저 반올림"하지 않고
  **정확한 R² 에서 곧바로** 평가할 수 있다: `V = round(V_real(√R²))`, 힘 성분 `F_x = round(F_real(R)·Δx/R)`.
- 대안: `R_rounded = round(√R²)`를 먼저 만들고 C1-A의 V(R)에 넣는다 — C1-A fixture를 그대로 쓰지만, **반올림이 두 번**(R, 그다음 V) 들어간다.
- **추천:** 정확한 R²에서 평가(반올림 한 번). C1-A 기준 평가기는 R을 유리수로만 받으므로 **R = √(유리수)를 구간으로 감싸는 확장**이 필요하다
  (새 입력 형태이지 퍼텐셜 의미 변경이 아니다 — C1-A 동결 유지). 세계 판단에 쓰는 비교(cutoff 등)는 **R²과 r_c²을 정확히 비교**해 반올림 논쟁을 없앤다.

### D5. 반지름 방향 힘 → 3D 힘 벡터, 작용·반작용

- 힘 벡터 `F⃗_j = F(R)·Δr/R` (Δr = r_j − r_i, F > 0이면 척력으로 j를 밀어냄), `F⃗_i = −F⃗_j`.
- **한 번만 계산**하고 두 원자에 `+`와 `−`로 적용한다(10판). 성분별로 정확한 값을 한 번 반올림하므로 반올림도 부호에 대해 대칭 —
  i·j 이름을 바꿔도 정확히 같은 결과.
- 충격량 형태: `J = round(F⃗·Δt')` 를 한 번 만들고 `p_j += J`, `p_i −= J` (Δt' 는 적분기의 반 걸음 등).
- **추천:** 위와 같음. 총 운동량은 FX에서 비트 단위로 정확, binary64에서는 `p ± J`의 반올림 때문에 경계 안 표류(C0 계획 E5-B와 같은 상황).

### D6. 시간 적분기

- 후보: **속도 Verlet / 도약(leapfrog), 운동량 형태 kick–drift–kick**
  ```
  p ← p + (Δt/2)·F(r)
  r ← r + Δt·p/m
  p ← p + (Δt/2)·F(r)
  ```
  시간 대칭·심플렉틱(C0 폐쇄 A-7 요구). 정확 산술이면 중심력에서 **각운동량을 정확히 보존**하고, 에너지는 표류 없이 O(Δt²)로 진동한다.
- 수치 규칙: 각 대입의 우변을 **정확히 계산하고 저장할 때 한 번 반올림**(C1-A와 같은 원칙). `Δt/m`을 미리 반올림한 상수로 쓰면 그것도
  반올림 한 번이 추가되므로 선언해야 한다.
- 비트 가역성(Δt → −Δt로 처음 상태 복귀)은 FX 정수 도약 적분에서 가능하다는 선행 연구가 있으나(Levesque & Verlet 1993) **요구 사항이 아니라
  수 체계 평가 항목**으로 둔다(폐쇄 문서 234행).
- **추천:** kick–drift–kick, 대입마다 한 번 반올림.

### D7. 시간 간격 Δt

- 규모: 충돌 시간 약 900 a.u.(21 fs), 진동 주기 약 44,700 a.u. 흔한 MD 관행(수 fs)은 참고일 뿐이다.
- **숫자를 미리 고르지 않는다.** 후보 10·20·40·80·160 a.u.(약 0.24~3.9 fs)에서 산란각·에너지 잔차를 재고 **수렴 곡선을 보고** 설계자가 정한다.
- 큰 Δt는 한 걸음에 반발 벽 깊숙이 뛰어들 수 있다. r_min 아래에 들어가면 C1-A대로 **`physics_domain_exceeded`로 세계를 멈춘다**
  (clamp·되돌리기 금지). 멈춤 자체가 "Δt가 너무 크다"는 측정 결과다.

### D8. cutoff의 물리적 정의

- **cutoff는 물리가 아니라 근사다.** Lang 퍼텐셜에는 끝이 없다(긴 거리 약 R⁻⁶~R⁻⁷).
- 두 원자에서는 비용 문제가 없다. **추천: C1-B1의 기준 실행은 cutoff 없이** 한다(동결 계약 그대로의 물리).
- cutoff는 C1-B1에서 **효과를 측정하는 별도 실험**으로만 넣는다. 후보:

  | 방식 | V | F | 결과 |
  |---|---|---|---|
  | 자르기 | r_c에서 불연속 | 불연속 | 넘을 때 에너지가 튄다 |
  | V 이동 | 연속 | 불연속 | 힘에 계단 |
  | 힘 이동 | 연속 | 연속 | 퍼텐셜 전체가 조금 바뀜 |
  | 전환 함수 [r_s, r_c] | 연속 | 연속 | 구간 안 힘이 바뀜 |

  어느 것이든 **바뀐 퍼텐셜은 Lang 2024가 아니다** — 주장 장부에 근사로 기록하고, 오차 상한(꼬리의 V·F 크기)과 함께 판정받는다.
- 알려진 암묵 cutoff: FX(64,32)에서는 V가 약 90 bohr, F가 약 61 bohr부터 **정확히 0**이다(C1-A). B0는 2²⁰ bohr 너머를 거부한다(실행기 한계).
  두 원자가 그 너머로 멀어지는 경우의 처리(측정 종료로 볼지)는 D10에서 정한다.

### D9. 두 원자 산란의 기준 해

- 고전 두 물체 문제는 질량 중심 + 상대 운동 1차원 문제로 줄어든다. 에너지 E, 충돌 매개변수 b에서 **편향각**
  `χ(E, b) = π − 2b ∫_{r₀}^{∞} dr / (r² √(1 − V(r)/E − b²/r²))` (r₀ = 되돌이 점).
- 결합 상태(E < 0): 진동 주기 `T(E) = 2 ∫ dr / √((2/μ)(E − V_eff(r)))`.
- 기준 해는 **독립 감사 쪽에서** 고정밀 적분(mpmath)으로 계산하고, 되돌이 점의 적분 특이점은 변수 치환으로 처리한다. 수치 적분은 증명이 아니므로
  C1-A 힘 검증과 같은 등급("독립적으로 강하게 검증됨")으로 기록한다.
- 시뮬레이션은 유한 거리 R₀에서 시작·종료하므로 꼬리 V(R₀)/E만큼 오차가 생긴다 — 기준 해에도 같은 R₀를 넣은 판을 함께 계산해 두 오차를 가른다.
- 시험 격자: 여러 E(예: 0.1kT~10kT)와 b. **궤도 선회(orbiting)·무지개 근처**는 매우 민감하므로 일반 시험에서 빼고 전용 사례로 따로 둔다.

### D10. 수렴·잔차 — 무엇을 재고 무엇을 섞지 않는가

C0 계획 11절의 구분을 그대로 따른다.

| 측정 | 방법 | 보는 것 |
|---|---|---|
| 이산화 오차 | Δt 절반씩(Δt, Δt/2, Δt/4 …), 기준 해와 비교 | 적분기 오차가 Δt²로 줄어드는지 |
| 반올림 오차 | **같은 Δt**에서 정확 유리수(또는 초고정밀) 궤적과 비교 | 수 체계 오차 |
| 정밀도 수렴 | binary64 · FX(64,32) · 더 넓은 FX · 정확 유리수 | 수 체계를 넓히면 반올림 오차가 줄어드는지 |
| 총 운동량 | Σp | FX: 비트 단위 0이어야 함, binary64: 상한 안 |
| 각운동량 | Σ r×p | 정확 산술이면 0 — 남는 것은 반올림 |
| 에너지 | K + V (V는 C1-A 값) | 표류 없는 O(Δt²) 진동인지, 장시간 표류가 있는지 |
| 불변성 | 두 원자 교환 · 세계 전체 평행이동 · 90° 회전 | FX: 비트 동일 기대. binary64: 평행이동하면 절대 위치의 반올림이 달라져 **다를 수 있음** |
| 실행기 | B0 = B1 = B2 (배치 독립) | C1-A와 같은 방식 |

### D11. 무엇을 "같은 결과"로 요구하는가

- 같은 초기 상태·Δt·profile이면 모든 실행기에서 **궤적 전체가 비트 동일**(RULES 1장 결정론).
- 서로 다른 Δt·profile끼리는 비트 동일을 요구하지 않고 **수렴**을 요구한다.

## 2. 구현 계획 (판정 뒤에만)

1. **기준 적분기**(Python, 정확 유리수 상태 + C1-A 기준 평가기의 √(유리수) 확장). 느려도 되는 정답 정의.
2. **독립 감사**: 산란각·진동 주기 기준 해(mpmath 적분), 보존량 재집계. `a_reference` import 금지.
3. **B0 쌍 커널**: 정확 Δr → R² → 구간으로 V·F → 성분 반올림 → ±J. B1·B2는 B0 뒤에.
4. 시험: 기준 해 비교, Δt·정밀도 수렴, 잔차, 불변성, 결함 주입(Δr 반올림, J 두 번 계산, 반 걸음 누락, 부호 오류 등).

관측량: 산란은 R₀에서 들어와 다시 R₀에 올 때까지 상대 좌표가 휩쓴 각과 걸린 시간(마지막 걸음 안의 통과 시점은 3차 Hermite 보간, 오차 O(Δt⁴));

### 5.2 측정된 사실

1. **r_min 침범 0건.** 600회 모두 정상 종료. E ≤ 10Dₑ에서는 Δt = 160에서도 drift 선분이 r_min에 닿지 않는다(가장 가까운 되돌이점 약 5.5 bohr).
   **따라서 이 격자만으로는 "침범 빈도"가 Δt 선택 자료가 되지 못한다** — 침범은 훨씬 높은 에너지에서나 나온다.
2. **이산화 오차는 모든 사례·관측량에서 정확히 Δt²** (Δt를 반으로 줄일 때마다 1/4, log₂ 비 2.00). 서로 독립인 두 계산(기준 적분기와 감사의
   적분)이 이 차수로 수렴한다는 것은 두 쪽 모두에 대한 강한 확인이다(증명은 아님).
3. **초기 표현 오차(①)는 무시할 만하다:** 상대 10⁻¹⁰ 이하(결합 f = 0.9 두 주기에서 5×10⁻⁹).
4. **반올림 오차(②), binary64:** 모든 Δt에서 이산화 오차의 **0.1% 미만**(최악 0.054%). 상대 10⁻¹⁴ 수준.
5. **반올림 오차(②), FX(64,32):** 상대 10⁻⁸ 수준으로 Δt와 거의 무관 — 그래서 **작은 Δt에서는 이산화 오차보다 크다**:
   산란 시간·각에서 Δt = 10이면 최대 약 **70~100배**, Δt = 20이면 약 20배, Δt = 40이면 3~4배, Δt = 80에서 비슷, Δt = 160에서야 이산화가 더 크다.
   (결합 주기에서는 이산화가 늘 더 크다.) 즉 **FX(64,32)로는 Δt를 줄여도 어떤 선 아래로는 정확도가 좋아지지 않는다.**
   원인 추정: 위치 해상도 2⁻³² bohr ≈ 2.3×10⁻¹⁰ bohr에서 매 drift의 반올림이 누적(측정 사실은 크기이고 원인은 추정).
6. **각운동량:** 고정밀에서 보존(정확 산술의 Verlet 성질), binary64·FX는 반올림만큼 변한다(FX 최대 |ΔL_z| 6×10⁻⁷). **총 운동량은 세 profile 모두
   600회에서 정확히 0 변화**(같은 J를 ±로 적용, 초기 p_i = −p_j).
7. **긴 꼬리(D8):** 20 bohr 밖 퍼텐셜이 무한대 편향각에 주는 몫(직선 비행 기하를 뺀 순수 꼬리 기여)은 최대 **1.0×10⁻³ rad**(E = 0.5Dₑ, b = 2Rₑ),
   대체로 1/E로 줄어든다. **Δt = 160의 이산화 오차보다 크다.** 20 bohr에서 자르는 cutoff는 저에너지 산란각을 이만큼 바꾼다는 뜻 — cutoff 근사 실험의 첫 자료.
8. **민감 사례(자동 제외하지 않고 분류):** 편향각의 b 민감도 |dχ/d(b/Rₑ)|가 큰 것 — **E = Dₑ, b = 1.5Rₑ: +25.3**(궤도 선회·무지개 근처), E = 0.5Dₑ, b = 1.5Rₑ:
   −8.6. 나머지는 |dχ/db| ≤ 4.4. 두 민감 사례도 이 Δt 격자에서는 정상 수렴(Δt²)했다 — 민감성은 Δt보다 **초기 조건 오차 증폭** 문제이고, 전용 시험으로 따로 둔다.

### 5.3 D10 불변성 — **binary64가 평행이동 A를 위반한다 (판정 필요)**

| 변환 | binary64 | FX(64,32) |
|---|---|---|
| i ↔ j 교환 | 비트 동일 ✅ | 비트 동일 ✅ |
| 90° 회전(축 치환 + 부호) | 비트 동일 ✅ | 비트 동일 ✅ |
| 평행이동 A(표현 보존) | **위반 ❌ — 첫 걸음부터 상대 궤적이 다름** | 비트 동일 ✅ |

1024 bohr 이동: 초기 위치가 FX 격자 값이라 이동 후에도 **정확히 표현되고 초기 Δr이 완전히 같다**(A형). 그런데 binary64의 drift
`r ← round(r + p·Δt/m)`은 **절대 위치의 ulp**(원점 근처 2⁻⁵⁰ 대 1024 근처 2⁻⁴²)에서 반올림되므로 첫 걸음부터 상대 궤적이 갈린다.
**원점 효과가 입력 표현이 아니라 동역학(drift 반올림)에서 새로 생긴다.** 11판 D10 기준으로는 binary64의 실패다.
시험에는 `strict xfail`(알려진 위반)로 기록했다 — 고쳐지면 시험이 깨져 알린다. FX는 격자 정렬 이동에서 drift 반올림이 이동과 교환되어 성립한다.

이것은 세계 수 체계 선택(C1-A 동결 문서 3절, 아직 미정)에 직접 걸리는 자료다. 가능한 방향(판정 아님): ① binary64를 세계 위치 표현에서 제외
② 위치는 고정소수점(격자), 운동량·충격량은 다른 profile ③ binary64를 쓰되 D10-A를 "입력 단계 한정"으로 완화 — ③은 11판의 "원점에 따라 물리가
달라도 상관없다는 판정은 하지 않는다"와 충돌한다.

### 5.4 설계자에게 묻는 것

1. **Δt 판정.** 요약: 이산화 오차가 정확히 Δt²이므로 허용 오차만 정하면 Δt가 계산된다. 예) 산란 관측량 상대 10⁻⁵ 이하 → Δt ≤ 약 43(측정점으로는 40),
   에너지 편차 Dₑ의 10⁻³ 이하 → Δt ≤ 약 55(측정점으로는 40). 비용은 Δt에 반비례(Δt = 40이면 10의 1/4).
2. **FX(64,32)의 반올림 바닥(5.2-5):** Δt를 작게 잡을 이유가 있다면 FX(64,32)는 그 이득을 막는다. 더 넓은 FX(예: 소수 비트 증가)를 후보에 넣을지.
3. **binary64 평행이동 A 위반(5.3):** 수 체계 결정에서 어떻게 다룰지.
4. **r_min 침범 자료가 비어 있다(5.2-1):** Δt 선택 근거로 쓰려면 더 높은 에너지(예: E/Dₑ = 100, 1000) 사례를 추가 측정할지.
5. 민감 사례 2개의 전용 시험 방식(초기 조건 오차 증폭을 어떻게 판정할지).

### 7.1 감사 끝점 보강 (8항)

- **한계(공개):** ① C1-B1의 J 평가기(√R² 입력)는 아직 네이티브로 없다 — 끝-끝의 힘 평가는 **C1-A F(R)을 binary64 R에서 평가한 대리값**
  (같은 식·같은 비용 계층, 정확히 같은 계산은 아님). ② FX(64,48)도 같은 limb 코드로 쟀다 — 네이티브 int64로 손으로 최적화하면 64비트가 더 빠를 수
  있다(측정 안 함). ③ GPU 묶음 수치는 메모리 대역폭 영향이 크다(쌍 구조체 적재).

### 9.3 typed 조합 수치 재확인 — `a_reference/c1b1_typed_study.py` → `fixtures/c1b1_typed_study_v1.json`

위치 FX(96,48) + 운동량 FX(64,48), 40사례 × Δt 10·20·40 = 120회:

  **12판 합격 기준 충족.**

  `test_typed_positions_reach_far_beyond_the_fx64_48_range`).

### 9.4 새로 발견: **정확한 drift 동점에서 FX도 평행이동 불변성을 어긴다** (판정 필요)

- 계약(D6)은 `r ← round(r + p·Δt/m)`, 반올림은 짝수 쪽(ties-to-even). p·Δt/m이 **정확히 반 칸**이면 결과가 **r(원시 정수)의 홀짝**을 따른다.
- 동점은 도달 가능하다: 1/m = 5485799090441 / 399623831237000000(서로소)이므로 Δt = 40, 소수 48비트에서 운동량 성분이
  **4995297890462500 × 2⁻⁴⁸ ≈ 17.7469 a.u.의 홀수 배**이면 동점(Δt = 20이면 35.49, Δt = 10이면 70.99 a.u.). 17.75 a.u.는 **검증 범위 안**
  (E ≤ 10Dₑ에서 |p| ≤ 약 18 a.u.).
- 실제 한 걸음: 이 운동량으로 drift하는 두 원자 상태를 홀수 raw 단위(2⁻⁴⁸ bohr)만큼 옮기면 **상대 위치가 1 raw 단위 달라진다** — D10-A 위반.
  `strict xfail`로 기록(`test_translation_invariance_survives_exact_drift_ties`), 도달 가능성은 통과 시험으로 고정.
- 지금까지 FX 평행이동 시험이 통과한 것은 **동점이 우연히 없었기 때문**이다(홀수 raw 이동을 썼는데도).
- 원인은 수 형식이 아니라 **반올림 지점의 정의**다. 가능한 수정(판정 아님): **변위를 반올림** `r ← r + round(p·Δt/m)` — r이 정수 격자이므로 동점이 아닐
  때는 지금과 완전히 같은 비트이고, 동점에서도 결과가 r에 의존하지 않는다. (Physics IR 요구사항 7.3의 "quantization 지점"에 동점 규칙까지 포함해야 한다는 사례.)
- 운동량 킥 `p ± J`는 두 값이 같은 격자라 **정확한 덧셈**(반올림 없음)이므로 이 문제가 없다.

### 9.5 설계자에게 묻는 것

1. **위치 FX(96,48) + 운동량 FX(64,48) 동결 여부** — 정밀도·불변성(동점 제외)·범위·비용 모두 측정됨(9.2·9.3).
2. **drift 동점 규칙(9.4):** `round(r + x)` 유지(동점에서 D10-A 위반 인정) / `r + round(x)`로 수정 / 다른 동점 규칙.
3. **적분기 범위 경계(9.1):** "E ≤ 10Dₑ" 엄격(검증 격자 5점이 경계 밖) / 선언된 여유.

## 10. 설계자 14판 — drift 의미 수정·경계 재구성·C1-B1 profile 동결 (2026-09-26)

### 10.1 판정

1. 위치 FX(96,48) + 운동량 FX(64,48) **채택**, 단 **"C1-B1 기준 profile"로만 동결**(±2⁴⁷ bohr ≈ ±7.4 km — A 전체의 영구 좌표 형식 아님).
2. drift를 **`δr = round_pos(p·Δt/m)`, `r' = r + δr`**로. 절대 위치를 포함해 `round(r + x)`를 하면 정확한 반 칸에서 평행이동·부호 대칭을 동시에
   만족하는 결정적 동점 규칙이 존재할 수 없고(짝수 쪽은 평행이동을 희생), 두 격자 위치가 같은 위치로 반올림돼 비가역일 수 있다. `r + round(x)`는
   고정된 p에서 격자 위 정수 이동이라 역연산이 명확하고 KDK 시간대칭과 맞는다. 동점이 아니면 기존과 비트 동일.
3. `E ≤ 10Dₑ` **여유 없이 엄격 유지** — tolerance를 넣지 않는다. 고칠 것은 계약 경계가 아니라 **시험 입력**.
4. 위치 덧셈 overflow는 wrap·saturate 없이 `executor_limit_exceeded`. domain guard는 반올림 전 정확한 경로 + 저장 위치 둘 다 검사 유지.

순서: drift 의미 수정 → 동점·가역성 시험 → 10Dₑ 경계 7개 재구성·재측정 → typed 120회 재검증 → 전체 회귀 → C1-B1 한정 동결 → B0.

### 10.3 설계자 14판 추가 판정 — 동결 보류, drift 세 방식 비교 (2026-09-26)

v2(`r + round(p·Δt/m)`)는 **임시 기본값**으로 유지(되돌리지 않음, 최종 계약 아님). 좌표의 이산성은 물리가 아니라 저장 정밀도이며, 공간 자체를
격자로 정의하지 않는다(물리는 상대 위치·거리로). 따라서 drift 규칙은 "연속 운동을 유한 좌표에 투영하는 수치 알고리즘 선택"이고, 세 방식을
같은 조건에서 비교한 뒤 drift와 위치 profile을 함께 판정한다:
① v1 `round(r + p·Δt/m)` ② v2 `r + round(p·Δt/m)` ③ 정확·잔여 drift(이동 잔여를 정확히 보존 = 더 미세한 위치 격자로 drift 반올림 제거).
측정: 기준해 대비 산란각·체류시간·결합 주기·에너지, Δt 10/20/40 수렴, 평행이동·교환·90° 회전, 정방향→운동량 반전→역방향 가역성, exact tie,
매우 느린 입자의 stall·누적 이동, 장시간 위치·에너지 오차 누적, CPU/GPU 상태 갱신 비용, R²·힘 평가 포함 한 걸음 비용, 위치 표현 실제 비트 폭,
다종 species·Δt 변경 시 필요한 정밀도 증가, local frame을 격자 정렬 offset만큼 바꿨을 때 완전 동일성.
판정 우선순위: **물리적 정확성·불변성 → 장기 안정성 → 일반화 가능성 → 비용**(앞 조건을 희생하면 싸도 탈락). ③은 정확하다는 이유만으로
채택하지 않는다 — 여러 질량·Δt에서 위치 격자가 얼마나 세분화되는지 수치로 보인다.
