# 문법 v3 + 탐침 계약 동결 (2026-09-24)

> **G12 세계를 설계하는 사람은 이 문서를 읽지 않는다.** 여기에는 문법 v3가 무엇을 말할 수 있고 무엇을 못 말하는지가
> 적혀 있다. 이걸 알고 세계를 만들면 "문법을 모르는 설계자"라는 조건이 깨진다.

## 왜 동결하나

G12는 B가 한 번도 본 적 없는 세계에서 B의 연구 방법을 시험한다. 이 시험이 의미 있으려면 **세계가 생기기 전에
방법이 고정돼 있어야 한다.** 그렇지 않으면 결과를 본 뒤 방법을 조금씩 고쳐 답에 맞출 수 있다(검증 한계 문서 유형 C).

## 동결된 것

`tests/test_probe_v3_freeze.py`가 파일 내용의 지문(sha256, 줄바꿈 정규화)을 고정한다.

| 묶음 | 파일 | 뜻 |
|---|---|---|
| B의 방법 | `probe_grammar.py` | 말할 수 있는 문장(효과 주장), `GRAMMAR_DIGEST` 7aff4cd7… |
| | `probe_induction.py` | 본 것 → 주장, 반박 → 조건 찾기(없음→하나→둘→설명 불가) |
| | `probe_planning.py` | 자기 주장으로 반박 실험 설계(충분성·필요성, 준비 동작 ≤3) |
| | `probe_research.py` | 탐색 → 봉인된 시험 → 호기심 순서 → 전체 검증 → 반박 실험 → 최종 봉인 |
| 탐침 계약 | `blind_probe.py` | B가 듣는 것(격자 크기·wrap·행동 기호와 인자 개수·방향 기호·채널 기호·최대 길이)과 보는 것(매 tick 탐침 상태 + 0 아닌 칸 값) |
| | `blind_probe_evaluator.py` | 실제 이름 → 중립 기호 번역(seed마다 섞음) |
| | `probe_world.py` | 탐침의 몸: 원시 동작 5개 MOVE/GRASP/RELEASE/HEAT/WAIT |

**테스트가 깨지면 지문을 고쳐서 통과시키지 않는다.** 방법이나 계약을 바꾸려면 새 파일로 새 버전(v3.1 / 계약 v2)을
만들고 설계자가 결정한다. G12 결과는 실행된 버전과 함께 보고한다.

**동결되지 않은 것:** 환경 세계의 법칙(`environment_kernel`, 세계 JSON)은 G12 설계자가 새로 쓸 수 있다. 공유
기반(`research_journal`, `blind_protocol`, `sealed_execution`, `execution`)은 이벤트 추가 같은 하위 호환 변경만 허용.

## 동결 직전 정리한 경계 (지문 계산 전에 반영)

`probe_research`의 import 사슬이 **A의 입자 커널**(`causal_kernel`)까지 닿고 있었다. B 코드가 부른 적은 없지만 닿을 수는
있었다. 두 경로 모두 "B는 인터페이스 하나만 필요했는데 그 인터페이스가 실제 구현과 같은 파일에 있었다"는 같은 원인이다.

- `causal_executor` → `AExecutor`/`ExecutionResult`를 `execution.py`로 분리
- `research_loop`(물리 세계 연구 루프) → `seal_predictions`/`execute_through_a`를 `sealed_execution.py`로 분리

기존 import는 재수출로 그대로 동작한다. 경계 테스트 금지 목록에 `causal_kernel`, `kernel`, `physical_research_adapter` 추가.

**남은 것(공개):** `causal_spec`/`spec`(세계 **기술 형식** — 물리 계산 코드 아님)은 여전히 닿는다. `PredictionSeal`이
있는 `causal_experiment.py`가 그것을 import하기 때문이다. 또 `engine/deterministic/__init__.py`가 패키지의 거의 모든
모듈을 불러오므로, **실행 시에는** 모듈들이 메모리에 올라와 있다. 경계 테스트가 보장하는 것은 "B의 코드가 그 모듈을
참조하지 않는다"(소스 의존성)이지 "파이썬 프로세스에 그 모듈이 없다"가 아니다.

## 알려진 한계 (G12 전에 이미 아는 것)

- 세계 자체의 흐름(물·열 확산)은 문법 밖 — 흐르는 세계에서는 탐침 효과와 세계 변화가 섞인다(v3.1 몫).
- 조건은 이웃 3×3 칸과 자기 상태의 `>= 1`/`= 0`만. 거리 2 이상, 수량 비교, 과거 이력은 말할 수 없다.
- 반박 실험 설계는 준비 동작 3단계까지만 찾는다.
- 한 번에 한 프로그램(레시피). 실시간 제어 없음.

이 한계에 걸리는 세계에서 B가 "설명 불가"를 내면 **정직한 실패**이고, 틀린 "지지됨"을 내면 **방법의 결함**이다.
G12의 채점은 이 둘을 구별해야 한다.
