# causal v5 에너지 v1 (S4) — 설계

**상태:** **승인 (2026-09-24).** E1·E4·E5·E6·E8 승인, E2 수식 승인 + 소유권 수정, E3 구조 내부 에너지 승인,
E7 v5 한정 승인 + 각운동량 잔차 감사. 설계자 검토 6개 항목 반영(7절). 다음: v5 명세 형식 → 기준 실행기.
**선행:** `A_MICRO_V5_KINEMATICS_TIME_V1.md` K1(연속 시간)·K2(정확한 유리수)·K3(v5 정사각형).
**범위:** v5 v1 = 입자만의 세계, 결합 생성(CREATE)·성장(GROW)·**구조끼리 병합(MERGE — 2026-09-24 GEO v1B D1로 추가 승인)**, 절단 없음(GEO G4), 회전 없음, 환경 field 결합 없음.

---

## 0. 결론 먼저

> 운동 에너지는 진짜 `½ m |v|²`이고 정확한 유리수다. 결합할 때 잃는 운동 에너지는 두 몸의 **상대 운동 에너지**
> `½ μ |Δv|²`(μ = 환산 질량)이고, 합쳐진 **구조의 내부 에너지**로 간다. 결합 문턱도 같은 양과 비교한다.
> 에너지는 정확히 보존되고, 화학이 관찰자의 좌표계에 의존하지 않는다.
> **내부 에너지는 결합이 아니라 구조가 가진다.** 결합별로 나누는 법칙이 없기 때문이다.

---

## 1. 에너지의 종류 — v5 v1에는 두 가지뿐

| 종류 | 누가 가지나 | 값 |
|---|---|---|
| 운동 에너지 `K` | 구조 (자유 입자 = 멤버 하나인 구조) | `K = |P|² / (2M)` — **운동량과 질량에서 유도, 저장하지 않는다** |
| 내부 에너지 `U` | **구조** (결합이 아님) | 상태로 저장. 자유 입자는 `U = 0`으로 시작 |

**v5 구조의 물리 상태:**

```
Structure
    members           멤버 요소들
    bonds             멤버 사이 결합 (관계만 — 에너지를 갖지 않는다)
    momentum          P (유리수 벡터)
    internal_energy   U (유리수, ≥ 0)
    (mass M은 멤버에서 유도)
```

v4의 `PortBond.stored_energy`(결합이 에너지를 가짐)는 **v5에서 쓰지 않는다.** v4는 그대로 동결.

**A-V4.B와의 관계 — Q2 딜레마가 풀린다.** `STRUCTURE_STATE_V1` Q2는 "운동량만으로 에너지를 복원할 수 없다"(+3/−1과
+2/0이 같은 운동량, 다른 에너지)는 이유로 운동 에너지를 따로 저장했다. v5에서는 그 차이가 어디로 갔는지가 명시된다:
멤버들이 서로에 대해 가지던 상대 운동 에너지는 결합 순간 구조의 내부 에너지 `U`로 옮겨진다. 그래서 구조의 운동 에너지는
정확히 `|P|²/2M`(평행 이동 에너지)이고 유도 가능하므로 저장하지 않는다.

v4의 "에너지가 속도와 무관하다" 문제(공간 v2 0절)는 v5에서 없다: 속도 = 운동량/질량이고 에너지는 속도에서 나온다.

## 2. 결합할 때의 회계 (CREATE / GROW) — 병합 보존식

한 순간에 서로 결합하는 구조들 `i = 1..n`(두 몸이면 n = 2; 여럿이면 운동학 K4의 충돌 그래프로 서로 독립임이 확인된 경우)이
하나의 구조로 합쳐질 때:

```
P' = Σ Pᵢ                                        운동량 — 정확히 보존
M' = Σ Mᵢ
K' = |P'|² / (2M')                               합쳐진 구조의 운동 에너지

U' = Σ Uᵢ + Σ Kᵢ − K'                             ← 병합 보존식 (내부 에너지)
```

**기존 내부 에너지 `Σ Uᵢ`도 반드시 넘어간다.** 빠뜨리면 이미 내부 에너지를 가진 구조가 입자를 붙일 때마다 그 에너지가
증발한다. 이 식 하나가 GROW를 여러 번 반복해도 에너지 장부가 끊기지 않게 만든다.

두 몸일 때 새로 흡수되는 양은 항등식으로

```
ΔU = K_A + K_B − K' = ½ · μ · |v_A − v_B|²       μ = M_A·M_B / (M_A + M_B)
```

이고 항상 0 이상이다 — 결합으로 에너지가 생기지 않는다.

**여러 결합이 한 순간에 생길 때(E3):** 흡수된 에너지 총량은 위 식으로 정확하지만, 그것을 결합별로 나누는 법칙은 없다
(둘씩 차례로 계산하면 순서에 따라 몫이 달라진다 — 원칙 2 위반). 그래서 **나누지 않는다.** 합쳐진 구조의 `U` 하나로 둔다.

**사건 기록 (역사, 물리 상태 아님):** 결합 사건마다 흡수된 운동 에너지를 기록할 수 있다.

```
BondFormationEvent
    time, participants, faces
    kinetic_energy_absorbed      = Σ Kᵢ − K'
    angular_momentum_residual    (5절, 감사용)
```

이것은 **과정 보존용 기록**이고, 이후 물리를 결정하는 값이 아니다. "이 에너지 중 3/7은 왼쪽 결합 소유" 같은 존재하지 않는
법칙을 발명하지 않으면서도 과정은 남긴다.

## 3. 결합 문턱 — 좌표계에 의존하면 안 된다

v4 규칙의 `minimum_collision_energy`는 **두 입자 운동 에너지의 합**과 비교했다. v5에서 그대로 쓰면:

```
정지한 입자 둘이 1의 속도로 다가옴       → 합 에너지 작음 → 결합 안 됨
같은 두 입자가 모두 +100으로 함께 날아감  → 합 에너지 큼  → 결합 됨
```

둘은 **같은 충돌**이다(갈릴레이 변환). 화학이 "세계 전체가 얼마나 빨리 날아가나"에 달라지면 안 된다.

→ 문턱은 **상대 운동 에너지 `½ μ |Δv|²`** 와 비교한다. 좌표계와 무관하고, 정확히 결합이 흡수할 에너지와 같다.

**문턱의 의미 (명시, 설계자 결정):** v5의 결합 문턱은 **법선 방향 충격 에너지의 문턱이 아니라, 결합 시 구조가 흡수해야 하는
전체 상대 운동 에너지의 문턱**이다. 따라서 면 방향으로는 아주 천천히 다가오지만 면을 따라 빠르게 미끄러지는 두 몸도 문턱을
넘을 수 있다. 버그가 아니라 이 선택의 물리적 결과다. **테스트:** 법선 속도는 고정하고 접선 속도만 바꿨을 때 문턱 통과 여부가
이 정의대로 바뀌는지 확인한다.

**갈릴레이 불변 검사 (운동학 Q8 표에 추가):** 모든 몸에 같은 속도 u를 더한 세계는 **같은 사건이 같은 시각에** 일어나고,
위치만 `u × 시각`만큼 옮겨진다. **범위: 외부 고정장·고정 경계가 없는 v5 입자 세계.** 벽·고정 물체·외부장이 생기면 그것이
좌표계를 정하므로 이 검사는 그대로 적용되지 않는다(그때 다시 정한다).

## 4. 접촉 방향과 에너지

정사각형이 면으로 닿으려면 그 면 방향으로 **서로 다가오는 중**이어야 한다(법선 상대 속도 > 0). 면을 따라 미끄러지는 성분
(접선 상대 속도)은 접촉을 만들지 않지만, 결합이 일어나면 v5에서 두 몸은 **하나의 비회전 강체로 같은 속도**가 되므로 접선
상대 운동도 사라진다 — 그 에너지도 `ΔU`에 포함되어 내부 에너지로 간다.

## 5. 정직하게 — v1이 보존하지 않는 것

**각운동량.** v1은 회전 자유도가 없다. 결합 면이 질량 중심에서 벗어나 있으면 현실에서는 일부가 회전 운동으로 남는다.
정확히 말하면: **현실에서 일부가 회전 운동으로 남을 수 있는 상대 병진 운동 에너지까지, v5에서는 회전 자유도가 없기 때문에
내부 에너지로 기록된다.** 각운동량은 보존되지 않는다.

**측정한다 (감사용, 물리에 되먹이지 않음):** 결합 사건마다

```
angular_momentum_residual = L_before − L_after
```

(원점 기준 z 성분, 정확한 유리수)을 계산해 사건 기록에 남긴다. 회전을 열 때 "기존 세계에서 각운동량 무시가 얼마나 컸는가"를
이 기록으로 알 수 있다. 에너지와 운동량은 정확히 보존되지만 각운동량은 아니라는 사실을 문서·감사에 명시한다.

**열(환경 field)과의 교환 없음.** 내부 에너지 `U`는 사실상 구조의 "뜨거움"이지만 v1에서는 밖으로 나가지 않는다. 절단(GEO v2)과
환경 결합이 열리기 전까지 에너지는 운동 → 내부로 한 방향으로만 흐른다. **이 상태로 평형·순환·촉매를 주장하지 않는다.**

**분모 증가.** `½`와 `μ`가 분모에 새 인수를 넣는다. K2 결정대로 측정 항목에 에너지와 각운동량 잔차도 포함한다.

**절단 설계 때 다시 볼 것:** 내부 에너지가 구조 전체의 것이므로, 결합이 끊길 때 "얼마가 어느 조각으로 가나"를 GEO v2에서
정해야 한다. 결합별 에너지가 없다는 것은 그때 **새 법칙을 선언해야 한다**는 뜻이지, 기록에서 역산해도 된다는 뜻이 아니다.

## 6. 단위

세계가 질량·길이·시간 단위를 선언하면(신체 계약 9.1, `physical_scale.py`) 에너지 단위는 `질량 × 길이² / 시간²`로 유도된다.
결합 규칙의 문턱도 이 단위로 적는다. v5 세계 명세는 단위 선언을 **필수**로 한다.
