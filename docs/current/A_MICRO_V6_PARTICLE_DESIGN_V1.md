# A-MICRO v6 심화 설계 v1 — 입자와 국소 상호작용에서 무엇이 나오나

**상태:** 초안 (2026-09-24). **설계자 검토 전 — 코드 없음, 수 표현 미정.**
**상위:** `A_V6_DEFORMABLE_MATERIAL_ARCHITECTURE_V1.md`(V0·V1 승인: MICRO 먼저, "구성 입자 + 유한 거리 상호작용").
**질문 (설계자):** 정사각형·포트·강체를 전제하지 않고 — **입자에 어떤 최소 상태와 국소 상호작용이 있으면 형상·충돌·회전·변형·결합이
결과로 나오는가?**

---

## 0. 결론 먼저

> 입자의 물리 상태는 **질량·종류·위치·속도**뿐이다. 입자끼리는 **거리(와 필요하면 세 입자가 이루는 각도)에만 의존하는 퍼텐셜**로
> 힘을 주고받는다. 그러면 형상·충돌·회전·변형은 **자동으로** 결과가 된다. **결합**을 따로 기억되는 상태로 둘지, 퍼텐셜의 결과로 둘지가
> 이 설계의 가장 큰 결정이다(M-A). 결과로 두면 v5의 결합 규칙·포트·문턱이 전부 사라지고, 결합 에너지·끊어짐·열이 한 법칙에서 나온다.

## 1. 무엇이 무엇에서 나오나 — v5의 예외들이 어떻게 사라지나

| 현상 | v5에서 | v6에서 (입자 + 퍼텐셜) |
|---|---|---|
| **형상** | 정사각형(선언) | 입자 배치의 결과. 모서리라는 개념이 없다 |
| **충돌** | 사건: 접촉 시각 계산, 탄성 공식, 토크 판정, 모서리·요람 중단 | 사건이 아님: 가까워지면 **밀어내는 힘**이 연속으로 커지고, 적분이 결과를 낸다. 반발 계수·접촉 법선을 정할 필요가 없다 |
| **중심 벗어난 충돌** | 중단(R3, 2D 61/64) | 입자 무리가 비스듬히 밀리면 **돌기 시작한다** — 각운동량은 중심력(두 입자를 잇는 방향의 힘)이면 저절로 보존 |
| **뉴턴 요람** | 중단(R6) | 힘이 유한 강성의 퍼텐셜을 따라 **유한 시간에** 전달 — 순서를 정할 필요 없음 |
| **변형** | 없음(강체) | 결합 길이·각도가 늘고 줄어드는 것 |
| **열 / 내부 에너지** | 구조의 `U` 한 숫자, `e < 1`은 나눌 법칙이 없어 금지 | **입자들의 진동(운동 + 퍼텐셜 에너지)** 자체. 비탄성 충돌은 에너지가 실제로 진동으로 옮겨가는 것 — 나누는 규칙이 필요 없다 |
| **결합** | 규칙 표(종류·면·문턱) | M-A 결정에 따라: 퍼텐셜 우물에 갇힌 상태(결과) 또는 기억되는 위상(상태) |
| **끊어짐 (GEO v2)** | 설계 전 | 진동 에너지가 우물 깊이를 넘으면 떨어져 나감 — 같은 퍼텐셜의 결과 |

**v5에서 멈추던 것 중 v6에서 정의 문제로 남는 것은 거의 없다.** 대신 새로 정해야 할 것은 **퍼텐셜의 모양과 매개변수**, 그리고
그것의 현실 근거다.

## 2. 최소 물리 상태

```
Particle (물리 상태)
    mass        질량 (종류에서 올 수도 있음)
    species     종류 → 명세의 상호작용 매개변수 (이름이 아니라 값)
    position
    velocity
```

**유도량:** 힘(퍼텐셜의 기울기), 퍼텐셜 에너지, 온도(운동 에너지 분포에서), 구조 묶음(4절), 질량 중심·각운동량.
**수치 상태:** 이웃 목록, 힘 캐시 — 지우고 다시 만들어도 같아야 한다(M0).
**입자에 방향(orientation)을 두지 않는다** — 점입자. 분자의 회전은 입자 배치의 회전으로 나온다. (방향을 가진 입자 = "patchy particle"은
방향·각속도·관성 모멘트를 물리 상태로 추가해야 해서 더 무겁다. 필요해지면 그때.)

## 3. 상호작용 — 결정 M-B

| 등급 | 무엇 | 나오는 것 | 못 나오는 것 |
|---|---|---|---|
| **쌍 퍼텐셜** (두 입자 거리만) | 가까우면 밀고 조금 멀면 당김 (Lennard-Jones 모양) | 충돌, 뭉침, 결정·액체·기체 같은 상, 회전, 변형, 열 | **원자가(결합 수 제한)와 결합 각도** — 뭉치기만 하고 "분자"가 따로 안 생김 |
| **+ 세 입자 각도 항** | 결합 각도에 선호가 생김 (Stillinger–Weber 계열) | 위 전부 + 방향성 있는 결합, 사슬·고리 같은 모양 | 결합 수 포화가 약함 |
| **결합 차수 퍼텐셜** | 결합 세기가 주변 이웃 수에 따라 약해짐 (Tersoff / ReaxFF 계열 축약) | 위 전부 + **원자가 포화**가 결과로, 결합이 생기고 끊어지는 것이 연속적 | 계산이 무겁고 매개변수가 많다 |

**권고:** 쌍 퍼텐셜로 시작해 교과서 검증(6절)을 통과시킨 뒤, 세 입자 각도 항을 더한다. 결합 차수는 화학 반응성이 실제로 필요해질 때.
**근거 등급:** 퍼텐셜은 **근사(유효 모델)**다 — 실제 결합은 양자역학이 정하고, 고전 퍼텐셜은 그 요약이다. 매개변수를 실제 원자 값으로
맞추면 등급이 "실험 보정"으로 올라간다. 지금 v6의 첫 세계들은 추상 매개변수 = **시험 세계**.
**설계자 6판(2026-09-25):** `species`는 **실제 원자종을 표현할 수 있는 구조**로 유지한다(Ar 전용 입자로 정의하지 않음). C0는 합성 퍼텐셜로
역학만 검증하고, C1에서 첫 현실 검증 종 **Ar**을 실제 Ar–Ar 퍼텐셜로 넣는다(C0 수치 계획 11.4).

모든 힘은 **퍼텐셜 에너지의 기울기**에서 나온다 — 그래야 에너지 보존이 법칙의 구조로 보장된다(힘을 따로 규칙으로 쓰지 않는다).

## 4. 결합은 상태인가 결과인가 — 결정 M-A (가장 중요)

| | (A1) 결합 = 결과 | (A2) 결합 = 기억되는 위상 |
|---|---|---|
| 무엇 | 결합 목록이 없다. 입자들이 퍼텐셜 우물에 갇혀 있으면 그것이 결합이다 | 결합 목록을 상태로 둔다(고전 분자 역장처럼). 결합된 쌍에만 결합 퍼텐셜 |
| 결합이 생김·끊어짐 | 에너지의 결과 — 규칙 없음 | 별도 규칙이 필요(언제 목록에 넣고 빼나) → v5의 규칙 표가 돌아옴 |
| 구조(분자)의 정체성 | **관찰자의 정의** — "이 거리/에너지 기준으로 묶인 것"을 유도량으로 계산 | 결합 그래프의 연결 성분(v5와 같음) |
| 화학 | 결합 차수 퍼텐셜이면 반응이 연속적으로 나옴 | 반응 규칙을 사람이 적어야 함 |
| 현실 근거 | 실제 결합도 상태로 저장되는 것이 아니라 전자 배치의 결과 | 계산 편의 |

**권고: A1(결합 = 결과).** "미시가 진실, 나머지는 유도"와 "현상을 만들려고 규칙을 더하지 않는다"에 맞는다. **대가:** 구조(분자)가 무엇인지는
관찰자가 거리·에너지 기준으로 정하는 유도량이 된다 — 그 기준은 물리가 아니라 관측 도구이므로 설정·기록하고, 기준을 바꿔도 **세계는 같다**.

## 5. 공간·시간·수치

| 결정 | 선택지 | 권고 |
|---|---|---|
| **M-C 차원** | 2D / 3D | 현실 근거 원칙은 3D를 요구한다(2D 화학은 현실과 다르다). 비용 때문에 **2D로 검증을 시작하되 "근사, 3D로 가야 함"을 선언**, 규모 다리 전에 3D |
| **M-D 경계** | 경계 없는 평면 / 주기 경계(상자) / 벽 | 주기 경계 권고 — 입자가 흩어지지 않아 만남이 계속되고(v5 측정에서 흩어짐이 문제), 갈릴레이 불변도 유지. 벽은 좌표계를 정해 버린다 |
| **M-E 시간 적분** | — | 알고리즘은 나중. **요구 조건:** 시간 대칭·심플렉틱(장기 에너지 거동이 안정), 이산화 = 시간 간격 → 수렴 검증(두 종류, 상위 문서 5.2) |
| **M-F 수 표현** | 상위 문서 5.1 계약 | 참고: 쌍 힘을 한 번 계산해 두 입자에 ±로 똑같이 주고(작용-반작용), **합산을 정수로 정확히** 하면 운동량 보존이 비트 단위로 정확하고 합산 순서가 결과를 바꾸지 않는다 — 재명명 불변성이 비트 수준에서 성립. 이것은 고정소수점 쪽의 강한 근거가 되지만, 계약 비교 뒤에 결정 |

**v5와의 다리:** 밀어내는 힘을 아주 가파르게 하면 v6의 두 입자 충돌은 v5의 완전 탄성 충돌에 수렴해야 한다 — v5가 v6의 극한 검증 기준이 된다.

## 6. 검증 — 교과서 값부터 (M1~M3의 MICRO판)

| 검증 | 기대값 |
|---|---|
| 두 입자 정면 충돌 (밀어냄만) | 가파른 극한에서 v5 탄성 결과 |
| 두 입자 결합 진동 | 조화 근사에서 진동 주기 `2π√(μ/k)` |
| 에너지 | 에너지 균형 잔차가 시간 간격을 줄이면 줄어듦 (± 모두 기록) |
| 운동량·각운동량 | 운동량 정확(작용-반작용), 각운동량 보존(중심력) |
| 재명명·입력 순서 | 비트 동일 (정규 축약) |
| 많은 입자 기체 | 속도 분포가 맥스웰–볼츠만으로 (관측량 수렴 — 긴 시간) |
| 입자 격자에서 파동 | 충격이 유한 속도로 전달, 격자 매개변수에서 계산한 음속과 맞음 (요람의 MICRO판) |
| 비스듬한 충돌 | 무리가 회전 — 각운동량 측정 |
| 결합 끊어짐 | 진동 에너지가 우물 깊이를 넘을 때만 |

## 7. 결정할 것

| | 질문 | 권고 |
|---|---|---|
| **M-A** | 결합 = 결과(퍼텐셜 우물) / 기억되는 위상 | **결과** — 규칙 표가 사라지고 결합·끊어짐·열이 한 법칙에서 나옴. 구조의 정체성은 관찰자의 유도량 |
| **M-B** | 상호작용 등급 | 쌍 퍼텐셜로 시작 → 세 입자 각도 항 → (필요 시) 결합 차수 |
| **M-C** | 차원 | 2D로 검증 시작, 근사로 선언, 규모 다리 전 3D |
| **M-D** | 경계 | 주기 경계 |
| **M-E** | 시간 적분 요구 조건 | 시간 대칭·심플렉틱, 수렴 검증 |
| **M-F** | 수 표현 | 계약(상위 5.1) 비교 뒤. 정수 합산의 결합 법칙 성질은 참고 |

**정직하게 — 잃는 것:** v5의 **정확성**(모든 값이 분수로 정확), **사건 단위의 명료함**(접촉·결합이 정확한 시각의 사건), **결합 규칙으로
화학을 직접 설계하는 능력**. 얻는 것: 모서리·요람·중심 벗어남·`e < 1` 분배·끊어짐 규칙이 **정의 문제에서 사라진다** — 퍼텐셜 하나가
정해지면 나머지는 결과다. 새로 떠안는 것: 수치 오차(수렴으로 관리), 퍼텐셜 매개변수의 현실 근거, 계산량(입자 수 × 시간 간격).
