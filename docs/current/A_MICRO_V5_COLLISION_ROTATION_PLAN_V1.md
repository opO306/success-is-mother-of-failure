## 1. C0 — 접촉의 분류 (측정한 사실부터)

**축 정렬 정사각형끼리는 접촉 모양이 두 가지뿐이다:**

| 접촉 | 모양 | v5에서 |
|---|---|---|
| 면-면 | 선분 (겹치는 길이 `w − |d⊥|` > 0) | 결합 규칙이 맞으면 결합, 아니면 **지금은 중단** |
| 모서리-모서리 | 점 | **지금은 중단** |

**모서리-면**(한 몸의 꼭짓점이 다른 몸의 면 안쪽을 찌르는 것)은 **회전이 있어야만 생긴다.** 두 정사각형이 같은 방향으로 놓여 있으면
꼭짓점이 상대 면 안쪽에 먼저 닿는 일은 없다.

**자리 찬 면, 문턱 미달, 규칙 없음은 "결합 실패"이지 "접촉이 없음"이 아니다.** 면-면 접촉은 일어났고, 결합만 안 된 것이다.
그러니 그 접촉의 물리(되튕김)가 필요하다.

**동시 접촉:** (a) 두 강체 구조가 한 순간 여러 쌍으로 닿음 — 한 몸끼리의 여러 접촉점 / (b) 여러 몸이 한 순간 서로 이어 닿음.

## 1.1 접촉과 결과를 분리한다 (설계자, 2026-09-24)

"결합하지 않는 면-면 접촉 = 반드시 튕김"이 아니다. 접촉은 "두 물체가 만났다"는 사건일 뿐이고, 그 뒤 결과는 여러 갈래일 수 있다 —
결합, 탄성 충돌, 비탄성 충돌, 흡수(한 구조가 다른 구조의 일부·전부를 제 구조로), 파괴·침식, 화학 반응. (소멸은 보존량이 어디로
갔는지 정하는 법칙 없이는 불가.) 그래서 구조는:

```
접촉 → 세계 법칙이 허용하는 과정(결합·흡수·반응·파괴 ...)이 있으면 그것 → 아무 과정도 없을 때 → 충돌 처리
```

지금 v5에 있는 과정은 **결합**뿐이다. C1은 "허용된 과정이 없을 때의 충돌"의 가장 단순한 경우다. 포식 같은 것은 한 사건이 아니라
접촉 → 반응 판정 → 결합 절단 → 물질 이동 → 새 결합 → 에너지 회계의 연쇄라서, 충돌 규칙에 바로 넣지 않는다.

## 2. C1 — 현실 근거가 분명한 충돌부터: 면-면, 마찰 없음, 회전 없는 강체

**제안:** 허용된 과정(지금은 결합)이 없는 면-면 접촉은 **면에 수직인 방향의 충격**으로 두 구조의 운동량을 주고받는다. 두 구조는 따로 남는다.

```
법선 n = 접촉 면의 축 (x 또는 y), 상대 속도의 법선 성분 v_n
J = (1 + e) · μ · v_n            μ = M_A M_B / (M_A + M_B)
P_A' = P_A + J n,  P_B' = P_B − J n        접선 성분은 그대로 (마찰 없음)
```

법선이 축과 나란하므로(정사각형의 이점, K3) 전부 **정확한 유리수**다. 운동량은 정확히 보존되고, 갈릴레이 불변이다(상대 속도만 씀).

**각 부분의 근거 등급** (`A_REALITY_GROUNDING_V1.md` 4절):

| 부분 | 등급 | 비고 |
|---|---|---|
| 충격이 운동량을 주고받음, 총 운동량 보존 | **근본** | |
| 법선 방향 충격, 접선은 그대로 | **근사** | 마찰 없는 접촉. 마찰은 계수가 필요하고 토크를 만든다(3절) |
| 반발 계수 `e` | **실험(재료값)** — 지금 v5 재료는 추상이라 **근거 없음** | 현실 재료는 측정값이 있다 |
| 회전 없음 | **근사** | 중심을 벗어난 충돌의 토크를 버림(3.1) |

### 2.1 결정해야 할 것: 반발 계수와 잃은 에너지의 행방

- `e = 1` (완전 탄성): 운동 에너지 보존, **잃는 에너지가 없어 나눌 것도 없다.** 이상화지만 규칙을 새로 만들 필요가 없다.
- `e < 1` (현실 재료): 잃은 운동 에너지 `½ μ (1 − e²) v_n²`가 **두 개의 따로 남는 구조**의 내부 에너지로 가야 한다. 그런데 **어느 쪽이
  얼마를 받는지는 물리 법칙이 없다** — 현실에서는 두 재료의 변형·열 성질에 달렸고, 기본 법칙 하나로 나오지 않는다(E3에서 결합별
  분배를 거부한 것과 같은 문제). 반씩·질량비 같은 분배는 근거 없는 규칙이다.

**권고:** C1은 **`e = 1`만** 연다(등급: 근사). `e < 1`은 열(내부 에너지 교환) 모형이 생긴 뒤에 다룬다. 결합은 지금처럼 결합 규칙이
맞을 때만 일어난다(결합 = 완전 비탄성, 흡수는 합쳐진 한 구조로 가므로 분배 문제가 없다).

### 2.2 결정해야 할 것: 설계자의 S7 결정을 바꾼다

S7(2026-09-24): "결합하지 않는 접촉은 통과 금지 → 기록 + 중단". C1은 그중 **면-면**을 중단 대신 되튕김으로 바꾼다. 통과가 아니라
정의된 물리로 대체하는 것이므로 S7의 취지(구현 한계를 법칙으로 만들지 않는다)와 맞지만, **설계자 결정의 변경**이다.

## 3. C2 — 중심을 벗어난 충돌과 모서리: 따져 보니 벽이 두 개 있다

### 3.1 중심을 벗어난 면-면 충돌 (회전 없이)

접촉선이 구조의 질량 중심을 지나지 않으면 현실에서는 토크가 생겨 회전한다. 회전이 없는 v5에서 C1을 그대로 쓰면:
에너지(e = 1)·운동량은 정확히 보존되고, **각운동량만 보존되지 않는다.** 이것은 결합 병합(E7)에서 이미 받아들이고 감사로 재는
한계와 같은 종류다. 그리고 **강체의 평평한 면 접촉에서는 충격이 면의 어느 점에 작용하는지 자체가 정해지지 않는다**(정역학적
부정정) — 회전을 열면 이것부터 새로 정해야 한다.

→ **설계자 결정: (b) — 회전 모델 전까지 기록 + 중단.** (a)를 기각한 이유: 결합(E7)은 이미 "회전 자유도가 없는 단순화된 결합
모델"이라는 큰 근사를 안고 있지만, 평범한 비결합 충돌마다 중심을 벗어난 충격을 회전 없이 처리하면 **알고 있는 물리 위반이 A의
일상적인 운동 법칙으로 퍼진다.** "모르면 멈추고 기록한다"는 원칙에 (b)가 맞다.

**C1에서 "토크가 없다"의 정확한 판정:** 법선이 x축이면 두 구조의 질량 중심 y 좌표가 같고(충격선이 두 중심을 지남), 그 y가 이번
접촉(같은 두 구조 사이의 모든 접촉 선분)이 덮는 범위 안에 있을 때. 그 밖은 모두 중단.

### 3.2 벽 1 — 모서리-모서리는 현재 모델만으로 유일하게 결정되지 않는다

**정확한 표현 (설계자 수정):** 현재 v5가 가진 완전 강체 형상·상태 변수·충돌 법칙만으로는 모서리-모서리 충돌 뒤의 상태를
**유일하게 결정할 수 없다.** 날카로운 꼭짓점에서는 매끈한 곡면처럼 하나의 공통 법선이 저절로 정해지지 않고, 강체 충돌에는 추가적인
접촉·충격 법칙이 필요하다. 이것이 "현실 물리로 해결 불가능"하다는 뜻은 아니다 — 유연성(compliance), 변형, 법선 원뿔 기반의
비매끄러운 접촉 모델 같은 방법이 있다. 현실에 **완전히 날카로운 모서리는 없고**, 실제 모서리의 곡률과 변형이 방향을 정한다.

- 회전을 열어도 풀리지 않는다(꼭짓점의 법선은 여전히 정해지지 않음).
- "두 면 법선의 합(대각선)으로 튕긴다"는 정확한 유리수로 계산은 되지만 **근거가 없다** — 금지 대상.
- 근거 있게 닫으려면 **몸의 모양을 바꿔야 한다**(예: 모서리가 둥근 사각형). 그러면 둥근 모서리끼리 닿는 시각이 원과 원처럼
  제곱근이 되어 **K2(정확한 유리수)와 부딪힌다.**

→ 모서리-모서리는 **지금은 중단을 유지**하고 빈도를 계속 잰다. 닫으려면 K3(몸의 모양)를 다시 결정해야 한다.

### 3.3 벽 2 — 일반적인 연속 회전은 지금의 유리수 체계에 닫혀 있지 않다

회전을 열면 각도 `θ(t) = θ₀ + ωt`이고, 꼭짓점 위치에 `cos θ`, `sin θ`가 들어간다. **정확한 표현 (설계자 수정):** "cos·sin은
초월수라 불가능"은 일반 명제로 틀렸다 — `cos 0 = 1`, `cos(π/3) = 1/2` 같은 예외가 있다. 문제의 본질은:

> **일반적인 연속 회전에서 위치와 접촉 시각은 K2가 요구하는 정확한 유리수 집합 안에 닫혀 있지 않다.**

정확 계산 자체가 수학적으로 불가능한 것도 아니다(기호 표현, 더 큰 수 체계, 검증된 구간 계산). 다만 **지금 K2의 단순한 유리수 기준
실행기와는 맞지 않는다.**

가능한 길(모두 큰 결정):
- (i) 정확 계산을 버리고 근사 수치 적분 — 결정론·재현성(CPU/GPU 동일)은 정수 고정소수점으로 지킬 수 있지만, "정확"은 잃는다
- (ii) 각도를 90° 단위로만 — 회전을 허용하지만 연속 회전은 아님(현실 근거 약함)
- (iii) 회전 없이 가며 각운동량 잔차를 한계로 선언 (3.1 a)

→ **이 판정이 설계자가 요구한 "회전 필요성 판정"의 핵심 결과다.** 회전은 충돌 규칙 하나를 더하는 일이 아니라 수 체계의 결정이다.

## 4. 동시 접촉 — 뉴턴 요람 문제

**정확한 표현 (설계자 수정):** 순간적 강체 다중 충돌 모델에서는 쌍별 순차 처리의 순서가 결과를 바꿀 수 있어서, **추가적인 다중 충돌
법칙 없이는 유일한 결과를 정하면 안 된다.** 뉴턴 요람 자체가 어려운 게 아니라, 물체를 "절대 안 찌그러지는 강체"로 단순화해서
현실이 결과를 정하는 정보(탄성 변형, 몸을 지나가는 응력파)를 지워 버린 것이 문제다. 다중 충격 법칙이 별도 연구 분야로 있는 이유다.

→ K4 그대로: **몸을 공유하는 동시 충돌은 기록 + 중단.** 몸을 공유하지 않는 충돌들은 서로 독립이므로 함께 적용한다.
결합과 충돌이 같은 순간 같은 몸에 걸리면 역시 중단.

**정직하게:** C1만으로는 모서리 중단(측정 B의 73%)이 줄지 않는다. 줄어드는 것은 **자리 찬 면·문턱 미달·규칙 없음**으로 인한 중단이다.
모서리는 몸의 모양(K3)과 수 체계(K2)를 다시 결정해야 풀린다 — 이 문서가 그 결정이 필요하다는 것을 처음으로 명시한다.

## 8. 장기 방향 — 형상은 근본 속성이 아니다 (설계자·sol, 2026-09-24)

**모서리 문제와 뉴턴 요람 문제는 같은 원인을 가리킨다: 물체를 "변형되지 않는 수학적 도형"으로 둔 것이 너무 강한 이상화였다.**
현실 물체는 부딪히면 조금 변형되고, 그 변형이 응력파로 몸 안을 지나가며, 재료 경계에서 일부는 반사되고 일부는 전달된다(기계적
임피던스 `Z = ρc`). 변형이 있으면 모서리도 한 점이 아니라 넓어지는 접촉 영역이 되어 힘의 방향이 결과로 나온다. 그리고 시간 동안
작용하는 물리 과정(반복 충돌·압력·피로·온도·부식·마찰)은 형상 자체를 바꾼다 — 같은 재료라도 살아온 역사가 다르면 다음 충돌 결과가 다르다.

그래서:

- **K3 재해석:** v5의 축 정렬 정사각형은 **변형 물리가 없는 초기 단계의 기준(근사) 거시 형상**이다. 장기 A에서 형상은 근본 속성이
  아니라, 미시 구성과 변형 상태에서 나타나는 거시적 결과다.
- **미시가 진실, 거시는 요약:** 물체는 미시 상태(구성 요소·결합·국소 응력·온도·손상)와 거시 상태(질량·질량 중심·운동량·
  회전량·외형·유효 물성)를 함께 갖되, **거시는 미시에서 유도되는 계산·관측 표현일 뿐 독립된 물리를 갖지 않는다.** 평소에는 거시만
  계산하고 접촉 부위의 미시만 자세히 계산할 수 있지만, 미시 상태는 늘 존재해야 한다 — 충돌 순간에 세부를 **지어내면 안 된다**
  (실행 구조 X4의 "정확한 요약만"과 같은 원칙).
- **정체성:** 변형·마모 수준에서는 같은 구조, 결합 그래프가 둘로 끊어지면 물리적으로 두 구조. "원래 A의 절반"은 기록에서만 안다.
- **순서:** C1 최소 충돌 → 유한 강성·접촉 변형 → 응력 전달 → 재료별 탄성·감쇠 → 항복·파괴 → 그 결과로 동시 충돌·모서리 재검토.
  응력파 속도는 탄성률·밀도를, 재료 경계는 임피던스를, 큰 응력은 항복·파괴를, 반복 응력은 피로를, 변형 열은 열-역학 결합을
  요구한다 — **앞 단계의 물리적 한계를 해결하려다 다음 물리가 강제로 요구되는 방식**으로 A가 자란다. 현상을 만들려고 법칙을 더하는
  것의 반대다. 그리고 이 길은 정확한 유리수 기하(K2)가 곧 부족해진다는 것을 이미 예고한다 — 그때 수 표현을 다시 정한다.
- **재료 성질은 하나의 "단단함"이 아니다:** 경도(표면 저항)·강성(변형 저항)·강도(파손 한계)·인성(파손까지 흡수 에너지)·감쇠(에너지
  손실)는 서로 다르다. 필요할 때 현실 재료값(밀도, 탄성률, 푸아송비, 항복·파괴 강도, 인성, 점탄성)을 출처와 함께 가져온다.
