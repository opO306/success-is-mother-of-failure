## 0. 구현 트랙을 둘로 나눈다 (V0 — 승인)

**정확한 표현 (설계자 수정):** "현실에는 규모가 둘"이 아니다 — 현실에는 원자 → 분자 → 나노·메조 → 연속체까지 중간 규모가 잔뜩 있다.
**지금 A의 구현 트랙을 둘로 나눈다**는 것이다. 이것은 새 방향 전환이 아니라 GEO의 G0(분자 규모 GEO-micro / 사람 규모 A-MACRO,
장기적으로 micro에서 나온 거시 물성이 MACRO 근사와 맞는지 검증)를 이어받은 것이다.

```
A
├─ A-MICRO v6     구성 입자 + 유한한 상호작용       원자·분자·결합·반응 — 발생 트랙(L)의 바닥
├─ A-MACRO v1     연속체 근사                       재료·물체·실험실·신체 — 연구 트랙(B)의 바닥
└─ 규모 다리      MICRO에서 측정한 거시 물성이 MACRO의 물성과 맞는지 검증
```

**이름:** A-MACRO는 v1부터 센다. MICRO의 세대 번호와 같을 물리적 이유가 없다.

**규모 다리는 핵심 계약이다.** 나중에 MICRO에서 한 물질을 아주 많이 모아 눌렀을 때 측정되는 밀도·탄성 반응·응력파 속도·열전달·파괴
거동이 MACRO가 쓰는 유효 물성과 이어져야 한다. **MICRO와 MACRO는 서로 다른 두 세계가 아니라 같은 현실을 다른 해상도에서 기술하는
두 표현이어야 한다.** 이 검증이 없으면 MICRO 지구와 MACRO 지구를 따로 만드는 꼴이다.

## 1. 순서 (V1 — 승인): MICRO 먼저

지금 막힌 곳(모서리, 중심 벗어난 충돌, 회전 없음, 강체 동시 충돌)이 전부 분자 규모 v5에서 나왔다. 사람 크기 연속체부터 만들면 문제를
피해 가는 것이다. 발생 트랙의 바닥도 MICRO다.

**MICRO를 "분자동역학(MD)"으로 확정하지 않는다.** 그것을 구현할 때 MD 계열 적분기가 자연스럽게 나올 수는 있다 — 물리 구조를 먼저
정하고 알고리즘 이름은 나중에 붙인다.

**A-MICRO의 정의 (2026-09-24 설계자 수정 — 1판의 "유한 거리"는 너무 좁았다):**

> A-MICRO = 공간에 존재하는 구성 입자 + **입자 상태와 공간적 관계에 의해 결정되는 상호작용.**
> 상호작용은 유한 범위일 수도, 장거리일 수도 있다. C0~C2-N의 초기 모델은 유한 범위 상호작용을 사용할 수 있지만,
> 그것은 A-MICRO 전체의 불변조건이 아니다.

이유: 1판 정의를 영구로 두면 C2-Q의 쿨롱(거리 제한 없음)과 정면충돌한다(`A_MICRO_V6_PHYSICS_CLOSURE_V1.md` 1.2). 이제 거리 자르기나
장거리 합산은 C2-Q 때 **수치 방법·근사 문제**로 판단하면 되고, 정의를 다시 뜯을 필요가 없다.

## 2. 상태의 세 층 — ① (설계자 수정)

```
물리 상태 (Physical State)          세계가 실제로 기억해야 하는 것      예: 위치, 속도, 질량, 물질 종류, (MACRO) 변형 이력
유도 물리량 (Derived Quantity)      물리 상태에서 계산할 수 있는 것      예: 응력, 현재 밀도, 질량 중심, 각운동량, 구조 묶음
수치 상태 (Numerical State)         계산하려고만 있는 것                예: 격자 값, 캐시, 이웃 목록, affine 보조값, 풀이기 임시값
```

**M0에서 강제로 시험한다:** 수치 상태를 **전부 지우고** 다시 만들어도 같은 물리 계산이 이어져야 하고, 유도량은 물리 상태에서 다시
계산돼야 한다. 이 경계가 없으면 "칸이 계산 도구였는데 어느새 세계 법칙이 됨"이 새 옷을 입고 돌아온다.

**MICRO의 물리 상태 출발점:** 질량, 종류(→ 명세의 상호작용 매개변수), 위치, 속도. 결합·위상을 상태로 둘지는 심화 설계의 핵심 결정이다.

**MACRO 메모 (보류 트랙이지만 적어 둔다):** 앞 초안의 affine 속도 기울기 `C`는 특정 계산 방법(APIC 계열)의 자유도라 **수치 상태**다 —
물리 상태로 확정하지 않는다. 밀도는 둘로 나눈다: **기준 밀도 `ρ₀`**(재료·초기 상태)와 **현재 밀도 `ρ = ρ₀ / det F`**(유도량). 압축·응력파·
질량 보존이 전부 여기에 물린다.

## 3. 거시는 유도량이다 — ②

질량, 질량 중심, 운동량, 각운동량, 관성 모멘트, 경계, 평균 온도 — 전부 물리 상태에서 유도한다. **거시를 지우고 미시에서 다시 만들 수
있어야 한다(M0).** 회전은 기능이 아니라 측정 결과다.

---

## 4. 계산 구조는 세계 상태에 개입하지 않는다 — ③

| 종류 | 예 | 계약 |
|---|---|---|
| **최적화** | 이웃 목록, 공간 해시, 병렬화, 캐시 | 같은 이산화 설정에서 기준 실행기와 **결과 동일**(X2 그대로) |
| **이산화** | 시간 간격, (MACRO) 격자 간격·물질점 밀도 | 세밀하게 할수록 **수렴**(5.2) — 이것이 "계산 구조가 물리가 아니다"의 증거 |

**금지:** 계산 칸이 법칙을 고르는 것, 칸 경계가 벽이 되는 것, 칸 번호가 결과를 정하는 것.

**비물리적 들러붙음 금지 (V4 — 원칙 승인):** 서로 물리적으로 연결되지 않은 물질 영역은 **같은 계산 셀을 쓴다는 이유만으로 운동량을
섞지 않는다.** 몸마다 속도장을 두는 것은 구현 후보일 뿐 영구 설계가 아니다 — 몸(Body) 자체가 미시에서 나타나는 결과이고, 파괴·병합으로
정체성이 바뀌기 때문이다.

## 5. 수치 계약 — V2 (원칙 승인, 수 표현은 미정)

"정확한 유리수 → **결정론적 근사 + 수렴 검증**"은 승인. **정수 고정소수점을 지금 확정하는 것은 보류** — 고정소수점이라고 결정론
문제가 끝나지 않는다: `(a×b)×c`와 `a×(b×c)`는 반올림이 끼면 다르고, 병렬 합산 순서·넘침(overflow)·나눗셈·제곱근이 남는다.
**숫자 형식보다 계약이 먼저다.**

### 5.1 먼저 동결하는 요구사항

1. 같은 초기 상태 + 같은 이산화 → **비트 단위 재현**
2. 연산 순서가 물리를 바꾸지 않도록 **정규 축약(canonical reduction)** 정의 — 합산 순서가 이름표·배열 순서에 의존하면 재명명 불변성이
   비트 수준에서 깨진다
3. **넘침 없음**(검출되면 중단)
4. 정밀도를 높이면 결과가 **수렴**
5. CPU/GPU 차이가 검증 계약 안에 들어와야 함

그 뒤에 후보(고정소수점 / 소프트웨어 부동소수점 / 임의 정밀도 / 구간 산술 / 기타 결정론 수치)를 비교해, 계약을 가장 단순하게 만족하는 것을 고른다.

### 5.2 수렴은 두 종류다

| | 무엇이 수렴해야 하나 |
|---|---|
| **짧은 시간 — 궤적 수렴** | 위치·속도 자체가 가까워지는가 |
| **긴 시간 — 관측량 수렴** | 에너지·압력·분포·반응률·구조 통계가 수렴하는가 |

결정론적 계도 초기의 아주 작은 오차가 오래 지나면 크게 벌어질 수 있다. "입자 하나 위치가 달라졌으니 실패"라는 잘못된 판정을 막는다.
결정론을 포기하는 것이 아니라, 수치 근사가 결정론적 연속계를 얼마나 추적하는지를 정직하게 나누는 것이다.

### 5.3 에너지 균형 잔차

앞 초안의 "수치 소산 장부"를 고친다 — 수치 오차는 에너지를 줄일 수도, **가짜로 만들 수도** 있다.

```
energy_balance_residual = (기대 에너지 균형) − (측정한 이산 에너지 균형)
```

양수·음수 모두 그대로 기록하고, **절대 물리 상태로 되먹이지 않는다** — 감사값일 뿐이다.

## 9. 설계자 원칙 (2026-09-25) — 보존량 기반 축약(coarse-graining)과 다중 해상도

**핵심:** 해상도를 낮추기 위해 **물리 법칙의 세기를 바꾸지 않는다.** 여러 미시 자유도를 하나의 유효 자유도로 묶고, 질량·에너지·운동량·
조성처럼 보존해야 하는 양을 **함께** 옮긴다. "가상 연료 50 mL가 100 mL의 힘을 낸다"(법칙 변경)가 아니라 "가상 요소 하나가 현실 요소
두 개를 대표한다"(같은 세계를 더 적은 계산으로 표현)이다 — 힘만 키우면 같은 질량이 두 배로 가속해 세계 법칙이 바뀐다.

**대표량은 명시한다.** 한 요소가 현실의 얼마를 대표하는지(`represents_mass`, `represents_count`, 에너지, 운동량, 온도, 조성 …)를 상태에
기록한다. 숫자를 몰래 키우는 일이 없게 한다.

**축약은 아무 데서나 되지 않는다.** 크기를 바꾸면 표면적/부피 비, 열 손실 속도, 저항·점성·관성의 상대 비중이 달라진다 — 축약이 같은
물리를 준다는 것은 **검증 대상**이지 가정이 아니다.

**다중 해상도:** MICRO ↔ MACRO 두 단계가 아니라 `MICRO₀(원자 1 = 요소 1) ↔ MICRO₁(원자 100 = 요소 1) ↔ … ↔ MACRO(밀도·온도·압력·조성)`.
규모 다리(0절)가 이 사다리 전체로 넓어진다.

**원칙 (동결 후보):**
1. **축약 모델은 진실이 아니라 대리 표현이다.** 필요하면 언제든 더 세밀한 표현으로 돌아갈 수 있어야 하고, 돌아갔을 때 통계적·물리적
   성질이 맞아야 한다.
2. **해상도 축소는 현상을 제거하지 않는다는 증거가 있는 영역에서만 허용한다.** 축약 오차가 정해진 한계를 넘거나 새로운 미시 자유도가
   필요해지면 즉시 세밀한 해상도로 전환한다.
3. **미지의 창발 현상을 탐색하는 영역**(생명 발생, 화학 반응, 경계면, 자기조직, 이상 현상)에서는 축약을 **기본값으로 쓰지 않는다.**
4. 축약 전후에 질량·운동량·에너지·조성 보존을 검사하고, 같은 구간을 미시 계산과 축약 계산으로 **둘 다** 돌려 오차를 계속 잰다.
5. **금지:** "계산량이 크니까 작은 구조를 삭제하거나 평균낸다." 작은 농도 차·희귀 충돌 하나가 큰 차이를 만드는 계에서 평균은 다른 세계다.

**적응형으로:** 평형에 가깝고 느린 영역은 거칠게, 변화·새 구조·오차가 커지는 영역은 세밀하게. 연구자 B가 이상을 발견하면 "이 해상도로는
원인을 구분할 수 없다"며 그 지역의 세밀화를 **요청**할 수 있다(헌법 제25조의 선언된 탐침 경로로 — B가 A를 직접 바꾸지 않는다).
규모 다리 자체가 연구 대상이 된다: 어느 해상도에서 화학 반응이 보존되고, 어디서 자기조직이 사라지는가.

**구현자 공개 — 이 원칙이 기존 계약과 부딪히는 곳:**
- **결정론·E9:** "오차가 커지면 세밀화"는 **분기**다. 세밀화 여부가 실행 배치나 반올림에 따라 갈리면 세계가 갈라진다 → 세밀화 판정도
  분기 감사(C0 계획 4절)와 E9 대상이어야 한다.
- **계산 구조는 세계 상태에 개입하지 않는다(4절 ③):** 해상도 전환이 세계의 물리 상태를 바꾸면 안 된다. 전환은 "같은 세계의 다른 표현"이어야
  하고, 전환 전후 보존량이 **비트 단위**(FX) 또는 증명된 한계(E5-B식) 안에서 같아야 한다.
- **되돌림(세밀화)의 비결정성:** 축약 상태에서 미시 상태를 복원하면 정보가 부족하다(여러 미시 상태가 같은 축약 상태에 대응). 무엇으로
  채우는가가 **숨은 난수·임의 선택**이 되면 헌법 위반이다 → 복원 규칙도 결정론적이고 선언되어야 한다. **아직 설계 없음.**
- 지금 단계(C0 수치 계약)에서는 구현하지 않는다. 기록만.
