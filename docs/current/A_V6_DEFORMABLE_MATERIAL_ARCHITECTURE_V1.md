# A v6 — 변형 가능한 물질 아키텍처 v1 (설계 초안)

**상태:** 초안 (2026-09-24). **설계자 검토 전 — 코드를 쓰지 않는다. 수치 방법도 아직 고르지 않는다.**
**출발점:** 설계자·sol 제안(2026-09-24). v5의 세 벽(모서리 73%, 가지·순환 경로 제한, 2D 충돌의 중심 벗어남 61/64)이 모두
"회전하지 않는 날카로운 강체 정사각형"을 가리킨다(`A_MICRO_V5_C1_RESULTS.md`). 다음 세대는 정사각형 강체의 확장이 아니라
**변형 가능한 물질**로 새로 잡는다. 형상은 근본 속성이 아니라 물질 상태의 결과다(`A_MICRO_V5_COLLISION_ROTATION_PLAN_V1.md` 8절).
**v5는 그대로 보존한다** — 정확한 유리수 강체 기준 세계로.

이 문서가 닫을 네 질문 (설계자):
① 미시에 실제로 저장하는 최소 상태 ② 거시에서 무엇을 유도하나 ③ 계산용 공간 구조가 세계 상태에 절대 개입하지 않는다는 계약
④ M1의 가장 단순한 탄성체. **그리고 그 앞에 하나 — 규모(0절).**

## 0. 먼저 — 규모가 둘이다 (결정 V0)

GEO 설계 때 G0로 규모를 나눴다: **분자 규모(pm, fs)**의 A-MICRO(발생 트랙 L의 바닥)와 **사람 규모(cm, s)**의 A-MACRO
(연구자 B의 몸과 실험실의 바닥). 이번 제안의 예시 — 돌, 고무, 강철, 밀도·탄성률·푸아송비, 풍화 — 는 **연속체 재료**, 즉
**사람 규모(또는 중간 규모)**의 물리다.

**분자 규모에서는 연속체 탄성이 맞는 물리가 아니다.** 분자는 연속된 재료가 아니라 낱낱의 입자이고, 탄성률·푸아송비 같은 것은
수많은 분자의 **평균으로 나타나는** 성질이다. 그러니 v5의 문제(모서리·요람)를 푸는 **올바른 답은 규모마다 다르다** — 다만 원리는 같다:
"물체를 절대 안 찌그러지는 도형으로 두지 말고, 유한한 강성으로 서로 밀어내는 구성 요소들로 둔다."

| | 분자 규모 (A-MICRO, 발생 트랙 L) | 사람 규모 (A-MACRO, 연구 트랙 B) |
|---|---|---|
| 최소 단위 | 입자(원자·분자 수준) | 물질점(재료의 작은 조각) |
| 상호작용 | **퍼텐셜**(거리에 따라 연속으로 변하는 힘) — 분자동역학(MD). 결합도 퍼텐셜(예: 조화·Morse), 나중에 결합 차수(ReaxFF 계열 축약) | **연속체 역학**(변형 → 응력 → 힘) — MPM/FEM 계열 |
| 모서리 | 없다 — 입자는 날카로운 모서리를 갖지 않고, 힘이 거리에 따라 부드럽게 변한다 | 없다 — 형상은 물질점 분포, 모서리는 변형되며 접촉 영역이 생긴다 |
| 뉴턴 요람 | 유한 강성의 퍼텐셜을 통해 힘이 입자 사이로 전달 | 응력파가 몸 안을 지나감 |
| 회전 | 입자 분포의 결과 | 물질점 분포의 결과 |
| 참고 계보 | Verlet(1967), LAMMPS, ReaDDy, ReaxFF | MPM(물질점법), FEM |

**권고 V0:** 이 문서의 "변형 가능한 물질 = 연속체(MPM 계열)"는 **A-MACRO v6**(사람 규모)로 이름을 바꾼다. 분자 규모(A-MICRO)의
다음 세대는 **입자 + 퍼텐셜(MD 계열)**로 따로 설계한다. 두 규모를 하나의 "v6"로 합치면 G0에서 막은 규모 혼동이 되풀이된다.
두 쪽 모두 "형상은 구성 요소에서 나온다", "미시가 진실, 거시는 요약"이라는 **같은 원리**를 따르고, 같은 수치 계약(4절)을 쓴다.

아래 ①~④는 두 규모 모두에 답하되, M1(가장 단순한 탄성체)은 사람 규모 기준으로 적는다(설계자 제안의 예시가 그쪽이므로).
**어느 쪽을 먼저 만들지가 결정 V1이다.**

## ① 미시에 저장하는 최소 상태

**원칙 (v5 E1과 같다):** 유도할 수 있는 것은 저장하지 않는다. 응력은 변형에서 유도되므로 저장하지 않는다.

### 사람 규모 — 물질점 (M1 기준, 탄성만)

```
MaterialPoint
    mass            고정 (물질점의 질량은 변하지 않는다 — 질량 보존이 자명)
    material        재료 참조 → 명세의 물성(밀도 ρ, 탄성률 E, 푸아송비 ν) — 이름(강철·고무)이 아니라 값
    position        x
    velocity        v
    deformation     F  (2×2 변형 기울기: 처음 모양에서 지금 모양으로 어떻게 늘고 비틀렸는지)
    affine          C  (2×2: 물질점 주변 속도의 기울기 — 회전·전단을 잃지 않기 위해; 11절 참조)
```

**저장하지 않는 것:** 응력 `σ = f(F; E, ν)`(구성 법칙으로 유도), 부피 `V = V₀·det F`(유도), 모양(분포에서 유도).
**나중 단계에서 추가(M4~M5):** 소성 변형 `F_p`, 손상 `d`, 온도/내부 에너지 — 각각 그 단계에서 근거 등급과 함께.

### 분자 규모 — 입자 (MD 계열 후보)

```
Particle
    mass, species(→ 명세의 퍼텐셜 매개변수), position, velocity
Bond (위상, 선택)  — 결합 퍼텐셜을 쓰는 입자 쌍. 결합 에너지는 퍼텐셜에서 유도, 저장하지 않음
```

v5의 `Structure`(결합 그래프의 연결 성분)는 그대로 유효한 개념이다 — 다만 강체가 아니라 **퍼텐셜로 이어진 유연한 입자 집합**이 된다.

## ② 거시에서 유도하는 것 — 거시는 진실이 아니다

```
Body = 한 몸으로 보는 미시 단위들의 집합 (사람 규모: 같은 몸의 물질점들 / 분자 규모: 결합 그래프의 연결 성분)

유도량:  질량 = Σm,  질량 중심,  운동량 = Σ m v,  각운동량 = Σ m (x × v) + (물질점 내부 회전 기여, C에서),
         관성 모멘트,  경계(물질점 분포의 바깥),  평균 온도,  유효 물성(나중에)
```

**계약 M0:** 거시 상태를 **지웠다가 미시에서 완전히 다시 만들 수 있어야 한다.** 거시에만 있는 값이 하나라도 있으면 거시에 숨은
물리가 있는 것이다(테스트로 강제). 회전은 거시에 넣는 기능이 아니라, 각운동량·자세·각속도를 **측정한 결과**다.

**정체성:** 변형·마모 수준에서는 같은 몸. 사람 규모에서 파괴(M4)로 물질점 집합이 공간적으로 둘로 갈라지면 두 몸 — "원래 몸의 절반"은
기록에서만. 분자 규모에서는 결합 그래프가 둘로 끊어지면 두 구조(v5와 같다).

## ③ 계산용 공간 구조는 세계 상태에 개입하지 않는다 — 그러나 v5와 계약이 달라진다

**v5의 계약:** 색인은 순수 최적화 — 색인을 바꿔도 결과가 **비트 단위로 같다**(X2).

**v6에서는 그대로 성립하지 않는다 — 정직하게.** MPM의 배경 격자는 검색 색인이 아니라 **이산화(계산 방법의 일부)**다. 격자 간격을
바꾸면 결과가 수치 오차만큼 달라진다. MD의 시간 간격도 마찬가지다. 그래서 계약을 둘로 나눈다:

| 종류 | 예 | 계약 |
|---|---|---|
| **최적화** (결과를 바꾸면 안 됨) | 이웃 목록, 공간 해시, 병렬화, 캐시 | 같은 이산화 설정에서 **기준 실행기와 결과 동일**(X2 그대로) |
| **이산화** (수치 오차를 만듦) | MPM 격자 간격, 시간 간격, 물질점 밀도 | 설정을 세밀하게 할수록 결과가 **한 값으로 수렴**해야 함 — 이 수렴이 "격자가 물리가 아니다"의 증거 |

**금지는 그대로:** 격자 칸이 "너는 7번 칸이니 이 법칙"처럼 법칙을 고르는 일, 칸 경계가 벽이 되는 일, 칸 번호가 결과를 정하는 일.
MPM 격자는 계산이 끝나면 매 단계 비운다(상태를 격자에 남기지 않는다) — 상태는 전부 물질점에 있다.

**알려진 함정 (정직하게, 사람 규모 MPM):** 기본 MPM에서는 서로 다른 몸의 물질점이 같은 격자 절점을 공유하면 **숫자상으로 들러붙는다**
(단일 속도장). 즉 "두 돌이 닿으면 붙어 버리는" 수치 현상이 생긴다 — 물리가 아니다. 몸마다 속도장을 따로 두는 접촉 알고리즘이
필요하고, 그 접촉 법칙(마찰 유무 등)은 **근거 등급과 함께 따로 선언**해야 한다.

## ④ M1 — 가장 단순한 탄성체

**사람 규모 권고:** 하나의 재료, 2차원, **선형 탄성에 가까우면서 큰 회전에도 틀리지 않는 구성 법칙**(예: 공회전(co-rotated)
선형 탄성 또는 신-후크(neo-Hookean) — 선택은 결정 V3). 순수 선형 탄성(작은 변형 가정)은 물체가 통째로 돌기만 해도 가짜 응력을
만든다 — 회전을 결과로 얻으려는 이 설계와 맞지 않는다.

- 물성: 밀도 ρ, 탄성률 E, 푸아송비 ν — **값으로만**, 재료 이름 없음(설계자). 현실값을 넣으면 그 재료에 가까워진다.
- 소성·손상·감쇠·열 없음(M4 이후).
- **M1 검증 — 교과서 값과 비교할 수 있는 것만:**

| 검증 | 기대값 (현실 물리) |
|---|---|
| 누르면 찌그러지고 놓으면 복원 | 에너지 되돌아옴(수치 소산 범위 안) |
| 응력파 속도 (M2) | 1차원 막대에서 `c = √(E/ρ)` |
| 재료 경계에서 반사·전달 (M3) | 반사 계수 `R = (Z₂ − Z₁)/(Z₂ + Z₁)`, `Z = ρc` |
| 비스듬히 부딪힌 몸의 회전 | 각운동량 보존(수치 오차 범위 안) |
| 해상도 수렴 | 격자·시간 간격을 절반씩 줄이면 결과 차이가 줄어든다 |

## 5. 수치 계약 — 정확 계산에서 "수렴하는 계산"으로 (결정 V2)

v6는 정확한 유리수로 닫히지 않는다(변형체·퍼텐셜 역학 모두). 그래서 **정확성의 정의를 수치해석에 맞게 바꾼다** — 포기가 아니다.

| 항목 | v5 | v6 |
|---|---|---|
| 수 | 정확한 유리수 | **정수 고정소수점 권고** — 부동소수점은 CPU/GPU·순서에 따라 비트가 달라져 결정론·재현성(RULES)을 깬다 |
| 반올림 | 없음 | **선언된 결정론적 반올림** — 물리 법칙이 아니라 수치 방법의 일부. 해상도를 높이면 영향이 사라져야 함 |
| 보존 | 사건마다 정확히 | 운동량: 방법이 보존하도록 설계(가능하면 정확) / 에너지: **수치 소산을 장부의 별도 줄로 기록** — 물리적 행방 없이 조용히 내부 에너지로 넣지 않는다(E3 원칙) |
| 검증 | 비트 동일 | 같은 설정에서는 비트 동일(결정론) + 설정을 세밀하게 하면 수렴 |

**RULES와 부딪힌다:** RULES 1절 "정수 또는 정확한 분수 사용"은 v6의 고정소수점 정수로는 지켜지지만, "정확"은 아니게 된다.
v6에 한해 **"결정론적 근사 + 수렴 검증"**을 허용하는 문구가 필요하다 — 설계자 결정.

**v5는 보존한다:** 정확 유리수 강체 기준 세계로 남고, v6의 단순한 극한(단단한 재료, 정면 충돌)이 v5와 맞는지 비교 기준으로 쓴다.

## 6. 단계 (설계자 제안 M0~M6 — 그대로, 규모 표시만 추가)

| 단계 | 내용 | 검증 | 실패의 뜻 |
|---|---|---|---|
| M0 | 미시/거시 계약 | 거시를 지우고 미시에서 재생성 | 거시에 숨은 물리 |
| M1 | 변형 가능한 단일 재료 | 누르면 찌그러지고 놓으면 복원 | 변형 표현이 틀림 |
| M2 | 국소 응력 전달 | 충격이 유한 시간 뒤 반대편 도달, 속도 `√(E/ρ)` | 힘이 순간이동하거나 수치 모델 오류 |
| M3 | 서로 다른 재료 | 반사·전달이 임피던스대로 | 물성이 결과에 연결 안 됨 |
| M4 | 소성·손상·파괴 | 한계 이하 복원, 넘으면 영구 변형·파손 | 임계 법칙·에너지 회계 오류 |
| M5 | 열·피로·마모·풍화 | 같은 재료도 다른 역사 뒤 다른 상태 — **나이는 원인이 아니다**, 충돌·온도 반복·용해·마찰·장기 하중의 결과 | 이력이 상태에 반영 안 됨 |
| M6 | 적응형 미시/거시 계산 | 자세히·거칠게 계산해도 허용 오차 안에서 같은 결과 | 요약이 물리를 바꿈 |

회전은 별도 기능으로 만들지 않는다 — M1~M3에서 비스듬한 충돌이 몸을 돌리는지 **측정**한다.
