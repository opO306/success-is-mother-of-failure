# GEO v1B 결과 — v5 위에서 구조의 생성·성장

**날짜:** 2026-09-24. **계획:** `A_MICRO_V5_GEO_V1B_PLAN.md`(승인). **실행기:** v5 기준 실행기 — **변경 없음**.
**테스트:** `tests/test_v5_geo_v1b.py` (34개). **조사 원자료:** `runs/v5_benchmarks/growth-20260924-094855.json` (Git 밖).
**모든 세계는 `NON_CANONICAL_TEST_WORLD`** — 현실 이전 후보가 아니다.

## 1. 판정

**v5의 요소-접촉 법칙은 CREATE / GROW / MERGE / 가지 / 순환까지 구조 크기와 이름에 상관없이 일관되게 확장된다.**
기준 실행기 코드를 한 줄도 바꾸지 않았고, 검증 중 실행기 결함은 나오지 않았다.

| 검증 | 결과 |
|---|---|
| 직선 사슬 | 31개 (v2 실측 최장 3). 모든 결합이 면끼리 딱 붙은 상태 유지 |
| 움직이는 구조의 성장 | 됨 (v2에서 막혀 있었음) |
| 가지 | 사슬 **끝** 멤버의 옆면에 붙음 |
| 순환 | 입자가 오목한 자리에 두 면으로 동시에 끼워져 결합 그래프가 닫힘(결합 8 = 멤버 8). "고리" 유형은 엔진에 없음 — 일반 결합일 뿐 |
| MERGE (D1) | 양쪽 멤버 여럿, U > 0, 질량·운동량 다름 → 멤버 합집합, 결합 = 옛 결합 + 새 결합, `U' = U_A + U_B + K_A + K_B − K'` 정확, 독립 감사 통과 |
| 한 순간 여러 결합 | 사슬 양 끝에 동시에 도착한 두 입자 모두 결합 (v2 "한 tick 결합 하나" 결함 해소) |
| 한 입자, 두 면 동시 (7a) | 두 결합 모두, 이름을 바꿔도 동일 (v2 "번호 작은 쪽" 결함 해소) |
| 한 면을 둘이 요구 (7b) | 누구도 고르지 않고 다툼 중단, 모든 참가자 기록, 이름을 바꿔도 동일 |
| 자리 찬 면 | 비결합 접촉(자리 참) 중단 |
| 성장 풍부한 세계 6개 | 무작위 이름 치환 + 모든 배열 섞기, 관측 간격 1/3, 갈릴레이 변환에서 물리 결과 동일, 독립 감사 통과 |
| `world_class` (D2) | 값만 바꾸면 명세 digest는 달라지고 물리 결과는 완전히 동일. 실행기는 이 값을 읽지 않음(AST 검사) |

**결함 주입 6종 전부 검출:** 움직이는 구조 성장 금지 · 한 순간 결합 하나 · 이름 순서로 입자당 한 면만 · MERGE에서 한쪽 내부
에너지만 · 다툼에서 승자 선택 · 실행기가 `world_class`를 읽음.

**v2 결함 두 개 이동 (D3):** `test_known_defects_causal_kernel.py`의 두 테스트를 `test_legacy_causal_semantics.py`로 옮김 —
이름에 `legacy_defect`, 설명에 "여전히 물리적으로 잘못된 동작, v2 재현성 때문에 보존"을 명시. known-defect 파일에는 살아 있는
결함이 없고, 다음에 어디서도 고쳐지지 않은 결함을 찾으면 쓸 자리로 남음. legacy 파일 머리말은 "뒤 형식(v4 또는 v5)에서 고쳐진
결함"으로 일반화.

**결론:** v2의 '길이 3' 구현 천장은 v5에 존재하지 않는다. v5에서는 최소 31개까지 같은 일반 결합 법칙으로 성장했으며, 별도의
구조 크기 상한은 구현되어 있지 않다. **다만 현재의 기하(2절)와 정의되지 않은 충돌이 실제 성장 경로를 제한할 수 있다** — 그래서
"구조 크기에 천장이 없다"로 일반화하지 않는다.

## 2. 새로 측정된 기하학적 결과 — 정사각형 모형의 한계 (설계자가 알아야 할 것)

테스트를 쓰다가 드러났다. 버그가 아니라 **K3(같은 크기 정사각형) + K6(모서리 접촉은 중단)의 조합이 만드는 결과**다.

**(1) 곧은 사슬의 가운데 멤버 옆면에는 같은 크기 입자가 붙을 수 없다.**
- 가운데 멤버 위에 정확히 내려앉으면 → 양옆 멤버와 모서리가 닿는다 → 모서리 중단
- 조금 비켜서 내려앉으면 → 한 면이 두 멤버에 동시에 닿는다 → 다툼 중단
- 수학적으로: 가운데 멤버에만 닿으려면 옆 멤버와의 가로 거리가 둘 다 1 이상이어야 하는데, 그 조건은 "정확히 맞춤"(모서리)일 때만
  성립한다. 가지는 사슬 **끝**(한쪽이 비어 있음)이나 오목한 자리에서만 생긴다.

**(2) 나란히 선 두 쌍은 면끼리 맞대어 고리를 닫을 수 없다.** 정확히 맞추면 대각선 멤버끼리 모서리가 닿고, 어긋나게 하면 한 면이
두 멤버에 닿아 다툼이 된다. 순환은 오목한 자리에 끼워지는 방식으로만 생겼다.

**의미:** v5에서 가지와 순환이 생기는 경로가 좁다. 성장 조사(3절)에서 2D 세계의 가지가 적고 순환이 0인 것도 이것과 맞는다.
모서리 물리가 정의되거나(충돌·회전 설계), 몸의 모양·크기가 달라지면(K3는 v5 한정 승인) 달라질 수 있다. **지금은 한계로 기록만 한다.**

## 3. 성장 조사 (관찰, 합격 기준 아님, 두 계열을 합치지 않음)

**파라미터:** 입자 20개, seed 0~31, 시간 200까지. 생성기 `v5_benchmark_worlds.row_world` / `offset_world`
(`python run_v5_benchmarks.py growth --n 20 --seeds 32`).

### 한 줄 세계 (`row_world`: 질량 1·2·3/2, 간격 1 + 무작위 분수, 속도 −4~4 / 1~5)

| | |
|---|---|
| 끝난 방식 | 32개 모두 완료 (모서리·다툼 불가능, 문턱 0) |
| 세계별 가장 큰 구조 | 5:1, 6:2, 7:1, 8:4, 9:6, 10:2, 11:3, 12:1, 13:1, 14:2, 15:4, 16:1, 18:1, 19:1, **20:2** (20개 전부 하나로) |
| 가지 / 순환 | 0 / 0 (한 줄이라 당연) |

### 반 칸 어긋난 2D 세계 (`offset_world`: 간격 3 격자 + x는 7분의 몇, y는 11분의 몇 어긋남, 질량 1·2, 네 면 결합)

| | |
|---|---|
| 끝난 방식 | 완료 27, 자리 찬 면 중단 4, 모서리 중단 1 |
| 세계별 가장 큰 구조 | 2:4, 3:13, 4:6, 5:7, 7:2 |
| 가지 지점(결합 3개 이상인 멤버) | 합계 8 |
| 순환 | 0 |

**읽는 법:** 한 줄에서는 정의된 물리만으로 20개짜리 구조까지 자란다. 2D에서는 구조가 작고(최대 7), 멈추는 이유가 모서리보다
**자리 찬 면**이 많았다 — 어긋난 시작 위치가 모서리 우연 일치를 줄인 대신, 구조가 커지면서 이미 결합된 면에 다른 몸이 닿는
일이 생긴다(결합하지 않는 충돌 S7의 부재). 측정 B(정수 격자, 73% 모서리 중단)와는 생성 분포가 달라 비교하지 않는다.
