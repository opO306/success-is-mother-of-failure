# A-V4.GEO — 접촉과 구조의 생성·성장 v1 — 설계 초안

**상태:** 초안 → **설계자 검토 반영 (2026-09-24).** G0·G4 승인, G1 재설계, G2·G3 기각(아래 8절). CREATE/GROW 구현 전에
선행 설계 `A_MICRO_SPATIAL_REPRESENTATION_V2.md`(GEO-micro v1A)가 먼저다. **커널을 고치지 않는다.**
**트랙:** A (causal v4, experimental). 선행: A-V4.A/B/C 완료, `STRUCTURE_STATE_V1.md`, `MINIMAL_LOCAL_GEOMETRY_V1.md` 단계 5~7,
`LOCAL_INTERACTION_PRINCIPLES_V1.md` 원칙 4종.
**한 줄:** v4 안에서 구조가 **스스로 생기고 자라게** 한다 — 번호가 결정하지 않고, 한 tick 한 결합 천장 없이,
움직이는 구조도 자라게.

---

## 0. 먼저 — 규모가 둘이다 (결정 G0)

설계자 Q6은 "GEO가 신체가 요구하는 시야·가림·거리·접촉·크기·도달 범위의 물리 기반을 만든다"였다.
**측정해보니 그대로는 성립하지 않는다.**

```
단위를 선언한 유일한 세계 (deterministic_physical_flux_v4.json):
  칸 한 변 = 4 피코미터,  tick 하나 = 16 펨토초      ← 분자 규모
사람 키 1.7 m = 약 4 × 10^11 칸
```

causal 입자는 **분자 규모**의 물질이다. 사람 몸·실험대·광물 조각은 **거시 규모**다. 한 격자에 둘을 같이
두는 것은 불가능하고, 억지로 두면 신체 계약 9.1절(실제 인간 생리값 + 물리 단위)과 바로 충돌한다.

그래서 GEO를 둘로 나눈다.

| | GEO-micro (이 문서) | 신체의 물리 기반 (별도 문서) |
|---|---|---|
| 규모 | 분자 (pm, fs) | 사람 (cm, s) |
| 무엇 | 입자 접촉, 구조 생성·성장·절단 | 고체가 공간 차지, 표면, 가림, 거리, 손이 닿는 범위, 빛 |
| 누구의 기반 | **발생 트랙(L)** — 자기 유지·복제로 가는 화학 | **연구 트랙(B)** — 인간형 신체와 실험실 |
| 기존 자산 | `causal_kernel` v4 | 환경 세계(`environment_*`, 이미 `solids_occupy_space` 있음), 탐침 세계 |

두 규모를 잇는 것은 신체 계약 7절의 "아래로 내려가는 원칙"이다. 거시 세계를 먼저 쓰고, 필요한 현상을
미시에서 설명할 수 있게 되면 그때 한 층씩 내려간다. **처음부터 한 격자로 합치지 않는다.**

**권고:** 이 문서는 GEO-micro만 다룬다. 신체의 물리 기반은 "A-MACRO"라는 별도 항목으로 나중에 설계한다
(Q6 순서상 신체 구현 전).

## 1. 지금 v4가 실제로 하는 것 — 측정

| 항목 | 지금 v4 | 원칙 위반 |
|---|---|---|
| 결합 형성 | v1과 같다: **같은 칸**에 모인 자유 입자 둘, 운동량 합 0일 때만 `PhysicalBond` | v3/v4의 기하(결합 = 이웃 칸 사이 관계)와 **어긋남** |
| 결합 수 | 입자당 1개 (`port_limits`가 v2 외에는 1) | 사슬 불가 |
| 성장 | **없음** (`_grow_chains`는 v2 전용) | — |
| `PortBond` | 손으로 만든 초기 상태에만 있음 | — |
| 절단 | `PhysicalBond`만 (`_break_existing`) | `PortBond`는 절대 안 끊김 |
| 한 칸 3개 이상 | 건너뜀 (`len(group) != 2`) | 원칙 1 |

즉 v4에서 구조는 **태어날 수 없다.** A-V4.B는 구조가 있다면 그 운동을 어떻게 다룰지만 만들었다.

---

## 2. 목표 — 이 설계가 여는 것

1. v4에서 결합은 **이웃한 두 칸 사이의 `PortBond`** 로만 생긴다. 같은 칸 `PhysicalBond`는 v4에서 만들지 않는다.
2. **CREATE** — 자유 입자 둘이 접촉해 구조가 된다. 운동량 합이 0일 필요가 없다(구조가 움직이며 태어날 수 있다).
3. **GROW** — 구조가 자유 입자를 붙인다. **움직이는 구조도.**
4. 서로 양립하는 결합은 **한 tick에 함께** 생긴다(원칙 2). 한 tick 한 결합 천장 없음.
5. 두 후보가 같은 포트를 다투면 **번호로 고르지 않는다** — 둘 다 결합하지 않고 기록한다(원칙 3).
6. 사슬 길이에 선언되지 않은 상한이 없다(원칙 4). 실측 목표: 자연 실행에서 길이 **4 이상**이 나온다.

**이번에 열지 않는 것:** 구조끼리 결합(MERGE), 3개 이상 참가 관계(hyperedge), 회전.

## 3. 접촉이란 무엇인가 — 가장 큰 결정 (G1)

이웃 칸 결합에는 **어긋남(parity) 문제**가 있다. 동쪽으로 가는 입자가 x에, 서쪽으로 가는 입자가 x+1에 있으면
다음 tick에 둘은 **서로를 통과해 자리를 바꾼다.** 같은 칸에서 만나지도, 이웃으로 멈추지도 않는다.
지금 v1식 결합은 "거리가 짝수여서 같은 칸에서 만나는" 쌍만 잡는다 — 우연한 거리의 짝홀이 화학을 정한다.

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **G1-a 끝 인접** | 이동 후 이웃한 두 몸, 마주 보는 빈 포트, 서로 **다가오는 중**이면 접촉 | 기존 이동 규칙 그대로. 작다 | 서로 통과(자리 바꿈)는 여전히 접촉이 아님 — 짝홀 문제가 방향만 바뀐다 |
| **G1-b 경로 접촉** | 이동 **경로**를 본다: 이번 tick 이동에서 두 몸이 같은 칸에 들어가거나 **서로 통과**하면 접촉. 접촉한 쌍은 이동 전 위치 기준으로 이웃이 되어 결합 판정 | 짝홀 문제 제거. 통과를 접촉으로 본다(고체는 서로 통과 못 함) | 결합되면 "통과하지 못하고 붙음" — 이동을 되돌리는 게 아니라 **이동 전 위치에서 결합**해야 해서 이동과 결합 순서가 얽힌다 |
| **G1-c 배타 점유** | 몸이 칸을 **배타적으로** 차지한다. 차지된 칸으로 들어가려 하면 막힘 = 접촉 | 가장 물리적. 한 칸 3개 문제(원칙 1)가 **구조적으로 사라짐**. 거시 쪽 `solids_occupy_space`와 같은 원리 | 기존 Q3(한 칸에 자유 입자 여럿 허용) 번복. 막혔을 때 운동량 교환 규칙이 새로 필요. 두 몸이 같은 빈 칸으로 동시에 들어가려 하면 또 경합 |

**권고: G1-b.** 짝홀 문제를 없애는 최소 변경이다. G1-c는 가장 옳아 보이지만 이동 규칙 전체를 다시 쓰고
새 경합(동시 진입)을 만든다 — GEO-micro v2로 미룬다.

## 4. 에너지·운동량 회계 (G2)

A-V4.B의 표현을 그대로 쓴다: 자유 입자 운동량 = 질량 × 에너지 × 방향, 구조 = `StructureState(momentum 벡터, motion_energy)`,
검사식 `|px| + |py| = motion_energy × 질량`.

**CREATE / GROW 공통:**

```
P' = 참가자 운동량의 벡터 합          (보존)
M' = 질량 합
e' = (|P'x| + |P'y|) / M'             정수로 나눠떨어질 때만
흡수 = (참가자 운동 에너지 합) - e'    → 새 PortBond.stored_energy    (항상 ≥ 0, 아래 증명)
```

흡수가 음이 아님: `|P'| ≤ Σ eᵢMᵢ` 이므로 `e' ≤ Σ eᵢMᵢ / ΣMᵢ ≤ max eᵢ ≤ Σ eᵢ`.

**결정해야 할 두 경우:**

| 경우 | 선택지 | 권고 |
|---|---|---|
| 나눠떨어지지 않음 | 결합 안 함 (v2와 같은 정수 물리) | **결합 안 함.** 이미 있는 규칙과 같다 |
| 합이 **대각** (예: 동쪽 입자 + 북쪽 입자) | (i) 결합하고 구조는 `UnresolvedMotion` (ii) 결합 안 함 | **(ii) 결합 안 함 + 기록.** 대각 구조가 생기는 순간 DISSOLVE·이동이 정의되지 않는다(`STRUCTURE_STATE_V1` 3.5, 4.2). 지금 `tests/test_diagonal_momentum_is_unreachable.py`가 이 전제를 지킨다 |

(ii)는 "안 일어남"이라는 선택이지만, 결과가 정의되지 않은 사건을 억지로 일으키지 않는다는 원칙 3의 적용이다.
그 횟수를 세서 대각 운동을 설계할 필요가 실제로 있는지 측정한다.

## 5. 경합 — 번호 대신 기록 (G3)

한 tick에 가능한 결합 후보를 **모두 먼저 모은다.** 그다음:

- 서로 다른 포트·다른 입자를 쓰는 후보들 → **전부 함께 적용** (원칙 2)
- 같은 포트(또는 같은 도착 입자)를 두 후보 이상이 원함 → **그 후보들 모두 적용하지 않고** `ContestedContact`로 기록 (원칙 3)
- 한 구조가 한 tick에 여러 입자를 붙이면 운동량·에너지는 **한 번에** 합산한다 (순서 없음)

"아무도 안 붙음"은 번호보다 낫지만 **그 자체도 선택**이다. `contested_census`로 빈도를 재서, 자주 일어나면
부족한 물리 자유도(도착 위상 등)를 찾으라는 신호로 본다(`MINIMAL_LOCAL_GEOMETRY_V1` 6.1절).

## 6. 절단 (G4)

`PortBond`는 지금 절대 끊기지 않는다. 절단 없는 화학은 한 방향으로만 굳는다 — 촉매·순환이 불가능하다.

| 질문 | 선택지 |
|---|---|
| 열은 어느 칸에서 재나 | (a) 두 칸 합 (b) 두 칸 중 작은 쪽 (c) 각 칸이 절반씩 지불 |
| 끊긴 뒤 운동량 | 두 조각에 어떻게 나누나 — 정수로 안 떨어질 수 있음 (`STRUCTURE_STATE_V1` 3.5 SPLIT 미해결) |

**권고:** 이번 v1에서는 절단을 **열지 않는다** — CREATE/GROW부터 검증한다. 대신 한계로 명시하고 GEO v2의 첫 항목으로 둔다.
(원칙을 어기는 천장이 아니라 "아직 선언 안 된 법칙"이다. 단, 절단 없이 나온 결과로 촉매·순환을 주장하지 않는다.)

| 기준 | 검사 |

### 8.1 설계자 결정 (2026-09-24)

| | 결정 |
|---|---|
| G0 | **승인.** GEO-micro(분자) / A-MACRO(사람 규모) 분리. 장기적으로 micro에서 나온 거시 물성이 MACRO 근사와 맞는지 검증 |
| G1 | **G1-b 그대로 구현하지 않음.** 접촉은 찾지만 접촉 후 위치를 정수 격자로 표현 못 함(가운데 칸에서 만남, tick 중간 통과). 접촉 사건과 tick 안 접촉 기하를 먼저 설계 |
| G2 | **기각.** "대각이면 결합 안 함"은 구현 한계를 화학 법칙으로 만든다. → `UNRESOLVED_DIAGONAL_MOTION` 기록 + 실행 중단. "대각 도달 불가능" 전제는 영구 불변식 지위를 잃음 |
| G3 | **기각.** "둘 다 안 붙음"도 물리가 정하지 않은 제3의 결과. → `ContestedContact` 기록 + 실행 중단 + 부족한 자유도 분석. 양립하는 결합의 동시 적용은 유지 |
| G4 | **승인.** 절단은 v2 첫 항목. 그동안 촉매·순환·동적 평형 주장 금지 |

구현자가 인정한 것: G2·G3의 원래 권고는 "구현이 못 하는 것 → 일어나지 않는다"로, 번호 선택과 같은 종류의 임의 선택이었다.

**새 순서:** GEO-micro v1A (공간 표현 v2 — 접촉 사건, tick 안 접촉, 대각 운동) → v1B (CREATE, GROW, 동시 결합, 경합 탐지) → v2 (BREAK/SPLIT).
사슬 길이 4는 성공 지표일 뿐 목적이 아니다 — 물리가 모호한데 나온 4는 가치가 없다.

**원래 구현 순서 (v1B용으로 보존):** 접촉 후보 수집(G1) → CREATE → GROW(움직이는 구조 포함) → 동시 적용·경합(G3) →
감사기 확장 → 새 v4 세계 파일·census 재정의 → 결함 주입. 각 단계마다 재명명 불변성 테스트를 다시 통과한다.
