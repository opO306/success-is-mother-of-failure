## 주요 변화

1. **확률 세계 중단·동결:** 전역에서 tick당 일반 사건 하나만 처리하던 구조가 밝혀졌다. 768 세계·시간에서 독립 후손은 0이었다. 옛 분할·융합 기록을 생명 증거로 쓰지 않는다.
2. **독립 검증:** 기록의 일관성, 보존량, 명세 준수, 물리·수치 감사가 분리됐다. `audit/`는 `engine`을 import하지 않고, 수치·물리 감사는 해당 기준 계산기도 import하지 않는다. 결함 주입 시험을 유지한다.
3. **B 연구 절차:** 익명 관측, 가설 경쟁, 실험 선택, 실행 전 예측 봉인, 반박·한계 기록, 최종 답 봉인, 원시 동작으로 도구 조합까지 구현됐다. 사람이 쓴 절차이므로 학습형 신경망이나 자유로운 과학적 발견 전체로 일반화하지 않는다.
4. **v5 구조 성장:** 정확한 분수·연속 시간으로 생성·성장·병합을 검증했다. v2의 ID 의존과 길이 3 천장은 제거됐고 31개 사슬을 검증했다. 정사각형 기하와 미정의 충돌은 여전히 성장·운동을 제한한다.
5. **v6 방향:** 증상별 기능을 붙이기보다 역학 → 응집 → 반응 가능한 물질 → 비평형 수송·반응 환경의 연결망을 검증하는 방향으로 바뀌었다. Ar은 첫 현실 검증 원자종이며, 모든 세계를 Ar로 고정한다는 뜻이 아니다.

## 구상 일치성과 남은 한계

- **확인한 구현·시험에서 일치:** 계산 장치·처리 배치가 물리 결과를 정하지 않도록 비교한다. 이름이 승자를 고르던 결함은 새 형식에서 해소하고, 옛 형식은 잘못된 동작임을 밝히며 동결한다. B의 예측과 검증 조회가 A 결과를 바꾸지 않는 시험을 유지한다.
- **근사:** 연속 현실을 시간 간격·유한 수 표현·고전적인 Ar 모델로 계산한다. 모델 불확도, 반올림, 시간 이산화의 오차를 구분한다. CPU/GPU 비트 일치가 현실 물리 정확도 전체를 증명하지는 않는다.
- **미구현·미완:** C1-B1 전체 동결, 속박 궤도 domain/error proof, native J evaluator와 비트 동등성, 다입자 응집·3체·화학·촉매·주형·생명 발생. 검증된 산란 범위를 이들 주장으로 확대하지 않는다.
- **장기 후보:** Physics IR/DSL, 다중 해상도, 계산·메모리·재생 기록 아키텍처는 요구사항·제안이다. 구현·동결 상태로 기억하지 않는다.
- **인프라:** 네이티브 실행은 600초 하드 타임아웃. 컴파일 빌드 타임아웃은 별도 미완 과제다. 원격 노드의 현재 가동·비용은 이번에 확인하지 않았다.
