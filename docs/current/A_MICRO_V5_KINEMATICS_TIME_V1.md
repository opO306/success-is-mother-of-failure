# causal v5 운동학·시간 의미론 v1 — 선행 설계 초안

**상태:** 초안 (2026-09-24). **승인 전 — 커널을 고치지 않는다.**
**위치:** `A_MICRO_SPATIAL_REPRESENTATION_V2.md`(2판) 검토에서 설계자가 S3·S5·S6 세부를 보류하고, 에너지(S4)보다
먼저 "물체가 어디에 있고 어떻게 움직였는가"를 하나의 역학으로 닫으라고 결정. 이 문서는 그 8개 질문에 답한다.

---

## 0. 결론 먼저

> **시간은 연속이고, tick은 관측 간격일 뿐이다. 세계는 사건(접촉) 단위로 정확히 계산한다.**
> **이를 정수·유리수로 정확히 하려면 몸은 원이 아니라 축에 나란한 정사각형이어야 한다.**

두 번째 줄이 이 문서의 핵심 발견이다. 아래에서 왜 그런지 보인다.

---

## 1. 발견 — 원은 정확한 계산을 불가능하게 만든다

2판 S2는 원(반지름)이었다. 연속 시간에서 두 원이 닿는 시각은

```
|d₀ + t·Δ|² = (rA + rB)²      ← t에 대한 2차방정식, 해 = 제곱근
```

비스듬히 다가오면 접촉 시각이 **무리수**다. 그 시각의 위치도 무리수다. 정수로도 분수로도 정확히 적을 수 없다.
2판이 "접촉 시각은 쓰지 않는다"로 피해 간 이유가 이것이고, 그 결과 설계자가 짚은 **tick 경계 문제**
(tick 중간에 닿았는데 tick 끝에는 멀어져서 결합 안 됨)가 생겼다. 다시 말해 **원을 고른 순간 tick 경계 문제는
피할 수 없었다.**

**축에 나란한 정사각형**이면:

```
x축에서 닿는 시각   t = (간격 x) / (상대 속도 x)     ← 1차방정식, 해 = 유리수
y축에서 닿는 시각   t = (간격 y) / (상대 속도 y)     ← 유리수
```

모든 접촉 시각, 그 시각의 위치, 접촉 방향(항상 동·서·남·북 면)이 **정확한 유리수**다. 그리고 면이 네 개뿐이라
**이름 있는 포트 N/E/S/W와 정확히 맞는다** — 포트는 곧 면이다. 결합하지 않고 부딪히는 경우(S7)도 접촉 방향이
축이므로 나중에 열 때 1차원 충돌이 되어 정확히 풀린다(원이면 비스듬한 반발이 무리수 — 2판의 S7 문제의 뿌리).

**대가:** 세계에 **선호 방향**(x·y축)이 생긴다. 회전하는 세계에서는 부자연스럽다. v1은 회전이 없고(선언된 한계),
포트가 이미 절대 방향이므로 새로 생기는 비대칭은 없다. 회전을 열 때 다시 결정한다.

**모서리 접촉:** 두 정사각형이 정확히 모서리끼리 닿으면(x·y 시각이 같음) 접촉 면이 정해지지 않는다 →
`CornerContact` 기록 + 실행 중단(정의되지 않은 물리, 설계자 원칙). 정수 세계에서는 자주 일어날 수 있으므로 census로 센다.

## 2. 여덟 질문에 대한 답

### Q1. 실제 위치의 정확한 수학적 표현
**위치는 유리수 쌍 (x, y)다.** 분자·분모 정수로 저장한다. 부동소수점 금지. 속도도 유리수 쌍(= 운동량 / 질량).

### Q2. remainder는 물리 상태인가
2판의 "정수 위치 + 나머지"는 **물리 위치를 유리수로 쓰는 한 가지 표기법**이었다 — 즉 나머지는 물리 상태의 일부였다.
그러나 그 표기는 아래 Q3에서 닫히지 않으므로 **버리고 유리수를 그대로 쓴다.** 남는 계산 상태는 없다.
계산 색인이 쓰는 "몇 번 구역" 같은 정수(`floor(x)`)는 **물리가 아니다**(버려도, 바꿔도 결과 불변).

### Q3. 질량이 바뀔 때 위치 표현의 변환
`정수 + r/M` 표기에서 질량이 M → M'로 바뀌면 `r/M = r'/M'`인 정수 r'가 대개 없다 — **닫히지 않는다.**
유리수 위치에서는 **질량이 바뀌어도 위치 값은 그대로다.** 결합은 위치를 바꾸지 않는다(S6 원칙). 새 구조의 속도만
`(P₁ + P₂) / (M₁ + M₂)`로 정해지고, 이것도 유리수로 정확하다. 변환할 것이 없다.

### Q4. tick은 근본 시간인가, 계산 간격인가
**계산 간격도 아니고 관측 간격이다.** 세계는 연속 시간이다. 이유:

| | tick이 근본 | 연속 시간 (권고) |
|---|---|---|
| 서로 통과 | 중간 위치가 없으므로 "통과"도 없다 → 홀짝 문제가 **법칙으로** 남음 | 경로가 있으므로 반드시 닿음 |
| tick 경계 | 결합 규칙이 tick 경계에 묶임 (설계자 지적) | 결합은 **접촉 순간**에. 경계 없음 |
| 현실 대응 | 이 규모의 현실은 연속 — 거시 근사와 비교(신체 계약 7절)할 때 tick 길이 의존이 드러남 | tick 길이와 무관 |
| 계산 | 쉬움 | 사건 대기열 필요, 분모 증가(5절) |

tick은 "B·기록기가 세계를 보는 간격"이다. tick 길이를 바꾸면 **본 장면의 수만 바뀌고 세계의 궤적은 같다.**

### Q5. 한 tick 안의 실제 궤적
두 사건 사이에서 모든 구조는 **등속 직선 운동**(v1에는 힘이 없다). 궤적은 사건 시각들로 나뉜 직선 조각들이다.
관측 시각의 위치는 마지막 사건 이후 `위치 + 속도 × 경과 시간` — 유리수로 정확.

### Q6. 여러 접촉 사건의 순서
- **시각이 다르면 시간 순서대로.** 이것은 임의 순서가 아니라 물리적 순서다.
- **정확히 같은 시각, 서로 다른 몸들** → 한꺼번에 적용(원칙 2).
- **정확히 같은 시각, 같은 면·같은 몸을 두 사건이 다툼** → `ContestedContact` 기록 + 실행 중단(설계자 결정).
- 사건 하나가 다음 사건의 예정 시각을 바꾸므로(구조가 합쳐지면 속도가 바뀜), 사건을 처리할 때마다 **관련된 몸의
  다음 접촉 시각만 다시 계산**한다. 계산 순서가 결과를 바꾸지 않는다는 것은 5절 테스트로 강제한다.

### Q7. 접촉 후 결합했을 때 위치·운동
접촉 순간 두 면은 **정확히 맞닿아 있다**(유리수 시각의 유리수 위치). 결합 규칙이 맞으면 그 자리에서 결합한다.
**아무도 옮기지 않는다**(S6 원칙이 이제 세부 규칙까지 닫힌다). 새 구조: 운동량 = 합(정확), 속도 = 합/질량 합(유리수).
잃은 운동 에너지가 결합에 저장되는 회계는 S4에서 정한다.

결합 규칙이 안 맞으면 **비결합 접촉** → `NON_BINDING_COLLISION_UNRESOLVED` 기록 + 실행 중단(설계자 결정, S7).

### Q8. 무엇이 바뀌어도 같아야 하고, 무엇은 달라도 되는가

| 바꿔도 **세계의 궤적이 같아야** 하는 것 | 검사 |
|---|---|
| 관측 간격(tick 길이) | 같은 초기 상태, tick 1 / 1/2 / 1/3 → 공통 시각의 상태가 같음 |
| 계산 색인 (grid / hash / tree / 동적 묶음, 크기) | 색인 여러 개로 같은 결과 |
| 이름표, 입자·결합·규칙의 배열 순서 | 재명명 불변 (A-V4.C 확장) |
| 같은 시각 사건들의 처리 순서 | 순서를 섞어도 같은 결과 |
| 정확한 요약(강체 한 몸 계산) 사용 여부 | 켜고 끔 비교 (S8) |

| **달라져도 되는** 것 | |
|---|---|
| 세계 법칙, 재료 값, 초기 상태 | 다른 세계다 |
| B가 본 장면의 수 | 관측 간격이 다르면 본 것도 다르다 — 세계는 같다 |

## 3. 이 설계가 닫는 것

| 이전 문제 | 여기서 |
|---|---|
| 홀짝 (서로 통과해 못 만남) | 연속 경로 — 반드시 닿음 |
| tick 경계가 화학을 정함 | 결합은 접촉 순간에 |
| 접촉 후 위치 표현 불가 | 접촉 순간 위치가 정확한 유리수 |
| 대각 운동 | 속도가 유리수 벡터 — 그냥 움직임 |
| 누적기와 연속 궤적의 불일치 | 누적기를 버리고 유리수 위치 |
| 질량 변화 시 위치 변환 | 위치 값은 그대로, 변환 불필요 |

---

## 4. 이 설계가 여는 새 문제 — 정직하게

1. **분모가 커질 수 있다.** 접촉 시각 = 간격 / 상대 속도, 속도 = 운동량 / 질량. 사건이 쌓이면 분모가 곱해져 커질 수 있다.
   **반올림으로 막지 않는다**(그러면 이번 논의 전체가 무너진다). 먼저 실제 세계에서 분모 크기를 측정한다. 계속 커지면
   그것은 "이 세계의 정확한 역학은 정보가 계속 늘어난다"는 발견이고, 그때 설계자가 판단한다.
2. **모서리 접촉**이 얼마나 자주 멈추게 할지 모른다 → census.
3. **비결합 접촉이 멈추게 한다**(S7 결정). 입자가 많은 세계는 거의 즉시 멈출 수 있다. 이것이 측정되면
   다음 작업은 충돌 역학(축 방향 1차원 충돌 — 정사각형이라 정확히 풀림)이다.
4. **GPU:** 사건 기반 유리수 계산은 GPU에 맞지 않는다. 입자 계산은 지금도 CPU다. 환경 field(격자, GPU)와의 결합은
   2판 10절대로 v1 범위 밖.
5. **사건 대기열 구현**은 지금 커널(단계형 tick)과 구조가 완전히 다르다 — 새 커널 파일이 된다.

공통 분모 문제(E1/E2/E3) 대부분이 사라진다 — 에너지도 유리수로 두면 된다.
