# A의 법칙은 현실 물리에 근거한다 — B는 현실을 모른다 (설계 원칙 v1)

**상태:** 설계자 승인 (2026-09-24). RULES 2절 반영.
**출발점:** sol의 제안(LAMMPS·ReaDDy·ReaxFF·patchy particle 비교, "A = 현실 지구의 근사")을 설계자가 **절반만** 채택.

---

## 1. 설계자 결정 — 한 문단

> A(세계)의 **물리 법칙**은 현실 지구의 실제 물리를 기준으로 한다. 문명·지능·생명 같은 **결과**를 기준으로 하는 것이
> 아니다(헌법 제1조 그대로). B(연구자)는 **현실이 어떤지 모른다** — 현실과 비교하는 연구를 하지도 않고 할 수도 없다.
> B는 오직 A를 통해 실험하고 배운다. 어떤 실험을 할지는 B의 자유다. A의 법칙이 현실에 근거하므로, **B가 A에서 찾은
> 결과는 현실에서도 도움이 될 가능성이 있다.** 그것이 이 구조의 가치다.

## 2. 채택한 것과 거부한 것

| sol의 제안 | 결정 |
|---|---|
| A의 법칙을 임의로 지어내지 않고 현실 물리(근본 / 유효 / 실험 / 근사)에 근거시킨다, 출처를 남긴다 | **채택** |
| A 내부의 법칙은 A 안에서 절대적, B의 이해는 언제나 잠정적 (A는 닫혀 있고 B는 열려 있다) | **채택** (기존 블라인드 구조와 같다) |
| B가 현실 관측 데이터와 A를 비교해 "현실-A 불일치"를 연구한다 | **거부** — B는 현실을 모른다 |
| B가 현실 데이터·현실 이론을 참조한다 | **거부** |
| B가 A 수정을 제안한다 | 기존대로 금지 (헌법 제25조: A를 직접 바꾸지 않는다) |

## 3. 세 층 — 누가 무엇을 아나

```
현실 지구 ──(설계자가 물리를 가져옴, 출처 기록)──> A의 법칙
                                                    │
                                                    │  B는 A만 본다. 현실은 모른다.
                                                    ▼
                                             B의 발견 (A 안에서 재현 가능)
                                                    │
                  (세계 밖에서, 사람이) ─────────────┘
                  "이것이 현실에서도 쓸모 있나?" 를 판단·시험
```

- **현실 → A:** 설계자가 한다. 법칙마다 출처와 근사 수준을 남긴다.
- **A → B:** 헌법 제25·26조 그대로. B는 A의 법칙도, 현실도 모른 채 관측·실험한다.
- **B → 현실:** B가 하지 않는다. B의 발견을 현실에 가져가 볼지는 세계 밖의 사람이 판단한다.
  B가 이 일을 알면 안 된다 — 알면 B의 탐색이 "현실에 쓸모 있을 것" 쪽으로 기울고, 그것은 B에게 목표를 주는 것이다.

## 4. 법칙의 출처 표기

A에 법칙(또는 재료 값)을 넣을 때 설계 문서에 다음을 적는다.

| 항목 | 뜻 |
|---|---|
| 근거 등급 | **근본**(확립된 기본 물리, 예: 운동량 보존) / **유효**(특정 규모에서 검증된 법칙) / **실험**(측정값으로 보정된 관계) / **근사**(계산 못 하는 미세 현상의 효과 모델) |
| 출처 | 이론·논문·측정값 |
| 적용 범위 | 길이·시간·에너지·온도 규모 |
| 알려진 한계 | 이 근사가 틀리는 조건 |

**금지:** 현실에 근거가 없는 법칙을 "현상이 나오게 하려고" 넣는 것. 원하는 현상(분열 등)이 나오지 않으면 그 현상을 만드는
규칙을 추가하는 것이 아니라, 현실 물리 중 무엇이 빠졌는지를 찾는다. (RULES "법칙은 최소 근본 수준으로"와 같은 방향.)

**현실에서도 아직 모르는 부분:** 지어내지 않는다. 필요 없으면 넣지 않고, 필요하면 "미해결 영역"으로 명시한다.

## 5. 지금 A의 위치 — 정직하게

| | 근거 등급 | 비고 |
|---|---|---|
| v5 운동량 보존, 운동 에너지 `½mv²`, 비탄성 결합의 에너지 흡수 `½μ|Δv|²` | 근본 | 뉴턴 역학 그대로 |
| v5 연속 시간, 등속 직선 운동(힘 없음) | 근본(힘이 없는 경우) | 힘·퍼텐셜은 아직 없음 |
| v5 정사각형 몸, 면 = 결합 자리 | **근사, 근거 약함** | 정확 계산을 위한 선택(K3). 현실 원자·분자의 모양이 아님 — 설계자가 v5 한정으로만 승인 |
| v5 결합 규칙(재료 종류·면 쌍·문턱) | **근거 없음(추상)** | 실제 원소·결합 에너지가 아님 |
| 환경 세계 열·물·용질 이동 | 유효(확산 형태) | 계수는 추상값 |

**따라서 지금 A에서 B가 찾는 결과가 현실에 도움이 될 가능성은 아직 낮다.** 현실로 옮길 가치는 A의 법칙이 현실에 얼마나
근거하느냐에 비례한다. 이 원칙은 앞으로 A에 법칙을 더할 때의 기준이고, 이미 만든 추상 부분을 당장 갈아엎자는 뜻이 아니다.

## 6. sol의 기술 제안은 어디로 가나

입자 표현 통일, patch(위치·방향·결합 수를 가진 물리적 결합 부위), 충돌 그래프 동시 처리, 이웃 목록(계산 색인), 에너지 기반
결합·절단 — 이것들은 **현실 근거를 높이는 방향**이라 이 원칙과 맞는다. v5가 이미 일부(구조 = 결합 그래프, 충돌 그래프 동시 병합)를
갖고 있다. 나머지는 GEO v1B 뒤 A의 다음 설계(GEO v2 이후)에서 이 문서의 출처 표기와 함께 다룬다.
