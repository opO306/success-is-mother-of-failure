# 공통 국소 충돌 동역학 v1

**상태:** 기존 가중치 사건계와 분리된 단계 C 새 실험 계통  
**목적:** 성장·복제·분리를 이름 붙인 사건 공식 없이 동일한 국소 결합 법칙에서 구조 변화를 발생시킴

## 1. 세계의 구성

- 내부 물질 기호 `0..3`
- 물질 단위마다 동일한 포트 4개
- 포트 하나는 결합 하나만 가질 수 있음
- 모든 결합은 같은 `PortBond` 자료형
- 전역 열에너지와 이산 미세 시간

골격, 측면 결합, 주형, 유전자와 복제본이라는 내부 종류는 없다. 그러한 형태가 생기면 관찰자가 결합 그래프를
보고 나중에 이름 붙인다.

## 2. 한 미세 시간

잘 섞인 v1 용액에서 서로 다른 두 단위의 모든 포트 쌍은 동일한 만남 가능성을 가진다. 외부 사건원이 그중
하나를 균등 선택한다. 이미 성공 가능한 쌍만 후보로 거르지 않으므로 무반응과 막힌 충돌도 실제 시간을 쓴다.

선택된 포트 쌍에는 하나의 공통 법칙만 적용한다.

- 두 포트가 이미 서로 결합했고 열에너지가 결합 세기 이상이면 결합이 끊어진다.
- 결합을 끊을 에너지가 부족하면 유지된다.
- 포트가 다른 결합에 점유되어 있으면 변화가 없다.
- 두 물질의 대칭 친화도가 양수이면 같은 세기의 결합이 생긴다.
- 친화도가 양수가 아니면 변화가 없다.

## 3. 에너지

```text
total_energy = thermal_energy - 모든 결합 세기의 합
```

결합이 생기면 같은 세기만큼 열에너지가 증가하고, 끊어지면 같은 양이 열에서 빠진다. 생성과 파괴는 동일한
결합 세기를 사용하며 전체 에너지를 보존한다.

## 4. 확률의 위치

세계의 결합 법칙에는 사건별 가중치가 없다. 확률은 어떤 두 포트가 이번에 만나는지 정하는 외부 스케줄에만
존재한다. seed 기반 의사난수는 재현 가능한 실험 스케줄이며, 세계 법칙과 분리되어 다른 사건원으로 교체할 수
있다.

## 5. 기존 계통과의 관계

`engine.sequence.substrate`의 가중치 사건계 v0는 삭제하거나 결과를 섞지 않는다. 새 구현은
`engine.sequence.local_dynamics`라는 별도 계통이며, 동일한 질문을 다른 바닥 법칙으로 실험하기 위한 것이다.

## 6. 현재 근사

- 실제 위치와 이동이 없는 완전 혼합 용액
- 단위마다 포트 4개를 사람이 고정
- 한 포트당 결합 하나
- 기존 두 축 물질 친화도 공식을 재사용
- 열에너지가 공간 없이 전역으로 공유됨
- 호환되는 빈 포트 충돌은 항상 결합함
- 활성화 장벽, 방향, 거리, 질량과 운동량 없음

따라서 이것은 현실 물리의 완성이 아니라 고수준 성공 공식을 제거한 첫 바닥 조각이다.
