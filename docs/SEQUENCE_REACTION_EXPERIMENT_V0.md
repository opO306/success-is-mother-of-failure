# 자기 해석형 서열 최소 반응망 실험기 v0

**상태:** 단계 C 관찰 실행기 명세  
**목적:** 짧은 서열 세계를 여러 사건 동안 실행하고 시간·반복·근접 인과를 세계 밖에서 관찰

## 1. 질문

이 실험기는 다음을 정답으로 요구하지 않고 관찰한다.

- 접힘이나 결합 상태가 여러 사건 동안 유지되는가
- 이전 사건이 나중 사건의 가능한 후보를 바꾸는가
- 같은 물리 구성이 다시 나타나는가
- 성장·분리·절단 사건이 어떤 참여 서열을 통해 이어지는가
- 한 구조가 다른 사건의 기본 가중치와 문맥 배율에 어떤 흔적을 남기는가

이를 기억, 학습, 사고 또는 생명이라고 자동 판정하지 않는다.

## 2. 실행과 관찰의 분리

```text
초기 SequenceState
        ↓
세계 실행기: 후보 생성 → 확률 표본 → 사건 → 다음 상태
        ↓ 값과 불변 사건 사본
외부 실험 기록: 전체 프레임 · 해시 · 인과 근접성 · 사건 수
```

세계 실행기는 기록기, 사건 통계와 인간 번역 결과를 입력으로 받지 않는다.

## 3. 한 프레임에 기록할 것

- 실행 직전 후보 수와 총 가중치
- 실제 사용한 확률 표본
- 발생한 세계 사건
- 사건 뒤 전체 상태
- 시간 포함 상태 해시
- 시간을 제외한 물리 구성 해시

시간 포함 해시는 완전 재생을 확인한다. 구성 해시는 같은 배치가 다른 시간에 다시 나타났는지 외부에서 찾는 데
사용한다. 다음 서열 식별자와 물질·접촉 상태는 구성에 포함하므로, 단순히 모양이 비슷한 다른 계보를 같은
상태로 오인하지 않는다.

## 4. 종료 조건

- `quiescent`: 가능한 사건이 하나도 없음
- `event_limit`: 지정된 사건 수에 도달함

생존, 복잡성, 특정 구조의 출현은 종료 조건이 아니다. 사건 제한은 컴퓨터 실행 경계이며 세계 안의 죽음이나
시간 끝이 아니다.

## 5. 근접 인과망

외부 분석기는 각 사건에 참여한 서열 식별자를 읽는다. 어떤 식별자가 직전에 참여한 사건을 현재 사건의
근접 부모로 연결한다.

```text
서열 2 결합 ─┐
              ├→ 서열 2와 3의 골격 결합
서열 3 결합 ─┘
```

이 연결은 “직전 참여 사건”을 보여주는 관찰자 추론이다. 세계의 모든 실제 원인을 완전히 증명하는 인과 법칙으로
취급하지 않는다. 열에너지와 공간 환경처럼 공유 상태를 통한 간접 원인은 후속 버전에서 별도 연결해야 한다.

## 6. 4차원 시간축

작은 검증 실험에서는 초기 상태와 매 사건 뒤 전체 상태를 불변 프레임으로 보존한다. 관찰자는 어느 프레임이든
열어 서열·접촉·에너지와 다음 후보가 달라진 이유를 확인할 수 있다.

장기 실행에서 전체 상태 복사를 계속하면 메모리가 커지므로 이후에는 체크포인트와 변경 사건을 조합한다. 저장
방식이 바뀌어도 임의 시점의 동일 상태를 복원할 수 있어야 한다.

## 7. 외부 요약

허용되는 요약:

- 사건 종류별 발생 횟수
- 후보 수와 총 가중치의 시간 변화
- 동일 구성 해시의 재등장
- 사건 사이 참여 서열 연결
- 기본 가중치와 구조 문맥 배율

금지되는 사용:

- 사건 수를 적합도 점수로 번식에 되먹임
- 반복 상태를 기억이라고 확정
- 복잡한 인과망을 지능이라고 자동 판정
- 관찰 결과에 따라 실행 도중 물리 상수 변경

## 8. 통과 조건

- 같은 초기 상태와 seed가 같은 모든 프레임을 만든다.
- 기록한 확률 표본만으로 전체 실행을 재생할 수 있다.
- 기록을 생성해도 세계 결과와 난수 소비량이 달라지지 않는다.
- 사건이 없는 세계는 구조하지 않고 `quiescent`로 끝난다.
- 사건 제한 종료와 세계 내부 정지를 구분한다.
- 근접 인과망과 사건 통계가 세계 상태로 역류하지 않는다.
