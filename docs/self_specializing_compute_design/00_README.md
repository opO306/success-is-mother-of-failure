# 자기 특화 계산 시스템 설계 문서

## 0. 문서 목적

이 문서 묶음은 다음 아이디어를 하나의 시스템 설계로 정리한 것이다.

> 복잡하고 반복적으로 실행되는 계산을 관찰하고, 계산을 작은 단위로 분해한 뒤, 각 부분에 대해 더 짧거나 더 빠른 동등 계산을 자동으로 탐색한다.  
> 후보는 반드시 독립적인 검증 단계를 통과해야 하며, 검증된 계산만 실제 실행 경로에 채택한다.  
> 장기적으로는 CPU/GPU 코드 생성뿐 아니라 FPGA 같은 재구성 가능한 하드웨어까지 확장할 수 있다.

핵심은 **정답을 근사해서 맞히는 AI**가 아니라, **계산 방법 자체를 탐색하고 검증하는 시스템**이라는 점이다.

---

## 1. 가장 짧은 정의

이 시스템은 다음 반복 루프를 가진다.

```text
프로그램 실행
    ↓
계산 패턴 관찰
    ↓
계산 그래프 분해
    ↓
더 좋은 동등 계산 후보 탐색
    ↓
정확성 검증
    ↓
비용 비교
    ↓
검증된 최적 계산 채택
    ↓
다음 실행에서 재사용
```

---

## 2. 핵심 원칙

1. **탐색기와 검증기를 분리한다.**
   - 탐색기는 틀려도 된다.
   - 검증기는 틀리면 안 된다.

2. **"짧은 공식"과 "빠른 실행"을 구분한다.**
   - 연산 수를 줄이는 것
   - 병렬화하는 것
   - 메모리 이동을 줄이는 것
   - 특수 하드웨어에 배치하는 것
   은 서로 다른 최적화다.

3. **전체 식을 한 번에 다루지 않는다.**
   - 계산 그래프로 분해한다.
   - 각 블록을 독립적으로 최적화한다.
   - 필요하면 다시 합쳐 상위 단계에서 또 최적화한다.

4. **동등성의 정의를 먼저 고정한다.**
   - 실수 수학에서 같은가?
   - IEEE-754 결과가 같은가?
   - 비트 단위로 완전히 같은가?
   - 허용 오차 내에서 같은가?
   기준이 다르면 최적화 결과도 달라진다.

5. **검증되지 않은 최적화는 실제 실행 경로에 넣지 않는다.**

## 4. 이 프로젝트를 무엇이라고 부를 것인가

임시 명칭 후보:

- **Self-Specializing Compute System**
- **Verified Adaptive Compute**
- **Verified Compute Distillation**
- **Adaptive Verified Optimizer**
- **자기 특화 계산 시스템**

## 5. 가장 중요한 한 문장

> 이 시스템의 목표는 "AI가 답을 대신 계산하는 것"이 아니라, "정확성이 검증된 더 좋은 계산 방법을 자동으로 발견하여 실행 구조에 반영하는 것"이다.
