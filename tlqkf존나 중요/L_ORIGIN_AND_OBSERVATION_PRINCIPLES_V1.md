# L 최상위 원칙 — 기원과 관측 v1

**상태:** 설계자 방향 확정 문안(2026-10-01). 저장소 반영 전. 헌법 조항과의 충돌(7절)은 설계자 판정 필요.
**적용:** L 계통 전체. L 구현이 시작되기 **전에** 고정하는 문서다.
**관계:** 헌법 제1·2·4·9·14·21조, RULES 2절(고수준 명령 금지), A 세 층 분리(세계 / 검증 / 관측).

---

## 핵심 한 줄

> **L은 생명을 만들지 않는다.** 현실적으로 허용된 초기 화학 조건에서 A를 실행하고, 자기조직화·자기유지·복제·유전·진화·신호처리·신경계 등이 자연적으로 발생하는지 **관측**한다. 그 어떤 현상도 발생하지 않는 결과 역시 **유효한 결과**다.

---

## 1. L은 생명 생성기가 아니다

```
A = 세계를 움직임 (현실 물리 + 현실 화학)
L = 그 세계에서 생명 관련 현상을 관측·분류하는 연구선
```

- L 전용 물리 법칙·화학 법칙을 A에 추가하지 않는다.
- L은 A의 **관측 층**에서 동작한다. L의 판단은 A의 상태·법칙·실행을 바꾸지 않는다.

## 2. 출발점은 생명체가 아니라 현실적으로 가능한 화학 환경이다

**초기조건으로 줄 수 있는 것 (현실 근거와 출처 필요):**
물, 현실적으로 가능한 분자(예: CO₂, N₂, H₂, CH₄ 등), 광물과 광물 표면, 온도·압력, 빛(UV 포함), pH, 농도 구배, 온도 구배, 습윤-건조 주기, 열수공 같은 환경 구조.

**넣지 않는 것:**
복제 기능, 유전 기능, 막 성장 명령, 대사 목적, 신호 시스템, 기억 장치, 학습 장치, 신경망, 그리고 **이런 결과가 나오도록 고른 특수 분자나 구조**(예: 미리 만든 자기복제자, 미리 만든 막 소포).

판단 기준: "그 물질·구조가 **그 환경에 현실적으로 있었을 근거**가 있는가"이지, "생명이 나오는 데 도움이 되는가"가 아니다.

## 3. 신호도 기본 객체로 넣지 않는다

- 세계에는 `Signal`, `Message`, `Sensor`, `Memory` 같은 객체가 없다.
- 있는 것은 분자, 결합, 반응, 에너지, 확산, 전하, 막, 농도차, 구조뿐이다.
- 어떤 물질 상태 변화가 다른 상태 변화에 영향을 주고, 그 연결이 생존·복제에 영향을 주면, 관측자가 **사후에** "신호", "감지", "기억"이라고 **분류**한다.
- 기억도 신경망일 필요가 없다. 분자 농도, 촉매 상태, 막 조성, 복제되는 서열 같은 물리적 흔적이 기억 역할을 할 수 있다. 이것 역시 관측 분류다.

## 4. 자기복제·유전·진화·정보처리·신경계는 목표가 아니다

| 결과 | 처리 |
|---|---|
| 생김 | 기록 |
| 안 생김 | 기록 (**실패가 아님**) |
| 생겼다가 사라짐 | 기록 |
| 예상과 다른 이상한 구조가 생김 | 기록 |

- L의 성공 조건을 "생명이 반드시 생긴다"로 잡지 않는다.
- 아래 계층은 **관측 분류용 이름표**이며 구현 순서가 아니고, 역사적 정답으로 동결하지 않는다(복제·대사·구획 중 무엇이 먼저였는지는 현실 연구에서도 미해결이다).

```
화학 반응 → 자기촉매 반응망 → 구획/원시 막 → 자기유지 + 에너지 흐름
→ 복제 + 변이 + 유전 → 원시 protocell 경쟁/진화 → 반응-반응 조절
→ 환경 감지 비슷한 현상 → 유전자 조절망 → … → 흥분성 세포 → 신경세포 → 신경망
```

## 5. 생명을 나오게 만들려고 법칙을 조정하지 않는다

| 상황 | 허용 여부 |
|---|---|
| 생명이 안 나옴 → 물리/화학 매개변수 조작 | **금지** |
| 생명이 안 나옴 → 현실적으로 가능한 다른 초기 환경으로 **독립** 실행 | 허용 (5.1 조건) |
| 너무 느림 → "여기서 protocell 생성" 같은 결과 삽입 | **금지** |
| 너무 느림 → 검증된 상위 유효 모델로 계산 방법 압축 | 허용 (6절 조건) |

### 5.1 환경 고르기로 결과를 만드는 것 방지 (구현자 추가)

환경을 여러 개 돌리는 것 자체가 "생명이 나올 때까지 환경을 바꿔 보는" 우회로가 될 수 있다. 그래서:

1. 실행할 초기 환경 목록과 각 환경의 현실 근거를 **실행 전에 봉인**한다(RULES 3절의 예측 봉인과 같은 방식).
2. 봉인한 목록의 **모든** 실행 결과를 보고한다. 아무것도 안 나온 실행도 포함한다.
3. 결과를 본 뒤 새 환경을 추가하려면, 추가 이유와 "이전 결과를 봤다"는 사실을 기록하고 설계자 판정을 받는다.
4. 여러 환경 중 "생명 비슷한 것이 나온 환경"만 골라 보고하지 않는다.

## 6. 계산 방법은 압축해도 되지만 결과를 압축하면 안 된다

```
미시 물리 → (검증) → 상위 유효 화학 모델 → (검증) → 반응·확산·막 모델 → 더 긴 시간 규모
```

- 헌법 제2조와 A 실행 구조 원칙(X1〜X5)을 그대로 따른다.
- 유효 모델은 **아래 계층이나 현실 화학 자료에서 유도·검증**된 것이어야 한다.
- **유효 모델을 고르는 기준이 "생명이 잘 나오는가"여서는 안 된다.** 어떤 반응을 반응망에 넣고 뺄지는 현실 화학 근거로 정하고 기록한다(반응망의 목록 선택 자체가 결과를 정할 수 있기 때문이다).
- 유효 모델의 적용 범위를 벗어나면 fail-closed로 멈추거나 아래 계층으로 내려간다. 조용히 외삽하지 않는다.

## 7. 관측 라벨이 결과를 만들면 안 된다

- 관측 층의 라벨(자기유지 후보, 구획화 후보, 복제 후보, 유전 후보, 진화 후보, 정보처리 후보 등)은 A의 행동을 바꾸지 않는다(세계 → 관측, 단방향).
- 라벨의 **판정 기준은 결과를 보기 전에 정해 둔다.** 결과를 본 뒤 기준을 바꾸면 그 사실과 이유를 기록한다.
- 기존 라벨에 안 맞는 현상을 억지로 끼워 넣지 않는다. "분류 불가"도 유효한 라벨이다.

## 8. 신경망은 아주 먼 미래의 가능한 결과일 뿐이다

- 뉴런, 신경망, 학습 시스템, 인공지능 구조를 미리 구현하지 않는다.
- 화학 조절 → 정보 유지 → 세포 간 신호 → 흥분성 구조 → … 가 실제로 이어질 수도, 아닐 수도 있다.

## 9. 알려진 비용과 한계 (먼저 공개)

- **시간 규모:** 자연 발생 확률이 낮다면, 현실적인 계산량 안에서 아무것도 안 나올 수 있다. 이것은 유효한 결과이며, 이를 이유로 5절을 어기지 않는다.
- **A의 현재 수준:** A에는 아직 화학이 없다(현재 C1-B1 = 두 Ar 원자 산란). 결합·반응·용매·막이 있는 A는 먼 뒤의 일이다. 이 문서는 그때까지 L의 방향이 바뀌지 않게 **지금** 고정하는 것이다.
- **초기조건 경계:** "어디까지를 현실적 초기 화학 조건으로 줄 수 있는가"는 L의 가장 중요한 미결 설계 문제다. 너무 많이 주면(막, 복제자, 대사 경로) 결과를 넣은 것이고, 너무 적게 주면(원소와 열만) 계산량이 감당 불가일 수 있다. 환경별 판단은 5.1 봉인 절차로 한다.

## 10. 기존 문서와의 충돌 (설계자 판정 필요)

| 기존 문서 | 충돌 내용 | 제안 |
|---|---|---|
| 헌법 **제5조** (유전자형과 표현형 분리: "유전체는 … 발생 규칙을 전달한다") | 유전체의 존재를 전제한다. 새 원칙에서 유전체는 넣는 것이 아니라 **나타날 수 있는 결과**다 | "유전 체계가 **나타난다면** …"으로 조건문화 |
| 헌법 **제6조** (구조와 언어의 진화) | 내부 언어·재작성 규칙의 존재를 전제 | 같은 방식으로 조건문화 |
| 헌법 **제8조** (교배와 계보) | 교배 메커니즘을 설계 대상으로 읽힐 수 있음 | "나타난 계보를 추적한다"로 관측 조항화 |
| 헌법 **제18조** ("내부 유전체는 선형 DNA형 기호 서열로 표현할 수 있다") | **설계된 유전체 표현**을 허용한다. 새 원칙 2·4절과 직접 충돌 | L에는 적용하지 않음을 명시하거나 조항 개정 |
| 헌법 **제22조** ("단순 상태와 복제부터 … 확장") | **복제부터 시작**하는 단계적 설계를 말한다. 새 원칙의 "복제는 목표가 아닌 결과"와 충돌 | "A의 물리·화학 계층을 단계적으로 확장하고, 생명 관련 현상은 관측한다"로 개정 |
| `EVOLUTION_V2_PLAN.md`, `EVOLVABLE_LANGUAGE_PLAN.md` (2026-09-17) | 설계된 유전·발생 언어, 뇌 구조 진화 | **L의 근거 문서가 아님**을 표시(역사/레거시). 삭제하지 않음 |

헌법은 "의미를 바꾸는 수정은 설계자에게 설명한 뒤 결정한다"고 정한다. 위 개정은 이 문서만으로 자동 적용되지 않는다.
